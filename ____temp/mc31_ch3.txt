## 第三章：月基策略操作规则


### 3.1 操作规则

**进场条件：**
- 只做 WXCD ∈ {金, 银}，排除屎尿唏嘘
- **金升（CD>0+ZC>0+ZB>0）** 才正式进场
- 银升（CD≤0+ZD>0+ZC>0+ZB>0）只跟踪，等转金升再进场（50.1%假信号，不提前介入）
- 进场前检查 **月基命分（V1）**，命分<10分的股票天然不参与月基

**退出条件：**
- **硬退出：** WXZB从>0转≤0 → **立即卖出**（当周P(≥3%)=7.6%，几乎必亏）
- **软退出：** 消极区双重确认(ZA下降+本周涨<0) → 不等WXZB转负，提前减仓
- **最终退出：** WXZC<0 → 月基策略最终退出
- **多被(金)** → WXZB转负即卖，不等
- **多被(银)/多被(唏)/NA(空看)/NA(空长)** → 月基不参与，不持仓

```
月基持仓中，每周检查判定类别：

多长(积极) → 继续持有，下周P(≥3%)=61.5%
多长(不定) → 可持有，关注ZA趋势方向
多长(消极) → 准备减仓：ZA下降→关注, 跌吞/本周涨<0→准备, 双重确认→立即减仓
多被(金)   → WXZB从>0转≤0 → 立即卖出（当周P≥3%=7.6%）
多被(银)   → 等待带动信号转多长，否则不参与
多被(唏)   → 月基不参与，趋势极弱
NA(空看)   → 月基不参与，有反弹可能但非月基逻辑
NA(空长)   → 月基不参与，三空全
```



**多长持续性数据：**
- 多长平均段长 **7.1 周**，期间下周冲高概率 **93.9%**（稳定，15周无衰减）
- 说明：多长区一旦进入，通常可持续7周以上，期间几乎每周都能冲高，无需频繁操作
### 3.2 持仓检查：WXZA>0延续性分析

月基策略中，当前WXZA>0（站稳A线）时，下周能否延续？关键因素：

| 因素 | 最优条件 | 延续率 |
|:----|:---------|:------:|
| **波型** | **龙猪** | **87.7%** |
| **盈提示** | **盈高** | **94.1%** |
| **柱排** | **升排** | **89.1%** |
| **ZA区间** | ZA3~5 | 84.0% |
| **最佳组合** | **龙猪+升排+ZA1~5** | **92.8%** |

**龙猪波型的WXZA>0延续率最高（87.7%），远优于震正（71.3%）。**
**盈高是延续性的最强单维度指标（94.1%），有盈高时下周几乎必定继续站稳A线。**
**组合策略建议：** 月基选股优先筛选龙猪波型+升排+ZA1~5，WXZA>0延续率达92.8%。

### 3.3 软退出：消极区操作细则

| 信号 | 操作 | 说明 |
|:----|:------|:------|
| ZA下降 | 关注减仓 | 连续2周下降立即升级 |
| 跌吞 | 准备减仓 | 72.1%概率5周内转负 |
| 本周涨<0 | 准备减仓 | 下周继续恶化立即行动 |
| 震正波型 | 警惕 | 龙猪转震正时趋势不稳 |
| 双重确认(ZA下降+本周涨<0) | **立即减仓** | 不等WXZB转负 |

### 3.4 硬退出：WXZB退出信号验证

基于谕组全量7,463只的ZB周列数据，验证了月基策略的退出预警信号。

**WXZB从>0转≤0是最强退出信号**

| WXZB状态 | 下周P(≥3%) | 真均幅 | 操作 |
|:---------|:----------:|:------:|:----|
| WXZB>0（正常持有） | 63.5% | 6.45% | ✅ 继续持有 |
| WXZB≤0（已下破） | 38.5% | 3.19% | ⚠️ 明显走弱 |
| **从>0转≤0（刚转负）** | **16.7%** | **1.31%** | 🚨 **立即卖出** |
| 转负当周 | **7.6%** | **0.34%** | 🔴 几乎不涨 |
| 转负后下周 | 27.7% | 2.95% | 观望 |
| 转负后下下周 | 31.5% | 3.09% | 仍在恢复 |

**五周内10%低点（信号②）：** 仅0.6%触发，预警价值低。WXZB≤0本身已足够作为退出信号。

**月基退出规则：**
```
月基持有中，每周检查WXZB：
  WXZB从>0转≤0 → 立即退出（当周P(≥3%)=7.6%，继续持有几乎必亏）
  WXZB仍>0 → 继续持有（下周P(≥3%)=63.5%）
```

**结论：** WXZB从>0转≤0时，当周P(≥3%)=7.6%，真均幅仅0.34%。**月基持仓中WXZB转负即卖，不犹豫。**

### 3.5 最终退出：退出阶段

- WXZC<0 = 月基策略的最终退出条件
- 消极区预警通常比WXZC<0提前2~5周触发
- 预警系统的作用是**提前退出，不等WXZC<0**
