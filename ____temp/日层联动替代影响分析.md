# 日层联动被日冲策略替代 — 分析与替换方案

> **任务记录：** `位谕of日层联动`保留但重新定义，未来用于"周级别看涨但日级别下跌"的捡漏场景。
> **当前动作：** 原有日层联动定义（E/V等级）已被日冲策略替代，以下为替代影响分析和替换操作方案。

---

## 一、日层联动原有定义的三要素

| 要素 | 来源 | 用途 |
|:----|:-----|:-----|
| **位1：联动首字** | 周层三鳄第2字(金/银/嘘/唏/屎/尿) | 四区划判定 |
| **位2：E/V等级** | 20级均线位置编码 | 等级串 → 周层猪操作 |
| **位3：后缀(.被/.警/.盈)** | DXAB护型 + 盈提示 | 辅助提示 |

---

## 二、替代方案：用日冲策略重建

### 2.1 联动首字 → DXEF

```
旧: 联动首字 = Left$(联动值, 1)     ← 从日层联动取
新: 联动首字 = DXEF第一字            ← 从日冲策略取(已有)
```

**影响：** 完全等效，无损失。DXEF第一字就是金/银/嘘/唏/屎/尿。

### 2.2 E/V等级 → 日冲策分

E/V等级在周层猪操作中被用作**等级串**，附加在仓位后面，如`长多基仓:E0上`。

```
旧: 等级串 = "E0上" / "v0忑" / "E4上" 等
新: 等级串 = 日冲策分(如82.4) 或 日冲策略分类(如"主升")
```

**影响：**
- 等级串原本是文字描述（E0上），给人看有用，给机器用没用
- 日冲策分是0~100的数值，可直接用于排序、筛选、回测
- **等级串丢失的具体信息：** E0~E9的20级精细位置 → 但已证明这个精细度是虚假的（同一E等级内→ZE>0从40%到100%）

**结论：** 用日冲策分代替等级串，信息不丢失，精确度反而提升。

### 2.3 后缀(.被/.警/.盈) → DXAB + 盈提示

```
旧: .被 = 丙(被动持有)  .警 = 丁/戊(警告)
新: DXAB = 丙/丁/戊(可直接判断)
```

**影响：** 无损失，DXAB列直接提供甲乙丙丁戊己六档，比三档更细。

### 2.4 四区划判定 → 日冲策略分类

四区划是周层猪操作的核心，判定逻辑如下：

**旧逻辑（依赖联动首字）：**
```
IF WXZC>0 AND DXZE>0 THEN
  IF 联动首字=金/银 AND 护型首字=甲/乙/己 → 长多
  ELSE → _可被仓
ELSE
  IF 联动首字=屎/尿 AND 护型首字=丙/丁/戊 → _勿长空
  ELSE → _勿可看
```

**新逻辑（用日冲策略重构）：**
```
IF 日冲策略 = "主升" THEN → 长多
ELSEIF 日冲策略 = "渡强" OR "渡弱" THEN → _可被仓
ELSEIF 日冲策略 = "空降" THEN → _勿长空
```

**差异分析：**

| 旧条件 | 新条件 | 差异 |
|:-------|:-------|:-----|
| 联动首字=金/银 | 日冲策略=主升(金/银+上/忐) | ❗ 旧条件更宽（金/银任何DXCD都算长多），新条件更严（金/银+上/忐忑算主升） |
| 护型首字=甲/乙/己 | 日冲策略不检查护型 | ❗ 旧条件要求WXAB=甲乙己，新条件不检查 |
| WXZC>0且DXZE>0 | 日冲策略不检查 | ❗ 旧条件有周门槛，新条件没有 |

**⚠️ 关键差异：** 旧四区划的"长多"比新日冲策略的"主升"范围更宽。旧长多涵盖所有金/银+甲乙己，即使DXCD=下/忠/忑。新主升只涵盖金/银+上/忐。这意味着：

- 旧长多 → 金/银+下/忠/忑 + 甲乙己 → 仍算可操作
- 新主升 → 金/银+下/忠/忑 → 不算主升，归为渡弱

**但这是正确的改进！** 旧逻辑把金/银+下/忠/忑也算作"长多"，但实际数据中金/银+下/忠/忑的→ZE+ZC+ZA只有10~30%，根本不应该重仓。日冲策略的评分更符合实际。

## 三、周层猪操作重构方案

### 3.1 新逻辑

```
等级串 → 日冲策分（数值）
联动首字 → DXEF
护型首字 → 不变（独立变量）

四区划：
  IF DXEF="金" OR "银" THEN
    IF DXCD="上" OR "忐" THEN → "长多"  (日冲分类=主升)
    ELSE → "_可被仓"
  ELSEIF DXEF="唏" THEN
    IF DXCD="上" OR "忐" THEN → "_可被仓"  (日冲分类=渡强)
    ELSE → "_可被仓"  (日冲分类=渡弱)
  ELSE → "_勿长空"  (日冲分类=空降)

仓位细分：
  IF 日冲策分 ≥ 30 THEN → "基仓"
  ELSEIF 日冲策分 ≥ 10 THEN → "浮仓"
  ELSEIF →ZE>0 ≥ 70 THEN → "减仓"
  ELSE → "清仓"
```

### 3.2 输出示例对比

| 旧输出 | 新输出 | 差异 |
|:-------|:-------|:-----|
| `长多基仓:E0上` | `长多基仓:82.4` | 数值比文字更精确 |
| `长多浮仓:E1上` | `长多浮仓:29.8` | 29.8%是实际概率 |
| `长多清仓:e7忑` | `长多清仓:10.8` | 10.8%是实际概率 |
| `_勿长空:v0忑` | `_勿长空:0.1` | 0.1%是实际概率 |

## 附录：位谕of周层猪操作重叠分析

### A.1 周层猪操作的定义

#### 四区划 ↔ 月基策略 ↔ 日冲策略分类

| 周层猪操作 | 月基策略 | 日冲策略 | 重叠度 |
|:----------|:--------|:--------|:------|
| **长多** | 多长(积极/消极/不定) | **主升** | ⚠️ 高 |
| **_可被仓** | 多被(金/银/唏) | 渡强/渡弱 | ⚠️ 高 |
| **_勿长空** | NA(空长) | **空降** | ⚠️ 高 |
| **_勿可看** | NA(空看) | 渡弱 | ⚠️ 高 |

**结论：四区划的信息已被月基策略和日冲策略双重覆盖，无独立信息。**

#### 仓位细分 ↔ 仓日类 + 仓位比

| 周层猪操作 | 仓日类 | 仓位比 | 重叠度 |
|:----------|:------|:------|:------|
| 基仓 | 上甲/上乙（站上DJA+甲乙） | 1倍 | ⚠️ 高 |
| 浮仓 | 上丙/上己（站上DJA但非甲乙） | 0.5倍 | ⚠️ 高 |
