# DSHA>3 梯度分布规律

## 核心发现：DXAB=强是必要条件

### DSHA>3 ≥ 50%（12个分支）— 最强冲高

| 条件 | 占比 | 说明 |
|:----|:----:|:------|
| **DXCD=强(上忐忠)** | **100%** | 必须的 |
| **DXAB=强(上忐忠)** | **100%** | 必须的 |
| DXCD=DXAB同向 | 100% | 完全一致 |
| 战场分布 | 龙5/虎4/武3 | 各战场都有 |

**结论：** 要50%以上概率冲高3%，必须 DXCD=强 AND DXAB=强，两者同向。

### DSHA>3 40~50%（26个分支）— 中等偏强

| 条件 | 占比 | 说明 |
|:----|:----:|:------|
| **DXAB=强(上忐忠)** | **96%** | 几乎必须 |
| DXCD=强 | 35% | 可以弱 |
| 战场分布 | 龙8/雀5/虎3/武10 | 分散 |

**结论：** DXAB=强是必要条件，DXCD可以弱。说明只要AB护段在强势方向，即使CD护段走弱，仍有40%+概率冲高。

### DSHA>3 30~40%（32个分支）— 中等

| 条件 | 占比 | 说明 |
|:----|:----:|:------|
| **DXAB=强(上忐忠)** | **100%** | 绝对必须 |
| DXCD=强 | 44% | 一半一半 |
| 战场分布 | 分散 | 无明显规律 |

**结论：** DXAB=强是唯一必要条件。只要DXAB=强，不管DXCD如何，都有30%+概率冲高3%。

---

## 规律总结

```
DSHA>3 ≥ 50%:  DXCD=强 + DXAB=强  (缺一不可) → 12个分支
DSHA>3 ≥ 40%:  DXAB=强 (DXCD任意)         → 38个分支
DSHA>3 ≥ 30%:  DXAB=强 (DXCD任意)         → 70个分支
```

**DXAB=强是冲高概率高的核心条件。** 只要DXAB护段在{上,忐,忠}，就有至少30%概率冲高3%以上。

## 小样本分布规律

小样本16个分支没有统一的"同向/异向"规律，但可以归纳为**三类**：

### 第一类：银战场小样本（6个）
银/下/中、银/忠/忐、银/忠/忠、银/忠/忑、银/忐/忠、银/忐/忑
- 银战场本身样本就少（约为金的1/3）
- 集中在DXCD=忠/下/忐等过渡位置
- 这些是"银战场中的弱状态"，本身出现频率低

### 第二类：尿战场小样本（5个）
尿/中/上、尿/中/中、尿/下/上、尿/下/中、尿/忐/忠
- 尿战场样本最少（约为金的1/10）
- 尿/中/上等是"屎尿中的强状态"，罕见
- 可以理解为：武(尿)本身样本少，武强更少

### 第三类：唏嘘战场小样本（5个）
唏/忐/忠、唏/忠/忠、嘘/中/上、嘘/中/中、嘘/下/中
- 唏嘘是过渡区，中间状态本身就少
- 嘘/中/上等是"虎中的中间状态"

**总结：小样本的本质是"矛盾组合"或"稀有组合"，不是"同向/异向"能概括的。** 银(龙)+弱CD+弱AB = 龙中的弱态，尿(武)+强CD+强AB = 武中的强态，都是小样本。
