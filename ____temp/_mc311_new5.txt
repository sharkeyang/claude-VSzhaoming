3. **周层大局的方向字段可忽略**——WXCD方向/WXAB方向完全由护型决定，无增量信息

**一句话：周策略P1是"精细尺子"（无冗余、区分度高），周层大局是"阶段罗盘"（波型主类判断主升/震荡/落）。两者互补，周策略P1做精细选股，周层大局做阶段判断。**

#### 5.5.2 信息对比

**周层大局** = WXCD方向 + WXCD护型 + WXAB护型 + WXAB方向 + 地型 + 主类 + 层界

**周仓类 + 周波型** = WXCD方向 + WXAB护型 + 地型 + 主类 + 层界

**差异：周层大局多了 WXCD护型 + WXAB方向，周仓类+周波型没有。**

但这两个字段都是**冗余**的（§4.12.3已验证）：
- **WXCD护型**（金/银/唏/嘘/尿/屎）由 **WXCD方向**（升/降/待）决定（金/银=升，唏/嘘=待，尿/屎=降）
- **WXAB方向**（上/中/下/忐/忠/忑）由 **WXAB护型**（甲/乙/己/丙/丁/戊）决定（甲=上，乙=上/中，己=忐，丙=下，丁=忑，戊=忑/忠）

**所以周层大局比周仓类+周波型多的两个字段（WXCD护型、WXAB方向）都是冗余的。**

#### 5.5.3 数据验证（区分度）

| 指标 | 区分度 |
|:-----|:------:|
| **周仓类+周波型** | **22.2pp** |
| 周波型 | 19.5pp |
| 周层大局 | 10.0pp |
| 周仓类 | 10.0pp |

**周仓类+周波型（22.2pp）远大于周层大局（10.0pp），是2.2倍。**

#### 5.5.4 结论

**周层大局可以被周仓类+周波型替代，而且更好：**

1. **信息等价**：周层大局 = 周仓类+周波型 + 两个冗余字段（WXCD护型、WXAB方向）
2. **区分度更高**：22.2pp vs 10.0pp，是2.2倍
3. **更简洁**：无冗余字段

**周层大局是"压缩版"的周仓类+周波型，但压缩时保留了冗余字段，且区分度更低。周仓类+周波型是更优的选择。**

**周层大局的实际价值：**
- 把 WXCD护型 + WXAB护型 + 波型 压缩成一个字符串，方便快速查看
- 但信息完全被 周仓类（WXCD方向+WXAB护型）+ 周波型（地型+主类+层界）覆盖
- 且周层大局多了两个冗余字段

**建议：**
1. 周层大局可保留用于"快速查看"，但决策应基于 周仓类 + 周波型
2. 周层大局的两个方向字段（WXCD方向、WXAB方向）可忽略
3. 周层大局的 WXCD护型、WXAB方向 是冗余字段，无增量信息

**一句话：周层大局是"压缩版"的周仓类+周波型，但压缩时保留了冗余字段且区分度更低。周仓类+周波型信息等价、区分度更高（22.2pp vs 10.0pp）、更简洁，可以替代周层大局。**

### 5.6 长线持仓规则：不破WJA不卖出 + 不破DXZB不退出（2026-08-16 新增）

> 长线持仓的两道防线，与月策略日H级形成镜面映射。

#### 5.6.1 核心规则

**长线持仓的两道防线：**

| 防线 | 规则 | 级别 | 作用 |
|:----:|:-----|:----:|:-----|
| **第一道** | **不破 WJA 不卖出** | 周线 | 守住周线升势 |
| **第二道** | **起码不破 DXZB 不退出** | 日线 | 守住日线多头排列 |

**与月策略日H级的镜面映射：**
- **月策略日H级** = EF差（嘘/屎/尿）+ 弱（下/忑）+ AB坏（下/忠/忑）→ "H弱坏禁"（禁止）
- **不破DXZB不退出** = 日线多头排列未破 → 守住

**镜面映射：H级是"该退不退"的最差状态，不破DXZB是"该守守住"的最好状态。两者是同一逻辑的两端。**

#### 5.6.2 从系统源码验证

**1. WJA（周线A线）是周级别最重要的趋势线**

**WJA之上 = 安心持有，下破WJA = 退出。** 验证"不破WJA不卖出"。

**2. DXZB（日线B线）是日线多头排列的关键**

[MC3.1_研究月基策略.md:1665](昭明计划VS优化_vba/../_主文档/MC3.1_研究月基策略.md#L1665)：

> "DXZB<0 → 可关注，最接近转势"（禁止区）

**DXZB<0 = 可持有。** 验证"不破DXZB不退出"。

**3. 月策略日H级的定义**

[IQQQ跨码_D据擎2神谕.bas:3435](昭明计划VS优化_vba/IQQQ跨码_D据擎2神谕.bas#L3435)：

#### 5.6.3 镜面映射的深层逻辑

**镜面映射核心：同一条件在正反战场效果相反。**

[MC3.1_研究月基策略.md:1671-1677](昭明计划VS优化_vba/../_主文档/MC3.1_研究月基策略.md#L1671-L1677)：

|:----------------------|:----------------------|
| DXZA>0 → **主** ✅ | DXZA>0 → **最危险，假突破** ❌ |
| DXZA<0, DXZB>0 → 被 | DXZA<0, DXZB>0 → 完全禁止 |
| DXZB<0 → 持有，无威胁 | DXZB<0 → **可关注，最接近转势** ⚠️ |

**长线持仓时，不破WJA不卖出（周线守住），不破DXZB不退出（日线守住）。这与月策略日H级形成镜面映射——H级是"禁止"（最差），而"不破DXZB不退出"是"守住"（最好）。**

#### 5.6.4 合理性分析

**1. 两道防线是"周线定方向 + 日线定时机"的体现**

- **WJA（周线）**：决定长线方向，不破WJA说明周线升势未破，应守住
- **DXZB（日线）**：决定日线时机，不破DXZB说明日线多头排列未破，应持有

**符合系统"先周后日"的核心原则**（见 [MC3.3.5_周日联合.md](MC3.3.5_周日联合.md) §1.1）。

**2. 与月策略日H级的镜面映射**

- **H级**（禁止）：EF差 + 弱 + AB坏 → 最差，禁止操作
- **不破DXZB不退出**：日线多头排列未破 → 守住

**镜面映射：H级是"该退不退"的最差状态，不破DXZB是"该守守住"的最好状态。**

**3. 但需要注意：WJA和DXZB是不同级别的均线**

- **WJA** = 周线A线（周类BTZA）
- **DXZB** = 日线B线（日类BTZB）

**WJA是周线级别，DXZB是日线级别。** 不破WJA是周线守住，不破DXZB是日线守住。两者是"周线定方向 + 日线定时机"的配合。

#### 5.6.5 结论

**长线持仓规则合理，且符合系统"先周后日"的核心原则：**

1. **不破WJA不卖出** = 周线守住升势（第一道防线）
2. **不破DXZB不退出** = 日线守住多头排列（第二道防线）
3. **与月策略日H级镜面映射** = H级是"该退不退"的最差，不破DXZB是"该守守住"的最好

**但需要注意：**
- WJA是周线级别，DXZB是日线级别，两者是"周线定方向 + 日线定时机"的配合
- 不破WJA是长线底线，不破DXZB是短线底线
- **如果周线破WJA，即使日线不破DXZB，也应考虑退出（周线优先）**

**一句话：不破WJA不卖出（周线守住升势）+ 不破DXZB不退出（日线守住多头排列），与月策略日H级形成镜面映射——H级是"该退不退"的最差，不破DXZB是"该守守住"的最好。这符合系统"先周后日"的核心原则。**
