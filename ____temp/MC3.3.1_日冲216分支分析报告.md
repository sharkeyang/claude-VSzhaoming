## 2. 贝叶斯收缩处理

### 2.1 为什么需要

总样本2000万行，但分布极不均匀：金/上/上=284万行，银/忠/下=12行。极端状态（上/忑）大量出现，中间状态（中/下/忐/忠）在矛盾战场中极少出现。

### 2.2 收缩公式

```
p_shrink = (n * p_raw + k * p_parent) / (n + k)
k = 100（收缩强度）
```

- 样本=9时：90%依赖父级，10%依赖自身
- 样本=87时：47%依赖父级，53%依赖自身
- 样本≥100：不收缩，完全使用原始数据

父级 = 同(DXEF, DXCD)下的所有DXAB合并统计。

### 2.3 收缩范围

16个N<100的分支被收缩，全部集中在银战场和尿战场的"矛盾组合"中（如银/忠/下、尿/中/中等）。

## 3. 小样本特征分析

### 3.1 核心规律：极端状态不缺，中间状态缺

**DXCD=上和忑 从不缺样本，DXCD=中/下/忐/忠 大量缺样本：**

| DXCD | 全样本分支 | N<10000分支 | 说明 |
|:----:|:---------:|:----------:|:------|
| **上** | 36 | 12 (33%) | ✅ 极端强，大量出现 |
| 中 | 36 | 25 (69%) | 过渡态，样本不足 |
| 下 | 36 | 24 (67%) | 过渡态，样本不足 |
| 忐 | 36 | 24 (67%) | 过渡态，样本不足 |
| 忠 | 36 | 25 (69%) | 过渡态，样本不足 |
| **忑** | 36 | 12 (33%) | ✅ 极端弱，大量出现 |

**原因：** 股票价格多数时间在DJE之上（上）或DJE之下（忑）运行，中/下/忐/忠只是短暂穿越DJC时的过渡状态，天生样本少。

### 3.2 小样本分布规律：相对占比视角

**核心规律：每个战场都有一个"主流DXCD"，非主流DXCD中容易出现小样本。** 小样本的本质不是绝对N值小，而是**该DXCD占该战场总样本的比例极低（<2%）**。

| 战场 | 主流DXCD | 占比 | 小样本出现区 | 该区占比 | 小样本数 |
|:----|:--------|:---:|:-----------|:--------:|:-------:|
| **金** | 上 | 61.9% | 无 | — | 0 |
| **银** | **上** | **79.2%** | **忐忑忠** | **2.9%** | **6** |
| 嘘 | 忑 | 67.7% | 上中 | 1.9% | 3 |
| **唏** | **上** | **66.9%** | **忐忑忠** | **7.8%** | **2** |
| 屎 | 忑 | 63.0% | 无 | — | 0 |
| **尿** | **上** | **80.4%** | **上中下** | **2.5%** | **5** |

**具体分布：**
- **银战场**：DXCD=忐忑忠占银总量仅2.9%，忠只有0.1%→ 6个小样本
- **嘘战场**：DXCD=上中占嘘总量仅1.9%，中只有0.3%→ 3个小样本

## 4. 中间态(DXCD=中/下/忐/忠)能否合并？

### 4.1 结论：不能合并

**极差经常超过30-50pp：**

```
金战场, DXAB=下:
  中=94.2% → 下=71.5% → 忐=60.8% → 忠=48.5%
  极差=45.7pp  ← 完全不能合并！

银战场, DXAB=忑:
  中=94.3% → 下=43.7% → 忐=80.0% → 忠=56.2%
  极差=50.6pp  ← 更不能合并！
```

如果合并成一个"中间态"，会丢掉30-50pp的区分度。

### 4.2 但不是随机——有清晰的梯度规律

在几乎所有战场中，→ZE>0 的排序一致：

```
DXAB=上/中/忐 时：  中 ≈ 下 ≈ 忐 > 忠
DXAB=下/忠/忑 时：  中 > 下 > 忐 ≈ 忠

                     →ZE>0 递减 →
```

| DXCD | 含义 | 概率趋势 |
|:----|:-----|:--------|
| 中 | 在DJC附近但尚未破位 | **最高** |
| 下 | 已破DJC但未破DJD | 次高 |
| 忐 | 在DJC之上但犹豫 | 再次 |
| 忠 | 粘在DJC附近不动 | **最低** |

### 4.3 极端 vs 中间对比

| →ZE>0区间 | 极端均值-中间均值 | 中间内部极差 | 能否合并 |
|:----------|:--------------:|:-----------:|:--------|
| >90% | -2.5~+1.4pp | 10~25pp | 勉强可合 |
| 70-90% | -17.6~+14.7pp | 18~42pp | **不能合** |
| <70% | -13.4~+14.7pp | 25~56pp | **绝对不能合** |

**规律：** 概率越高（>90%），中间态越一致，可以简化；概率越低（<70%），中间态差异越大，必须保留细分。

## 5. 最终建议

### 5.1 216个分支保持不变

不需要合并，不需要调整。小样本分支的稀缺性本身就是信号。

### 5.2 使用分层

| 层级 | 样本 | 分支数 | 使用方式 |
|:----|:---:|:-----:|:--------|
| A级 | ≥100,000 | 72 | 直接使用，完全可信 |
| B级 | 10,000~99,999 | 22 | 直接使用，标注置信度 |
| C级 | 1,000~9,999 | 50 | 参考使用，结合父级 |
| D级 | 100~999 | 56 | 贝叶斯收缩后参考 |
| E级 | <100 | 16 | **建议忽略**（矛盾状态，无操作价值） |

### 5.3 关键发现

1. **嘘战场不能一刀切"必须退出"**：嘘/上/上=92.7%→ZE>0，嘘战场中DXCD=上/忐仍有高概率续站DJE
2. **屎/尿应分开**：屎/忠/上=3.8% vs 尿/忠/上=1.9%，尿比屎更烂
3. **DXAB仅在过渡区起作用**：金/上场景中DXAB=上→忑的→ZE>0从99.8%→99.0%（Δ=0.8pp），但屎尿/上场景中从73.5%→18.1%（Δ=55.4pp）
4. **中间态(C/D/E级)不是操作盲区**：这些分支代表"理论存在但现实中极少出现的矛盾状态"，稀缺性本身就是不建议操作的信号

## 7. 日冲评分系统设计

### 7.1 三核心指标

| 指标 | 含义 | 决策作用 |
|:----|:-----|:--------|
| **→ZE+ZC+ZA** | 次日续站DJE+DJC+DJA概率 | 安全兜底，排除屎尿/抓住金银 |
| **下日DSHA>1** | 次日偏离DJA>1%概率 | 冲高幅度预期，参考柱排/柱型 |
| **小样本标记** | N<100罕见状态 | 跳过不具备普遍性的分支 |

### 7.2 决策链

> **概率就是评分，这是可验证的。** →ZE+ZC+ZA 概率直接作为日冲策分，下日DSHA>1概率作为日冲HA分，VBA中已实现（见7.3）。

```
日冲过滤链（按优先级）：
1. 小样本标记 → 忽略
2. 战场过滤 → 只操作金/银/唏（排除嘘/屎/尿）
3. →ZE+ZC+ZA < 10% → 风险高，不操作
4. 均线修正（不会比概率更有效）：管宽 < 5 → 波动不足，不操作；柱排 = 跌 → 等待阳柱。
6. 通过 → 按DSHA>1判断力度：>=80%强 / >=50%中 / 其他弱
```

**注：4和5是均线的形态修补，用于过滤极端情况，不能替代概率评分。**

### 7.3 评分公式（与VBA一致）

**概率就是评分，无需加权组合。** VBA中直接存储两个原始概率：

| 字段 | 内容 | 取值范围 |
|:----|:-----|:--------:|
| **日冲策分** | →ZE>0+ZC>0+ZA>0 概率，保留1位小数 | 0.0~100.0 |
| **日冲HA分** | 下日DSHA>1 概率，保留1位小数 | 0.0~100.0 |

**使用方式：**
- 日冲策分 = 安全评分（越高越安全）
- 日冲HA分 = 冲高预期（越高冲高概率越大）
- 两个分数独立使用，不组合加权

**验证方式：** 查表即可验证。例如金/上/上分支：
- 日冲策分 = 82.4（→ZE+ZC+ZA=82.4%）
- 日冲HA分 = 86.8（DSHA>1=86.8%）

### 7.4 VBA实现

VBA中已在 `IQQQ跨码_D据擎2神谕.bas` 实现：

| 字段 | 位置 | 实现 |
|:----|:------|:-----|
| `位谕of日冲策分` | 神谕.bas:3552 | `Round(日冲pZA, 1)` |
| `位谕of日冲HA分` | 神谕.bas:3553 | `Round(日冲pDSHA1, 1)` |
| `日冲查概率` | ZPY接口.bas:523 | 查216分支概率表 |
| 日冲策略分类 | 神谕.bas:3556-3564 | 金/银+上/忐→**主升**；唏+上/忐→**渡强**；屎/尿→**空降**；其他→**渡弱** |
- 理由：→ZE>0在金银区普遍>98%，区分度极低；DSHA和管宽才有实际区分度

**改进2：只在大战场操作**
- 金/银/唏：可操作（唏需DXCD=上/忐）
- 嘘/屎/尿：禁止
- 理由：屎/尿的均HR普遍在1.5-1.8%，无论DXCD/DXAB如何都难以覆盖交易成本

**改进3：加入管宽过滤**
- 管宽>10：加分，管宽<5：禁止
- 理由：管宽是日级别最强单一指标，管宽>10时次日冲高≥3%概率从~4%跳跃到~25-43%

### 8.2 位谕of日层联动 — 20级DJE走势等级

**输出格式：** `{联动首字}{E/V等级}{.后缀}`

#### 位2：DJE走势等级（核心）

**E系列（DJE之上，从最强→最弱）：**

| 等级 | 条件 | 含义 |

| **E4上** | CD>0, ZC>0, **BC≤0** | BC跌破 |
| **e5中** | CD>0, **ZD>0** | 失去ZC，但ZD仍正 |
| **e6下** | CD>0 | 失去ZD |
| **e7忑** | CD≤0, ZC≤0 | CD转负 |
| **e8忠** | CD≤0, ZC>0, ZD≤0 | ZC回弹但ZD仍负 |
| **E9忐** | CD≤0, ZD>0 | ZD回弹但CD仍负 |
| **>转空** | 以上都不是 | 跌破DJE |

### 8.3 位谕of周层猪操作 — 仓位管理建议

**输出格式：** `{区划}{仓位}:{等级串}`

**示例：** `长多基仓:E0上`、`长多浮仓:E1上`、`长多减仓:e5中`、`长多清仓:e7忑`、`_可被仓:e5中`、`_勿长空:v0忑`

#### 四区划判定

```
大前提：WXZC>0 且 DXZE>0 = 可参与门槛
├─ 满足门槛 + 联动首字=金/银 + 护型首字=甲/乙/己 → 长多
├─ 满足门槛 + 其他 → _可被仓
└─ 不满足门槛
   ├─ 联动首字=屎/尿 + 护型首字=丙/丁/戊 → _勿长空
   └─ 其他 → _勿可看
```

#### 长多区仓位细分

| 条件 | 仓位 |
|:-----|:----|
| ZE>0, ZC>0, **ZA>0** | **长多基仓** |
| ZE>0, ZC>0, ZA≤0 | 长多浮仓 |
| ZE>0, ZC≤0 | 长多减仓 |
| ZE≤0 | 长多清仓 |

#### 止盈叠加

当 日层盈提示≠空 且 等级串≠空 时，在仓位后追加 `/止盈`：

```
长多基仓:E0上  → 有盈提示 → 长多基仓/止盈:E0上
```

#### 等级串来源

等级串从日层联动中提取：取联动值的第2字符到第一个"."之间的部分。

```
金E0上.警.盈 → 等级串 = "E0上"
屎v0忑.警   → 等级串 = "v0忑"
```

| 维度 | 日冲策略 | 日层联动 | 周层猪操作 | 日层漏提示 |
|:----|:--------|:--------|:----------|:----------|
| **预测目标** | 次日续涨概率 | 当前均线位置 | 仓位建议 | 捡漏信号 |
| **数据支撑** | 2000万行216分支 ✅ | 无概率数据 | 无概率数据 | 无概率数据 |
| **可验证性** | 可直接回测 ✅ | 需另做统计 | 无法验证 | 无法验证 |
| **预测精度** | 有具体%值 | 只有排序 | 只有建议 | 只有描述 |
| **触发范围** | 全216分支 | 全20等级 | 全 | 极窄 |
