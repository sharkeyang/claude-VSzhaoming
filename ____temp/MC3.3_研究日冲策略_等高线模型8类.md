## 〇、适用范围：日冲策略的股票池限定

### 猜想

日冲策略（等高线+BSHA信号）不应该对所有市板一视同仁。月基策略主要针对 Qd(指数成分)/Qe(基金)/Qif(沪深300)，而日冲策略应该专注于排除这些后的核心股票池。Qst(ST/退市) 风险过高也应排除。

### 验证（全量2000万行，7461文件）

**分组：**
- **核心池（日冲策略主战场）：** Qic(中证500) + Qimit(中证1000/2000) + Qin(非成分股)
- **排除池（月基策略主战场+风险股）：** Qd(指数成分) + Qe(基金) + Qif(沪深300) + Qst(ST/退市)

**市板分组统计（代码数+样本数，花册花天→谕组日CSV匹配）：**

| 分组 | 市板 | 含义 | 代码数 | 代码占比 | 样本数 | 样本占比 |
|:---:|:---:|:----|------:|:-------:|------:|:-------:|


| **排除池** | Qd | 指数成分 | 550 | 7.4% | 1,920,167 | 9.6% |
| | Qe | 基金/ETF | 1,498 | 20.1% | 1,441,014 | 7.2% |
| | Qif | 沪深300 | 300 | 4.0% | 1,229,334 | 6.1% |
| | Qst | ST/退市 | 207 | 2.8% | 831,468 | 4.1% |
| | **小计** | | **2,555** | **34.2%** | **5,421,983** | **27.0%** |
| **核心池** | Qic | 中证500 | 499 | 6.7% | 1,953,575 | 9.7% |
| | Qimit | 中证1000/2000 | 2,952 | 39.6% | 9,077,791 | 45.2% |
| | Qin | 非成分股 | 1,455 | 19.5% | 3,649,035 | 18.2% |
| | **小计** | | **4,906** | **65.8%** | **14,680,401** | **73.0%** |
| **总计** | | | **7,461** | **100%** | **20,102,384** | **100%** |

**① 基准差异巨大（14.9pp）：**

| 池 | 加权平均基准≥2% | 总样本 |
|:---|:--------------:|:-----:|
| **核心池** | **37.0%** | 1,468万（占73%） |
| 排除池 | 22.1% | 542万（占27%） |

**② 核心池内高度同质（极差仅1.2pp），排除池内极度异质（极差24.9pp）：**

| 池 | 组成 | 基准范围 | 极差 |
|:---|:----|:-------:|:---:|
| 核心池 | Qic=36.1% / Qimit=37.2% / Qin=37.0% | 36.1~37.0% | **1.2pp** |
| 排除池 | Qd=13.3% / Qe=15.1% / Qif=33.0% / Qst=38.2% | 13.3~38.2% | **24.9pp** |

**③ 策略在核心池命中率更高（+2~4pp）：**

| 策略 | 核心池≥2% | 排除池≥2% | 优势 |
|:----|:--------:|:--------:|:---:|
| C等3.偏5连门 | 57.5% | 53.6% | **+3.9pp** |
| C等3.偏5 | 55.7% | 52.4% | +3.4pp |
| C等4.偏5 | 58.8% | 58.5% | +0.3pp |

### 结论

**日冲策略（等高线+BSHA+连阳等所有信号）的应用范围限定为：**

> ✅ **核心池：** Qic(中证500) + Qimit(中证1000/2000) + Qin(非成分股)
> ❌ 排除：Qd(指数成分) + Qe(基金) + Qif(沪深300) + Qst(ST/退市)

**理由：**
1. 核心池占全样本73%，策略空间充足
2. 核心池内高度同质（1.2pp），可统一处理
3. 策略在核心池命中率比排除池高2~4pp
4. Qd/Qe 基准极低（13~15%），非日冲策略有效战场
5. Qif 是月基策略主战场，日冲策略避免冲突
6. Qst 风险过高，不适合日冲策略

## 一、分类系统设计

### 1.1 核心变量

| 变量 | 来源 | 含义 |
|:----|:-----|:------|
| **DTZA（日ZA）** | ARRLLL(基位日类+位osBTZA) | JZ快均线相对JA慢均线的衍生交叉天数，正数=JZ在JA之上N柱，负数=JZ在JA之下N柱（详见VBA函数 `STBASE结算工具_衍生交叉天数`） |
| **日中符（中符串）** | 谕组(位谕of日管中符串) | 5位移位寄存器，末位（Right$）为当前柱与JA的关系。A=全上(最强)，B=上探，C=鼎(继鼎)，D=反鼎，E=下探，F=全下(最弱) |
| **顶型** | ARRLLL(基位日类+位os基顶型) | 多空力量综合分类，含"鼎"字=有支撑（数据中几乎无鼎样本） |

### 1.2 DTZA的设置理由（寿命分布 + 最优分割证明）

> **数据：** 800文件抽样218万行（与全量2010万行验证一致），DTZA正数/负数运行长度分布。

**DTZA 寿命分布（JZ在JA之上；负数运行几乎对称）：**

| 指标 | 正数运行 |
|:----|:-------:|
| 均值 | 5.29天 |
| 中位数 | **4.0天** |
| 标准差 | 4.87天 |
| 最大值 | 164天 |

**累计分布 = 运行≥该天数的概率（这是DTZA阈值划分的核心依据）：**

| 天数 | 单日占比 | 累计（≥该天） |
|:----:|:------:|:----------:|
| 1 | 21.4% | 100% |
| 2 | 14.1% | 78.6% |
| **3** | **11.2%** | **64.5%** |
| 4 | 9.3% | 53.3% |
| 5 | 8.0% | 44.0% |
| 7 | 5.5% | 29.0% |
| 10 | 3.1% | 15.4% |

**关键结论：**

1. **21.4% 的上升段只持续1天**（DTZA=1后就被打回）——"刚突破可能失败"的数据支撑。
2. **每个 step 的续存率约82~83%**（DTZA=2→3有64.5/78.6=82%，DTZA=3→4有53.3/64.5=83%），恒定衰减。
3. **DTZA≥4 只占53.3%**——过半的上升段不到4天就结束。
4. **DTZA≥7 仅29%，≥10 仅15.4%**——长趋势是少数。

**为什么阈值选3（|DTZA|=3是拐点）：**

- **中位数4天**说明DTZA=4已处于一次运行的中后段。
- **续存率从DTZA=3开始从高位滑落**：DTZA=2→3续存82%，DTZA=3→4续存83%，但运行≥4天只有53.3%。
- **DTZA=-3~3是"频繁贯穿、积蓄力量区"**：JZ围绕JA上下波动，|DTZA|≤3时方向倾向弱（贯穿区与稳态区方向差异仅0.9~2.5pp），|DTZA|>3进入趋势/回归稳态。
- **与柱型系统重合**：DTZA=-3~3 = 柱型的根(-3~0)+枝(1~3)区域（重合度99%+），印证2026-08-08阈值更新与柱型对齐的正确性。

**末符区分力 vs DTZA区分力（证明DTZA阈值只做微调）：**

| 划分 | 类别 | 下柱>0 | 方向差异 |
|:----|:----|:-----:|:-------:|
| **末符（强力维度）** | AB末符(等3) | 85.3% | **15.1pp** |
| | CDEF末符(等2+等4) | 70.2% | |
| **DTZA阈值（微调）** | 等2(DTZA=2~3) | 73.8% | **5.2pp** |

**等高线的方向区分力主要来自末符（AB vs CDEF，15.1pp），DTZA阈值（等2 vs 等4）只贡献5.2pp。** DTZA的主要作用是把"频繁贯穿区"（|DTZA|≤3）与"稳态区"（|DTZA|>3）分开，而非在CDEF末符内部细分方向。

> **对冲高的影响不同：** 末符指明方向（下柱DTZA符号），但冲高幅度是另一属性。等4（远离JA后回归）冲高概率反而最高（≥2%=36.3%），因为回归前有冲高。所以**不能简单合并等2+等4**——等4本身的冲高价值要保留（详见§4策略赛马）。

### 1.3 分类规则（VBA末位逻辑）

> **关键修正：** 全量验证发现VBA代码使用 `Right$(中符串,1)`（末位）而非"包含"逻辑。旧版文档用"包含"造成等2/等4/等6/等8的分类偏差。**本表已更新为末位逻辑。**

**DTZA > 0（JZ在JA之上）：**

| 分类 | 条件 | 含义 |
|:----|:-----|:------|
| **等1** | DTZA=1 | JZ刚上穿JA。刚突破，可能形成上攻，也可能围绕DJA波动 |
| **等2** | DTZA=2~3 且 末符∈CDEF | JA之上2~3柱，当前柱与JA相交（鼎C/反鼎D/下探E/全下F）。**可能波动，也可能形成上攻势头** |
| **等3** | DTZA≥2 且 末符∈AB | JA之上且当前柱强势（全上A/上探B），有向上动力 |

| 分类 | 条件 | 含义 |

> **2026-08-08 阈值更新：** 等4/等8 阈值从 |4| 调整为 |3|，与柱型系统（位谕of日层柱型）的 TZA 分段对齐（柱型过渡区为 |TZA|≤3：根-3~0、枝1~3）。

**核心结论：对于"下日冲高"目标，用周门就够了，月门不需要单独使用。**

- 满足周门 42.9% vs 不满足 32.8%，过滤掉68%弱样本
- 等高线内增量 +4.2~5.1pp

**2. 月门不需要单独作为每日筛选：**
- 与周门高度相关（满足周门97%也满足月门，周门✓+月门✗仅0.9%样本）
- 在BSHA5+连阳加持下月门完全无增量（57.8% = 57.8%）
- BSHA5+连阳本身就隐含了月门（月门+BSHA5+连阳 = BSHA5+连阳无门 = 56.6%）
- 月门的价值在"等高线效果翻倍"（等高线在ZE>0时区分度翻倍），而非每日筛选

**3. 每日筛选优先级：**
```
第一优先：市板过滤（核心池Qic+Qimit+Qin）→ 硬性过滤
第二优先：周门（ZC>0 且 DXCD=上）→ 硬性过滤
第三优先：等高线（等3/等4）→ 位置判断
第四优先：BSHA5+连阳 → 高确定性信号
```

**4. 月门（ZE>0）的正确用法：** 不是每日筛选条件，而是"等高线是否有区分度"的前提判断。等高线 + 满足月门时等高线区分度翻倍，等高线 + 不满足月门时区分度缩小。所以在等高线分析时需确认月门，而非每日选股时过滤。

### 3.5 综合结论
#### 3.5.1 核心发现：DXZC和DXCD是"周门"，其他都是微调

**研究过程：** 等高线（DTZA+中符串末位）本身对延续性（→ZE>0）有一定区分度，但在周门（ZC>0+DXCD=上）的约束下，所有等高线分类的→ZE>0都在93%以上。

**周门验证（核心池，阈值3）：**

| 等高线 | ZC>0 + DXCD=上（满足周门） | ZC≤0 或 DXCD≠上（不满足周门） |
|:------|:-----------------------:|:-------------------------:|
| 等1 | →ZE>0=**96.0%** | →ZE>0=19.5% |
| 等2 | →ZE>0=**96.5%** | →ZE>0=19.3% |
| 等3 | →ZE>0=**98.7%** | →ZE>0=26.6% |
| 等4 | →ZE>0=**98.4%** | →ZE>0=23.9% |
| 等5 | →ZE>0=**95.3%** | →ZE>0=20.7% |
| 等6 | →ZE>0=**93.7%** | →ZE>0=22.3% |
| 等7 | →ZE>0=**93.9%** | →ZE>0=21.6% |
| 等8 | →ZE>0=**93.6%** | →ZE>0=21.7% |

**关键发现：**

- **满足周门（ZC>0+DXCD=上）→ →ZE>0=93~99%，无论等高线分类**
- **不满足周门（ZC≤0 或 DXCD≠上）→ →ZE>0<27%，无论等高线分类**

#### 3.5.2 等高线的实际价值

等高线不回答"能不能做"，只回答"**做了以后弹性多大**"。具体来说：

1. **冲高幅度：** 等4下日冲高≥2%=40.7%（最高），等8=32.3%（最低），差8.4pp
2. **回归确认：** 等4后31.4%会下破，等8后32.7%会反弹——这是等高线独有的预测力，周门不能替代
3. **趋势延续：** 等3后85.0%继续走，等7后85.8%继续跌
4. **持有期：** 核心池下各等高线持有期差异不大，等3/等4略优

#### 3.5.3 最终结论

**决定"做不做"的唯一因素是：ZC>0 且 DXCD=上。**

```
ZC>0 且 DXCD=上 → 做（→ZE>0>93%）
ZC≤0 或 DXCD≠上 → 不做（→ZE>0<28%）
```

**等高线的作用：** 不是"做不做"的决定因素，而是"满足周门后"的微调工具——等4冲高弹性最大但需确认是否下破，等3趋势延续最稳，等1刚突破持有期最好。

#### 4.4.5 合并CDEF类会丢失什么？

| 场景 | 合并前 | 合并后（模拟） | 损失 |
|:----|:------|:-------------|:----|
| BSHA5 | 等4=58.6%（样本1.4万） | CDEF≈57.5%（样本2万） | **-1.1pp** |
| BSHA5+连阳+周门 | 等4=60.1%（A级第3） | CDEF≈58.5%（B级） | **掉出A级** |
| 柱梯+周门 | 等4=29.1%（≥3%） | CDEF≈28.5% | **-0.6pp** |

合并后，等4的冲高优势被等2的弱表现稀释，导致A级策略掉出A级。

#### 4.4.6 最终结论

**不合并，保留等2和等4的细分。** 理由：

1. **方向维度**：等2 vs 等4差异仅5.2pp，确实小——但方向不是DTZA的主要价值。
2. **冲高基准**：基准下等2 vs 等4差异仅2.1pp，确实接近随机——**但这是表面现象。**
3. **赛马信号叠加后，差异放大到4.2~4.6pp**：等4的弹性是BSHA5的放大器，均冲高从2.10%跳到3.59%（+1.49pp），等2只跳到3.27%（+1.34pp）。
4. **等级差异**：等4+BSHA5+连阳+周门=60.1%（A级第3），等2对应策略只有56.5%（B级第8）。**合并会让A级策略掉出A级。**
5. **柱型叠加**：柱梯+等4_周门=29.1%是全场最高组合，等4是这个组合的基座。

**DTZA的价值不在基准，而在"与BSHA5等动量信号叠加后的弹性放大"。** 等4的弹性大，是BSHA5的天然放大器。合并CDEF类会丢失这个效果，得不偿失。

## 五、操作指南（四层）


### 5.1 日冲策略全景流程（四级过滤）

```
输入：当前股票 + 当日谕组数据
  │
  ├─ 第1级：【市板过滤】← 核心池限定
  │   ├─ ✅ 核心池：Qic(Q中证500) / Qimit(中证1000/2000) / Qin(非成分) → 继续
  │   └─ ❌ 排除池：Qd(指数) / Qe(基金) / Qif(沪深300) / Qst(ST/退市) → 跳过，无策略
  │
  ├─ 第2级：【周门过滤】
  │   ├─ ✅ ZC>0 且 CD=上 → 继续
  │   └─ ❌ 否则 → 跳过，无策略
  │
  ├─ 第3级：【等高线定位】
  │   ├─ DTZA=1 → 等1（刚穿越，可能上攻或震荡）
  │   ├─ DTZA≥2 + 末位AB → 等3（趋势延续，最强）
  │   ├─ DTZA>3 + 末位CDEF → 等4（回归确认，需验证）
  │   ├─ DTZA≥2 + 末位CDEF → 等2（近DJA弱）
  │   ├─ DTZA=-1 → 等5（刚下穿）
  │   ├─ DTZA<-3 + 末位ABCD → 等8（回归反弹）
  │   └─ ...（等6/等7）
  │
  ├─ 第3.5级：【增强过滤】← 操作区域限定 + 前一柱护型（详见§5.6）
  │   ├─ 下侧等高线（等5~等8）→ 强制操作区域限定（ZC>0 或 AB∈甲乙己），+2.5~4.4pp
  │   ├─ 等1 → 前一柱护型要求乙/丙（+2~3.5pp）
  │   ├─ 等4/等5/等8 → 前一柱护型要求甲乙，回避戊己（+3~5pp）
  │   └─ 不满足 → 降级或跳过
  │
  └─ 第4级：【条件评分】→ 映射策略名
      ├─ BSHA>5 → 偏5（最强信号，+7~8pp）
      ├─ BSHA>3 → 偏3（次强信号）
      ├─ 连阳>0 → 连（+1~3pp）
      ├─ 层主+升排 → 层主升（+3~5pp）
      ├─ 层主 → 层主
      └─ 升排 → 升
```

## 六、连阳趋势延续分析

> **⚠️ 范畴说明：连阳（BT连阳≥3）本质属于 [等3（趋势延续）](#13-分类规则vba末位逻辑) 的范畴。** 等3（DTZA≥2 + 末位AB）是"JA之上且当前柱强势，有向上动力"；连阳是"连续阳柱"的动量延续信号。两者都描述"趋势延续"，连阳是等3内部更细的动量细分。因此本分析应放在等高线（等3）框架下理解，连阳信号是对等3趋势延续的精细量化。

---

### 6.1 核心发现

**连阳越长，下日冲高概率越高（单调递增，无衰减）。** 这打破了"连阳长了会衰竭"的直觉——实际是"越连越强，强者恒强"。

> **数据：** 全量7461文件，核心池，门开后。
> **基线：** P(≥2%)=43.3%，P(≥3%)=30.0%。

### 6.2 连阳位置与下日冲高概率

| 连阳位置 | 样本 | P(≥2%) | 相对基线 | P(≥3%) | 均HR | 含义 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---|
| 基线 | 3,500,000+ | 43.3% | — | 30.0% | 2.08% | — |
| **第1根** | 1,223,704 | 45.8% | +2.5pp | 32.6% | 2.65% | ❌ 最弱 |
| 第2根 | 513,661 | 48.0% | +4.7pp | 35.4% | 2.91% | 一般 |
| **第3根** | 199,803 | **52.3%** | +9.0pp | 40.6% | 3.36% | ✅ 跳升点 |
| 第4根 | 77,260 | 56.3% | +13.0pp | 45.6% | 3.72% | 强 |
| 第5根 | 31,090 | 64.1% | +20.8pp | 54.9% | 4.83% | 很强 |
| 第6根 | 14,339 | 61.0% | +17.7pp | 53.4% | 4.37% | 强 |
| 第7根 | 6,106 | 70.8% | +27.5pp | 64.7% | 5.35% | 极强 |
| **第8+根** | 3,144~5,699 | **79.0~88.5%** | +36~45pp | 74.8~86.8% | 6.5~8.1% | 🏆 最强 |

**关键发现：**
1. **连阳第1根是最弱的（45.8%）**，不是"更容易冲高"
2. **连阳≥3 是明显跳升点**（48.0%→52.3%），这也是赛马用连阳≥3的依据
3. **连阳越长越强**，无衰竭现象
4. **连阳≥8+ 时 P(≥2%) 高达 79-89%**，但样本较少（3,144~5,699），可作为极强信号参考

**在等高线基座（等3_升_强）内验证，趋势完全一致：**

| 连阳位置 | 样本 | P(≥2%) | 相对基线(44.0%) |
|:---:|:---:|:---:|:---:|
| 第1根 | 32,067 | 43.1% | -0.9pp |
| 第2根 | 36,212 | 47.9% | +3.9pp |
| 第3根 | 18,804 | 52.6% | +8.6pp |
| 第4根 | 8,057 | 55.9% | +11.9pp |
| 第5根 | 3,342 | 63.9% | +19.9pp |
| 第6+根 | 2,520 | 68.7% | +24.7pp |

**连阳在等3升强基座内的规律与全局一致，且幅度更大（第5根+19.9pp）。**

### 6.3 操作建议（连阳阈值）

| 连阳区间 | P(≥2%) | 操作建议 |
|:---:|:---:|:---|
| 连阳=1~2 | 46-48% | 一般，不特殊处理 |
| 连阳=3~4 | 52-56% | ✅ 可操作（基本条件） |
| 连阳=5~7 | 61-69% | 🟢 优先 |
| 连阳≥8 | 80-87% | 🏆 极强信号，但样本少 |

**策略优化：** 等3升强+连阳≥3 = 52.6%（大样本），等3升强+连阳≥5 = 63.9%（+11.3pp）。

### 6.4 打板策略（市场连阳/涨停板）

> **范畴：** 打板策略（追涨停/连板）本质上是连阳信号在 A 股短线市场的应用，属于等3（趋势延续）范畴的极端形态。

**打板策略与连阳的关系：**
- 打板 = 追涨停板（首板/二板/三板...），本质是"连阳/连板的动量延续"
- 连阳（BT连阳）聚类了"连续上涨"的动量状态，打板是其最激进的应用
- **连板数越高，次日冲高概率越高**——与连阳"越长越强"的规律一致
- 打板的风险：连板后期（≥8板）样本骤减，追高风险大，需结合护型/BSHA确认

**打板策略的等高线框架：**
```
等高线等3（趋势延续）→ 连阳（动量延续）→ 打板（连板的极端形态）
```
打板是连阳信号在短线交易中的极致应用，其收益与风险都远高于普通连阳。当连阳≥5且满足等3+BSHA5时，可视为打板候选（P(≥2%)达60%+）。
