# 周级别等高线设计方案

## 目标
仿照日级别等高线（等1~等8），基于周级别数据设计一套周等高线，用于预测下周冲高。

## 日级别参考
```
等1: DTZA=1               → DJA边缘刚站上
等2: DTZA=2~3 + 末位CDEF  → 近DJA软弱
等3: DTZA≥2 + 末位AB      → 远离DJA强势主升
等4: DTZA>3 + 末位CDEF    → 回归DJA
等5: DTZA=-1              → DJA边缘下方
等6: DTZA=-3~-2 + 末位ABCD → 近DJA下方偏强
等7: DTZA≤-2 + 末位EF     → 远离DJA弱势
等8: DTZA<-3 + 末位ABCD   → 回归DJA
核心：BTZA + 中符末位 + 阈值3
```

## 周级别方案

### 替代变量
| 日级别 | 周级别 | 理由 |
|--------|--------|------|
| DTZA(日BTZA) | ZA级(周BTZA) | 同理，距JA的交叉天数 |
| 中符末位(AB/CDEF) | ZC级正负或周柱型末位 | 判断方向/强弱 |
| 阈值3 | 阈值3 | 保持一致 |

### 方案A：ZA级 + ZC级正负（最简）
```
ZA级=1                  → 等1
ZA级=2~3 + ZC级>0       → 等3
ZA级=2~3 + ZC级≤0      → 等2
ZA级>3 + ZC级>0        → 等4
ZA级>3 + ZC级≤0        → 等2
ZA级=-1                 → 等5
ZA级=-2~-3 + ZC级>0    → 等6
ZA级=-2~-3 + ZC级≤0    → 等7
ZA级<-3 + ZC级>0       → 等8
ZA级<-3 + ZC级≤0       → 等7
```

### 方案B：ZA级 + 周柱型末位（仿照日级别）
```
ZA级=1                  → 等1
ZA级=2~3 + 柱末位AB     → 等3
ZA级=2~3 + 柱末位CDEF   → 等2
ZA级>3 + 柱末位AB       → 等3
ZA级>3 + 柱末位CDEF     → 等4
ZA级=-1                 → 等5
ZA级=-2~-3 + 柱末位ABCD → 等6
ZA级=-2~-3 + 柱末位EF   → 等7
ZA级<-3 + 柱末位ABCD    → 等8
ZA级<-3 + 柱末位EF      → 等7
```

### 方案C：仅ZA级（无细分，极简）
```
ZA级=1       → 等1
ZA级=2~3     → 等2
ZA级>3       → 等3
ZA级=-1      → 等4
ZA级=-2~-3   → 等5
ZA级<-3      → 等6
```

## 验证计划
1. 用周线数据计算各方案的下周P(≥3%)
2. 对比方案间的区分度（等1 vs 等6的P3差距）
3. 选择区分度最大的方案
4. 如果方案A/B区分度接近，选方案A（最简）
