## 一、总览

### 1.1 策略定位

| 维度 | 内容 |
|:----|:-----|
| 策略类型 | 日冲策略（极短线） |
| 核心问题 | 次日盘中冲高概率有多大？ |
| 时间尺度 | 日级别（前日尾盘买入→次日冲高卖出） |
| 评估工具 | 日冲评分（待设计） |
| 分析体系 | **以均线为骨（日级别执行框架§3、日层联动§5），以形态修补（按形态探索§4）** |


### 1.2 现状与瓶颈

现有日级别回测数据显示：
- 各类条件下日胜率均在 **47%~52%** 之间，接近随机
- 唯一略优的是 **金+甲乙己+买初** 区域，胜率54.3%
- 日级别预测力有限，**核心价值在筛选冲高幅度而非方向**


### 1.3 待研究问题

- [x] 日级别哪些条件能有效提升次日冲高概率？已组织日级别探索路径，见[研究日级别探索路径.md](研究日级别探索路径.md)（含36个探索子项，待逐项回测）

## 二、日周联动（周←→日映射）

> 日周联动连接周级别（月基策略）和日级别（日冲策略），提供双向映射框架。<br>
> **周级别参考：** [月基带日§5](MC3.1_研究月基策略.md#第五章月基带日日级别看盘工具) — 完整8格分类系统、216分支概率表、规则验证<br>
> **核心原则：** 只在 DJE 之上介入，不在 DJE 之下抄底

### 2.1 周←→日映射关系

| 周级别 | 映射到日级别 | 含义 |
|:------|:-----------|:------|
| **WXCD**（周CD方向） | → **DXEF**（日EF战场） | 均线排列方向，金/银/唏=好，嘘/尿/屎=差 |
| **WXZC**（周ZC位置） | → **DXZE**（日ZE位置） | 是否在DJE之上，>0=无限区，≤0=有限区 |
| **WXAB**（周AB护型） | → **DXCD**（日CD护段） | 护型质量，上/中/忐=好，下/忠/忑=差 |

### 2.2 月基四域→日冲5层 完整映射

| 月基四域 | 月基操作 | 日冲层级 | 日冲等级 | 日冲操作 |
|:--------|:--------|:--------|:--------|:--------|
| **多长** | 持有 | 🟦 **主** | A级, E级 | 主动持仓 |
| **多被** | 被动持有 | 🟩 **被** | B级, C级, D级, F级 | 被动持有 |
| **空看** | 仅WXZB>0(甲乙己)可观察 | 🟪 **傻** | G级 | 傻吃屎豆（极小仓） |
| **空长** | 完全禁止 | 🟥 **禁** | H级 | 禁止 |

### 2.3 日冲5层操作列表

| 层级 | 色系 | 等级 | 底色 | 对应月基 |
|:----|:----|:----|:----|:--------|
| 🟦 **主** | 靛系 | A级, E级 | 亮靛/中靛 | 多长 |
| 🟩 **被** | 绿系 | B级, C级, D级, F级 | 亮绿~最深绿 | 多被 |
| 🟪 **傻** | 棕系 | G级 | 深粪棕 | 空看 |
| 🟥 **禁** | 红系 | H级 | 深红 | 空长 |

### 2.4 为什么G级需要单独处理为"傻吃屎豆"

G级（EF差+CD差+AB好）对应月基的**空看**（WXZC≤0但WXAB>0），月基允许"可观察/试仓"。但日冲策略中G级有一个致命陷阱：

**AB好的假象：** G级看起来"AB好"（上中忐），容易让人误判安全。但实际上：
- EF差（嘘尿屎）→ 当前在DJE之下，有限区
- CD差（下忠忑）→ 当前在DJC之下，ZCD全部崩坏
- 唯一亮点是AB好 → 但AB好救不了EF差+CD差
- **→ZE>0仅27.6%** → 72.4%概率次日仍在DJE之下，趋势不延续

**风险偏好陷阱：** 投资者容易因"捡漏"心理，把过多仓位放在G级这类"看起来有机会"的位置。一旦被套，轻则割肉，重则陷入主跌浪。

**取名"傻吃屎豆"的原因：** 屎中确实有豆（AB好的确偶尔能反弹），但为了一颗豆去翻屎，大概率弄一身臭。极小仓可以，重仓就是找死。

> ⚠️ **完整数据支撑（8格分类表、216分支概率表、规则验证）见** [月基带日§5](MC3.1_研究月基策略.md#第五章月基带日日级别看盘工具)

## 三、日级别执行框架

### 3.1 DXEF-DXCD 日级别执行框架

> 本框架是日冲策略的**核心操作规则**，回答"何时可以买、何时不能买、买了何时卖"的问题。

#### 3.1.1 核心概念

| 层级 | 含义 | 值 | 作用 |
|:----|:-----|:---|:------|
| **DXEF** | 日级别均线排列（战场） | 金/银/唏/嘘/屎/尿 | 决定整体趋势方向 |
| **DXCD** | 日级别护级（时机） | 上/中/下/忐/忠/忑 | 决定具体操作时机 |
| **DXAB** | 日级别护级 | 上/中/下/忐/忠/忑 | 实际就是月基带日的定义 |

**DXCD→DXEF 带动逻辑：**
| DXCD | 传导方向 | 对DXEF的影响 |
|:----:|:--------:|:------------|
| 上/忐 | ↗ 向上 | 带动DXEF转金银 |
| 中/忠 | ○ 无 | 无法传导，等待 |
| 下/忑 | ↘ 向下 | 带动DXEF转屎尿 |

**完整带动规则（AB→CD 与 CD→EF 同逻辑）：**

| 条件 | 信号 | 含义 |
|:----|:----:|:------|
| 上游∈{上,忐} 且 下游∈{上,忐} | **▲** 同上 | 两级别同步向上，趋势最强 |
| 上游∈{下,忑} 且 下游∈{下,忑} | **▽** 同下 | 两级别同步向下，趋势最弱 |
| 上游∈{上,忐} 但 下游不在{上,忐} | **↗** 抬 | 上游向上拉下游，有改善趋势 |
| 上游∈{下,忑} 但 下游不在{下,忑} | **↘** 压 | 上游向下压下游，有恶化趋势 |
| 上游∈{中,忠} | **○** 待定 | 上游方向不明，带动作用不确定 |

> 注：CD→EF的"下游"判定中，{上,忐}映射为{金,银}，{下,忑}映射为{屎,尿}。

**日EF护级判定规则：**

| 条件 | 护级 | 含义 |
|:----|:----:|:------|
| BTEF>0 且 BTZF<0 | 尿 | EF>0但ZF下破，走弱 |
| BTEF>0 且 BTZE<0 | 嘘 | EF>0但ZE下破，混合 |
| BTEF>0 且 BTZE<BTEF | 金 | EF>0, ZE>0但低于EF，上升中 |
| BTEF>0 且 BTZE≥BTEF | 金 | EF>0, ZE≥EF，强升 |
| BTEF≤0 且 BTZF>0 | 银 | EF≤0但ZF>0，恢复中 |
| BTEF≤0 且 BTZE>0 | 唏 | EF≤0但ZE>0，混合 |
| BTEF≤0 且 BTZE>BTEF | 屎 | EF≤0, ZE>EF，下降中 |
| BTEF≤0 且 BTZE≤BTEF | 屎 | EF≤0, ZE≤EF，强降 |

**月基带日输出格式：** `(EF护级)(CD促EF)(CD护级)(AB促CD)(AB护级)`

| 输出值 | 含义 |
|:------|:------|
| `(金)▲(上)↗(上)` | EF金级，CD同上(▲)，CD上，AB抬(↗)，AB上 → 全线向上，最强状态 |
| `(屎)▽(下)↘(下)` | EF屎级，CD同下(▽)，CD下，AB压(↘)，AB下 → 全线向下，最弱状态 |
| `(银)↗(中)↗(上)` | EF银级，CD抬(↗)，CD中，AB抬(↗)，AB上 → AB向上带动CD，CD在恢复中 |
| `(金)○(忠)↘(下)` | EF金级，CD待定(○)，CD忠，AB压(↘)，AB下 → AB向下压CD，CD方向不明 |

#### 3.1.2 完整执行规则

##### ① 完全禁止介入（绝对禁止，无例外）

| 场景 | 状态 | 理由 |
|:-----|:-----|:------|
| 屎尿区 | DXEF<0, DXZE<0, DXCD<0, DXZC<0 | 未上破DJC，无任何试价值 |
| 屎尿区·最危险 | DXEF<0, DXZE<0, DXCD<0, DXZC<0, DXZA>0 | 镜面：曾站上DJA却仍在DJE之下，假突破，最易诱多 |
| 嘘区 | DXEF>0, DXZE<0 | **必须退出**，无任何操作空间 |
| 金银区·退出 | DXEF=金/银, DXCD>0, DXZD<0 | DXCD正面但ZD已转负，表明CD开始负面带动DXEF，应退出 |

##### ② 试，不介入（可以看，不能买）

| 场景 | 状态 | 理由 |
|:-----|:-----|:------|
| 屎尿区·观察 | DXEF<0, DXZE<0, DXCD<0, DXZC>0 | 试，容易再次下破DJC |
| 屎尿区·关注 | DXEF<0, DXZE<0, DXCD<0, DXZC<0, DXAB=甲乙己 | 关注DXAB，但未上破DJC无试价值 |
| 唏区·中性 | DXEF<0, DXZE>0, DXCD=中/忠 | DXCD无法传导至DXEF，等待 |
| 金银区·暂退 | DXEF=金/银, DXCD>0, DXZC<0 | 可暂时清仓，但DXCD未形成负面带动（ZC转负但ZD仍正），还有机会站上DJC |

##### ③ 可警惕（向下传导，可能恶化）

| 场景 | 状态 | 理由 |
|:-----|:-----|:------|
| 唏区·警惕 | DXEF<0, DXZE>0, DXCD=下/忑 | DXCD向下传导(↘)，DXEF可能进一步恶化 |

##### ④ 超短/试（手痒可做，但必须严格止损）

| 场景 | 状态 | 止损条件 |
|:-----|:-----|:---------|
| 屎尿区·试 | DXEF<0, DXZE<0, DXCD<0, DXZD>0 | 以DJC为丘，下破DJC退出 |
| 屎尿区·试 | DXEF<0, DXZE<0, DXCD<0, DXZC>0, 刚上破DJC | 以DJC为丘，下破DJC退出 |
| 唏区·试 | DXEF<0, DXZE>0, DXCD=上/忐 | DXAB传导至DXCD→DXEF(↗)，有望转势 |

##### ⑤ 正式介入（主战场）

| 场景 | 状态 | 操作 |
|:-----|:-----|:------|
| **屎尿区·主战场** | DXEF<0, DXZE<0, **DXCD>0, DXZC>0** | 站上DJC，带动DXEF |
| → 主动 | DXZA>0 | **日级别主** |
| → 被动 | DXZA<0, DXZB>0 | 日级别被 |
| → 持有 | DXZB<0 | 可持有 |
| **金银区·主战场** | DXEF>0, DXZE>0, **DXCD>0, DXZC>0** | 主战场 |
| → 主动 | DXZA>0 | **日级别主** |
| → 被动 | DXZA<0, DXZB>0 | 日级别被 |
| → 持有 | DXZB<0 | 可持有 |

**镜面映射（同一条件在正反战场效果相反）：**

| 主战场(DXCD>0,DXZC>0) | 禁止区(DXCD<0,DXZC<0) |
|:----------------------|:----------------------|
| DXZA>0 → **主** ✅ | DXZA>0 → **最危险，假突破** ❌ |
| DXZA<0, DXZB>0 → 被 | DXZA<0, DXZB>0 → 完全禁止 |
| DXZB<0 → 持有，无威胁 | DXZB<0 → **可关注，最接近转势** ⚠️ |

#### 3.1.3 核心流程图

```
DXEF>0, DXZE>0 (金银)
  ├─ DXCD>0, DXZC>0 → 主战场 ✅
  │   ├─ DXZA>0       → 主
  │   ├─ DXZA<0,DXZB>0 → 被
  │   └─ DXZB<0       → 持有
  ├─ DXCD>0, DXZC<0   → 可暂退
  └─ DXCD>0, DXZD<0   → 应退出 ❌
DXEF>0, DXZE<0 (嘘) → 必须退出 ❌
DXEF<0, DXZE>0 (唏)
  ├─ DXCD=上/忐       → 可试 ⚠️ (↗)
  ├─ DXCD=下/忑       → 可警惕 (↘)
  └─ DXCD=中/忠       → 试
DXEF<0, DXZE<0 (屎尿)
  ├─ DXCD>0, DXZC>0   → 主战场 ✅ (站上DJC带动DXEF)
  │   ├─ DXZA>0       → 主
  │   ├─ DXZA<0,DXZB>0 → 被
  │   └─ DXZB<0       → 持有
  ├─ DXCD>0, DXZC<0   → 可暂退
  ├─ DXCD<0, DXZD>0   → 以DJC为丘试 ⚠️
  ├─ DXCD<0, DXZC>0   → 试
  └─ DXCD<0, DXZC<0   → 完全禁止 ❌
      ├─ DXZA>0       → 最危险（假突破）
      ├─ DXZA<0,DXZB>0 → 完全禁止
      └─ DXZB<0       → 可关注（最接近转势）
```


#### 3.1.4 与日冲策略的关系

日冲策略的核心问题是"次日冲高概率多大"，而本框架回答的是"当前位置是否可以操作"。两者结合：

| 状态 | 日冲操作 |
|:-----|:---------|
| **主战场·主动** | 可正常操作日冲策略 |
| 主战场·被动 | 可操作，但需降低仓位 |
| 试 | 极小仓试探，严格止损 |
| 试 | 不操作，等待 |
| 完全禁止 | **绝对不操作** |

| 10~20 | **24.8%** | **1.98%** | 3,418 | **3.3x** |
| 20~40 | **39.9%** | **3.06%** | 696 | **5.4x** |
| >40（极宽） | **43.1%** | **3.55%** | 58 | **5.8x** |

**结论：** 管宽（顶JC）是日级别最强的单一指标。管宽>10时，次日冲高≥3%的概率是基准的3倍以上。建议将管宽作为日冲评分公式的核心维度。

### 4.2 DSHA（偏离DJA）— 与直觉相反

| DSHA | P(≥3%) | 均HR | 样本 |
|:----|:------:|:----:|:----:|
| 0~3（贴均线） | 4.1% | 0.76% | 54,203 |
| 3~5 | 12.3% | 1.29% | 14,268 |
| 5~8 | 23.2% | 1.87% | 4,979 |
| >10（大幅偏离） | **42.4%** | **3.44%** | 816 |

**结论：** 原"偏BSHA警告"假设不成立。DSHA越大后续日涨幅越大，不是回撤风险高。大幅偏离DJA的股票次日仍有更大波动，可能是趋势延续而非反转。

### 4.3 鼎 — 区分度有限

| 鼎值 | P(≥3%) | 均HR |
|:----|:------:|:----:|
| 1~2（初现） | 8.2% | 1.02% |
| 3~4 | 7.3% | 1.01% |
| 5~6 | 8.5% | 1.03% |
| 7~8 | 9.4% | 1.10% |
| ≥9（高位） | 11.5% | 1.21% |

**结论：** 鼎值高≠要跌。鼎连续出现的衰竭信号仅对单只股票成立，不是普遍规律。鼎不适合作为日冲评分中的否决条件。

### 4.4 四域日 / 柱排 — 区分度弱

**四域日：** 多长(8.3%) vs 空长(7.1%)，差仅1.2pp
**柱排：** 升(8.1%) vs 跌(7.2%)，差仅0.9pp

**结论：** 四域日和柱排在日级别上的预测力非常有限，不值得作为独立评分维度。它们作为操作准入条件（日服从周）仍有意义，但对冲高幅度筛选帮助不大。

**月基带日+柱排过滤验证：** 柱排对月基带日(V4)的带动链（DXAB→DXCD→DXEF）无过滤效果。相同带动链下，柱排=升 vs 跌的P(≥3%)差距最大仅3.8pp，且方向与直觉相反（跌排时P(≥3%)反更高）。月基带日无需加柱排过滤。

### 4.5 关键启示

```
日级别最强信号：管宽 > DSHA > 鼎 > 四域日 ≈ 柱排

管宽 >10 时，次日冲高概率从 ~4% 跳跃到 ~25%~43%
这是日冲评分公式的基石指标
```

### 4.6 窄管蓄力验证（200只×160组合，VBA回测）

> **VBA模块：** `Call XL展探窄管蓄力` — 参数网格：窗口×DS顶JA×波动阈值×均线级别

| 窗口 | 均阳柱率 | 总样本 | 最佳参数 | 说明 |
|:---:|:--------:|:------:|:---------|:-----|
| **5** | **12.2%** | 1,517 | DS顶JA=12, 波动≥1%, DJB | ✅ 有效，样本充足 |

**结论：**
- 窄管条件确实有效，阳柱率从基准~4-8%提升到**12.2~16.7%**（+4~8pp）
- **DS顶JA阈值越大越好**（12优于5），说明"窄管"的初始定义过严
- 均幅涨/均幅高数据存在列偏移bug（显示-80%~-118%），**优先级较低，暂不处理**
