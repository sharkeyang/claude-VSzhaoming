## 一、日类微观指标概览

> **承接（承上启下）：** 日级别分析框架的**宏观（DXCD/DXZC/DXAB）**与**护型操作规则（里程碑）**已在[第三章（必赢操盘方法V2）](MC3.3_研究日冲策略.md)完成（3.1 起心动念 / 3.2 操盘规则体系 / 3.3 完整操盘决策树）。以下直接进入**微观指标分析**——只在护型操作范围内（✅/⚠️）做柱排/顶型/管中/特殊K线/连阳的微观精调，**不再考虑 DXCD/DXZC/DXAB 等宏观均线**。

> **概览说明：** 本章按 **管宽 → 日顶型 → 连阳 → 日柱排 → 特殊K线** 顺序，列出各微观指标的**优选条件**与**核心结论**，作为第二章微观调整工具箱的 **snapshot**（速览）；每个指标均指向第二章对应的详细讨论位置（2.x），完整定义与全量数据见第二章。

### 1.1 日类微观指标概览

#### 1.1.1 管宽（最强区分指标）

> **优选条件：** 管宽>10（P(≥3%)=24.8%，是基准的3.3倍）；管宽>40（43.1%，5.8倍）

> **核心结论：** 管宽>10时，次日冲高≥3%的概率跳跃到基准3倍以上——**这是日冲评分公式的核心维度**。DSHA也随管宽增强（大幅偏离DJA>10时 P(≥3%)=42.4%）

> **详见第二章 2.3 管中形态**

#### 1.1.2 日顶型（管上沿）

> **优选条件：** ZC>0 + 触顶（P3=31.1%）；ZC>0+触顶+BSHA≥10%（P3=54.7%）

> **核心结论：** 先看ZC方向（ZC>0才有效），再看触顶状态；合顶天数是最强单一指标（区分度16.5pp）；BSHA与触顶强正相关

> **详见第二章 2.2 日顶型**

#### 1.1.3 连阳（动量延续）

> **优选条件：** 连阳≥3（跳升点，P(≥3%)=40.6%）；连阳≥5（P(≥3%)=54.9%）

> **核心结论：** 连阳越长，下日冲高概率越高（单调递增，无衰减）——"强者恒强"。连阳第1根最弱（45.8%），连阳≥8+极强（P(≥2%)=79-89%）

> **详见第二章 2.5 连阳趋势延续**

#### 1.1.4 日柱排（方向·条件性微调）

> **优选条件：** 升排（升连/升吞），不要单阳柱

> **核心结论：** 日柱排区分度弱（升vs跌仅0.9pp），不作为独立评分维度，但作为操作准入条件（日服从周）仍有意义；关键在识别诱多

> **详见第二章 2.1 日柱排**

#### 1.1.5 特殊K线（鼎/薡/栅）

> **优选条件：** 继鼎（升连/升吞/升孕）；薡（D2e首下破）

> **核心结论：** 特殊K线作为形态参考信号，需在周类决策满足时参考，不单独做买入决策

> **详见第二章 2.4 特殊K线形态**

### 1.2 日类微观指标综合决策

> **说明（总纲参考）：** 本节的快速决策表与操作口诀为**完整判断链总纲（含宏观列参考）**，从宏观（DXCD/DXZC/DXAB）到微观（柱排/顶型/管中/连阳）的全局一览。实际微观分析时**不重复宏观判断**——宏观已在第三章（C3）完成，微观只在护型操作范围内（✅/⚠️）精调。

#### 1.2.1 微观指标交互关键规律

> **为何能分清楚高低贵贱（P3≥3%）？** 各微观维度联合把组合分出清晰的高低梯队：**管宽是决定性维度**（管宽>10 是基准3.3倍）、**BSHA是增强维度**（触顶+BSHA≥10% P3=54.7%）、**ZC方向是先决条件**（ZC>0触顶才有效）、**连阳是动量延续**（越长越强）。

**① ZC方向是先决条件**：ZC<=0时触顶几乎无效（P3=21.4% vs 20.1%），ZC>0时触顶有效（31.1%）。先看ZC方向，再看微观形态。

**② 管宽是决定性维度**：管宽>10 → P(≥3%) 24.8%（3.3x），管宽>40 → 43.1%（5.8x）。管宽与BSHA/DSHA高度联动。

**③ BSHA是顶型增强维度**：触顶+BSHA≥5%（36.1%）、触顶+BSHA≥10%（54.7%）。冲得动的触顶才是强信号，冲不动的触顶（BSHA<3%）是假信号。

**④ 连阳是动量延续**：连阳越长越强，第1根最弱（45.8%），≥3跳升（52.3%），≥5很强（64.1%），≥8极强（79-89%）。

#### 1.2.2 快速决策表（完整判断链，含宏观列）

| 场景 | 判断链 | 结果 |
|:-----|:-------|:----:|
| 最优 | ZC>0 → 甲乙己 → 触顶+BSHA≥10% → 管宽>20 → 连阳≥5 | P3≥54.7% |
| 可做 | ZC>0 → 甲乙己 → 触顶+BSHA≥5% → 管宽>10 → 连阳≥3 | P3 36-52% |
| 谨慎 | ZC>0 → 甲乙己 → 触顶（无BSHA） | P3 31% |
| 回避 | ZC<=0 → 任何形态 | P3<22% |
| 最差 | ZC>0 → 触顶+BSHA<3%（冲不动） | P3<14%（假信号） |

#### 1.2.3 一句话操作口诀

> **大势看DXZC，护型看甲乙己，冲高看BSHA，上沿看触顶合顶，动量看连阳，管宽>10是基石。**
