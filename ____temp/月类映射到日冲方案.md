# 月类映射到日冲四层：统一方案

## 周←→日映射关系

| 周级别 | 映射到日级别 | 含义 |
|:------|:-----------|:------|
| WXCD（周CD方向） | → **DXEF**（日EF战场） | 均线排列方向 |
| WXZC（周ZC位置） | → **DXZE**（日ZE位置） | 是否在DJE之上 |
| WXAB（周AB护型） | → **DXCD**（日CD护段） | 护型/护段质量 |

## 月基四域 → 日冲四层 映射对照

| 月基四域 | 周条件 | 日冲等级 | 月基操作 | 当前日冲操作 | 差异 |
|:--------|:------|:--------|:--------|:-----------|:----|
| **多长** | WXZC>0+CD>0+ZB>0 | A级(EF好+CD好+AB好) | 持有 | **主** | ✅ 一致 |
| **多长** | WXZC>0+CD>0+ZB>0 | E级(EF差+CD好+AB好) | 持有 | **主** | ✅ 一致 |
| **多被** | WXZC>0+CD≤0 | B级(EF好+CD好+AB差) | 被动持有 | **被** | ✅ 一致 |
| **多被** | WXZC>0+ZB≤0 | F级(EF差+CD好+AB差) | 被动持有 | **被** | ✅ 一致 |
| **多被** | WXZC>0+其他 | C级(EF好+CD差+AB好) | 被动持有 | **试** | ⚠️ C级应被动持有 |
| **空看** | WXZC≤0+CD>0或ZB>0 | — | 仅WXZB>0可观察 | — | 无直接对应 |
| **空长** | WXZC≤0+CD≤0+ZB≤0 | **G级(EF差+CD差+AB好)** | **完全禁止** | **试** | ❌ **严重不一致** |
| **空长** | WXZC≤0+CD≤0+ZB≤0 | **H级(EF差+CD差+AB差)** | **完全禁止** | **禁** | ✅ 一致 |

## 关键差异

### 差异1：C级（EF好+CD差+AB好）
月基→多被（被动持有），日冲→试仓。
实际风险较低（→ZE>0=82.5%），**试仓合理，不需改**。

### 差异2：G级（EF差+CD差+AB好）← 核心问题
月基→空长（完全禁止），日冲→试仓。
实际风险极高（→ZE>0=27.6%，且EF差+CD差），**应从严**。

## 修改方案：G级独立为"屎(屎中捡豆)"等级

### 新5层结构

| 层级 | 包含等级 | 原操作 | 新操作 | 对应月基 |
|:----|:--------|:------|:------|:--------|
| 🟦 **主** | A级, E级 | 主动持仓 | 主动持仓 | 多长 |
| 🟩 **被** | B级, F级 | 被动持有 | 被动持有 | 多被 |
| ⬜ **试** | C级 | 试仓 | 试仓 | 多被(弱) |
| 🟪 **屎** | **G级** | 试仓 | **屎中捡豆** | 空长 |
| 🟥 **禁** | D级, H级 | 禁止 | 禁止 | 空长/空看 |

### G级(屎)的操作规则

```
G级(屎中捡豆):
  - 条件: EF差(嘘尿屎) + CD差(下忠忑) + AB好(上中忐)
  - →ZE>0=27.6%, 无限区概率极低
  - 对应月基: 空长(WXZC≤0+CD≤0+ZB≤0)
  - 操作: 仅极小仓试错，单笔不超过总仓位1%
  - 止损: 严格以DJE为界，跌破立即清仓
  - 心理准备: 大概率亏损，目的仅为保持盘感
  - 注意: 不要因"AB好"而误判安全，AB好救不了EF差+CD差
```

### 彻底禁止的（H级+D级）

```
H级: EF差+CD差+AB差 → 三差全，绝对禁止
D级: EF好+CD差+AB差 → 禁止（属于多被，但操作上不建议）
```
