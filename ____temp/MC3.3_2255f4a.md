- 各类条件下日胜率均在 **47%~52%** 之间，接近随机

### 1.4 总结与规则

#### 1.4.1 修正后的统一模型规则

```
DXZC > 0（多头环境）：
  ┌── 己 → 最优介入 → 重仓
  ├── 甲 → 优选 → 正常介入
  ├── 乙 → 优选 → 正常介入
  ├── 戊 → 试仓 → 少量试探
  ├── 丁 → 被动持仓 → 不新开仓
  └── 丙 → 排除 → 退出观望

DXZC < 0（空头环境）：
  ┌── 己 → 唯一可操作 → 轻仓介入
  ├── 甲 → 可观察 → 勿重仓
  └── 乙丙丁戊 → 排除 → 不操作
```

#### 1.4.2 关键发现

1. **己的统治性地位：** 己在所有条件下都是最强的护型，无论DXZC正负、无论日线周线、无论哪个花册分组。涨率始终在 73%+ 以上。己的定义是"BTAB≤0 且 BTZB>0"（均线负交但短均线走强），这本质上是"回调尾声"的信号。

2. **丙的异常：** 丙在所有条件下（包括DXZC>0）都表现为负收益，夏普为-61.10。丙的定义是"BTAB>0 且 BTZB<0"（均线正交但短均线已走弱），表明护型进入衰减阶段。建议将丙直接视为"退出观望"信号，而非任何形式的持仓信号。

3. **跨周期普适性：** 日线护型排序与周线护型排序完全一致，说明DXZC+DXAB（以及WXZC+WXAB）是**基于均线的跨周期普适规律**，不依赖于时间周期。

4. **跨规模普适性：** 沪深300/中证500/中证小盘/中证非四大花册分组的护型排序完全一致（排名跨度=0），说明此规律是**跨市值规模的普遍规律**，大小盘股通用。

## 七、探索路径四：日警（风险预警）

### 7.1 偏BSHA 警告

**规则：** 不要相信偏离DJA较大的阳柱。

> 当阳柱偏离DJA幅度过大时，即使形态上看是强势突破，也容易回落。

**量化条件：**
- `DSHA`（偏离DJA的幅度）大于某一阈值
- 阳柱虽然强势，但偏离过大导致回撤风险高

**探索子项：**

- [ ] DSHA阈值多少时阳柱后续冲高概率显著下降
- [ ] 偏离DJA较大的阳柱 vs 紧贴DJA的阳柱，后续冲高概率对比

### 7.2 偏管警告

**规则：** 去掉偏离DJC>20%的DTZA=1/2。

> 当价格偏离DJC幅度超过20%时，DTZA=1或2的参考价值降低。

**条件：**
- `价格偏离DJC > 20%`
- `DTZA = 1` 或 `DTZA = 2`

### 7.3 管宽(5,15) 在DJA附近找机会

当管宽处于(5,15)时，在DJA附近找机会：

| 规则 | 说明 |
|:----|:-----|
| ❌ 不要相信DTZA过久 | DTZA值过大说明在DJA之上停留太久，动能衰竭 |
| ✅ 可以相信升排 | 升连/升吞/跌孕 → 可靠的上升信号 |
| ✅ 可以相信跌排止跌 | 跌排后止跌（十字星/小阳柱）→ 下跌衰竭信号 |
| ❌ 不要相信DTZA=1 | 要等待DTZA两柱以上，单柱站上DJA不可靠 |
| ✅ 可以相信薡/DTZA=-1/-2 | 已冲高应止盈，未冲高可以试仓 |
| ✅ 阴柱后立刻回升 | 相信阴柱后立刻回升的力度 |

**探索子项：**

- [ ] DTZA过久的阈值定义（>多少算过久？）
- [ ] 管宽(5,15)区间内不同DTZA值的胜率分布
- [ ] 升排（升连/升吞/跌孕）在管宽(5,15)下的胜率
- [ ] 跌排止跌信号的可靠性
- [ ] DTZA=1 vs DTZA≥2的可靠性对比
- [ ] 薡/DTZA=-1/-2的试仓策略胜率

#### 9.1.3 对鼎

#### 9.1.4 鼎的相关规则

**用途建议：** 并符仅是参考信号，不能作为买入决策。应在周类决策满足时参考这些信号。

### 十三.4 为什么G级需要单独处理为"傻吃屎豆"

G级（EF差+CD差+AB好）对应月基的**空看**（WXZC≤0但WXAB>0），月基允许"可观察/试仓"。但日冲策略中G级有一个致命陷阱：

**AB好的假象：** G级看起来"AB好"（上中忐），容易让人误判安全。但实际上：
- EF差（嘘尿屎）→ 当前在DJE之下，有限区
- CD差（下忠忑）→ 当前在DJC之下，ZCD全部崩坏
- 唯一亮点是AB好 → 但AB好救不了EF差+CD差
- **→ZE>0仅27.6%** → 72.4%概率次日仍在DJE之下，趋势不延续

**风险偏好陷阱：** 投资者容易因"捡漏"心理，把过多仓位放在G级这类"看起来有机会"的位置。一旦被套，轻则割肉，重则陷入主跌浪。

**取名"傻吃屎豆"的原因：** 屎中确实有豆（AB好的确偶尔能反弹），但为了一颗豆去翻屎，大概率弄一身臭。极小仓可以，重仓就是找死。

> ⚠️ **完整数据支撑（8格分类表、216分支概率表、规则验证）见** [月基带日§5](MC3.1_研究月基策略.md#第五章月基带日日级别看盘工具)

| 分类 | P≥3% | 说明 |

#### 十三.5.4 关键启示

## 十五、按形态探索

> **数据来源：** 30只股票算展文件，覆盖全部日级别行情数据
> **分析脚本：** `_产出物/MC3.9_算展批量分析_日级别阈值.py`



### 十五.1 管宽 — 最强区分指标

| 管宽 | P(≥3%) | 均HR | 样本 | 相对基准 |
|:----|:------:|:----:|:----:|:--------:|
| 0~5（极窄） | 3.7% | 0.75% | 26,044 | 0.5x |
| 5~10 | 11.8% | 1.30% | 8,381 | 1.6x |
| 10~20 | **24.8%** | **1.98%** | 3,418 | **3.3x** |
| 20~40 | **39.9%** | **3.06%** | 696 | **5.4x** |
| >40（极宽） | **43.1%** | **3.55%** | 58 | **5.8x** |

**结论：** 管宽（顶JC）是日级别最强的单一指标。管宽>10时，次日冲高≥3%的概率是基准的3倍以上。建议将管宽作为日冲评分公式的核心维度。

### 十五.2 DSHA（偏离DJA）— 与直觉相反

| DSHA | P(≥3%) | 均HR | 样本 |
|:----|:------:|:----:|:----:|
| 0~3（贴均线） | 4.1% | 0.76% | 54,203 |
| 3~5 | 12.3% | 1.29% | 14,268 |
| 5~8 | 23.2% | 1.87% | 4,979 |
| >10（大幅偏离） | **42.4%** | **3.44%** | 816 |

**结论：** 原"偏BSHA警告"假设不成立。DSHA越大后续日涨幅越大，不是回撤风险高。大幅偏离DJA的股票次日仍有更大波动，可能是趋势延续而非反转。

### 十五.3 鼎 — 区分度有限

| 鼎值 | P(≥3%) | 均HR |
|:----|:------:|:----:|
| 1~2（初现） | 8.2% | 1.02% |
| 3~4 | 7.3% | 1.01% |
| 5~6 | 8.5% | 1.03% |
| 7~8 | 9.4% | 1.10% |
| ≥9（高位） | 11.5% | 1.21% |

**结论：** 鼎值高≠要跌。鼎连续出现的衰竭信号仅对单只股票成立，不是普遍规律。鼎不适合作为日冲评分中的否决条件。

### 十五.4 四域日 / 柱排 — 区分度弱

**四域日：** 多长(8.3%) vs 空长(7.1%)，差仅1.2pp
**柱排：** 升(8.1%) vs 跌(7.2%)，差仅0.9pp

**结论：** 四域日和柱排在日级别上的预测力非常有限，不值得作为独立评分维度。它们作为操作准入条件（日服从周）仍有意义，但对冲高幅度筛选帮助不大。

**月基带日+柱排过滤验证：** 柱排对月基带日(V4)的带动链（DXAB→DXCD→DXEF）无过滤效果。相同带动链下，柱排=升 vs 跌的P(≥3%)差距最大仅3.8pp，且方向与直觉相反（跌排时P(≥3%)反更高）。月基带日无需加柱排过滤。

### 十五.5 关键启示

```
日级别最强信号：管宽 > DSHA > 鼎 > 四域日 ≈ 柱排

管宽 >10 时，次日冲高概率从 ~4% 跳跃到 ~25%~43%
这是日冲评分公式的基石指标
```

### 十五.6 窄管蓄力验证（200只×160组合，VBA回测）

> **VBA模块：** `Call XL展探窄管蓄力` — 参数网格：窗口×DS顶JA×波动阈值×均线级别

| 窗口 | 均阳柱率 | 总样本 | 最佳参数 | 说明 |
|:---:|:--------:|:------:|:---------|:-----|
| **5** | **12.2%** | 1,517 | DS顶JA=12, 波动≥1%, DJB | ✅ 有效，样本充足 |
| 10 | 16.7% | 272 | DS顶JA=5~8, DJB | ⚠️ 样本偏少 |
| 15/20 | — | <50 | 样本不足 | ❌ 不可靠 |

**结论：**
- 窄管条件确实有效，阳柱率从基准~4-8%提升到**12.2~16.7%**（+4~8pp）
- **DS顶JA阈值越大越好**（12优于5），说明"窄管"的初始定义过严
- 均幅涨/均幅高数据存在列偏移bug（显示-80%~-118%），**优先级较低，暂不处理**
