### 3.7.7 WXCD×护型转坏率与转好率矩阵

> **核心问题：** 按WXCD六域×护型，各护型的转坏率（向更差转移或维持在最差）和转好率（转为甲或乙(ZA>0)）是多少？
> 数据：高波池（Qic+Qim+Qit）3451 只，周线全量。

#### 3.7.7.1 定义

**转坏率** = 当前护型向更差护型转移的概率 + 维持在最差护型的概率

| 当前护型 | 转坏去向 | 说明 |
|:--------|:---------|:------|
| 甲 | →乙(ZA≤0)、→丙、→丁 | 向弱转坏 |
| 乙(ZA>0) | →乙(ZA≤0)、→丙、→丁 | ZA转负或直接恶化 |
| 乙(ZA≤0) | →丙、→丁 | 继续恶化 |
| 丙 | →丁 | 死亡螺旋 |
| 丁 | →戊(ZA>0)、→戊(ZA≤0) | 向死水转移 |
| 戊(ZA>0) | →戊(ZA≤0) | ZA转负 |
| **戊(ZA≤0)** | **维持戊(ZA≤0)** | **已最差，维持也算转坏** |
| 己 | →戊(ZA>0)、→戊(ZA≤0) | 转弱 |

**转好率** = 当前护型转为甲或乙(ZA>0)的概率
- 甲和乙(ZA>0)已最优，转好率 = 维持率
- 其他护型只算→甲或→乙(ZA>0)，不算→己或其他

#### 3.7.7.5 关键发现

**① 转坏率最高的组合（应回避）：**
- 嘘/尿 + 丙：75-77%（几乎必转丁）
- 嘘/尿 + 戊(ZA≤0)：76-84%（死水，维持在最差）
- 嘘/尿 + 乙(ZA≤0)：54-58%（超一半概率恶化）
- 嘘 + 甲/乙(ZA>0)：40-41%（即使在好护型，嘘下也危险）

**② 转好率最高的组合（应关注）：**
- 银/唏 + 己：71-72%（→甲或乙(ZA>0)）
- 金 + 己：56%（→甲）
- 金/银 + 甲：83-87%（维持正交）
- 金/银 + 乙(ZA>0)：80-83%（维持正交）

**③ 戊(ZA≤0)的转坏率=维持率（53-84%）**——已最差，维持戊(ZA≤0)本身就是坏情况。这是死水，不应持有。
