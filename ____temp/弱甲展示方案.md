# 弱甲展示方案

## 目标

在现有 4 强（龙强/雀强/虎强/武强）的基础上，新增 4 个弱甲分类：
- 日冲策略为"弱"，但 DXAB ∈ {上,中,忐}（甲乙己）的标的

## 改动

### 1. 神谕模块（据擎2神谕.bas）— 日冲策略输出格式

在现有 日冲分类 后追加后缀"甲"：

```vba
' 日冲分类 = 战场 & 强弱
日冲分类 = 日冲战场 & 日冲强弱
' 弱且AB好时加"甲"后缀
If 日冲强弱 = "弱" Then
    If 日AB护级 = "上" Or 日AB护级 = "中" Or 日AB护级 = "忐" Then
        日冲分类 = 日冲分类 & "甲"
    End If
End If
```

效果：
- 龙强/雀强/虎强/武强 → 不变
- 龙弱 + AB好 → **"龙弱甲"**
- 龙弱 + AB差 → "龙弱"（不变）

**优势：** 现有筛选 InStr(日冲策名, "龙弱") > 0 仍能匹配到"龙弱甲"，不影响现有逻辑。

### 2. 筛选模块（展擎1筛选.bas）— 新增 4 个典码

在现有 4 个典日策_XX强 旁边，新增 4 个：

```vba
Dim 典日策_龙弱甲 As New Dictionary  '日冲龙弱+AB好(甲乙己)
Dim 典日策_雀弱甲 As New Dictionary  '日冲雀弱+AB好(甲乙己)
Dim 典日策_虎弱甲 As New Dictionary  '日冲虎弱+AB好(甲乙己)
Dim 典日策_武弱甲 As New Dictionary  '日冲武弱+AB好(甲乙己)
```

在筛选循环中，弱甲也要在 BTZC>0 的门内：

```vba
If 谕组(X, 位谕of日类BTZC) > 0 Then
    日冲策名 = 谕组(X, 位谕of日冲策略)
    If InStr(日冲策名, "龙强") > 0 Then
        典日策_龙强.Add ...
    ElseIf InStr(日冲策名, "龙弱甲") > 0 Then
        典日策_龙弱甲.Add ...
    ElseIf InStr(日冲策名, "雀强") > 0 Then
        ...
    ElseIf InStr(日冲策名, "雀弱甲") > 0 Then
        典日策_雀弱甲.Add ...
    ...
    End If
End If
```

### 3. 筛选模块 — 输出页面

在现有 4 个强输出之后，新增 4 个弱甲输出：

```vba
Call IQQQ展擎出程至页(WB, 表名, 谕组, _
     强列:=位谕of日冲策分, 强序:=xlDescending, _
     章色:=常色八43, _
     典码输出:=典日策_龙弱甲, _
     区签:="【日冲】龙弱甲(龙弱+AB好)", 区色:=常色八43)
```

## 需要注意的问题

**BTZC>0 门槛：** 弱类（DXCD∈{下,忠,忑}）的股票，ZC 大概率 ≤ 0。如果保持 BTZC>0 门槛，弱甲典码里可能只有很少的标的。是否要放低这个门槛，或者直接去掉？需要你决定。

**选项 A：** 保持 BTZC>0 → 弱甲数量少但质量高
**选项 B：** 去掉 BTZC>0 → 弱甲数量多但质量参差
**选项 C：** 弱甲单独设门槛（如 BTZC>0 or BTZE>0）→ 折中
