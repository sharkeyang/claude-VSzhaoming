### 3.7.6 柱排信号：跌吞/跌连对甲乙(WXZC>0)的影响

> **核心问题：** 甲乙(WXZC>0)时，若出现跌吞或跌连，是否应退出？
> 数据：高波池（Qic+Qim+Qit）3451 只，周线全量。跌吞=柱排以"跌"开头且含"吞"，跌连=柱排以"跌"开头且含"连"。

#### 3.7.6.1 转坏率定义

转坏率 = **当前护型向更差护型转移的概率**。各护型的转坏去向定义：

| 当前护型 | 转坏去向（更差的护型） |
|:--------|:-------------------|
| **甲** | →乙(ZA≤0)、→丙、→丁 |
| **乙(ZA>0)** | →乙(ZA≤0)、→丙、→丁 |
| **乙(ZA≤0)** | →丙、→丁 |
| **丙** | →丁 |
| **丁** | →戊(ZA>0)、→戊(ZA≤0) |
| **戊(ZA>0)** | →戊(ZA≤0)、→丙 |
| **戊(ZA≤0)** | →丙 |
| **己** | →戊(ZA>0)、→戊(ZA≤0)、→丙 |

计算方法：`转坏率 = 该护型转坏的总样本数 ÷ 该护型的总样本数 × 100%`

注意：转坏率 ≠ 1 - 维持率。因为还有"转好"和"其他转移"：
`维持率 + 转好率 + 转坏率 + 其他率 = 100%`

#### 3.7.6.2 甲(WXZC>0) + 跌吞/跌连

| 指标 | 正常（非跌排） | 跌吞 | 跌连 |
|:----|:-------------:|:----:|:----:|
| 样本 | 423,318 | 3,893 | 35,625 |
| 下周均HR | 6.61% | 5.09% | 5.47% |
| 下周涨率 | 93.5% | 92.0% | 92.6% |
| 下周HR≥3% | **63.0%** | **55.0%** | **57.9%** |
| 下周HR≥5% | 45.6% | 37.2% | 40.1% |
| **转坏率** | **15.9%** | **46.8%** | **39.0%** |

**跌吞时甲转坏率从 15.9% 飙升至 46.8%（+30.9pp），跌连时升至 39.0%（+23.1pp）。**

#### 3.7.6.3 乙(ZA>0)(WXZC>0) + 跌吞/跌连

| 指标 | 正常（非跌排） | 跌吞 | 跌连 |
|:----|:-------------:|:----:|:----:|
| 样本 | 285,483 | 1,819 | 17,519 |
| 下周均HR | 6.39% | 5.08% | 5.63% |
| 下周涨率 | 93.5% | 91.1% | 93.0% |
| 下周HR≥3% | **63.3%** | **55.7%** | **59.7%** |
| 下周HR≥5% | 45.7% | 37.4% | 41.6% |
| **转坏率** | **20.0%** | **49.8%** | **41.0%** |

**跌吞时乙转坏率从 20.0% 飙升至 49.8%（+29.8pp），跌连时升至 41.0%（+21.0pp）。**

#### 3.7.6.4 操作建议

| 条件 | 操作 | 理据 |
|:----|:----|:------|
| **甲(WXZC>0) + 跌吞** | **🔴 立即退出** | 转坏率46.8%，是正常的3倍 |
| **甲(WXZC>0) + 跌连** | **🔴 退出** | 转坏率39.0%，是正常的2.5倍 |
| **乙(ZA>0)(WXZC>0) + 跌吞** | **🔴 立即退出** | 转坏率49.8%，是正常的2.5倍 |
| **乙(ZA>0)(WXZC>0) + 跌连** | **🔴 退出** | 转坏率41.0%，是正常的2倍 |

**跌吞比跌连更严重**——跌吞时转坏率接近 50%，相当于抛硬币有一半概率下周转坏。跌连稍好但转坏率仍高达 39-41%。

**结论：甲乙(WXZC>0)出现跌吞或跌连，应退出。** 跌吞是更强烈的退出信号。
