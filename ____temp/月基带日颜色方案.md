# 月基带日颜色方案（调整版）

## 三大类

| 大类 | 色系 | 包含 | 等级顺序 |
|:----|:----|:-----|:---------|
| **必须参与** | 🟢 绿系 | S级、A级、B级 | 深绿→中绿→浅绿 |
| **观察** | 🔵 蓝系 | C级、D级、E级、F级 | 深蓝→中蓝→浅蓝→最浅蓝 |
| **禁止** | 🔴 红系 | 禁止级 | 深红（仅一级） |

## 颜色映射表

| 等级 | 底色 | 常色常量 | RGB | 条件 |
|:----|:----|:---------|:----|:------|

## 判断逻辑

```
EF好(金银唏) ─┬─ CD好(上中忐) ─┬─ AB好 → S级(常色四绿)  必须参与
               │                └─ AB差 → A级(常色六绿)  必须参与
               │
               └─ CD差(下忠忑) ─┬─ AB好 → B级(常色八绿)  必须参与
                                └─ AB差 → C级(常色四蓝)  观察

EF差(嘘尿屎) ─┬─ CD好(上中忐) ─┬─ AB好 → D级(常色六蓝)  观察
               │                └─ AB差 → E级(常色八蓝)  观察
               │
               └─ CD差(下忠忑) ─┬─ AB好 → F级(常色十蓝)  观察
                                └─ AB差 → 禁止级(常色四红) 禁止
```
