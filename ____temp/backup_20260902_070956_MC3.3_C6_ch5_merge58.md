> **定位：** 这是日类第三阶段（微观指标微调）的具体落地——在护型操作范围内，用微观指标判断"甲是否即将转乙（DXZA<0）"以及"甲 DXZA>0 时是否该提前退出"。数据：谕组日全量约 2020 万样本。
>
> **框架衔接：** 见 `MC3.3_C2日DXZC+DXAB全维度分析.md` 第四章 §4.3（日类三阶段框架的第三阶段）。C2 第四章 §4.4 仅保留概括性叙述与计划，详细微观数据与本处一致。

### 5.1 预警护型甲转坏

> **主题：** 甲 是好的稳定态（已有结论）。甲 脱离稳定态（转坏）都是不好的，需预警。下设三个子节：甲转乙（5.1.1）、甲DXZA>0退出（5.1.2）、VBA落地（5.1.3）。

#### 5.1.1 甲转乙（DXZA<0）的微观指标映射


甲总数 419 万，甲转乙（DXZA<0）40.9 万，**总转乙率 9.75%**：

| 微观指标 | 高转乙率（预示甲→乙）| 低转乙率（甲稳定）|
|:--|:--|:--|
| **日柱排** | 跌.尾连VW.W2 **29.5%**、跌.尾连vW.W2 21.7%、(升)人.连后吞QV 18.2%（跌排/连后吞=跌吞）| 升.尾连QQ.Q3 3.4%、升.尾连OQ.Q2 3.7%（升排稳定）|
| **日地型** | 3桮 **19.2%**、2栅 14.0%、1柜 12.6%（含杂/含W）| 0橅 5.5%（纯QOov）|
| **盈提示** | 宽 **29.8%**、宽偏 15.5%、偏 13.3% | a高 3.2%、a连3 3.2%、a连4 2.6%（a系稳定）|
| **日等型** | 等12 16.3%、等9 15.8%、等10 16.3%、等8 15.6%、等7 14.8%（高等等型）| 等2 3.2%、等3 5.9%（低等等型稳定）|
| **日顶型** | 上a 11.0%、无 8.9% | 下a 4.9%、中a 4.5% |

**结论：甲在跌排（跌吞）、地型桮/栅、盈提示宽、高等等型（等8+）时更易转乙（DXZA<0）——预示"甲即将转乙"，应警惕退出/减仓；升排、0橅地型、盈提示a系、低等等型时甲稳定，可继续持有。**

#### 5.1.2 甲 DXZA>0 时哪些指标预示"该退出"


甲保持 DXZA>0 时，次日转差率（次日不再是甲/乙(ZA>0)）：

| 微观指标 | 高转差率（预示甲应退出）| 低转差率（甲稳定可持有）|
|:--|:--|:--|
| **日柱排** | 跌.尾连vW.W2 **35.0%**、(升)人.连后吞QV 30.8%、升.尾反孕vOv 22.9%（跌排/连后吞/反孕）| 升.尾连QQ.Q6 3.7%、QQ.Q4 4.5%、QQ.Q5 4.3%（升连稳定）|
| **日地型** | 3桮 **30.7%**、2栅 22.9%、1柜 20.9%（含杂/含W）| 0橅 9.4%（纯QOov）|
| **日顶型** | 中a **38.2%**、下a 36.4%、忑a 27.2%（下/中/忑顶）| 上a 16.5%、忐a 10.7%（上/忐顶稳定）|
| **日等型** | 等10 19.5%、等14 19.4%、等8 19.2%（高等等型）| 等1 6.3%、等2 8.2%（低等等型稳定）|
| **盈提示** | 空 **26.9%**、雀 17.4%、偏 16.9%（无盈/雀/偏）| a连3高 2.0%、a连4 1.6%、a连4高 1.6%（a连系稳定）|

> **① vs ② 的差异（顶型）：** ①甲转乙（DXZA<0）时"上a"略高（11.0%）；②甲保持 DXZA>0 的转差时"下/中/忑顶"最危险（38.2%/36.4%/27.2%）。**综合：甲 DXZA>0 时，跌排/桮栅/高等等型/盈空偏/下中顶 → 应警惕退出。**

#### 5.1.3 日层机警写入方案（VBA 落地）


> **目的：** 把 §5.1.1/§5.1.2 的甲转乙/甲DXZA>0转差微观指标预警，写入日层机警变量（微观指标展示变量）。
> ⚠️ **不改正式 VBA**——需验证副本（____temp）跑通后由用户手动导入正式版。

**现状（神谕.bas L3825-3839）：** 日层机警只输出 `等3顶`/`等3`/`开门` 三个信号。

**方案：在现有信号基础上，叠加"甲转乙预警"信号：**

```vba
'--- 在 谕组(X, 位谕of日层机警) = 等机警 之前，追加甲转乙预警 ---
Dim 日护型 As String: 日护型 = 组结算(X, 基位日类 + 位os层护型AB)
Dim 日柱排 As String: 日柱排 = 谕组(X, 位谕of日层柱排)
Dim 日地型 As String: 日地型 = Left$(谕组(X, 位谕of日层波型), 2)   '0橅/1柜/2栅/3桮
Dim 日盈 As String: 日盈 = 谕组(X, 位谕of日盈提示)
'--- 甲 + DXZA>0 + 命中跌排/桮栅/盈空偏/高等等型 → 甲转乙预警 ---
If InStr(日护型, "甲") > 0 And 日类BTZA > 0 Then
    Dim 转乙预警 As Boolean: 转乙预警 = False
    If InStr(日柱排, "跌") > 0 Or InStr(日柱排, "吞") > 0 Then 转乙预警 = True
    If InStr(日地型, "桮") > 0 Or InStr(日地型, "栅") > 0 Then 转乙预警 = True
    If 日盈 = "" Or InStr(日盈, "偏") > 0 Or InStr(日盈, "雀") > 0 Then 转乙预警 = True
    If InStr(等值, "等") > 0 And Val(Mid$(等值, 2)) >= 8 Then 转乙预警 = True
    If 转乙预警 Then 等机警 = "甲转乙预警"
End If
```

**落地步骤（待用户确认）：** ① ____temp 验证副本改神谕.bas 验证 → ② 用户手动导入正式版（vba2EXCEL）→ ③ 重导出谕组日 CSV。

> 注：`位谕of日层柱排`/`位谕of日盈提示` 等常量需按 VBA 实际命名核对（神谕.bas 族日层定义）。

#### 5.4.1 全样本基准：触顶/合顶/护型

### 5.11 日层机警 VBA 落地：新增"冲顶星"最强信号

> **目的：** 将 §5.10 的最强信号（触顶 + 十字星无长上影 + BSHA≥8 ≈ 85% 次日冲高）写入系统的 **日层机警** 字段，使筛选/回测可直接读取。

**① 日层机警 原有逻辑（`IQQQ跨码_D据擎2神谕.bas` L3825-3839）：**

| 机警值 | 触发条件 |
|:--|:--|
| 等3顶 | 等3 + ZC>0 + 顶型含龙 + 上符末位A |
| 等3 | 等3 + ZC>0 |
| 开门 | ZC>0 + CD>0 |
| （空） | 其余 |

**② 新增最高优先级信号"冲顶星"（2026-08-31 写入）：**

| 机警值 | 触发条件（全部满足） |
|:--|:--|
| **冲顶星** | **ZC>0 + 触顶(上符末位A) + BSHA≥8 + 十字星(无长上影)** |

- 十字星(无长上影) 判断：`实体=Abs(今收-今开)`，`全幅=今高-今低`，`上影=今高-Max(今收,今开)`；`全幅>0 And 实体<0.1*全幅 And 上影<=2*实体`
- **优先级最高**：若触发"冲顶星"，则不再覆盖为 等3/开门（先判冲顶星，未触发才回退等高线机警）

**③ VBA 实现（已在 `IQQQ跨码_D据擎2神谕.bas` L3825-3849）：**

```vba
'--- 最强信号：触顶+十字星(无长上影)+BSHA≥8 → 高概率次日冲高（C6§5.10 约85%） ---
If 日类BTZC > 0 And Right$(等上符, 1) = "A" Then
    If Val(谕组(X, 位谕of日层BSHA)) >= 8 Then
        Dim 实体 As Double: 实体 = Abs(日类今收 - 日类今开)
        Dim 全幅 As Double: 全幅 = 日类今高 - 日类今低
        Dim 上影 As Double: 上影 = 日类今高 - IIf(日类今收 > 日类今开, 日类今收, 日类今开)
        If 全幅 > 0 And 实体 < 0.1 * 全幅 And 上影 <= 2 * 实体 Then
            等机警 = "冲顶星"
        End If
    End If
End If
'--- 若未触发最强信号，回退到等高线机警 ---
If 等机警 = "" Then
    ' 原有 等3顶/等3/开门 逻辑不变
    ...
End If
谕组(X, 位谕of日层机警) = 等机警
```

**④ 使用说明：**
- **日层机警 = "冲顶星"** → 最强单日介入信号（次日冲高率约 85%），可作筛选/回测的高优买入条件
- **日层机警 = "等3顶"** → 次强（等高线龙头触顶）
- 该字段已通过 CSV [19] 日机警 导出（若导出代码含该列），可直接 Python 读取

> **注意：** 此 VBA 修改在 `昭明计划VS优化_vba/IQQQ跨码_D据擎2神谕.bas`（已提交）。**需用户 `vba2EXCEL` 导入正式版并重新跑算展后，日层机警字段才会输出"冲顶星"。** Claude 不导入正式 Excel（铁律）。

### 6.2 日柱排

> **核心原则：** 日柱排才是关键。要选**升排**（升连/升吞），不要选单阳柱。单阳柱特别是升吞形态，很有可能是诱多。
>
> 本节研究日柱排的各类形态，以及如何识别诱多信号。

#### 6.2.1 升排 vs 单阳柱

**升排（可靠信号）：**
- 升连：连续阳柱，趋势确认
- 升吞：阳柱吞没前阴，但需警惕诱多
- 跌孕：阴柱后小阳/十字星，止跌信号

**单阳柱（不可靠信号）：**
- 单阳柱可能是诱多，特别是升吞形态
- 单阳柱后需等待确认（回踩/跌孕/第二根阳柱）
- 单阳柱+触顶 → 假突破概率高

#### 6.2.2 诱多识别

**升吞诱多特征：**
- 单根阳柱吞没前阴，但后续无延续
- 出现在高位（远离DJA）时诱多概率高
- 升吞+BSHA<3% → 冲不动，假信号
- 升吞+ZC≤0 → 逆势反弹，大概率诱多

**单阳柱诱多特征：**
- 单阳柱后次日即阴柱（一日游）
- 单阳柱+触顶 → 冲高回落
- 单阳柱+宽哼JC<5（刚突破哼JA）→ 未站稳，诱多

**防诱多规则：**
1. 不追单阳柱，至少等第二根阳柱确认
2. 升吞必须有后续升连或跌孕确认
3. 高位（等3以上）升吞一律视为诱多，除非BSHA≥5%
4. ZC≤0时的任何阳柱都视为反弹，不参与

#### 6.2.3 基本突破回踩


**条件：**
- 刚突破DJA（价格由下向上穿越DJA）
- 连阳后跌孕（突破以连阳完成，随后回调跌孕）
- 既是升排，又有DJA支撑

#### 6.2.4 突破后的启动结构


- 第一柱：上破DJA（阳柱突破）
- 第二柱：跌孕（回踩确认）
- 第三柱：继鼎（继续上升）

#### 6.2.5 潜在四柱栅


**条件：**
- DJA之上
- 中阳后跌孕
- 跌孕后小阳
- 构成四柱栅形态

#### 6.2.6 悬阳升连


**条件：**
- DXAB正交
- 从DJA之下以阳柱上破DJA
- 在DJA之上出现悬空/十字星/小阳柱/小阴柱

#### 6.2.7 向上突破


| 回踩信号 | 说明 |
|:---------|:-----|
| 回踩跌孕 | 突破后以跌孕形态回踩，确认支撑 |

**策略一：找下跌之后的止跌再升**

### 6.3 日顶型

> 基于日CSV上符串数据，研究触顶/触哼/合顶对下日冲高的预测能力。<br>
> 数据源：日CSV列30（上符串）、列29（上符范）、列43（顶型）、列22（宽哼JC）等。<br>
> 验证日期：2026-08-22，**高波池（Qic+Qim+Qit）全量**，11,031,366 样本。<br>
> 指标定义：P3 = 下日高幅（次日高幅）>= 3% 的概率；期望HR = 下日高幅均值。<br>
> 触顶 = 上符串末位为 'A'（今天创新高）；触哼 = 上符串末位为 'B'（触到哼JA）；强触顶 = BSHA>=5 且 触顶。<br>
> 合顶天数 = 从上符串末位开始往左数连续A的个数。

> **核心逻辑链（一句话）：** ZC>0 是前提 → 触顶是信号 → 合顶天数定强度 → BSHA/宽哼JC 增强 → 等高线定位置 → 综合操作。<br>
>
> **最关键的 3 个发现：**<br>
> ① **ZC 方向是总开关**——ZC<=0 时触顶无效，ZC>0 时触顶才有效（见 §6.3.2）；<br>
> ② **合顶天数是最强单一指标**——区分度 16.5pp，5天全触顶 P3=39%（见 §6.3.3）；<br>
> ③ **合顶的意义在趋势延续**——合顶5天未来20天累计收益 453%（见 §6.3.7）。

#### 6.3.1 上符串编码与基础定义

**上符串（日CSV列30）：** 5位滚动记录，末位=今天，每位含义：
- `A` = 触顶（创新高）
- `B` = 触哼（触到哼JA）
- `v` = 触哈
- `_` = 无触顶

**上符范（日CSV列29）：** 编码值，含触顶次数/触哼次数等信息。

**顶型（日CSV列43）：** 龙/雀/虎/篪/武等分类。

**宽哼JC（日CSV列22）：** 当前价格距哼JA的百分比距离。

#### 6.3.4 触顶增强维度

> 以下分析均在 ZC>0+今天触顶 条件下，各维度对P3的增强效果。

##### 6.3.4.1 BSHA（冲高幅度）

**BSHA（当日高幅）与触顶后的P3强正相关，区分度极高。** 触顶当天的冲高幅度越大，下日继续冲高的概率越高。

| BSHA | P3 | 样本 | 判断 |
|:----:|:--:|-----:|:----|
| 0~1% | 20.7% | 6,433 | ⚠️ 样本少 |
| 1~2% | 7.4% | 84,218 | ❌ 极弱 |
| 2~3% | 13.1% | 193,823 | ❌ 弱 |
| 3~5% | 21.6% | 452,345 | ⚠️ 接近基线 |
| **5~10%** | **36.1%** | 651,618 | ✅ 强信号 |
| **>=10%** | **54.7%** | 281,002 | ✅ 极强信号 |

**BSHA>=5%+触顶是最强组合之一（P3=36.1%），BSHA>=10%+触顶更是高达54.7%。** 而BSHA<3%+触顶几乎无效（P3<14%），说明"冲不动的触顶"是假信号。

##### 6.3.4.2 宽哼JC（管宽）

**宽哼JC（距哼JA的距离）与触顶后的P3强正相关。** 触顶时离哼JA越远，下日冲高概率越高。

| 宽哼JC | P3 | 样本 | 判断 |
|:-----:|:--:|-----:|:----|
| <5（刚突破） | 15.3% | 411,315 | ❌ 弱 |
| 5~20 | 31.9% | 1,030,867 | ✅ 正常 |
| **>=50%** | **56.0%** | 227,257 | ✅ 极强信号 |

**宽哼JC>=20时P3=56.0%**，说明触顶时已远离均线很远，趋势极强。宽哼JC<5时P3仅15.3%，说明刚突破哼JA时触顶信号弱。

##### 6.3.4.3 等高线（位置）

**等高线在ZC>0+触顶条件下仍有区分度。** 等1/等2（刚站上DJA附近）触顶最强，等3（远离DJA）最弱。

| 等高线 | P3 | 样本 | 判断 |
|:-----:|:--:|-----:|:----|
| **等1** | **34.9%** | 95,966 | ✅ 刚站上DJA+触顶，最强 |
| **等2** | **32.7%** | 245,130 | ✅ 回归DJA+触顶 |
| 等3 | 30.6% | 1,307,747 | ⚠️ 一般 |
| 等5 | 27.4% | 18,616 | ⚠️ 弱（样本少） |
| 等6 | 22.3% | 1,270 | ❌ 弱（样本少） |
| 等7 | 22.3% | 710 | ❌ 弱（样本少） |

**等1/等2（DJA附近）触顶远强于等3（远离DJA）触顶。** 等1=34.9% vs 等3=30.6%，差4.3pp。说明在DJA附近触顶是有效突破，远离DJA后触顶是强弩之末。

##### 6.3.4.4 柱体形态（叠幅/上身）

**叠幅（当日涨跌幅）与触顶后的P3强正相关。** 触顶当天涨幅越大，下日冲高概率越高。

| 叠幅 | P3 | 样本 | 判断 |
|:----:|:--:|-----:|:----|
| 叠幅<0（阴线触顶） | 样本不足 | — | — |
| 叠幅0~3% | 3.8% | 10,856 | ❌ 极弱 |
| 叠幅3~5% | 8.4% | 103,633 | ❌ 弱 |
| 叠幅5~10% | 18.8% | 555,756 | ⚠️ 一般 |
| **叠幅>=10%** | **40.4%** | 991,453 | ✅ 强信号 |

**结论：叠幅与BSHA高度相关（大涨的柱叠幅也大），叠幅本身不是独立信号，BSHA更直接。**

##### 6.3.4.5 顶型（龙/雀/虎）

**顶型在ZC>0+触顶条件下区分度有限。** 只有a龙（33.2%）和非龙（25.3%）之间有7.9pp差距。

| 顶型 | P3 | 样本 | 判断 |
|:----|:--:|-----:|:----|
| **a龙** | **33.2%** | 1,227,349 | ✅ 主升龙，最强 |
| e非（非龙） | 25.3% | 442,090 | ⚠️ 弱 |

**结论：在ZC>0+触顶条件下，顶型的边际贡献7.9pp，不如BSHA和宽哼JC有价值。**

#### 6.3.5 触顶后行为

##### 6.3.5.1 合顶中断后的走势

**合顶中断（昨天触顶+今天不触顶）本身不是危险信号（P3=29.9%），但结合跌幅有区分度。**

| 条件 | P3 | 样本 | 判断 |
|:----|:--:|-----:|:----|
| 合顶中断（无条件） | 29.9% | 765,710 | ⚠️ 接近基线 |
| 合顶中断+**跌幅>3%** | **37.5%** | 151,391 | ✅ **暴跌后反弹，强信号** |
| 合顶中断+跌幅1~3% | 24.7% | 238,044 | ⚠️ 一般 |
| 合顶中断+跌幅0~1% | 19.9% | 146,624 | ❌ 微跌，弱 |
| 合顶中断+上涨 | 27.9% | 237,500 | ⚠️ 一般 |

**合顶中断+跌幅>3%是强信号（P3=37.5%），说明暴跌后次日反弹概率高。** 而微跌（0~1%）后P3=19.9%最弱，说明"慢慢跌"比"暴跌"更危险。

##### 6.3.5.2 触顶后次日是否还能触顶

**今天触顶→明天也触顶的概率为50.7%。** 宽哼JC越小，明天继续触顶的概率越高。

| 条件 | 明天触顶概率 | 样本 |
|:----|:-----------:|-----:|
| 宽哼JC<5 | **58.7%** | 411,315 |
| 宽哼JC 5~20 | 48.9% | 1,030,867 |
| 宽哼JC>=20 | 51.2% | 227,257 |

**宽哼JC<5时，明天继续触顶的概率接近60%**，说明刚突破哼JA时趋势延续性最强。

#### 6.3.6 触顶信号 vs 日策略P2 / 日层段 一致性

##### 6.3.6.1 触顶信号 vs 日策略P2（等高线+BSHA）

日策略P2 = 等高线 + BSHA（偏5/偏3）+ 连阳/层主/升排/跌排。它已包含BSHA信息，但**未包含触顶信息**。

**偏5（BSHA>=5）中触顶占比62.3%**，两者高度一致。

| 条件 | P3 | 样本 |
|:----|:--:|-----:|
| 等1+偏5+触顶 | 43.6% | 53,290 |
| 等2+偏5+触顶 | 43.8% | 127,812 |
| 等3+偏5+触顶 | 41.2% | 744,147 |

**关键发现：在偏5（BSHA>=5）条件下，触顶的边际贡献有限。** 因为BSHA>=5本身已是强信号（P3~41%），触顶与否的差异不大。

##### 6.3.6.2 触顶信号 vs 日层段

> 日层段定义（持主/持被/卖浮）见 [MC3.3.1_日类必赢算法.md §2.6](MC3.3.1_日类必赢算法.md#26-日层段细分持主持被卖浮)。

**触顶信号与日层段高度一致：**

| 条件 | P3 | 样本 | 判断 |
|:----|:--:|-----:|:----|
| **持主+强触顶(BSHA>=5)** | **43.0%** | 752,387 | ✅ 最强 |
| 持被+强触顶 | 42.0% | 6,047 | ✅ 强（样本少） |
| 持主+触顶 | 33.9% | 1,215,024 | ✅ |
| 持被+触顶 | 28.1% | 14,972 | ⚠️ |

**强触顶信号中持主占绝大多数**，触顶信号几乎都发生在持主阶段。

##### 6.3.6.3 结论

1. **触顶信号与日策略P2一致**：偏5信号中触顶占比高，但偏5本身已足够强，触顶的边际贡献小
2. **触顶信号与日层段一致**：强触顶信号主要出现在持主，持主+强触顶=43.0%最强
3. **日层段是比触顶更强的过滤条件**：持主+强触顶=43.0% vs 持被+强触顶=42.0%，差1.0pp

#### 6.3.7 合顶周期（趋势延续）

##### 6.3.7.1 核心发现：合顶不是看单日，而是看整个周期

之前验证"合顶天数×下日P3"发现合顶天数越长P3越高，但那是**只看下日冲高**（单日）。**合顶的真正意义在于"趋势延续"**——从合顶开始到离顶结束的整个周期，累计收益显著。

##### 6.3.7.2 合顶天数 × 未来N天累计收益

| 合顶天数 | 未来1天 | 未来3天 | 未来5天 | 未来10天 | 未来20天 |
|:-------:|:------:|:------:|:------:|:-------:|:-------:|
| 1天 | 16.18% | 34.45% | 43.82% | 88.05% | 150.84% |
| 2天 | 14.84% | 41.78% | 48.59% | 108.61% | 171.49% |
| 3天 | 18.59% | 49.05% | 63.18% | 149.48% | 222.64% |
| 4天 | 36.03% | 61.57% | 87.10% | 191.83% | 272.59% |
| **5天** | **55.09%** | **139.87%** | **207.67%** | **357.87%** | **453.04%** |

**合顶天数越长，未来累计收益越高。** 合顶5天 vs 合顶1天：
- 未来5天：207.67% vs 43.82%（差163.85pp）
- 未来10天：357.87% vs 88.05%（差269.82pp）
- 未来20天：453.04% vs 150.84%（差302.20pp）

##### 6.3.7.3 合顶天数 × 未来N天冲高>=3%概率

| 合顶天数 | 未来1天 | 未来3天 | 未来5天 | 未来10天 |
|:-------:|:------:|:------:|:------:|:-------:|
| 1天 | 26.5% | 53.1% | 66.7% | 82.7% |
| 2天 | 28.6% | 55.3% | 68.8% | 83.9% |
| 3天 | 30.6% | 57.3% | 70.6% | 84.8% |
| 4天 | 31.8% | 59.1% | 72.2% | 85.6% |
| **5天** | **37.5%** | **64.6%** | **76.2%** | **87.4%** |

**任何合顶天数下，未来5天冲高>=3%的概率都超过66%！** 未来10天更是超过82%。

##### 6.3.7.4 结论

1. **合顶周期是有效的**——合顶天数越长，未来累计收益越高（合顶5天未来20天=453%）
2. **合顶开始是入场信号**——合顶开始后未来5天冲高>=3%概率66.7%+
3. **合顶的意义在于"趋势延续"**——连续创新高代表趋势强，未来N天累计收益高

#### 6.3.9 综合操作规则

> 基于全部验证结果，按优先级排序。

```
第一层：ZC方向（最重要）
  ZC<=0 → 不参与，无论是否触顶（P3<22%）

第二层：触顶状态（ZC>0范围内）
  今天未触顶 → 非主升（P3=25.7%），不参与
  今天触顶 + BSHA<3% → 假信号（P3<14%），不参与
  今天触顶 + BSHA>=5% → 强信号（P3=36.1%），可参与
  今天触顶 + BSHA>=10% → 极强信号（P3=54.7%），优先参与

第三层：触顶频率（排除震荡偶尔触顶）
  5天中触顶>=3次 → 主升确认（P3=30.9%）
  5天全触顶 → 强主升（P3=39.0%）

第四层：位置确认
  等高线=等1/等2（DJA附近）→ 有效突破（P3=33%+）
  等高线=等3（远离DJA）→ 强弩之末（P3=30.6%）

第五层：持仓判断
  宽哼JC<5 → 刚突破，趋势延续性强（明天触顶概率58.7%）
  宽哼JC>=20 → 已远离均线，注意回调
  合顶中断+跌幅>3% → 暴跌后反弹机会（P3=37.5%）
  合顶中断+微跌0~1% → 最危险（P3=19.9%）
```

### 6.6 连阳趋势延续分析

> **范畴说明：** 连阳（BT连阳≥3）本质属于等3（趋势延续）范畴的动量细分信号。从 MC3.3.3 移入本文档（探索层），作为形态探索的一部分。

#### 6.6.1 核心发现

**连阳越长，下日冲高概率越高（单调递增，无衰减）。** 这打破了"连阳长了会衰竭"的直觉——实际是"越连越强，强者恒强"。

> **数据：** 高波池，门开后。
> **基线：** P(≥2%)=43.3%，P(≥3%)=30.0%。

#### 6.6.2 连阳位置与下日冲高概率

| 连阳位置 | 样本 | P(≥2%) | 相对基线 | P(≥3%) | 均HR | 含义 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---|
| 基线 | 3,500,000+ | 43.3% | — | 30.0% | 2.08% | — |
| **第1根** | 1,223,704 | 45.8% | +2.5pp | 32.6% | 2.65% | ❌ 最弱 |
| 第2根 | 513,661 | 48.0% | +4.7pp | 35.4% | 2.91% | 一般 |
| **第3根** | 199,803 | **52.3%** | +9.0pp | 40.6% | 3.36% | ✅ 跳升点 |
| 第4根 | 77,260 | 56.3% | +13.0pp | 45.6% | 3.72% | 强 |
| 第5根 | 31,090 | 64.1% | +20.8pp | 54.9% | 4.83% | 很强 |
| 第6根 | 14,339 | 61.0% | +17.7pp | 53.4% | 4.37% | 强 |
| 第7根 | 6,106 | 70.8% | +27.5pp | 64.7% | 5.35% | 极强 |
| **第8+根** | 3,144~5,699 | **79.0~88.5%** | +36~45pp | 74.8~86.8% | 6.5~8.1% | 🏆 最强 |

**关键发现：**
1. **连阳第1根是最弱的（45.8%）**，不是"更容易冲高"
2. **连阳≥3 是明显跳升点**（48.0%→52.3%），这也是赛马用连阳≥3的依据
3. **连阳越长越强**，无衰竭现象
4. **连阳≥8+ 时 P(≥2%) 高达 79-89%**，但样本较少（3,144~5,699），可作为极强信号参考

**在等高线基座（等3_升_强）内验证，趋势完全一致：**

| 连阳位置 | 样本 | P(≥2%) | 相对基线(44.0%) |
|:---:|:---:|:---:|:---:|
| 第1根 | 32,067 | 43.1% | -0.9pp |
| 第2根 | 36,212 | 47.9% | +3.9pp |
| 第3根 | 18,804 | 52.6% | +8.6pp |
| 第4根 | 8,057 | 55.9% | +11.9pp |
| 第5根 | 3,342 | 63.9% | +19.9pp |
| 第6+根 | 2,520 | 68.7% | +24.7pp |

**连阳在等3升强基座内的规律与全局一致，且幅度更大（第5根+19.9pp）。**

#### 6.6.3 操作建议（连阳阈值）

| 连阳区间 | P(≥2%) | 操作建议 |
|:---:|:---:|:---|
| 连阳=1~2 | 46-48% | 一般，不特殊处理 |
| 连阳=3~4 | 52-56% | ✅ 可操作（基本条件） |
| 连阳=5~7 | 61-69% | 🟢 优先 |
| 连阳≥8 | 80-87% | 🏆 极强信号，但样本少 |

**策略优化：** 等3升强+连阳≥3 = 52.6%（大样本），等3升强+连阳≥5 = 63.9%（+11.3pp）。

#### 6.6.4 打板策略（市场连阳/涨停板）

> **范畴：** 打板策略（追涨停/连板）本质上是连阳信号在 A 股短线市场的应用，属于等3（趋势延续）范畴的极端形态。

**打板策略与连阳的关系：**
- 打板 = 追涨停板（首板/二板/三板...），本质是"连阳/连板的动量延续"
- 连阳（BT连阳）聚类了"连续上涨"的动量状态，打板是其最激进的应用
- **连板数越高，次日冲高概率越高**——与连阳"越长越强"的规律一致
- 打板的风险：连板后期（≥8板）样本骤减，追高风险大，需结合护型/BSHA确认

**打板策略的等高线框架：**
```
等高线等3（趋势延续）→ 连阳（动量延续）→ 打板（连板的极端形态）
```
打板是连阳信号在短线交易中的极致应用，其收益与风险都远高于普通连阳。当连阳≥5且满足等3+BSHA5时，可视为打板候选（P(≥2%)达60%+）。
