- **日级别微观（管下沿）**：日地型、日柱排、日等型
- **日级别微观（管上沿）**：日顶型

**三阶段各自区分度（次日冲高≥3%，基线 20.53%）：**
- **宏观 DXEF 区分度 7.96pp**——金 24.27% vs 屎 16.31%，确为"大势"级别

**承上启下：** 规定操作范围后，**只做微观微调，不再越界操作**；微观指标（柱排/顶型/地型/等型）在范围内精调，不再看宏观均线。护型操作规则（4.3）规定可操作范围后，**今后只进行微观层面的分析，而不再考虑 DXEF/DXZE/DXCD/DXZC 等宏观均线**——例如只会在乙(ZA>0)中按柱排寻找机会，但绝不会在丙/丁中寻找机会（因为按范围已规定要回避）。**护型操作规则很重要，是承上启下的节点。**

### 4.2 第一阶段：宏观（均线+概率）

**五符号（日级别均线）· 条件优先级总览（从宏观到微观，执行顺序）：**

| 层级 | 指标 | 地位 | 作用 | 要求 |
|:----:|:-----|:-----|:-----|:-----|
| **1** | **DXEF** | **天时/战场**（金/银/唏/嘘/尿/屎） | 决定哪些大区域能冲高；月级别趋势判断，确定WXCD方向 | 最优条件但不是必须 |
| **2** | **DXZE** | 空间（站上 DJE 日线E线） | 决定有无收益空间；日级别趋势判断 | 最优条件但不是必须，可作权重划分 |
| **3** | **DXCD** | **地利/护段**（上/中/下/忐/忠/忑） | 决定护型转移方向；周级别操盘指标，替代WXAB | 选择甲乙己戊(DXZC>0) |

### 4.3 第二阶段：日类操作范围（里程节点，四维度）

> 本小节确立**第二阶段成果（里程节点）**——先给出三种尝试的演进与综合建议（§4.3.1），再落地为确定的可操作范围（**范围判定** + **等级划分** + **综合基础范围**）。

#### 4.3.1 三种尝试综合：日类操作范围的演进与建议

> 这段是对整个日类决策树框架的深刻理解——操作范围不是单一规则的产物，而是三种方法论尝试逐层演进、权衡风险与收益后的收敛。

**① 误区澄清：日策分坏/好 ≠ 圈定范围**

日策分坏/好（DXCD×日护型查表）**只区分 DXAB 能否延续最优条件**，完全不是圈定总体操作范围——已并入 §4.4.3 作为护型延续性的预警/展示变量。

**② 三种尝试的演进（从粗到细、从静态到动态）：**

| 尝试 | 依据 | 核心范围 | 贡献 | 缺陷 |
|:--|:--|:--|:--|:--|
| **尝试一 · 月基带日**（MC3.1 §6） | DXEF→DXCD→DXAB 三级带动 | 8 格分类（A~H）+ 三条铁律，映射月基四域（主/被/傻/禁） | 框架完整；三条铁律直指要害 | **只考虑次日冲高概率，没有 DXZC+DXAB 概率转移**；8 格是静态分类 |
| **尝试二 · 必赢 V1**（DXZE>0+DXZC>0） | 两条长期均线 | DXZE>0 且 DXZC>0（胜率 92.5%、年化约 156%） | 极简、极稳，无条件跳过 DJE/DJC 之下的陷阱 | **粒度太粗**——放弃 DJE 之下 1/3 的交易日，错过大量 DXZC>0 但 DXZE≤0 的反弹 |
| **尝试三 · 必赢 V2**（DXCD+DXZC+DXAB） | 三条均线 + 概率转移 | 淡化 DXZE、引入 DXCD、融入 DXZC+DXAB 转移 | 均线级别最细；**灵活 + 细颗粒度兼得** | 需配合微观指标做精判，复杂度上升 |

**③ 关键洞察：把 DXEF+DXZE 从"范围判定"降级为"等级划分"**

先厘清矛盾根源：**范围**与**等级**是两回事，不能混为一谈。
- **范围 = 门禁**（进不进场）：由 **DXCD + DXZC + DXAB** 确定（护段 + 总开关 + 护型）
- **等级 = 仓位/期望**（进场后放多少、期望多高）：由 **DXEF + DXZE** 划分（战场 + 是否站上 DJE）

**结论：DXEF+DXZE 不直接划分日类范围，而是日类范围之内的等级划分。** 范围内用 DXCD+DXZC+DXAB 圈定后，再用 DXEF+DXZE 分级。这样：

1. **DXZE 的地位，不容置疑。** DXZE>0 且 DXEF=金 时，是**主升浪的必要条件**（最高等级）；但 **DXZE 之下也存在很多机会**——它们不是"范围外的例外"，而是**范围内、但等级较低的介入**（有 DXZC>0 撑着，只是收益空间受限），所以**轻仓 + 严格止损**。
2. **如何识别 DXCD 所代表的周级别机会在日级别的具体展现。** 特例是**月基带日 G 级**（EF差+CD差+AB好）：尝试一只能对 G 级设"谨慎"；本框架明确 **DXZC<0 之下没必要参与**，而当 **DXCD<0 且 DXZC>0** 时（G 级中 CD 差但 ZC>0 的分支），**配合微观指标有很多日级别反弹机会**——它在范围内（DXZC>0），只是 DXEF/DXZE 让它属于低等级。

**④ 综合建议：两段式（平衡风险与收益）**

**第一段 · 范围判定（能不能做）——DXCD + DXZC + DXAB：**

| 条件 | 判定 | 来源 |
|:--|:--|:--|
| **DXZC>0** | **总开关**，无条件要求，ZC>0 才介入 | V2 保留 |
| **DXCD** | 上/忐 可做；忠 可观察（ZC>0）；中/下/忑 谨慎或回避 | 尝试一 + 尝试三 |
| **DXAB** | 乙(ZA>0)/甲 主动持仓；己 试仓；丁/戊(ZA≤0)/丙 回避/退出 | V1+V2 |

**第二段 · 等级划分（做得多好）——DXEF（DXEF 与 DXZE 完全共线）：**

> ⚠️ **DXEF 与 DXZE 完全共线（绑定），不能当独立轴随意组合：** **金银唏 ⟹ DXZE>0（DJE 之上/无限区），嘘尿屎 ⟹ DXZE≤0（DJE 之下/有限区）**。因此等级实际由 **DXEF 六值阶梯**决定（金>银>唏>嘘≈尿>屎），DXZE 不额外提供独立信息。

| 等级 | DXEF | DXZE | 含义 |
|:--|:--|:--|:--|
| 🥇 **主升** | 金 | >0 | DJE 之上，收益无限，可重仓 |
| 🥈 **上行** | 银 | >0 | DJE 之上，趋势向上，正常参与 |
| 🥉 **过渡** | 唏 | >0 | DJE 之上但**会回调**（过渡），谨慎 |
| ⚠️ **谨慎反弹** | 嘘/尿/屎 | ≤0 | **DJE 之下**，收益受限，轻仓+严格止损 |

**三条铁律融入两段式：**
1. **只在 DJE 之上介入，不在 DJE 之下抄底** —— DJE 之上（金银唏）是**高等级**；DJE 之下（嘘尿屎）是**低等级**（谨慎反弹），轻仓 + 严格止损（不再有"例外"，而是"等级"差别）
2. **CD=下忠忑 时，AB=甲乙己 救不了尿/屎+忠/忑** —— CD 差的战场，好护型无效，应回避（属范围判定）
3. **CD=上 时 DXAB 可任意；CD=忐 时 DXAB 必须选甲乙己** —— 上战场大势已定，忐战场靠护型弥补（属范围判定）

**⑤ 结论：** 日类操作范围采用**两段式**——**范围**由 **DXCD+DXZC+DXAB** 圈定（DXZC>0 总开关、CD 上/忐、护型乙(ZA>0)/甲），**等级**由 **DXEF** 划分（金>银>唏>嘘≈尿>屎；金银唏 为 DJE 之上高等级、嘘尿屎 为 DJE 之下低等级，DXEF 与 DXZE 完全共线）。此分工在 4.3.2（四维参数分工表）与 4.3.3（基础范围表）落地，微观精调在 §4.4。

#### 4.4.3 日层机警写入方案（VBA 待落地）

> **日策分坏/好（查表预警变量，非圈范围）：** 日策分坏/好（DXCD×日护型查表，见 §2.9）**只是区分 DXAB 能否延续最优条件**的预警变量，完全不是圈定总体操作范围——范围由 4.3 的四维度（DXEF/DXZE/DXCD/DXZC）界定。它服务于持仓管理（护型能否维持/会否转坏），回答"当前护型在当前位置能否维持"，作为日层机警的展示/预警基础。

```vba
    Dim 转乙预警 As Boolean: 转乙预警 = False
    If InStr(日柱排, "跌") > 0 Or InStr(日柱排, "吞") > 0 Then 转乙预警 = True      '跌排/连后吞
    If InStr(日地型, "桮") > 0 Or InStr(日地型, "栅") > 0 Then 转乙预警 = True      '地型桮/栅
    If 日盈 = "" Or InStr(日盈, "偏") > 0 Or InStr(日盈, "雀") > 0 Then 转乙预警 = True '盈空/偏/雀
    If InStr(等值, "等") > 0 And Val(Mid$(等值, 2)) >= 8 Then 转乙预警 = True        '高等等型
    If 转乙预警 Then 等机警 = "甲转乙预警"
End If
```

**写入说明：** 该方案在 `等3顶/等3/开门` 判定之后，对"甲 且 DXZA>0 且命中跌排/桮栅/盈空偏/高等等型"时，追加 `甲转乙预警` 信号，覆盖原 `等机警`。
