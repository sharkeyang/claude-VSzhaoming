## 🔴 一、明确错误：龙a / 龙b

### 文档中的定义（错误）
`_主文档/MC3.3_C6研究日类微观形态.md:271-272`（§5.4.1 ⑥ 触顶持续性）：
```
| 龙a（合顶≥2 继续触顶）| 32.1% |
| 龙b（合顶=1 刚触顶）| 29.9% |
```
文档把"龙a/龙b"定义为**合顶天数**分类（合顶≥2 vs 合顶=1）。

### VBA 中的真实定义
"a龙/b龙"是**顶型**（`位os基顶型`），与合顶天数**完全无关**。

`IQQQ跨码_D据擎2神谕.bas:4520-4528`（正向 JC 以上，多头排列，BT哼≥-2 龙族）：
```vba
If ARROS(位os龟BT哼) >= -2 Then        '龙族：t顶>=-2
    If ARROS(位os龟BT顶) > 0 Then
        ARROS(位os基顶型) = "a龙"       'a龙 = 今日触顶（t顶>0）
    ElseIf ARROS(位os龟BT顶) >= -2 Then
        ARROS(位os基顶型) = "b龙"       'b龙 = 距顶2日内未触顶（t顶∈[-2,0]）
    Else
        ARROS(位os基顶型) = "c雀"
    End If
End If
```
反向 JC 以下（`IQQQ跨码_D据擎2神谕.bas:4589-4597`）对称用 BT底/BT哈。

**结论：a龙 = 已触顶（t顶>0），b龙 = 接近顶但未触顶（t顶∈[-2,0]）。** 文档用"龙a/龙b"命名"合顶天数"分类是**错误借用**了 VBA 的"龙"概念。

### 建议
文档 §5.4.1 ⑥ 的表格应改名为"合顶≥2 继续触顶 / 合顶=1 刚触顶"，**不要用"龙a/龙b"**。若想表达"触顶龙"（顶型 a龙/b龙），需用 VBA 顶型定义重算数据。

## ⚠️ 二、口径需注意：合顶天数

### 文档中的定义
`_主文档/MC3.3_C6研究日类微观形态.md:218`：
> 合顶天数 = 从右往左连续 'A' 的个数

### VBA 中的真实定义
`IQQQ跨码_D据擎5结算.bas:645` + `1298-1316`（`STBASE结算工具_衍生交叉天数`）：
```vba
'位os龟BT合顶 = 衍生交叉天数(位os龟BT合顶, 结哼, 结顶)
'当 结哼 >= 结顶 时 前值+1，否则重置为 -1
'结哼 = Max(H0..H4) = 5日最高；结顶 = Max(H0..H9) = 10日最高
```
**合顶天数 = 当前最高价（5日高）连续触及/超过运行顶（10日高）的天数计数器**，并非"从右往左连续 A 的个数"。

### 说明
文档的"合顶天数"统计口径（连续 A 个数）与 VBA 的"BT合顶"（结哼≥结顶的连续天数）**不完全等价**。若文档数据来自上符串连续 A 计数，则口径与 VBA 的 BT合顶 有差异，需确认数据来源。

## 📋 五、总结

### 找到定义的概念（29 个）
触顶、上符串编码、触哼/触哈/触底、冲顶星、十字星、阴柱/阳柱、护型、DXZA/DXZC/DXAB、甲转乙、BSHA、宽哼JC、等高线/等N、柱排、顶型、叠幅、上身、地型、鼎、薡、连阳、涨停、管宽、DSHA(=BSHA)、管中、窄管、打板、诱多、突破、回踩、长上影

### 明确错误（1 个）
**龙a/龙b** — 文档定义为"合顶天数"分类，VBA 真实定义是"顶型"（a龙=已触顶 t顶>0，b龙=接近顶 t顶∈[-2,0]），与合顶天数无关。

### 口径需注意（2 个）
- **合顶天数** — 文档口径（连续 A 个数）与 VBA 的 BT合顶（结哼≥结顶连续天数）不完全等价。
- **长上影** — 用户定义（上影>全幅/2）与冲顶星"无长上影"条件（上影<=2*实体）口径不同，需注意。

### 找不到独立定义（1 个）
帐篷 — 定性/描述性概念，VBA 无独立判定逻辑。

### 对结论可信度的影响
- **龙a/龙b 错误**：§5.4.1 ⑥ 的"触顶持续性"表格（32.1%/29.9%）用的是"合顶天数"口径，但**错误命名为"龙a/龙b"**。数据本身可能来自合顶天数统计，但名称错误会误导读者以为用的是 VBA 顶型"龙"。**需改名，或按 VBA 顶型重算。**
- **合顶天数口径**：文档的"合顶天数"（连续 A 个数）与 VBA 的 BT合顶 不完全等价，§5.4.1 ③ 的单调性结论（合顶天数越多越强）需确认数据来源口径。
- **其余概念**：定义基本正确，结论可信度不受影响。
