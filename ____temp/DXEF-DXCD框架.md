## DXEF-DXCD 完整执行框架

### 完全禁止介入（绝对禁止，无例外）

| 场景 | 状态 | 理由 |
|:-----|:-----|:------|
| 屎尿区 | DXEF<0, DXZE<0, DXCD<0, DXZC<0 | 未上破DJC，无任何试仓价值 |
| 屎尿区·最危险 | DXEF<0, DXZE<0, DXCD<0, DXZC<0, **DXZA>0** | 镜面：曾站上DJA却仍在DJE之下，假突破，最易诱多 |
| 屎尿区·完全禁止 | DXEF<0, DXZE<0, DXCD<0, DXZC<0, DXZA<0, DXZB>0 | 镜面：完全禁止 |
| 嘘区 | DXEF>0, DXZE<0 | **必须退出**，无任何操作空间 |
| 金银区·退出 | DXCD>0, DXZD<0 | DXCD已负面带动DXEF，应退出 |

### 仅观察，不介入（可以看，不能买）

| 场景 | 状态 | 理由 |
|:-----|:-----|:------|
| 屎尿区·观察 | DXEF<0, DXZE<0, DXCD<0, DXZC>0 | 仅观察，容易再次下破DJC |
| 屎尿区·关注 | DXEF<0, DXZE<0, DXCD<0, DXZC<0, DXAB=甲乙己 | 关注DXAB，但未上破DJC无试仓价值 |
| 唏区·中性 | DXEF<0, DXZE>0, DXCD=中/忠 | DXCD无法传导至DXEF，等待 |
| 金银区·暂退 | DXCD>0, DXZC<0 | 可暂时清仓，但DXCD未形成负面带动，还有机会站上DJC |

### 可警惕（向下传导，可能恶化）

| 场景 | 状态 | 理由 |
|:-----|:-----|:------|
| 唏区·警惕 | DXEF<0, DXZE>0, DXCD=下/忑 | DXCD向下传导(↘)，DXEF可能进一步恶化 |

### 超短/试仓（手痒可做，但必须严格止损）

| 场景 | 状态 | 止损条件 |
|:-----|:-----|:---------|
| 屎尿区·试仓 | DXEF<0, DXZE<0, DXCD<0, DXZD>0 | 以DJC为丘，下破DJC退出 |
| 屎尿区·试仓 | DXEF<0, DXZE<0, DXCD<0, DXZC>0, 刚上破DJC | 以DJC为丘，下破DJC退出 |
| 唏区·试仓 | DXEF<0, DXZE>0, DXCD=上/忐 | DXAB传导至DXCD→DXEF(↗)，有望转势 |

| **金银区·主战场** | DXEF>0, DXZE>0, **DXCD>0, DXZC>0** | 主战场 |
| → 主动 | DXZA>0 | **日级别主动持仓** |
| → 被动 | DXZA<0, DXZB>0 | 日级别被动持有，DXAB未形成负向带动 |
| → 持有 | DXZB<0 | DXAB负向带动但无威胁，可持有 |

### 核心流程图

```
DXEF>0, DXZE>0 (金银)
  ├─ DXCD>0, DXZC>0 → 主战场 ✅
  │   ├─ DXZA>0       → 主动持仓
  │   ├─ DXZA<0,DXZB>0 → 被动持有
  │   └─ DXZB<0       → 持有（负向带动无威胁）
  ├─ DXCD>0, DXZC<0   → 可暂退，但还有机会
  └─ DXCD>0, DXZD<0   → 应退出 ❌
DXEF>0, DXZE<0 (嘘) → 必须退出 ❌
DXEF<0, DXZE>0 (唏)
  ├─ DXCD=上/忐       → 可试仓 ⚠️（向上传导↗）
  ├─ DXCD=下/忑       → 可警惕（向下传导↘）
  └─ DXCD=中/忠       → 仅观察
DXEF<0, DXZE<0 (屎尿)
  ├─ DXCD>0, DXZC>0   → 主战场 ✅（站上DJC带动DXEF）
  │   ├─ DXZA>0       → 主动持仓
  │   ├─ DXZA<0,DXZB>0 → 被动持有
  │   └─ DXZB<0       → 持有
  ├─ DXCD>0, DXZC<0   → 可暂退
  ├─ DXCD<0, DXZD>0   → 以DJC为丘试仓 ⚠️
  ├─ DXCD<0, DXZC>0   → 仅观察
  └─ DXCD<0, DXZC<0   → 完全禁止 ❌
      ├─ DXZA>0       → 最危险（假突破，最易诱多）
      ├─ DXZA<0,DXZB>0 → 完全禁止
      └─ DXZB<0       → 可关注（最接近转势）
```
