### 1.2 主入口

```
Sub STCALL组合管理_检查()
  ├─ ① 读取基础数据
  │   ├─ 从花册读取所有持仓（CIDL/名称/行业/在池/数量/成本）
  │   ├─ 从神谕读取策略评分（按月基策略/策分/命分/带向）
  │   ├─ 从Name读取总资金（ZF总资产/ZJ总资产）
  │   └─ 从神谕读取WXCD（总仓位上限）
  │
  ├─ ② 按账户逐只检查
  │   ├─ 宝彦账户 → 检查每只股票
  │   │   ├─ 命分 ≥ 50？
  │   │   ├─ 单票上限 = 计算(池, 策分, 周冲置信度)
  │   │   ├─ 当前仓位 > 单票上限？ → 超限预警
  │   │   └─ 月基占比 ≥ 60%？
  │   └─ 宝福账户 → 同上
  │
  ├─ ③ 行业分散度检查
  │   └─ 各行业总仓位 > 30%？ → 预警
  │
  ├─ ④ 总仓位检查
  │   ├─ 各账户总仓位 > WXCD上限？
  │   └─ 各账户月基占比达标？
  │
  └─ ⑤ 输出结果
      └─ 写入工作表"组合管理"
```

### 1.3 单票上限计算函数

```
Function 计算单票上限(在池, 月基策略, 月基策分, 周冲策略) As Double
    ' 基础上限（按池）
    Select Case 在池
        金 → 20%    银 → 10%    铜 → 5%    黑 → 2%
    End Select

    ' 策略修正（按月基策略+策分）
    Select Case 月基策略
        多长 + 策分≥80 → 基础上限 × 100%
        多长 + 策分≥60 → 基础上限 × 70%
        多长 + 策分<60 → 基础上限 × 50%
        多被         → 基础上限 × 50%
        空看/空长    → 0%（不参与）
    End Select

    ' 周冲置信度修正
    Select Case 周冲策略
        金+多长+升排+非孕 → × 100%
        金+多长+升排      → × 70%
        其他             → × 50%
    End Select

    ' 最终上限 = 基础上限 × 策略系数 × 置信度系数
End Function
```
