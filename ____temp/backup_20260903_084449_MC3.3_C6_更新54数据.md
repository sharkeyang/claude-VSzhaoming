### 5.0 第三阶段定位

> **定位：** 这是日类第三阶段（微观指标微调）的具体落地——在护型操作范围内，用微观指标判断"甲是否即将转乙（DXZA<0）"以及"甲 DXZA>0 时是否该提前退出"。数据：谕组日全量约 2020 万样本。
>
> **框架衔接：** 见 `MC3.3_C2日DXZC+DXAB全维度分析.md` 第四章 §4.3（日类三阶段框架的第三阶段）。C2 第四章 §4.4 仅保留概括性叙述与计划，详细微观数据与本处一致。

---

### 5.1 日稳定态预警转坏（日稳定态 = 甲乙(DXZA>0)）

> **主题：** **日稳定态 = 甲乙(DXZA>0)**（好的稳定态，已有结论）。甲 或 乙(DXZA>0) 脱离稳定态（转坏）都是不好的，需预警。下设三个子节：甲转非稳定态（5.1.1）、乙转非稳定态（5.1.2）、VBA落地（5.1.3）。

#### 5.1.1 甲转为（非稳定态）的微观指标研究

> **定义：** "甲 → 非稳定态" = 甲 变成任何非稳定态（乙(DXZA<0)/丙/丁/戊/己 等）。由于甲 不可能直接转成乙(ZA>0)（稳定态），故"甲→非稳定态"自然覆盖所有转坏情况。数据：**高波池全量（Qic+Qim+Qit，3451 只）**，甲→非稳定态 样本 372,300，**总转坏率 3.16%**。

| 微观指标 | 高转坏率（预示甲→非稳定态）| 低转坏率（甲稳定）|
|:--|:--|:--|
| **日柱排** | 跌.尾连VW.W2 **4.8%**、跌.尾连vW.W2 3.9%、(升)人.连后吞QV 4.1%（跌排/连后吞=跌吞）| 升.尾连QQ.Q3 2.2%、升.尾连OQ.Q2 2.0%（升排稳定）|
| **日地型** | 2栅.Bc **5.6%**、1柜.Aa 5.2%、2栅.Fa 4.1%（含杂/含W）| 0橅 2.8%（纯QOov）|
| **盈提示** | 偏 **13.2%**、宽 11.6%、宽偏 10.5%（偏/宽）| a 1.4%、雀 1.4%（a系/雀稳定）|
| **日等型** | 等11 **5.0%**、等10 4.7%、等9 4.3%、等8 4.2%（高等等型）| 等0 2.0%、等2 2.2%（低等等型稳定）|
| **日顶型** | 上b **4.2%**、无 2.0% | 忐b 2.9%、忠b 3.0%（上/忐顶稳定）|

**结论：甲在跌排（跌吞）、地型栅/柜、盈提示偏/宽、高等等型（等8+）时更易转坏（甲→非稳定态）——预示"甲即将转坏"，应警惕退出/减仓；升排、0橅地型、盈提示a系、低等等型时甲稳定，可继续持有。**

---

#### 5.1.2 乙(DXZA>0) 转为（非稳定态）的微观指标研究

> **定义：** "乙(DXZA>0) → 非稳定态" = 乙(DXZA>0) 变成任何非稳定态（乙(DXZA<0)/丙/丁/戊/己 等）。由于乙(DXZA>0) 是稳定态，转坏变成 乙(DXZA<0)/丙/丁 等。数据：**高波池全量（Qic+Qim+Qit，3451 只）**，乙(DXZA>0)→非稳定态 样本 343,498，**总转坏率 3.62%**。

| 微观指标 | 高转坏率（预示乙→非稳定态）| 低转坏率（乙稳定）|
|:--|:--|:--|
| **日柱排** | 跌.尾连vW.W2 **4.9%**、跌.尾连VW.W2 4.8%、(升)人.连后吞QV 4.6%（跌排/连后吞=跌吞）| 升.尾连QQ.Q3 2.5%、升.尾连OQ.Q2 2.7%（升排稳定）|
| **日地型** | 2栅.Bc **5.3%**、1柜.Aa 4.8%、2栅.Fd 3.7%（含杂/含W）| 0橅 3.5%（纯QOov）|

##### 5.4.2.3 冲顶星 VBA 落地


> **目的：** 将 §5.10 的最强信号（触顶 + 十字星无长上影 + BSHA≥8 ≈ 64-68% 次日冲高）写入系统的 **日层机警** 字段，使筛选/回测可直接读取。

**① 日层机警 原有逻辑（`IQQQ跨码_D据擎2神谕.bas` L3825-3839）：**

| 机警值 | 触发条件 |
|:--|:--|
| 等3顶 | 等3 + ZC>0 + 顶型含龙 + 上符末位A |
| 等3 | 等3 + ZC>0 |
| 开门 | ZC>0 + CD>0 |
| （空） | 其余 |

**② 新增最高优先级信号"冲顶星"（2026-08-31 写入）：**

| 机警值 | 触发条件（全部满足） |
|:--|:--|
| **冲顶星** | **ZC>0 + 触顶(上符末位A) + BSHA≥8 + 十字星(无长上影)** |

- 十字星(无长上影) 判断：`实体=Abs(今收-今开)`，`全幅=今高-今低`，`上影=今高-Max(今收,今开)`；`全幅>0 And 实体<0.1*全幅 And 上影<=2*实体`
- **优先级最高**：若触发"冲顶星"，则不再覆盖为 等3/开门（先判冲顶星，未触发才回退等高线机警）

**③ VBA 实现（已在 `IQQQ跨码_D据擎2神谕.bas` L3825-3849）：**

```vba
'--- 最强信号：触顶+十字星(无长上影)+BSHA≥8 → 高概率次日冲高（C6§5.10 约64-68%） ---
If 日类BTZC > 0 And Right$(等上符, 1) = "A" Then
    If Val(谕组(X, 位谕of日层BSHA)) >= 8 Then
        Dim 实体 As Double: 实体 = Abs(日类今收 - 日类今开)
        Dim 全幅 As Double: 全幅 = 日类今高 - 日类今低
        Dim 上影 As Double: 上影 = 日类今高 - IIf(日类今收 > 日类今开, 日类今收, 日类今开)
        If 全幅 > 0 And 实体 < 0.1 * 全幅 And 上影 <= 2 * 实体 Then
            等机警 = "冲顶星"
        End If
    End If
End If
'--- 若未触发最强信号，回退到等高线机警 ---
If 等机警 = "" Then
    ' 原有 等3顶/等3/开门 逻辑不变
    ...
End If
谕组(X, 位谕of日层机警) = 等机警
```

**④ 使用说明：**
- **日层机警 = "冲顶星"** → 最强单日介入信号（次日冲高率约 64-68%），可作筛选/回测的高优买入条件
- **日层机警 = "等3顶"** → 次强（等高线龙头触顶）
- 该字段已通过 CSV [19] 日机警 导出（若导出代码含该列），可直接 Python 读取

> **注意：** 此 VBA 修改在 `昭明计划VS优化_vba/IQQQ跨码_D据擎2神谕.bas`（已提交）。**需用户 `vba2EXCEL` 导入正式版并重新跑算展后，日层机警字段才会输出"冲顶星"。** Claude 不导入正式 Excel（铁律）。

### 5.10 MC3.3.3"好模型"转触顶类别的验证（高波池全量）

> **目的：** MC3.3.3 日等型文档的"好模型"= ZC>0 + 甲乙己（+BSHA5，全场最强61.5%）。验证能否将该好模型转成"普适触顶（末位A）类别"。
> **触顶定义：** 上符串末位 **A**（t顶>0），非旧文档的"含 v"（v 实为触哈）。

**① 好模型 ZC>0+甲乙己 上，触顶A vs BSHA5：**

| 条件 | P(次日≥3%) | 增益 |
|:--|:--:|:--:|
| 好模型（ZC>0+甲乙己 基准） | 27.7% | — |
| 好模型 + **BSHA5** | 37.9% | +10.2pp（核心信号）|
| 好模型 + **触顶A** | 31.1% | +3.4pp（弱）|
| **好模型 + 触顶A + BSHA5** | **41.7%** | **+14.0pp（联合最强）** |
| 好模型 + 触顶A + 合顶≥3 | 34.1% | +6.4pp |

> **触顶A 不能替代 BSHA5**（BSHA5 +10.2pp ≫ 触顶A +3.4pp），但**触顶A 是 BSHA5 的叠加增强**（41.7%，+3.8pp 高于 BSHA5 单独）。

**② 真正的最强转触顶类别信号（叠加 BSHA≥8 + 十字星无长上影）：**

| 组合 | P(≥3%) | 均值 | 样本 |
|:--|:--:|:--:|:--:|
| 触顶A+BSHA8+十字星 | **64.4%** | 5.17 | 10,834 |
| [好模型甲乙己]+触顶A+BSHA8+十字星 | 64.4% | 5.17 | 10,834 |
| **乙+触顶A+BSHA8+十字星** | **67.8%** | 5.40 | 4,006 |
| **触顶A+BSHA8+合顶≥3+十字星** | **65.3%** | 5.22 | 6,245 |
| 触顶A+BSHA8（无十字星） | 50.1% | 3.99 | 470,774 |
| **不触顶+BSHA8+十字星（对照）** | **40.6%** | 3.02 | 20,965 |

**③ 关键结论：**

1. **"好模型"（甲乙己）在这个最强触顶信号下是冗余的**：触顶A+BSHA8+十字星 = 64.4%，与 [好模型甲乙己]+ 完全相同（n 一致 10834）——满足该触顶组合后，护型甲乙己与否不再影响。
2. **触顶A 是十字星增强的必要前提（决定性）**：触顶A+BSHA8+十字星 = 64.4% vs 不触顶+BSHA8+十字星 = 40.6%，**相差 23.8pp**。
3. **最强转触顶类别信号：** 触顶A(末位) + BSHA≥8 + 十字星(无长上影) ≈ **64%**；再叠合顶≥3 → **65.3%**；乙护型 → **67.8%**。

**④ 结论：好模型可转触顶类别，但正确方式不是用触顶A替代BSHA5，而是建立新的最强触顶类别信号：**

> **触顶类别（最强）= 触顶A + BSHA≥8 + 十字星(无长上影) ≈ 64-68% 次日冲高**，取代/超越原"ZC>0+甲乙己+BSHA5"好模型。此触顶类别已并入日层机警"冲顶星"（§5.4.2.3）。

### 6.2 日柱排

> 基于日CSV柱排数据，研究升排/单阳柱/诱多对下日冲高的预测能力。<br>
> 数据源：日CSV列10（柱排）、列30（上符串）、列34（并符串）、列21（BSHA）、列24（宽哼JC）等。<br>
> 验证日期：2026-09-03，**高波池（Qic+Qim+Qit）全量**，11,087,371 样本。<br>
> 指标定义：P3 = 下日高幅（次日高幅）>= 3% 的概率；期望HR = 下日高幅均值。<br>
> 柱排编码：升连 = 连续阳柱；升吞 = 单阳柱吞没前阴；跌孕 = 阴柱后小阳/十字星止跌。

> **核心原则（数据修正版）：** 日柱排才是关键。**升吞不是诱多，反而是最强的升排形态**（P3=26.8% > 升连25.7%）。真正的诱多信号是"**冲不动**"（BSHA<3%）或"**未站稳**"（宽哼JC<5），而非"单阳柱/升吞"这个形态本身。
>
> **最关键的 3 个发现：**<br>
> ① **升吞是升排中最强**——P3=26.8%，比升连(25.7%)还高，推翻"升吞=诱多"的旧认知（见 §6.2.1）；<br>
> ② **诱多的本质是"冲不动"**——升吞+BSHA<3% 时 P3 暴跌到 14.7%（见 §6.2.2）；<br>
> ③ **高位升吞不是诱多**——等型≥3 时 P3=32.5%，除非 BSHA<5%（22.9%）（见 §6.2.2）。

### 6.3 日顶型

> 基于日CSV上符串数据，研究触顶/触哼/合顶对下日冲高的预测能力。<br>
> 数据源：日CSV列30（上符串）、列29（上符范）、列43（顶型）、列22（宽哼JC）等。<br>
> 验证日期：2026-08-22，**高波池（Qic+Qim+Qit）全量**，11,031,366 样本。<br>
> 指标定义：P3 = 下日高幅（次日高幅）>= 3% 的概率；期望HR = 下日高幅均值。<br>
> 触顶 = 上符串末位为 'A'（今天创新高）；触哼 = 上符串末位为 'B'（触到哼JA）；强触顶 = BSHA>=5 且 触顶。<br>
> 合顶天数 = 从上符串末位开始往左数连续A的个数。

> **核心逻辑链（一句话）：** ZC>0 是前提 → 触顶是信号 → 合顶天数定强度 → BSHA/宽哼JC 增强 → 等高线定位置 → 综合操作。<br>
>
> **最关键的 3 个发现：**<br>
> ① **ZC 方向是总开关**——ZC<=0 时触顶无效，ZC>0 时触顶才有效（见 §6.3.2）；<br>
> ② **合顶天数是最强单一指标**——区分度 16.5pp，5天全触顶 P3=39%（见 §6.3.3）；<br>
> ③ **合顶的意义在趋势延续**——合顶5天未来20天累计收益 453%（见 §6.3.7）。

#### 6.3.1 上符串编码与基础定义

**上符串（日CSV列30）：** 5位滚动记录，末位=今天，每位含义：
- `A` = 触顶（创新高）
- `B` = 触哼（触到哼JA）
- `v` = 触哈
- `_` = 无触顶

**上符范（日CSV列29）：** 编码值，含触顶次数/触哼次数等信息。

**顶型（日CSV列43）：** 龙/雀/虎/篪/武等分类。

**宽哼JC（日CSV列22）：** 当前价格距哼JA的百分比距离。

| 宽哼JC>=20 | 51.2% | 227,257 |

**宽哼JC<5时，明天继续触顶的概率接近60%**，说明刚突破哼JA时趋势延续性最强。

#### 6.3.6 触顶信号 vs 日策略P2 / 日层段 一致性

##### 6.3.6.1 触顶信号 vs 日策略P2（等高线+BSHA）

日策略P2 = 等高线 + BSHA（偏5/偏3）+ 连阳/层主/升排/跌排。它已包含BSHA信息，但**未包含触顶信息**。

**偏5（BSHA>=5）中触顶占比62.3%**，两者高度一致。

| 条件 | P3 | 样本 |
|:----|:--:|-----:|
| 等1+偏5+触顶 | 43.6% | 53,290 |
| 等2+偏5+触顶 | 43.8% | 127,812 |
| 等3+偏5+触顶 | 41.2% | 744,147 |

**关键发现：在偏5（BSHA>=5）条件下，触顶的边际贡献有限。** 因为BSHA>=5本身已是强信号（P3~41%），触顶与否的差异不大。

##### 6.3.6.2 触顶信号 vs 日层段

> 日层段定义（持主/持被/卖浮）见 [MC3.3.1_日类必赢算法.md §2.6](MC3.3.1_日类必赢算法.md#26-日层段细分持主持被卖浮)。

**触顶信号与日层段高度一致：**

| 条件 | P3 | 样本 | 判断 |
|:----|:--:|-----:|:----|
| **持主+强触顶(BSHA>=5)** | **43.0%** | 752,387 | ✅ 最强 |
| 持被+强触顶 | 42.0% | 6,047 | ✅ 强（样本少） |
| 持主+触顶 | 33.9% | 1,215,024 | ✅ |
| 持被+触顶 | 28.1% | 14,972 | ⚠️ |

**强触顶信号中持主占绝大多数**，触顶信号几乎都发生在持主阶段。

##### 6.3.6.3 结论

1. **触顶信号与日策略P2一致**：偏5信号中触顶占比高，但偏5本身已足够强，触顶的边际贡献小
2. **触顶信号与日层段一致**：强触顶信号主要出现在持主，持主+强触顶=43.0%最强
3. **日层段是比触顶更强的过滤条件**：持主+强触顶=43.0% vs 持被+强触顶=42.0%，差1.0pp

#### 6.3.7 合顶周期（趋势延续）

##### 6.3.7.1 核心发现：合顶不是看单日，而是看整个周期

之前验证"合顶天数×下日P3"发现合顶天数越长P3越高，但那是**只看下日冲高**（单日）。**合顶的真正意义在于"趋势延续"**——从合顶开始到离顶结束的整个周期，累计收益显著。

##### 6.3.7.2 合顶天数 × 未来N天累计收益

| 合顶天数 | 未来1天 | 未来3天 | 未来5天 | 未来10天 | 未来20天 |
|:-------:|:------:|:------:|:------:|:-------:|:-------:|
| 1天 | 16.18% | 34.45% | 43.82% | 88.05% | 150.84% |
| 2天 | 14.84% | 41.78% | 48.59% | 108.61% | 171.49% |
| 3天 | 18.59% | 49.05% | 63.18% | 149.48% | 222.64% |
| 4天 | 36.03% | 61.57% | 87.10% | 191.83% | 272.59% |
| **5天** | **55.09%** | **139.87%** | **207.67%** | **357.87%** | **453.04%** |

**合顶天数越长，未来累计收益越高。** 合顶5天 vs 合顶1天：
- 未来5天：207.67% vs 43.82%（差163.85pp）
- 未来10天：357.87% vs 88.05%（差269.82pp）
- 未来20天：453.04% vs 150.84%（差302.20pp）

##### 6.3.7.3 合顶天数 × 未来N天冲高>=3%概率

| 合顶天数 | 未来1天 | 未来3天 | 未来5天 | 未来10天 |
|:-------:|:------:|:------:|:------:|:-------:|

**任何合顶天数下，未来5天冲高>=3%的概率都超过66%！** 未来10天更是超过82%。

##### 6.3.7.4 结论

1. **合顶周期是有效的**——合顶天数越长，未来累计收益越高（合顶5天未来20天=453%）
2. **合顶开始是入场信号**——合顶开始后未来5天冲高>=3%概率66.7%+
3. **合顶的意义在于"趋势延续"**——连续创新高代表趋势强，未来N天累计收益高

#### 6.3.9 综合操作规则

> 基于全部验证结果，按优先级排序。

```
第一层：ZC方向（最重要）
  ZC<=0 → 不参与，无论是否触顶（P3<22%）

第二层：触顶状态（ZC>0范围内）
  今天未触顶 → 非主升（P3=25.7%），不参与
  今天触顶 + BSHA<3% → 假信号（P3<14%），不参与
  今天触顶 + BSHA>=5% → 强信号（P3=36.1%），可参与
  今天触顶 + BSHA>=10% → 极强信号（P3=54.7%），优先参与

第三层：触顶频率（排除震荡偶尔触顶）
  5天中触顶>=3次 → 主升确认（P3=30.9%）
  5天全触顶 → 强主升（P3=39.0%）

第四层：位置确认
  等高线=等1/等2（DJA附近）→ 有效突破（P3=33%+）
  等高线=等3（远离DJA）→ 强弩之末（P3=30.6%）

第五层：持仓判断
  宽哼JC<5 → 刚突破，趋势延续性强（明天触顶概率58.7%）
  宽哼JC>=20 → 已远离均线，注意回调
  合顶中断+跌幅>3% → 暴跌后反弹机会（P3=37.5%）
  合顶中断+微跌0~1% → 最危险（P3=19.9%）
```

### 6.6 连阳趋势延续分析

> **范畴说明：** 连阳（BT连阳≥3）本质属于等3（趋势延续）范畴的动量细分信号。从 MC3.3.3 移入本文档（探索层），作为形态探索的一部分。

#### 6.6.1 核心发现

| 第6根 | 14,339 | 61.0% | +17.7pp | 53.4% | 4.37% | 强 |

#### 6.6.4 打板策略（市场连阳/涨停板）

> **范畴：** 打板策略（追涨停/连板）本质上是连阳信号在 A 股短线市场的应用，属于等3（趋势延续）范畴的极端形态。

**打板策略与连阳的关系：**
- 打板 = 追涨停板（首板/二板/三板...），本质是"连阳/连板的动量延续"
- 连阳（BT连阳）聚类了"连续上涨"的动量状态，打板是其最激进的应用
- **连板数越高，次日冲高概率越高**——与连阳"越长越强"的规律一致

**打板策略的等高线框架：**
```
等高线等3（趋势延续）→ 连阳（动量延续）→ 打板（连板的极端形态）
```
打板是连阳信号在短线交易中的极致应用，其收益与风险都远高于普通连阳。当连阳≥5且满足等3+BSHA5时，可视为打板候选（P(≥2%)达60%+）。

### 9.1 明确错误：龙a / 龙b（已修正）

**原文档定义（错误）：** 曾把"龙a/龙b"定义为**合顶天数**分类（合顶≥2 vs 合顶=1）。**已修正为"合顶≥2/合顶=1"。**

`IQQQ跨码_D据擎2神谕.bas:4520-4528`（正向 JC 以上，多头排列，BT哼≥-2 龙族）：
```vba

        ARROS(位os基顶型) = "a龙"       'a龙 = 今日触顶（t顶>0）
    ElseIf ARROS(位os龟BT顶) >= -2 Then
        ARROS(位os基顶型) = "b龙"       'b龙 = 距顶2日内未触顶（t顶∈[-2,0]）

End If
```
反向 JC 以下（`IQQQ跨码_D据擎2神谕.bas:4589-4597`）对称用 BT底/BT哈。

**结论：a龙 = 已触顶（t顶>0），b龙 = 接近顶但未触顶（t顶∈[-2,0]）。** 文档曾用"龙a/龙b"命名"合顶天数"分类是**错误借用**了 VBA 的"龙"概念，已修正。

### 9.2 口径需注意：合顶天数

**文档口径：** 合顶天数 = 从右往左连续 'A' 的个数（Python 脚本 `calc_合顶天数` 即此口径）。
