# 谕组导出数据错误 — 诊断与修复方案

## 一、诊断结果

### 问题 A：谕组周（表头 63 列 vs 数据 60 列）

**现象：** 表头 63 列，数据行只有 60 列，从 [5] 起全部错位。

**根因：** 表头（`PX算研_RAP算展1引擎.bas` L1812）已加 3 列（地型周/等周/大局周），但周类串函数 `XL算展取样调程_谕组周类串`（L1721-1784）**没同步加这 3 列**，数据行仍是 60 列。

**错位示例（sh600004 第1行）：**
| 列 | 表头 | 数据行实际值 | 应为 |
|:--:|:--|:--|:--|
| [4] | 护型 | a甲↗上1.I | ✓ 对齐 |
| [5] | 地型周 | Aa龙扩猪.初（波型值） | 0橅/1柜/2栅... |
| [6] | 等周 | 首柱.Q1（等周值？） | 等高线分类 |
| [7] | 波型 | .44枝贯连待X（柱型值） | 波型 |
| ... | ... | 全部左移错位 | |

### 问题 B：谕组日（表头 128 列 vs 数据 71 列）

**现象：** 表头 128 列，数据行只有 71 列，周类串列 [70] 全空（5643 行全空）。

**根因：** 谕组日导出（L1932）用 `If 谕组(X, 位列算展of周键)` 判断周收盘日，但**周键列在 `XL算展数程跨期` 路径下从未被设置**（只在 `XL算展格程跨期_通用生成` L668 设置），全为 False，周类串永不更新 → 全空。

谕组周导出（L1821）用 `ARRLLL` 直接判断（正确），所以谕组周能输出周类串。

### 问题 C：谕组日表头缺 3 列

**现象：** 谕组日表头周类串部分（[70]~[127]）也是 58 字段，缺地型周/等周/大局周 3 列。修复问题 A 后周类串变 61 字段，谕组日数据行会变 131 列，表头需同步加 3 列。

---

## 二、修复方案（3 处修改，全在 `PX算研_RAP算展1引擎.bas`）

### 修复 1：周类串函数加 3 列（L1725-1744 段1）

当前段1：
```vba
段1 = 周波今涨幅, 周波临涨幅, 周波临高幅, 周层护型, 周层波型, 周层柱排, 周层柱型, 周层界, 周层势型, ...
```

改为（护型后插地型/等，柱排后插大局）：
```vba
段1 = 周波今涨幅, 周波临涨幅, 周波临高幅, 周层护型, 周层地型, 周层等, 周层波型, 周层柱排, 周层大局, 周层柱型, 周层界, 周层势型, ...
```

对应谕组数组字段：
- 地型周 = `位谕of周层地型`（族周层+6）
- 等周 = `位谕of周层等`（族周层+7）
- 大局周 = `位谕of周层大局`（族周层+11）

### 修复 2：谕组日周类串改用 ARRLLL 判断（L1932）

当前：
```vba
If 谕组(X, 位列算展of周键) Then 周类串 = XL算展取样调程_谕组周类串(谕组, X)
```

改为（与谕组周 L1821 一致）：
```vba
If ARRLLL(X, 基位周类 + 位os结期) = ARRLLL(X, 基位日类 + 位os结期) Then 周类串 = XL算展取样调程_谕组周类串(谕组, X)
```

### 修复 3：谕组日表头加 3 列（L1844）

当前周类串部分：
```
...,DTZB,DTZD,DTAB,DTCD,周涨,周PR,周HR,周护型,周波型,周柱排,周柱型,周层界,周势型,...
```

改为（周护型后加周地型/周等，周柱排后加周大局）：
```
...,DTZB,DTZD,DTAB,DTCD,周涨,周PR,周HR,周护型,周地型,周等,周波型,周柱排,周大局,周柱型,周层界,周势型,...
```
