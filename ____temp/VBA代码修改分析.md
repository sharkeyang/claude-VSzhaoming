# VBA代码修改分析

## 需要改动的文件

### 1. 据擎3格程.bas — 月基带日颜色（8处注释）

**现状：** 颜色逻辑基于条件（EF好/CD好/AB好），条件本身没变，只是注释中的等级名需要更新。

| 旧注释 | 新注释 |
|:------|:------|
| S级: 亮靛(牢牢抓住) | A级: 亮靛(主) |
| A级: 亮绿(可持仓) | B级: 亮绿(被) |
| B级: 中绿(可持仓) | C级: 中绿(试) |
| C级: 浅灰(仅观察) | D级: 浅灰(禁) |
| D级: 深绿(可持仓) | E级: 深绿(主) |
| E级: 中灰(仅观察) | F级: 中灰(被) |
| F级: 深灰(仅观察) | G级: 深灰(试) |
| 禁止级: 深红(坚决禁止) | H级: 深红(禁) |

**影响：** 仅注释，逻辑不变。8处。

### 2. 据擎2神谕.bas — 日冲策略后缀（4处）

**现状：** 日冲分类后缀为 好主/好持/坏观/坏禁
**需要改为：** 好主/好**被**/坏**试**/坏禁

| 旧后缀 | 新后缀 | 含义 |
|:------|:------|:------|
| 好主 | 好主 | 主(主动持仓) |
| 好持 | 好**被** | 被(被动持有) |
| 坏观 | 坏**试** | 试(试仓) |
| 坏禁 | 坏禁 | 禁(禁止) |

**影响：** 后缀字符串变了，InStr匹配也要同步改。

### 3. 展擎1筛选.bas — 典码名+InStr+输出标签（约30处）

**现状：** 典码名包含 主/持/观/禁 后缀
**需要改为：** 主/被/试/禁

| 典码名 | 改为 |
|:------|:-----|
| 典日策_龙强主 | 典日策_龙强主（不变） |
| 典日策_龙弱好持 | 典日策_龙弱好**被** |
| 典日策_龙强好持 | 典日策_龙强好**被** |
| 典日策_嘘强坏观 | 典日策_嘘强坏**试** |
| 典日策_嘘弱好观 | 典日策_嘘弱好**试** |
| 典日策_嘘弱坏禁 | 典日策_嘘弱坏禁（不变） |

InStr匹配和输出标签中的"持"→"被"、"观"→"试"。

### 4. 益盟公式ZQQQW.txt — 四级分类变量（2处）

**现状：** `S_牢牢抓住`、`A_可持仓`、`X_坚决禁止`
**需要改为：** `A_主`、`B_被`、`D_禁` 等
