## 一、总览

### 1.1 策略定位

| 维度 | 内容 |
|:----|:-----|
| 策略类型 | 日冲策略（极短线） |
| 核心问题 | 次日盘中冲高概率有多大？ |
| 时间尺度 | 日级别（前日尾盘买入→次日冲高卖出） |
| 评估工具 | 日冲评分（待设计） |
| 分析体系 | **以均线为骨（第三节、第五节），以形态修补（第四节）** |


### 1.2 现状与瓶颈

现有日级别回测数据显示：
- 各类条件下日胜率均在 **47%~52%** 之间，接近随机
- 唯一略优的是 **金+甲乙己+买初** 区域，胜率54.3%
- 日级别预测力有限，**核心价值在筛选冲高幅度而非方向**


### 1.3 待研究问题

- [x] 日级别哪些条件能有效提升次日冲高概率？已组织日级别探索路径，见[研究日级别探索路径.md](研究日级别探索路径.md)（含36个探索子项，待逐项回测）
- [x] 日冲评分公式设计？已确定（概率就是评分，查216分支表）
- [x] 是否可以从周冲策分降维推导日冲策略？**不能。** 周级别=金和唏的日冲策分相近(49.3% vs 51.3%)但趋势相反，周冲丢失日冲所需的DXCD×DXAB细分粒度。
- [x] 日冲与周冲的关系：**日冲需要独立操作，周冲不能替代。** 周级别=金时日冲策分均值仅49.3%，周级别=屎尿时P(≥3%)仍有8-12%，两者独立。

## 四、按形态探索

> **数据来源：** 30只股票算展文件，覆盖全部日级别行情数据
> **分析脚本：** `_产出物/MC3.9_算展批量分析_日级别阈值.py`



### 4.1 管宽 — 最强区分指标

| 管宽 | P(≥3%) | 均HR | 样本 | 相对基准 |
|:----|:------:|:----:|:----:|:--------:|
| 0~5（极窄） | 3.7% | 0.75% | 26,044 | 0.5x |
| 5~10 | 11.8% | 1.30% | 8,381 | 1.6x |
| 10~20 | **24.8%** | **1.98%** | 3,418 | **3.3x** |
| 20~40 | **39.9%** | **3.06%** | 696 | **5.4x** |
| >40（极宽） | **43.1%** | **3.55%** | 58 | **5.8x** |

**结论：** 管宽（顶JC）是日级别最强的单一指标。管宽>10时，次日冲高≥3%的概率是基准的3倍以上。建议将管宽作为日冲评分公式的核心维度。

### 4.2 DSHA（偏离DJA）— 与直觉相反

| DSHA | P(≥3%) | 均HR | 样本 |
|:----|:------:|:----:|:----:|
| 0~3（贴均线） | 4.1% | 0.76% | 54,203 |
| 3~5 | 12.3% | 1.29% | 14,268 |
| 5~8 | 23.2% | 1.87% | 4,979 |
| >10（大幅偏离） | **42.4%** | **3.44%** | 816 |

**结论：** 原"偏BSHA警告"假设不成立。DSHA越大后续日涨幅越大，不是回撤风险高。大幅偏离DJA的股票次日仍有更大波动，可能是趋势延续而非反转。

### 4.3 鼎 — 区分度有限

| 鼎值 | P(≥3%) | 均HR |
|:----|:------:|:----:|
| 1~2（初现） | 8.2% | 1.02% |
| 3~4 | 7.3% | 1.01% |
| 5~6 | 8.5% | 1.03% |
| 7~8 | 9.4% | 1.10% |
| ≥9（高位） | 11.5% | 1.21% |

**结论：** 鼎值高≠要跌。鼎连续出现的衰竭信号仅对单只股票成立，不是普遍规律。鼎不适合作为日冲评分中的否决条件。

### 4.4 四域日 / 柱排 — 区分度弱

**四域日：** 多长(8.3%) vs 空长(7.1%)，差仅1.2pp
**柱排：** 升(8.1%) vs 跌(7.2%)，差仅0.9pp

**结论：** 四域日和柱排在日级别上的预测力非常有限，不值得作为独立评分维度。它们作为操作准入条件（日服从周）仍有意义，但对冲高幅度筛选帮助不大。

**月基带日+柱排过滤验证：** 柱排对月基带日(V4)的带动链（DXAB→DXCD→DXEF）无过滤效果。相同带动链下，柱排=升 vs 跌的P(≥3%)差距最大仅3.8pp，且方向与直觉相反（跌排时P(≥3%)反更高）。月基带日无需加柱排过滤。

### 4.5 关键启示

```
日级别最强信号：管宽 > DSHA > 鼎 > 四域日 ≈ 柱排

管宽 >10 时，次日冲高概率从 ~4% 跳跃到 ~25%~43%
这是日冲评分公式的基石指标
```

### 4.6 窄管蓄力验证（200只×160组合，VBA回测）

> **VBA模块：** `Call XL展探窄管蓄力` — 参数网格：窗口×DS顶JA×波动阈值×均线级别

| 窗口 | 均阳柱率 | 总样本 | 最佳参数 | 说明 |
|:---:|:--------:|:------:|:---------|:-----|
| **5** | **12.2%** | 1,517 | DS顶JA=12, 波动≥1%, DJB | ✅ 有效，样本充足 |
| 10 | 16.7% | 272 | DS顶JA=5~8, DJB | ⚠️ 样本偏少 |
| 15/20 | — | <50 | 样本不足 | ❌ 不可靠 |

**结论：**
- 窄管条件确实有效，阳柱率从基准~4-8%提升到**12.2~16.7%**（+4~8pp）
- **DS顶JA阈值越大越好**（12优于5），说明"窄管"的初始定义过严
- 均幅涨/均幅高数据存在列偏移bug（显示-80%~-118%），**优先级较低，暂不处理**

## 五、日层联动

> **数据来源：** 350个算展xlsx × 16万行日级别数据，7463个谕组CSV × 422万行周数据
> **分析脚本：** `____temp/验证_日层联动等级.py`、`____temp/验证_日层联动维度.py`、`____temp/验证_DXCD护段.py`

#### 5.1 原 E/V 21 级体系 — 区分度差

```
E0上(9.7%) → E2上(9.5%) → E1上(8.9%) → E3上(7.6%) → e6下(7.7%) → v0忑(6.9%)
```

**强 vs 弱差距仅 2.8 个百分点**，相邻等级之间重叠严重，不值得保留。

#### 5.2 首字(金银唏嘘尿屎) — 区分度好

| 首字 | P≥3%（日级别） | P≥3%（周级别，422万行） | 级别 |
|:----|:------------:|:---------------------:|:----:|
| **银** | 8.5% | **66.1%** | A |
| **金** | 8.8% | **59.7%** | A- |
| **唏** | 6.3% | **59.3%** | A- |
| 嘘 | 7.3% | 43.0% | B |
| 屎 | 6.4% | 41.2% | B |
| 尿 | 8.1% | 39.6% | B- |

**差距：银(66%) vs 尿(40%) = 26 个百分点（周级别），日级别区分度弱于周级别但仍有意义。**

#### 5.3 DXCD护段 — 提升区分度

| 分类 | P≥3% | 说明 |
|:----|:----:|:-----|
| 金_b | **10.2%** | 最强组合 |
| 银_b | 9.5% | |
| 银_a | 9.2% | |
| 唏_r | **3.5%** | 最弱组合 |
| 唏_y | 4.5% | |

**金_b(10.2%) vs 唏_r(3.5%) = 6.7 个百分点差距。** WXAB护段(周级别)对区分度影响极大，同构的DXCD护段(日级别)同样有效。

#### 5.4 关键启示

```
原 E/V 21级体系 → 区分度差，建议废弃
首字(金银唏嘘尿屎) + DXCD护段(a/b/c/r/y/z) → 替代方案

推荐新分类：
  强: 金_b, 银_b, 银_a          → P≥3% ≈ 9~10%
  中: 金_a, 金_c, 金_z, 尿_z   → P≥3% ≈ 8~9%
  弱: 屎_y, 屎_c, 唏_z, 唏_r   → P≥3% ≈ 3~6%
```
