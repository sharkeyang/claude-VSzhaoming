### 1.2 微观指标综合决策

> **说明（总纲参考）：** 本节的快速决策表与操作口诀为**完整判断链总纲（含宏观列参考）**，从宏观（WXCD/WXAB）到微观（等型/地型/柱排/顶型）的全局一览，是**有意保留的总纲**。实际微观分析时**不重复宏观判断**——宏观已在第四章（C4）完成，微观只在护型操作范围内（✅/⚠️）精调，不再看 WXCD/WXAB。

#### 1.2.1 四维交互关键规律

> **为何能分清楚高低贵贱（HR≥3%）？** 四个维度联合把四维组合分出清晰的高低梯队：**柱排是决定性维度**（±10-15pp，区分度最大）、**触顶是双刃剑**（升排+触顶=强机会、跌排+触顶=高风险）、**等型决定位置**（等1/2 回归WJA 弹性大、等3 高位）、**地型影响较小**（3-5pp）。柱排+触顶+等型三个维度共同决定高低，地型只在同类内微调。完整四维组合分类详见 §1.3。

**① 柱排是决定性维度**：升排 vs 跌排，HR≥3% 差 10-15pp。升排组合 HR≥3% 普遍 58-72%，跌排组合普遍 44-58%。

**② 触顶是"双刃剑"**：
- 升排+触顶 → 强机会（HR≥3% 67-72%）
- 跌排+触顶 → 高风险（HR≥3% 44-52%）
- **触顶本身不决定方向，方向由柱排决定**

**③ 等型决定位置**：
- 等1/等2（回归WJA）→ 机会型（刚站上WJA，弹性大）
- 等3（远离WJA）→ 中性偏机会（已在高位，但仍有冲高）

**④ 地型影响较小**：0橅/1柜/2栅/3桮 对 HR≥3% 影响约 3-5pp，远小于柱排和等型。

#### 1.2.2 快速决策表（完整判断链，含宏观列）

| 场景 | 判断链 | 结果 |
|:-----|:-------|:----:|
| 🏆 **最优** | 银/唏/金 → 甲乙己 → 等1/2/3 → 栅/桮/柜 → 升排 | **B级80+分** |
| ✅ **可做** | 金/银 → 甲乙己 → 等1/2/3 → 栅/桮/柜/橅 → 不限 | **C级75-79分** |
| ⚠️ **谨慎** | 尿/屎 → 丙丁戊 → 等1/3 → 栅/柜/橅 → 升排 | **C级75-78分** |
| ❌ **回避** | 嘘 → 丙丁戊 → 等5/6/7 → 姗/娝/姖/妩 → 升排 | **D级60-67分** |
| 🚫 **最差** | 尿/屎 → 丙丁戊 → 等5/7 → 娝 → 升排 | **E级56分** |

#### 1.2.3 一句话操作口诀

> **大势看金银唏，护型看甲乙己，方向看等1/2/3，形态看栅桮柜，柱排等3升等5跌。**

### 1.3 四维组合对最优条件（甲/乙(ZA>0)）的环境分类（2026-08-26 新增）

#### 1.3.1 最优条件与四维组合定义

> **最优条件叙述：** 周类条件中**最优的是 甲 / 乙(ZA>0)**——正交且 ZA>0，操作上为主动持仓/试仓（见[第四章（月基操作规则与范围）](MC3.1_研究月基策略.md#第四章第二阶段里程碑-月基操作规则与范围) 4.1.3 可操作范围界定表）。四维组合正是针对这一**最优条件子集**，进一步做微观环境分类。
> **四维组合通用定义：** 用 **周地型 × 周等型 × 周柱排 × 周顶型** 四维，对护型范围内最优条件（甲/乙(ZA>0)）分类，描述其所处环境、提示风险与机会。数据：高波池（Qic+Qim+Qit）3451 只，周线全量；护型 = WXAB 首字符，乙按 WXZA 符号拆分；四维定义：地型（0橅/1柜/2栅/3桮，二元WTZA+前四柱）、等型（等1/等2/等3，ZA+中符串末位）、柱排（升/跌）、顶型（触顶/合顶）。

#### 1.3.2 四维组合 → 环境语义

#### 1.3.5 对操作的启示

#### 2.3.1 核心定义

**最后一柱**：虽然符合WJA之上升排，但已代表主升结束。

- **延续性**：只要不是最后一柱，且处于主升区域，都可备选进行下柱冲高
- **中止性**：主升遇到最后一柱，代表前一波主升趋势的停止，其后转入震荡或开启下一波主升
- **注意**：不一定是最高点，而是**主升浪的结束**

#### 2.3.6 柱排信号：跌吞/跌连对甲乙(WXZC>0)的影响

> **核心问题：** 甲乙(WXZC>0)时，若出现跌吞或跌连，是否应退出？
> 数据：高波池（Qic+Qim+Qit）3451 只，周线全量。跌吞=柱排以"跌"开头且含"吞"，跌连=柱排以"跌"开头且含"连"。

##### 2.3.6.1 转坏率定义

转坏率 = **当前护型向更差护型转移的概率**。各护型的转坏去向定义：

| 当前护型 | 转坏去向（更差的护型） |
|:--------|:-------------------|
| **甲** | →乙(ZA≤0)、→丙、→丁 |
| **乙(ZA>0)** | →乙(ZA≤0)、→丙、→丁 |
| **乙(ZA≤0)** | →丙、→丁 |
| **丙** | →丁 |
| **丁** | →戊(ZA>0)、→戊(ZA≤0) |
| **戊(ZA>0)** | →戊(ZA≤0)、→丙 |
| **戊(ZA≤0)** | →丙 |
| **己** | →戊(ZA>0)、→戊(ZA≤0)、→丙 |

计算方法：`转坏率 = 该护型转坏的总样本数 ÷ 该护型的总样本数 × 100%`

注意：转坏率 ≠ 1 - 维持率。因为还有"转好"和"其他转移"：
`维持率 + 转好率 + 转坏率 + 其他率 = 100%`

##### 2.3.6.2 甲(WXZC>0) + 跌吞/跌连

| 指标 | 正常（非跌排） | 跌吞 | 跌连 |
|:----|:-------------:|:----:|:----:|
| 样本 | 423,318 | 3,893 | 35,625 |
| 下周均HR | 6.61% | 5.09% | 5.47% |
| 下周涨率 | 93.5% | 92.0% | 92.6% |

|:----|:----|:------|

**结论：甲乙(WXZC>0)出现跌吞或跌连，应退出。** 跌吞是更强烈的退出信号。

#### 2.5.1 波型定义与结构

| 地型 | 0/1/4 | 9/8/5 |
| 含义 | 主升 | 下跌中的反弹 |

## 三、研究微观指标_WXZA维持

### 3.1 设计初衷

#### 3.1.1 问题背景

月策略周（积极/消极/不定）与周策略P1维度高度重叠，两者可相互印证。但月策略周目前缺少一个明确的"下破WJA概率"维度，导致"积极/消极/不定"的判定不够精确。

**核心问题：WXZA（周类BTZA，距WJA天数）何时由正转负？**

即：当前站上WJA（ZA>0）时，下周是否会跌破WJA（ZA<0）？

#### 3.1.2 设计目标

1. **构建"维持WXZA>0概率"** = 下周继续站上WJA的概率
2. **构建"WXZA<0概率"** = 下周跌破WJA的概率
3. **重点捕捉：WJA之上的连跌或阴阳阴**（最后一柱/M头等特征）
4. **用概率作为评分**，而非人为设定的分数

#### 3.1.3 与现有系统的关系

| 现有指标 | 与本指标的关系 |
|:---------|:---------------|
| **月策略周（积极/消极/不定）** | 维度重叠，可相互印证 |
| **周策略P1** | 维度重叠，可相互印证 |
| **不破WJA不卖出** | 本指标量化"不破WJA"的概率 |
| **最后一柱/M头** | 本指标捕捉这些特征 |
| **DJE与DJC之上 = 日类必赢** | 日线级别的必赢策略 |

> 1. **第一次**：抽样时误以为顶触（14.7pp）比柱型（21.1pp）差，选顶触为第三变量。
> 2. **第二次**：全量后误以为柱型（15.7pp）比顶触（12.3pp）好，且柱型增量+10.4pp，改选柱型。

#### 3.6.4 月策分周的逻辑及其与周策略ZA的互补（2026-08-18 新增）

##### 3.6.4.1 月策分周与周策略ZA的互补

**周策略ZA** 是**反面信号**（预测下周跌破WJA概率），与月策分周（预测5周后是否仍在多长）是**互补**的：

| 指标 | 预测周期 | 方向 | 含义 |
|:-----|:--------:|:----:|:-----|
| **月策分周** | 5周后 | 正面 | 是否仍在多长（长期维持） |
| **周策略ZA** | 下周 | 反面 | 是否跌破WJA（短期变坏） |

**两者可以配合：**
- 月策分周高 + 周策略ZA安全（_）→ 长期维持 + 短期不破 → **坚定持有**
- 月策分周低 + 周策略ZA危险（W）→ 长期转弱 + 短期将破 → **退出**

**一句话：月策分周看"5周后是否还在多长"（长期维持），周策略ZA看"下周是否跌破WJA"（短期变坏），两者互补，配合使用可同时把握长期方向和短期风险。**

##### 3.6.4.2 周策略ZA编码：G→W（2026-08-18 新增）

**周策略ZA的G改为W（warning）：**

| 指标 | 预测方向 | 编码 | 含义 |
|:-----|:--------:|:----:|:-----|
| **周策略P1/P3** | 积极概率 | **G**(good) | 下周冲高概率≥基线（好） |
| **周策略ZA** | 消极概率 | **W**(warning) | 下周跌破WJA概率≥基准19%（危险） |

**统一规则：**
- **G（good）** = 预测积极概率（P1/P3的冲高）
- **W（warning）** = 预测消极概率（ZA的跌破）
- **_** = 低于基线（安全）

**周策略ZA的W/_分界 = 全量基准跌破率19.0%**（非人为50%）：
- **W** = 跌破率≥19%（危险）
- **_** = 跌破率<19%（安全）

#### 3.6.5 W信号有效性验证（2026-08-18 新增）

**周策略ZA的目标变量 = 下周WTZA<0（跌破WJA）**，这是正确的设计。

**W信号（跌破率≥30%）发出后，下周实际表现（全量500文件抽样，1345样本）：** 下周PR>0仅44.3%，平均PR仅+0.19%（几乎持平），但下周HR>0达89.5%、平均HR=8.41%。

**关键发现：W信号是"冲高回落预警"。** HR是"盘中最高涨幅"，PR是"收盘涨幅"。W信号发出后，下周可能盘中冲高（HR高），但收盘回落（PR低）。因此：
- **W信号不应直接触发"退出"**——下周盘中可能冲高（HR=8.41%）
- **W信号应触发"冲高减仓"**——利用盘中冲高减仓，因为收盘大概率回落（平均PR仅+0.19%）

**补充验证：跌破率 vs 下跌率是不同维度。** 用PR（下跌率）重新构建ZA表，策略完全反转（连阳+触高+宽高连3跌破率最低但下跌率最高）。周策略ZA用"下周WTZA<0"（跌破率）作为目标变量是正确的，与P1/P3（冲高概率）互补。

##### 3.7.3.3 关键发现

- **最危险**：跌反孕|离撤|宽 = 32.8%
- **区分度：51.4pp**

**2. 顶触状态是决定性因素**

- **触高**（触顶后一高）→ 维持率高
- **离撤**（离撤）→ 维持率低
- 同一柱排形态，触高 vs 离撤 差距可达20pp+

**3. 连跌/阴阳阴 + 离撤是最危险信号**

- **连跌|离撤|宽** = 40.2%（最危险）
- **阴阳阴|离撤|宽** = 45.7%
- **连跌|离撤|其他** = 48.2%

**这些组合对应最后一柱/M头特征，预示WXZA即将由正转负。**

**4. 盈提示的"宽"是危险信号**

- 含"宽"的组合普遍维持率低
- 含"宽高连3"的组合维持率高

##### 3.7.3.4 操作建议

**用概率作为评分，按维持WXZA>0概率分级：**

| 维持率 | 操作 |
|:------:|:-----|
| **≥80%** | ✅ **安全持有**（升反孕/连阳+触高+宽高/宽高连3） |
| **70-80%** | ✅ **可持有**（连阳+触高为主） |
| **60-70%** | ⚠️ **关注**（阴阳阴/升反孕+触高） |
| **50-60%** | 🔴 **警惕**（连跌/阴阳阴+离撤） |
| **<50%** | 🚫 **退出**（连跌/阴阳阴/跌反孕+离撤+宽） |

**重点捕捉：**
- **WJA之上的连跌**（跌.尾连WW）+ **离撤** → 维持率48.2%，最危险
- **WJA之上的阴阳阴**（吞吞）+ **离撤** → 维持率50.4%
- 配合**盈提示宽** → 维持率降至40-46%

**这些形态对应最后一柱/M头等特征，预示WXZA即将由正转负。**

**一句话：用概率作为评分，完整分类WJA之上的162种组合（有效52种），区分度51.4pp。最安全是升反孕/连阳+触高+宽高（84.2%），最危险是连跌/阴阳阴/跌反孕+离撤+宽（32.8-48.2%）。顶触状态是决定性因素，连跌/阴阳阴+离撤对应最后一柱/M头特征。**
