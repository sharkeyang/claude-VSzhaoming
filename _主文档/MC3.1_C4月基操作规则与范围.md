### 4.1 承上启下：护型操作规则 = 周级别分析框架的里程节点

在完整的周类分析框架（或日类分析框架）中，指标分三段，护型操作规则是**承上启下的关键里程节点**：

| 段 | 内容 | 回答的问题 |
|:--:|:-----|:-----------|
| **前一部分 · 宏观（均线+概率）** | WXCD（大势）、WXAB（护型）等均线，依靠概率分析 | 能做什么市场 / 能做什么股票 |
| **里程节点 · 护型操作规则（本章）** | **界定可操作范围**——哪些护型可做、哪些回避 | 允许在哪些护型内操作 |
| **后一部分 · 微观指标** | 柱排、顶型、地型、等型 | 在范围内做微观层面的精调 |

**承上（前一部分·宏观）：** 第三、五章（WXCD/WXAB 均线 + 概率分析）决定"能做什么市场、能做什么股票"。

**启下（后一部分·微观）：** 第七、八章（C7 周类微观指标）衔接本章，只做微观层面的分析，**不再考虑 WXCD、WXAB 等宏观均线**。本章之后，只在护型操作范围内寻找机会。

**核心示例：** 只会在 **乙(WXZA<0)** 中按柱排寻找机会，但**绝不会在丙、丁中寻找机会**——因为按本章规定的可操作范围，丙（死亡螺旋）退出、丁（死水）回避。

**日级别/周级别的三层结构（从 C7 1.1 框架总纲迁移）：**

在一个确定的级别（如日级别、周级别），指标分三层（宏观/中观属前一部分，微观属后一部分）：

- **日级别：** 宏观（均线）DXAB、DXCD → 决定趋势方向；微观（低级别聚焦指标）日等型、日柱型、日柱排、日顶型 → 细节聚焦
- **周级别：** 宏观（大势）WXCD → 决定大势方向；中观 WXAB → 决定中观趋势；微观（管下沿）周地型、周柱型、周柱排；微观（管上沿）周顶型
- 周等型属于**微观指标（管下沿）**，与周柱型/周柱排同级

### 4.1.2 可操作范围界定表（护型操作规则 = 承上启下里程碑）

本章的核心职责是**界定可操作范围**。范围依据 C3 §3.5.1 修正后的统一模型规则（六操作）：

**6 种操作定义：** 主动持仓（可买入并持有，维持率高）/ 被动减仓（已持有减至底仓，不新买）/ 试仓（轻仓介入赌转好）/ 减仓（降低仓位，转坏风险上升）/ 退出（卖出离场，死水/恶化）/ 回避（不碰，死水/负收益）。

| 护型 | WXZC>0 | WXZC<0 |
|:-----|:-------|:-------|
| **甲** | ✅ **主动持仓**（维持84.1%、转坏仅5.5%） | ⚠️ **试仓**（维持70.7%、下周HR≥3% 53.7%） |
| **乙(ZA>0)** | ✅ **主动持仓**（维持80.0%、转坏仅6.5%） | ⚠️ **试仓**（维持65.0%、下周HR≥3% 52.2%） |
| **己** | ⚠️ **试仓**（60.5%→甲，存续1.3周） | ⚠️ **试仓**（33.3%→甲，存续1.7周） |
| **戊(ZA>0)** | ⚠️ **试仓**（38.1%→己、13.6%→甲，合计51.7%向好） | ❌ **回避**（转甲仅2.7%） |
| **乙(ZA≤0)** | ⚠️ **被动减仓**（转坏38.4%>转好28.2%，减至底仓，转丙止损） | ⚠️ **被动减仓**（32.5%转回乙(ZA>0)，减至底仓，转丙止损） |
| **丁** | ❌ **回避**（死水终点，转好22.7%、70.4%概率亏损） | ❌ **回避**（死水，转甲仅1.1%） |
| **戊(ZA≤0)** | ❌ **回避**（死水，维持62.8%、转好仅13.3%） | ❌ **回避**（死水，维持81.5%） |
| **丙** | ❌ **退出**（死亡螺旋，转坏78.2%、-3.73%） | ❌ **退出**（死亡螺旋加速，转坏85.1%、-5.08%） |

> **⚠️ 角色判定原则：** 上表 `操作判定` 基于**转移矩阵（转好概率/转坏概率）+ 持续时间 + 冲高期望（HR）** 综合判定（详见 C3 §3.3、§3.5.2），**不是**由本周涨幅判定。完整论证见 C3 §3.5.2。

**据此简化的可操作范围（里程碑结论）：**

| 范围 | 护型 | 操作 |
|:--|:--|:--|
| ✅ **可做（主动持仓/试仓）** | 甲、乙(ZA>0)、己、戊(ZA>0)（WXZC>0） | 主动持仓 / 试仓 |
| ⚠️ **被动减仓（持有赌恢复）** | 乙(ZA≤0) | 被动减仓，转丙止损 |
| ❌ **回避/退出（不在范围内找机会）** | 丙、丁、戊(ZA≤0) | 退出 / 回避 |

**里程碑口诀（从 C7 第二段迁移）：** 甲乙己在范围内（可做）、丙丁回避/退出、戊按 ZA 拆分（戊(ZA>0)可试仓/戊(ZA≤0)回避）、乙(ZA≤0)被动减仓。**范围内**才继续微观，**范围外（丙丁）不再找机会**。

**本章之后（后一部分·微观）：** 只在 ✅/⚠️ 范围内做微观（等型/地型/柱排/顶型），**绝不在 ❌ 范围（丙丁）内找机会**。

### 4.2 操作规则

#### 4.2.1 进场条件
- 只做 WXCD ∈ {金, 银}，排除屎尿唏嘘
- **金升（CD>0+ZC>0+ZB>0）** 才正式进场
- 银升（CD≤0+ZD>0+ZC>0+ZB>0）只跟踪，等转金升再进场（50.1%假信号，不提前介入）
- 进场前检查 **月基命分（V1）**，命分<10分的股票天然不参与月基

> **数据支撑（第三章 §3.2.1）：** 金升时WXZC>0，好护型（甲乙己）维持率84~93%，持有期中位数3~5周。银升时WXZC≤0，仅己可试仓（维持率41.9%），甲/乙(ZA>0)维持率虽高但下周HR≥3%仅52~55%，不可持续。

#### 4.2.2 退出条件
- **硬退出：** WXZB从>0转≤0 → **立即卖出**（当周P(≥3%)=7.6%，几乎必亏）
- **软退出：** 消极区双重确认(ZA下降+本周涨<0) → 不等WXZB转负，提前减仓
- **最终退出：** WXZC<0 → 月基策略最终退出

> **数据支撑（第三章 §3.4.1）：** WXZC<0时，ZC≤-2进入死亡区，所有护型均涨幅为负。乙(ZA≤0)→丙36.3%，恶化概率高。详见§3.4 ZC分段和§3.6操作指南。
- **多被(金)** → WXZB转负即卖，不等
- **多被(银)/多被(唏)/NA(空看)/NA(空长)** → 月基不参与，不持仓

```
月基持仓中，每周检查判定类别：

多长(积极) → 继续持有，下周P(≥3%)=61.5%（对应甲/乙(ZA>0)，维持率84~93%）
多长(不定) → 可持有，关注ZA趋势方向（对应乙(ZA≤0)，维持率61.6%，36.3%→丙）
多长(消极) → 准备减仓：ZA下降→关注, 跌吞/本周涨<0→准备, 双重确认→立即减仓（对应丙丁戊，维持率<71%，下周HR≥3%<52%）
多被(金)   → WXZB从>0转≤0 → 立即卖出（当周P≥3%=7.6%）
多被(银)   → 等待带动信号转多长，否则不参与
多被(唏)   → 月基不参与，趋势极弱
NA(空看)   → 月基不参与，有反弹可能但非月基逻辑
NA(空长)   → 月基不参与，三空全
```



**多长持续性数据：**
- 多长平均段长 **7.1 周**，期间下周冲高概率 **93.9%**（稳定，15周无衰减）
- 说明：多长区一旦进入，通常可持续7周以上，期间几乎每周都能冲高，无需频繁操作
#### 4.2.3 持仓检查：WXZA>0延续性分析

月基策略中，当前WXZA>0（站稳A线）时，下周能否延续？关键因素：

| 因素 | 最优条件 | 延续率 |
|:----|:---------|:------:|
| **波型** | **龙猪** | **87.7%** |
| **盈提示** | **盈高** | **94.1%** |
| **柱排** | **升排** | **89.1%** |
| **ZA区间** | ZA3~5 | 84.0% |
| **最佳组合** | **龙猪+升排+ZA1~5** | **92.8%** |

**龙猪波型的WXZA>0延续率最高（87.7%），远优于震正（71.3%）。**
**盈高是延续性的最强单维度指标（94.1%），有盈高时下周几乎必定继续站稳A线。**
**组合策略建议：** 月基选股优先筛选龙猪波型+升排+ZA1~5，WXZA>0延续率达92.8%。

> **数据关联（第三章 §3.3.3）：** WXZA>0对应甲/乙(ZA>0)的维持率。甲维持率84.1%，乙(ZA>0)维持率93.5%，与上表最佳组合92.8%基本一致。乙(ZA>0)的93.5%维持率是月基持仓中最稳定的状态。

#### 4.2.4 软退出：消极区操作细则

| 信号 | 操作 | 说明 |
|:----|:------|:------|
| ZA下降 | 关注减仓 | 连续2周下降立即升级 |
| 跌吞 | 准备减仓 | 72.1%概率5周内转负（单周36.3%，5周累计约85%） |
| 本周涨<0 | 准备减仓 | 下周继续恶化立即行动 |
| 震正波型 | 警惕 | 龙猪转震正时趋势不稳 |
| 双重确认(ZA下降+本周涨<0) | **立即减仓** | 不等WXZB转负 |

> **数据支撑（第三章 §3.3.1.2）：** ZA下降对应乙(ZA≤0)状态。乙(ZA≤0)维持率仅61.6%，36.3%会恶化到丙。丙的下周涨幅-0.12%/46.8%，几乎必亏。详见§3.3.3乙护型专题和§3.3.6丙护型专题。

#### 4.2.5 硬退出：WXZB退出信号验证

基于谕组全量7,463只的ZB周列数据，验证了月基策略的退出预警信号。

**WXZB从>0转≤0是最强退出信号**

| WXZB状态 | 下周P(≥3%) | 真均幅 | 操作 |
|:---------|:----------:|:------:|:----|
| WXZB>0（正常持有） | 63.5% | 6.45% | ✅ 继续持有 |
| WXZB≤0（已下破） | 38.5% | 3.19% | ⚠️ 明显走弱 |
| **从>0转≤0（刚转负）** | **16.7%** | **1.31%** | 🚨 **立即卖出** |
| 转负当周 | **7.6%** | **0.34%** | 🔴 几乎不涨 |
| 转负后下周 | 27.7% | 2.95% | 观望 |
| 转负后下下周 | 31.5% | 3.09% | 仍在恢复 |

**五周内10%低点（信号②）：** 仅0.6%触发，预警价值低。WXZB≤0本身已足够作为退出信号。

**月基退出规则：**
```
月基持有中，每周检查WXZB：
  WXZB从>0转≤0 → 立即退出（当周P(≥3%)=7.6%，继续持有几乎必亏）
  WXZB仍>0 → 继续持有（下周P(≥3%)=63.5%）
```

**结论：** WXZB从>0转≤0时，当周P(≥3%)=7.6%，真均幅仅0.34%。**月基持仓中WXZB转负即卖，不犹豫。**

> **与第三章的关联（§3.3.1.2）：** WXZB转负对应WXZC下降趋势。此时护型向丙/丁转移的概率大幅升高（丙→丁32.2%，乙(ZA≤0)→丙36.3%），与WXZB转负的退出信号一致。WXZB转负时护型多为丙丁戊，属于死亡螺旋区域。

#### 4.2.6 最终退出：退出阶段

- WXZC<0 = 月基策略的最终退出条件
- 消极区预警通常比WXZC<0提前2~5周触发
- 预警系统的作用是**提前退出，不等WXZC<0**

> **数据支撑（第三章 §3.4.1）：** WXZC<0时，ZC≤-2进入死亡区，所有护型均涨幅为负。-2<ZC<0时是"死亡区"，所有护型涨率接近0%。详见§3.4 ZC分段。


### 4.3 长线持仓规则：不破WJA不卖出 + 不破DXZB不退出（2026-08-16 新增）

> 长线持仓的两道防线，与月策略日H级形成镜面映射。

#### 4.3.1 核心规则

**长线持仓的两道防线：**

| 防线 | 规则 | 级别 | 作用 |
|:----:|:-----|:----:|:-----|
| **第一道** | **不破 WJA 不卖出** | 周线 | 守住周线升势 |
| **第二道** | **起码不破 DXZB 不退出** | 日线 | 守住日线多头排列 |

**与月策略日H级的镜面映射：**
- **月策略日H级** = EF差（嘘/屎/尿）+ 弱（下/忑）+ AB坏（下/忠/忑）→ "H弱坏禁"（禁止）
- **不破DXZB不退出** = 日线多头排列未破 → 守住

**镜面映射：H级是"该退不退"的最差状态，不破DXZB是"该守守住"的最好状态。两者是同一逻辑的两端。**

#### 4.3.2 从系统源码验证

**1. WJA（周线A线）是周级别最重要的趋势线**

**WJA之上 = 安心持有，下破WJA = 退出。** 验证"不破WJA不卖出"。

**2. DXZB（日线B线）是日线多头排列的关键**

> "DXZB<0 → 持有"（主战场）
> "DXZB<0 → 可关注，最接近转势"（禁止区）

**DXZB<0 = 可持有。** 验证"不破DXZB不退出"。

**3. 月策略日H级的定义**

> H级 = EF差（嘘/屎/尿）+ 弱（下/忑）+ AB坏（下/忠/忑）→ "H弱坏禁"（禁止）

#### 4.3.3 镜面映射的深层逻辑

**镜面映射核心：同一条件在正反战场效果相反。**

| DXZB<0 → 持有，无威胁 | DXZB<0 → **可关注，最接近转势** ⚠️ |

**长线持仓时，不破WJA不卖出（周线守住），不破DXZB不退出（日线守住）。这与月策略日H级形成镜面映射——H级是"禁止"（最差），而"不破DXZB不退出"是"守住"（最好）。**

#### 4.3.4 合理性分析

**1. 两道防线是"周线定方向 + 日线定时机"的体现**

- **WJA（周线）**：决定长线方向，不破WJA说明周线升势未破，应守住
- **DXZB（日线）**：决定日线时机，不破DXZB说明日线多头排列未破，应持有

**符合系统"先周后日"的核心原则**（见 [MC3.3.5_周日联合.md](MC3.3.5_周日联合.md) §1.1）。

**2. 与月策略日H级的镜面映射**

- **H级**（禁止）：EF差 + 弱 + AB坏 → 最差，禁止操作
- **不破DXZB不退出**：日线多头排列未破 → 守住

**镜面映射：H级是"该退不退"的最差状态，不破DXZB是"该守守住"的最好状态。**

**3. 但需要注意：WJA和DXZB是不同级别的均线**

- **WJA** = 周线A线（周类BTZA）
- **DXZB** = 日线B线（日类BTZB）

**WJA是周线级别，DXZB是日线级别。** 不破WJA是周线守住，不破DXZB是日线守住。两者是"周线定方向 + 日线定时机"的配合。

#### 4.3.5 结论

**长线持仓规则合理，且符合系统"先周后日"的核心原则：**

1. **不破WJA不卖出** = 周线守住升势（第一道防线）
2. **不破DXZB不退出** = 日线守住多头排列（第二道防线）
3. **与月策略日H级镜面映射** = H级是"该退不退"的最差，不破DXZB是"该守守住"的最好

**但需要注意：**
- WJA是周线级别，DXZB是日线级别，两者是"周线定方向 + 日线定时机"的配合
- 不破WJA是长线底线，不破DXZB是短线底线
- **如果周线破WJA，即使日线不破DXZB，也应考虑退出（周线优先）**

**一句话：不破WJA不卖出（周线守住升势）+ 不破DXZB不退出（日线守住多头排列），与月策略日H级形成镜面映射——H级是"该退不退"的最差，不破DXZB是"该守守住"的最好。这符合系统"先周后日"的核心原则。**

#### 4.3.6 数据支撑验证（用第三章概率与规则）
