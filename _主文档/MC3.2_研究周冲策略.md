> ## 核心信念：天底下没有新鲜事
>
> 股票市场每天涨涨跌跌，看似随机。但 **"天底下没有新鲜事"**——相同条件的结果会重复。
>
> 过去30年，A股市场走过了422万周。在这422万周中，每当某些条件同时出现时，下周的走势就呈现出可预测的规律。这不是玄学，不是预测，而是**统计规律**——当条件A出现时，历史上B发生的概率是X%。
>
> 我们做的，就是找出这些条件，给每个条件组合打一个概率分。

> ## 我们找到了什么
>
> | 成果 | 证据 | 意味着什么 |
> |:----|:------|:-----------|
> | **金最优(全部) 76%概率达标** | 76,104周，P(≥3%)=**76.0%** | 最强条件组合，约3/4概率下周冲高≥3% |
> | **金+升排+非孕+盈高 71%概率达标** | 89,587周，P(≥3%)=**71.0%** | 次优组合，接近金最优 |
> | **金+升排+非孕 54.3%** | 441,731周 | **接近基准**（区分度有限） |
> | **银+盈提示有 87.6%** | 66,191周 | 银系最优，备用钥匙 |
> | **11种策略分组输出** | VBA已上线 | 每日筛选自动按策略优劣排序 |
>
> > **这不是万能钥匙，是大概率钥匙。** 历史概率是最佳指南，但不是承诺。每100次操作中，金最优以外的策略总有几次会"打不开"——这是正常的，不影响策略的长期有效性。

> ## 这个研究的价值
>
> 1. **不靠感觉，靠数据** — 422万周的统计，不是拍脑袋
> 2. **不预测涨跌，筛选冲高幅度** — 核心目标是"下周冲高≥3%"，不是"下周涨"
> 3. **可验证、可迭代** — 每项策略有验证报告，实盘偏差>5pp即修正
> 4. **可操作** — VBA每日自动筛选，A+→G共11组，优先级一目了然

## 第一章 总体思路

### 1.1 设计哲学 + 梯度分析

**核心问题**
> 是否只使用最优条件进行下周冲高判定？次要条件是否有分数？

**答案**

**周冲评分方案：概率即分数。** 策分 = 下周冲高≥3%的概率（P(≥3%)），直接查概率表赋值。

例如 "金+多长+升排+非孕" 在中证500上 P(≥3%)=90.3%，策分就是 90.3 分。
详见 [§1.2 概率即分数](#12-概率即分数-评分设计) 和 [§4.2 全量条件概率表](#42-全量条件概率表)。

**哲学：** 策分本质是 **0~100 的连续概率值**，不是"通过/不通过"的二元判定。全量梯度分析证实：

| 概率区间 | 周数 | 真均幅 | 相对基准 | 操作建议 |
|:------|:----:|:-----:|:--------:|:--------|
| 🏆 85~100 | 254272 | **11.90%** | 2.5x | A级 核心买入 |
| 🟢 70~84 | 648007 | **6.32%** | 1.33x | B级 辅助买入 |
| 🟡 50~69 | 638106 | **5.70%** | 1.20x | C级 观察 |
| 🟠 30~49 | 1703450 | **3.80%** | 0.80x | D级 回避 |
| 🔴 0~29 | 983395 | **2.95%** | 0.62x | E级 剔除 |
| **基准** | **4229602** | **4.76%** | 1x | — |

**关键结论：梯度平滑，无阈值效应。** 70~84 仍有 6.32% 真均幅（高出基准 32%），次优条件有价值。策分的连续分布保证了自然排序——高分高概率，低分低概率，无需人为分档。

**次要条件的自然处理**
概率即分数的设计天然处理了次要条件：条件越严格 → P(≥3%) 越高 → 策分越高，无需额外加权求和逻辑。

例如：
- 金+多长 → 中证500上 69.5分
- +升排 → 81.4分（+11.9pp）
- +非孕 → 90.3分（+8.9pp）
- +盈高+龙猪 → 100分（+9.7pp）

分数 = 历史数据说话，不是拍脑袋定的权重。

### 1.2 概率即分数 — 评分设计

##### 1.2.1 核心概念

**策分 = 条件组合在下周冲高≥3%的历史概率。**

```
策分不再是"专家打分"，而是"历史数据说话"。

金+多长+升排+非孕 在中证500上 → 历史上H R≥3%的概率 = 90.3%
                                          ↓
                               策分 = 90.3分
```

**分数含义就是概率：** 策分 90 意味着"如果今日满足此条件，下周有 90% 的概率冲到 3% 以上"。每10次出现，就有9次达标。

##### 1.2.2 为什么选 P(≥3%)？

| 计分基准 | 基准值 | 最优条件值 | 区分度 | 缺陷 |
|:---------|:-----:|:---------:|:-----:|:------|
| **P(>0)** | 91.5% | 100% | 8.5pp | 区分度太小，大部分组合都接近100% |
| **P(≥3%)** ✅ | **50.6%** | **100%** | **49.4pp** | **区分度最大，核心操作阈值** |
| P(≥5%) | 32.8% | 100% | 67.2pp | 最优条件以下大部分组合低于50%，参考性差 |

**P(≥3%) 是最佳平衡点：**
- 基准值 50.6% 恰好在中间，留出上下各 50pp 的分布空间
- 3% 是实际交易中有意义的冲高幅度（覆盖手续费+利润空间）
- 低于基准 50.6% 的条件自动表明"不如随机持有" → 不参与

##### 1.2.3 分数意味着什么

| 策分 | 概率语言 | 操作语言 |
|:---:|:---------|:---------|
| 100 | 下周必冲到3%以上 | 最强信号，几乎无风险 |
| 90 | 10周中9周达标 | 极大概率，放心操作 |
| 80 | 10周中8周达标 | 高概率，正常操作 |
| 70 | 10周中7周达标 | 中高概率，可参与 |
| 60 | 10周中6周达标 | 中性，略优于基准 |
| 50 | 等于全量基准 | 无区分度，不操作 |
| <50 | 低于全量基准 | 不如不操作 |

##### 1.2.4 VBA实现链路

```
神谕主循环:
  ① 条件判定 → 匹配策略名
     例: "金+多长+升排+非孕"

  ② 获取市板
     例: "Qic" (中证500)

  ③ 查概率表 P(≥3%)
     键 = "金+多长+升排+非孕|Qic" → 90.3

  ④ 写入
     谕组(X, 位谕of周冲策分) = 90.3
     谕组(X, 位谕of周冲策略) = "金+多长+升排+非孕"
```

源数据是 **全量7463只×4229602周回测**，按条件+市板组合统计 HR≥3% 的频率，存入 `D:\zdata\照明概率.txt`。VBA 首次调用时加载到 Dictionary 缓存，后续查表为 O(1)。

##### 1.2.5 概率表的结构

概率表是一个 **策略×市板 的矩阵**，每格 = P(≥3%)：

```
条件              全量    Qd    Qe   Qif   Qic  Qimit   Qin
金+多长+升排+非孕  81.6  50.0  48.5  86.6  90.3   91.4  90.5
银+盈提示有       83.3  59.6  63.8  85.2  88.2   87.2  86.4
```

- **行 = 策略名**（共17个条件策略，从"全量基准"到"龙猪/管+盈提示有"）
- **列 = 市板**（Qd指数/Qe基金ETF/Qif沪深300/Qic中证500/Qimit中证小盘/Qin中证非）
- 每格 = 该策略在该市板上的 P(≥3%)，即策分
- 全表见 [§4.2](#42-全量条件概率表)

**为什么会跨市板不同？** 同一条件在不同市板上的效果差异显著。例如"银+盈提示有"在指数上仅 59.6 分，在中证小盘上 87.2 分——差 27.6 分。不拆分市板就会全部被指数拖低。

### 1.5 评分实施方案

#### 1.5.2 概率即分数（已实现）

**核心思路：** 不再"给条件赋分"，而是**用条件自身的下周冲高概率作为分数**。

```
传统方案：四域=多长 → 拍脑袋给20分
概率方案：四域=多长 → 下周冲高概率95.5% → 分数就是95.5
```

**优势：**
- 分数天然可解释（"策分96" = "下周有96%概率冲高"）
- 不需要设计权重，概率就是权重
- 每个条件组合的分数随市场自动变化（需定期更新概率表）
- 基础条件以下自动得0分（例如全量基准91.5%，低于此的都不参与）

**VBA输出两个变量：**

```
输出结构：
  策略名称: "金+甲乙己+升排+非孕"
  冲高概率: 99.7%
```

**按类别细分的必要性：**
同一个条件在不同类别基金中的下周冲高概率不同。例如"银+盈提示有"在沪深300和中证2000中的概率可能相差10个百分点。因此需要按类别生成概率表，VBA查表赋值。

**1. 四域完整度——周线趋势在哪个区域？**

**VBA判定：**
```
' 四域判定逻辑（基于位谕of周层大局 + 位谕of周层护型）
If WXZC > 0 And DXZE > 0 Then  ' WJC之上
    If WXCD = '金' And (WXAB = '甲' Or WXAB = '乙' Or WXAB = '己') Then
        四域 = '多长'
    ElseIf WXCD = '金' Then

    End If
Else
    四域 = '空看' Or '空长'
End If
```

**通俗解释：** 趋势好不好？多长=在高速公路上开车，又快又稳。多被=在国道上开，也能走但要小心。空看/空长=在水沟或悬崖边开，不应该参与。

**20分的意思：** 四域是周冲策略的基础条件——只有多长区才能参与。给20分是因为它是入场门槛，没有这个条件其他都免谈。

### 2.6 策分卡七大结论 + 核心结论

**1. ** 体积效应：市值越小冲高越大
中证2000(5.39%) > 中证1000(5.22%) > 中证500(4.96%) > 沪深300(4.52%) > ETF(2.45%)
- 小盘股波动大，冲高机会多，但风险也大
- 大盘蓝筹冲高中等但稳定
- ETF/指数只适合做基准仓位，不适合冲高策略

**2. ** 真冲高率92% = 天然优势
任何股票在任何一周都有92%概率盘中冲高。这不是策略的功劳，是市场规律。
**策略的核心价值不是提高冲高率，而是筛选冲高幅度更大的标的。**

**3. ** 多长区是唯一有效操作区
- 四域=多长时真均幅+4.32%（全量），远优于多被(+3.46%)
- 多长区内的震仓频率决定月基分高低
- 仁慈庄家的特征：多长区内柱排方向稳定，不频繁反转

**4. **ZA 5~10 是最佳入场区间
- ZA 5~10 真冲高94%，真均幅+4.6%
- ZA 1~2 还是初期，ZA≥10 超买但仍有收益
- 原「ZA>5=失败」结论完全错误（基于错误列数据）

**5. **盈提示是正信号，不是见顶信号

### 4.2 为什么要做系统性验证？

策分是一个单一概率值（如"金最优 = 76.0%"），但一个数字掩盖了五个重要问题：

| 问题 | 举例 | 影响 |
|:----|:------|:------|
| **① 概率稳定吗？** | 76.0%是50周平均还是5周平均？近10周是否下滑到70%？ | 策分可能已过时 |
| **② 样本够吗？** | 76.0%基于多少周数据？100周 vs 10000周可信度差很远 | 小样本策分不可靠 |
| **③ 尾部风险？** | 即使76.0%达标，那24.0%失败的周里最大跌幅是多少？ | 单次亏损可能吃掉多次收益 |
| **④ 条件交互？** | 升排+非孕效果好，但再加波型=震正是否直接归零？ | 策略叠加可能产生负效应 |
| **⑤ 时间衰减？** | 这个条件3年前有效，现在是否仍然有效？ | 市场风格变化后旧规律失效 |

**核心矛盾：** 策分只能回答"历史上有多少比例冲高"，但无法回答"这个策略未来是否依然可靠"。系统性验证就是要回答后者。

### 4.3 如何验证？

5 维度验证框架，每项策略逐一检验：

| 维度 | 方法 | 判定标准 | 
|:----|:------|:---------|
| **① 稳定性** | 按年切片计算 P(≥3%)，观察年际波动幅度 | 最大偏差 ≤5pp = 稳定；≤10pp = 可接受；>10pp = 警告 |
| **② 置信度** | Wilson 95% 置信区间宽度 | 宽度 ≤10pp = 高置信度；≤15pp = 可接受；>15pp = 样本不足 |
| **③ 样本量** | 策略命中总周数 | ≥5000 周 = 可信；500~5000 = 需谨慎；<200 = 不可靠 |
| **④ 尾部风险** | 失败周中最差5%的HR分布 | 最差5% ≤ -5% = 高尾部风险 |
| **⑤ 时间衰减** | 近年(2023-2026)趋势是否与历史均值方向一致 | 逐年显著下降 = 策略可能失效 |

  _多长区 → 仅基仓（单一仓位，满足条件即持有，不下破DJE不退）
  浮仓   → 独立操作模式，由冲高信号触发，不隶属_多长区

    _空看    → 不参与

                  │          ┌─ 能<日冲策略>？→ <日冲策略>策略
