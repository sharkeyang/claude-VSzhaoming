## 二、核心调用链

```
菜单模块 (SET_设1菜单)                   常量模块 (SET_设0常量)
  UGSOP_MENU_生成                         提供 常花中股/常簿缀市板
    │ OnAction 绑定                       提供 位os*/位qt* 列定义
    ▼
主控模块 (IQQQ跨码_P展擎0主控)
  前调子过程 (IQQQ展擎主前调_*)
    │ 打包参数
    ▼
  IQQQ展擎主前调正程 (唯一引擎正程)
    │ 调用外部引擎
    ▼
  IQQQ跨码据擎_数程生成全息 → C0章按通用 → C1章按仓类 → D0节按通用 → 写页
  IQQQ展擎频谱输出分程
  IQQQ展擎筛程至A1册按全数据
  IQQQ展擎筛程至A2册按市类
  IQQQ展擎筛程至A9册按股性
  IQQQ展擎筛程至A2组合管理检查
```

三个入口（主控/全息/瓜页）最终都汇聚到 **C0章按通用 → C1章按仓类 → D0节按通用 → 写页**。

## 三、主控模块（IQQQ跨码_P展擎0主控）

### 3.1 定位
主控调度层，本身不实现算法，通过大量"前调"子过程把参数组合打包成菜单/宏入口，全部汇聚到唯一引擎正程 `IQQQ展擎主前调正程`。

### 3.2 核心引擎正程 `IQQQ展擎主前调正程`（行285-443）
参数表（行285-302）：
- `指定花册`（默认`常花中股`）— 数据源花册
- `研究日期` — 可选，指定研究日期
- `实结类型` — `cCCC`/`sCCC`/`sSCC`/`sSSC`/`sSSS`（大小写敏感，`Like "SS*"` 判断实时版）
- `是否剔黑` / `是否外簿` / `是否筛频谱` / `是否筛决策` / `是否筛市类` / `是否筛股性`
- `参of筛决策剔池` / `参of筛决策详表` — 决策输出开关
- `出章模式` / `出节模式` — 输出章节/节模式
- `WB` — 可选外部工作簿引用

内部调度流程：
1. 初始化计时器 `TT = Timer`
2. 构建 MSG 头部
3. **生成全息** → `IQQQ跨码据擎_数程生成全息`（外部模块），`计数全息=0` 则退出
4. `UTL宏工具_BEGIN`
5. **设置工簿**（外簿/本簿）
6. **输出频谱**（`是否筛频谱=True`）→ `IQQQ展擎频谱输出分程`
7. **输出市类**（`是否筛市类=True`）→ `IQQQ展擎筛程至A2册按市类`
8. **输出决策**（`是否筛决策=True`）→ `IQQQ展擎筛程至A1册按全数据` + `IQQQ展擎筛程至A2组合管理检查`
9. **输出股性**（`是否筛股性=True`）→ `IQQQ展擎筛程至A9册按股性`
10. `Erase 谕组` 释放内存
11. **保存外部存档**（`是否另存=True`）
12. `UTL宏工具_END`，返回 MSG

### 3.3 前调子过程分组
- **QQQ研究部分**（行16-51）：某时版批处理/本簿/外簿
- **QQQ花天调用**（行74-225）：按结算类型分5组（sCCC/cCCC/sSCC/sSSC/sSSS），每组含"决策简/详按周仓周地/周仓日综/混日机"变体
- **QQQ花港调用**（行244-252）：指定`常花港股通`

## 四、常量模块（SET_设0常量）

### 4.1 定位
全局常量定义模块，`Option Explicit` + `Option Compare Text`。所有常量 `Public Const`，无函数/子过程。

### 4.2 分组结构
1. **设定**（行9-23）：汇率/版本/格式常量
2. **常值：仓位**（行29-33）：`常仓限冲=10/常=5/试=3/警=1/禁=0`
3. **常值：分类**（行39-126）：花册名/数据目录/外簿路径/结算周期/簿缀/仓名/股东代码/池名/市板通配符/代码通配符
4. **定义OS列**（行141-569）：核心数据结构，用**相对偏移量**定义OS数组各列位置
5. **定义QT列**（行573-603）：行情表列定义，绝对编号，`位qt主宽=26`

### 4.3 OS列定义（锚点+相对偏移模式）
采用"锚点 + 偏移"模式，每个分节有 `位os始X类` 和 `位os终X类` 锚点，后续分节从上一分节终点+1开始：
- **(1) 基本信息**（行145-148）：代码/期类/口期/停牌
- **(2) 波动信息**（行152-196）：`位os始柱波类=5`，结价/前价/临价三套
- **(3) 柱组信息**（行200-290）：`位os始柱组类`，结幅PR0-9/HR0-9/LR0-9
- **(4) 均线信息**（行294-337）：`位os始均线类`，JZ/JA-JG、BT交叉系列
- **(6) 奏信息**（行341-371）：`位os始奏类`
- **(5) 阶部信息**（行375-383）：`位os始阶部类`
- **(3a) 波动信息（龟类）**（行387-423）：`位os始龟类`
- **(7) 工具箱**（行427-462）：`位os始具类`
- **(7) 算法信息**（行466-489）：`位os始算法类`
- **(9) 统计信息（基类）**（行493-497）：`位os始基类`
- **(10) 统计信息（统涨/统线/统区/统高）**（行501-567）
- **`位os容积 = 位os终统高类`**（行569）— OS数组总容量

**关键设计模式：** OS列定义采用"锚点+相对偏移"，新增字段只需在节内追加偏移，无需改动其他节。

## 十一、关键设计原则

1. **精确度优先**：精确度>效率，COM调用保证两者
2. **VBA→Python调用优先**：Python直接调用VBA而非重写
3. **神谕函数按行号顺序执行**：修改代码必须注意填充顺序
4. **Private/Public统一前缀**：变量名有意义，代码风格一致
5. **CInt(Timer) 溢出修复**：全项目替换为 CLng(Timer)，VBA禁止用CInt计时
6. **OS列定义锚点+相对偏移**：新增字段只需在节内追加偏移，无需改动其他节
7. **主控薄封装模式**：前调子过程只打包参数，统一交给唯一引擎正程
