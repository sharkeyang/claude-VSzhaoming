## 一、策略定位

| 维度 | 内容 |
|:----|:-----|
| 策略类型 | 日冲策略（极短线） |
| 核心问题 | 次日盘中冲高概率有多大？ |

| 评估工具 | 日冲评分（待设计） |

## 二、现状与瓶颈

现有日级别回测数据显示：
- 各类条件下日胜率均在 **47%~52%** 之间，接近随机
- 唯一略优的是 **金+甲乙己+买初** 区域，胜率54.3%
- 日级别预测力有限，**核心价值在筛选冲高幅度而非方向**

## 四、初步条件验证（2026-07-17 批量算展分析）

> **数据来源：** 30只股票算展文件，覆盖全部日级别行情数据
> **分析脚本：** `_产出物/MC3.9_算展批量分析_日级别阈值.py`

### 4.1 管宽 — 最强区分指标

| 管宽 | P(≥3%) | 均HR | 样本 | 相对基准 |
|:----|:------:|:----:|:----:|:--------:|
| 0~5（极窄） | 3.7% | 0.75% | 26,044 | 0.5x |
| 5~10 | 11.8% | 1.30% | 8,381 | 1.6x |
| 10~20 | **24.8%** | **1.98%** | 3,418 | **3.3x** |
| 20~40 | **39.9%** | **3.06%** | 696 | **5.4x** |
| >40（极宽） | **43.1%** | **3.55%** | 58 | **5.8x** |

**结论：** 管宽（顶JC）是日级别最强的单一指标。管宽>10时，次日冲高≥3%的概率是基准的3倍以上。建议将管宽作为日冲评分公式的核心维度。

### 4.2 DSHA（偏离DJA）— 与直觉相反

| DSHA | P(≥3%) | 均HR | 样本 |
|:----|:------:|:----:|:----:|
| 0~3（贴均线） | 4.1% | 0.76% | 54,203 |
| 3~5 | 12.3% | 1.29% | 14,268 |
| 5~8 | 23.2% | 1.87% | 4,979 |
| >10（大幅偏离） | **42.4%** | **3.44%** | 816 |

**结论：** 原"偏BSHA警告"假设不成立。DSHA越大后续日涨幅越大，不是回撤风险高。大幅偏离DJA的股票次日仍有更大波动，可能是趋势延续而非反转。

### 4.3 鼎 — 区分度有限

| 鼎值 | P(≥3%) | 均HR |
|:----|:------:|:----:|
| 1~2（初现） | 8.2% | 1.02% |
| 3~4 | 7.3% | 1.01% |
| 5~6 | 8.5% | 1.03% |
| 7~8 | 9.4% | 1.10% |
| ≥9（高位） | 11.5% | 1.21% |

**结论：** 鼎值高≠要跌。鼎连续出现的衰竭信号仅对单只股票成立，不是普遍规律。鼎不适合作为日冲评分中的否决条件。

### 4.4 四域日 / 柱排 — 区分度弱

**四域日：** 多长(8.3%) vs 空长(7.1%)，差仅1.2pp
**柱排：** 升(8.1%) vs 跌(7.2%)，差仅0.9pp

**结论：** 四域日和柱排在日级别上的预测力非常有限，不值得作为独立评分维度。它们作为操作准入条件（日服从周）仍有意义，但对冲高幅度筛选帮助不大。

### 4.5 关键启示

```
日级别最强信号：管宽 > DSHA > 鼎 > 四域日 ≈ 柱排

管宽 >10 时，次日冲高概率从 ~4% 跳跃到 ~25%~43%
这是日冲评分公式的基石指标
```

### 4.6 窄管蓄力验证（200只×160组合，VBA回测）

> **VBA模块：** `Call XL展探窄管蓄力` — 参数网格：窗口×DS顶JA×波动阈值×均线级别

| 窗口 | 均阳柱率 | 总样本 | 最佳参数 | 说明 |
|:---:|:--------:|:------:|:---------|:-----|
| **5** | **12.2%** | 1,517 | DS顶JA=12, 波动≥1%, DJB | ✅ 有效，样本充足 |
| 10 | 16.7% | 272 | DS顶JA=5~8, DJB | ⚠️ 样本偏少 |
| 15/20 | — | <50 | 样本不足 | ❌ 不可靠 |

**结论：**
- 窄管条件确实有效，阳柱率从基准~4-8%提升到**12.2~16.7%**（+4~8pp）
- **DS顶JA阈值越大越好**（12优于5），说明"窄管"的初始定义过严
- 均幅涨/均幅高数据存在列偏移bug（显示-80%~-118%），**优先级较低，暂不处理**

## 三、DXEF-DXCD 日级别执行框架

> 本框架是日冲策略的**核心操作规则**，回答"何时可以买、何时不能买、买了何时卖"的问题。

### 3.1 核心概念

| 层级 | 含义 | 值 | 作用 |
|:----|:-----|:---|:------|
| **DXEF** | 日级别均线排列（战场） | 金/银/唏/嘘/屎/尿 | 决定整体趋势方向 |
| **DXCD** | 日级别护级（时机） | 上/中/下/忐/忠/忑 | 决定具体操作时机 |
| **DXAB** | 日级别护型（参考） | 甲/乙/丙/丁/戊/己 | 仅参考，不一定能穿透DXCD影响DXEF |

**DXCD→DXEF 带动逻辑：**
| DXCD | 传导方向 | 对DXEF的影响 |
|:----:|:--------:|:------------|
| 上/忐 | ↗ 向上 | 带动DXEF转金银 |
| 中/忠 | ○ 无 | 无法传导，等待 |
| 下/忑 | ↘ 向下 | 带动DXEF转屎尿 |

### 3.2 完整执行规则

#### ① 完全禁止介入（绝对禁止，无例外）

| 场景 | 状态 | 理由 |
|:-----|:-----|:------|
| 屎尿区 | DXEF<0, DXZE<0, DXCD<0, DXZC<0 | 未上破DJC，无任何试仓价值 |
| 屎尿区·最危险 | DXEF<0, DXZE<0, DXCD<0, DXZC<0, DXZA>0 | 镜面：曾站上DJA却仍在DJE之下，假突破，最易诱多 |
| 嘘区 | DXEF>0, DXZE<0 | **必须退出**，无任何操作空间 |
| 金银区·退出 | DXCD>0, DXZD<0 | DXCD已负面带动DXEF，应退出 |

#### ② 仅观察，不介入（可以看，不能买）

| 场景 | 状态 | 理由 |
|:-----|:-----|:------|
| 屎尿区·观察 | DXEF<0, DXZE<0, DXCD<0, DXZC>0 | 仅观察，容易再次下破DJC |
| 屎尿区·关注 | DXEF<0, DXZE<0, DXCD<0, DXZC<0, DXAB=甲乙己 | 关注DXAB，但未上破DJC无试仓价值 |
| 唏区·中性 | DXEF<0, DXZE>0, DXCD=中/忠 | DXCD无法传导至DXEF，等待 |
| 金银区·暂退 | DXCD>0, DXZC<0 | 可暂时清仓，但DXCD未形成负面带动，还有机会站上DJC |

#### ③ 可警惕（向下传导，可能恶化）

| 场景 | 状态 | 理由 |
|:-----|:-----|:------|
| 唏区·警惕 | DXEF<0, DXZE>0, DXCD=下/忑 | DXCD向下传导(↘)，DXEF可能进一步恶化 |

#### ④ 超短/试仓（手痒可做，但必须严格止损）

| 场景 | 状态 | 止损条件 |
|:-----|:-----|:---------|
| 屎尿区·试仓 | DXEF<0, DXZE<0, DXCD<0, DXZD>0 | 以DJC为丘，下破DJC退出 |
| 屎尿区·试仓 | DXEF<0, DXZE<0, DXCD<0, DXZC>0, 刚上破DJC | 以DJC为丘，下破DJC退出 |
| 唏区·试仓 | DXEF<0, DXZE>0, DXCD=上/忐 | DXAB传导至DXCD→DXEF(↗)，有望转势 |

#### ⑤ 正式介入（主战场）

| 场景 | 状态 | 操作 |
|:-----|:-----|:------|
| **屎尿区·主战场** | DXEF<0, DXZE<0, **DXCD>0, DXZC>0** | 站上DJC，带动DXEF |
| → 主动 | DXZA>0 | **日级别主动持仓** |
| → 被动 | DXZA<0, DXZB>0 | 日级别被动持有 |
| → 持有 | DXZB<0 | 可持有 |
| **金银区·主战场** | DXEF>0, DXZE>0, **DXCD>0, DXZC>0** | 主战场 |
| → 主动 | DXZA>0 | **日级别主动持仓** |
| → 被动 | DXZA<0, DXZB>0 | 日级别被动持有 |
| → 持有 | DXZB<0 | 可持有 |

### 3.3 核心流程图

```
DXEF>0, DXZE>0 (金银)
  ├─ DXCD>0, DXZC>0 → 主战场 ✅
  │   ├─ DXZA>0       → 主动持仓
  │   ├─ DXZA<0,DXZB>0 → 被动持有
  │   └─ DXZB<0       → 持有
  ├─ DXCD>0, DXZC<0   → 可暂退
  └─ DXCD>0, DXZD<0   → 应退出 ❌
DXEF>0, DXZE<0 (嘘) → 必须退出 ❌
DXEF<0, DXZE>0 (唏)
  ├─ DXCD=上/忐       → 可试仓 ⚠️ (↗)
  ├─ DXCD=下/忑       → 可警惕 (↘)
  └─ DXCD=中/忠       → 仅观察
DXEF<0, DXZE<0 (屎尿)
  ├─ DXCD>0, DXZC>0   → 主战场 ✅ (站上DJC带动DXEF)
  │   ├─ DXZA>0       → 主动持仓
  │   ├─ DXZA<0,DXZB>0 → 被动持有
  │   └─ DXZB<0       → 持有
  ├─ DXCD>0, DXZC<0   → 可暂退
  ├─ DXCD<0, DXZD>0   → 以DJC为丘试仓 ⚠️
  ├─ DXCD<0, DXZC>0   → 仅观察
  └─ DXCD<0, DXZC<0   → 完全禁止 ❌
      ├─ DXZA>0       → 最危险（假突破）
      ├─ DXZA<0,DXZB>0 → 完全禁止
      └─ DXZB<0       → 可关注（最接近转势）
```

### 3.4 镜面映射

| 主战场(DXCD>0,DXZC>0) | 禁止区(DXCD<0,DXZC<0) |
|:----------------------|:----------------------|
| DXZA>0 → **主动持仓** ✅ | DXZA>0 → **最危险，假突破** ❌ |
| DXZA<0, DXZB>0 → 被动持有 | DXZA<0, DXZB>0 → 完全禁止 |
| DXZB<0 → 持有，无威胁 | DXZB<0 → **可关注，最接近转势** ⚠️ |

### 3.5 与日冲策略的关系

日冲策略的核心问题是"次日冲高概率多大"，而本框架回答的是"当前位置是否可以操作"。两者结合：

| 状态 | 日冲操作 |
|:-----|:---------|
| **主战场·主动** | 可正常操作日冲策略 |
| 主战场·被动 | 可操作，但需降低仓位 |
| 试仓 | 极小仓试探，严格止损 |
| 仅观察 | 不操作，等待 |
| 完全禁止 | **绝对不操作** |

### 6.7 日线数据概率验证

> 数据状态：5414只股票，16,806,241个有效交易日（DXEF非空行）。按DXEF/DXCD/DXAB三级分类，共112个分支。
> 生成方式：`XL算展取谕组日` 导出日线谕组CSV。
> 概率含义：次日日柱转为目标状态的可能性。**概率即分数**，下次介入时直接查 →ZE>0 列。

#### 核心发现

**① DXEF > DXCD > DXAB，三级递减：**
| 层级 | 最大概率跨度 | 说明 |
|:----|:----------:|:------|
| **DXEF**（金 vs 屎尿） | 99.8% → 0.3% | **决定性因素**，Δ=99.5pp |
| DXCD（上 vs 忑） | 99.8% → 72.3% | 次级因素，Δ=27.5pp（金战场内） |
| DXAB（上 vs 忑） | 99.8% → 99.2% | 最次，Δ=0.6pp（金/上战场内） |

**② 过渡区才需要关注低等级均线：**
| 场景 | DXAB=上→忑的差值 | 说明 |
|:-----|:---------------:|:------|
| 金/上（最强） | 99.8%→99.2% **Δ=0.6pp** | DXAB几乎无用 |
| 金/忑（金中最弱） | 88.8%→72.3% **Δ=16.5pp** | 金变弱时DXAB开始起作用 |
| 屎尿/上（屎尿中最强） | 73.5%→18.1% **Δ=55.4pp** | DXAB分割力极强 |
| 屎尿/忑（屎尿中最弱） | 2.1%→0.3% **Δ=1.8pp** | 已经烂透，DXAB也没用了 |

**③ 绝对不要靠直觉交易：**
- "屎尿跌多了该抄底" → 屎尿/忠/上=**3.8%** →ZE>0，不是底
- "金涨多了落袋为安" → 金/上/上=**99.8%** 续涨，提早卖出错失主升
- "DXAB转差危险了" → 金/上/忑=**99.2%** 续涨，DXAB转差但金趋势仍在

**④ 关注主升，不在震荡区逗留：**

## 八、ZE阈值分析：主升区 vs 震荡区

### 8.1 核心问题

日冲筛选中，ZE>0（站上DJE）是否必须？ZE≤0但ZC>0的情况是否值得参与？

### 8.2 分析方法

用"状态持有期累计最大收益"——从进入一个状态到退出该状态期间，计算累计收益的最大值。这比单日收益更能反映真实交易场景。

- **状态1（主升区）：** ZE>0, ZC>0 → 退出条件：ZE≤0或ZC≤0
- **状态2（震荡区）：** ZE≤0, ZC>0 → 退出条件：ZE>0或ZC≤0

### 8.3 对比结果（全量7462只股票）

**全量统计：**

**市板差异分析：**

- **Qd(指数)和Qe(ETF)收益显著低于个股：** 主升中位仅2.7~4.3%，震荡中位1.7~1.9%，主升>50%概率仅6.5~7.0%。本身波动小，更适合做波段
- **个股（Qif/Qic/Qim/Qin）结论高度一致：** 主升中位8~10%，震荡中位4~5%，倍数2.1~2.2x。主升>50%概率17~20%，震荡>50%概率1.0~1.7%

- **Qin(中证非)P90比最高（3.7x）：** 尾部收益差异最大，一旦突破空间极大

### 8.4 结论

**ZE≤0+ZC>0 就是在DJC到DJE之间震荡，收益有天花板，赚不到大钱。** 中位持有期收益仅2~5%，持有期超10%的概率只有12~42%。

**ZE>0+ZC>0 才是主升，收益无限。** 中位持有期收益5~14%，持有期超10%的概率40~65%，最大收益可达ZE≤0的3~6倍。

**日冲筛选的硬过滤条件 ZE>0+ZC>0 是正确的。** 突破DJE是打开收益空间的关键门槛，DJE之下即使ZC>0也不值得参与。
- 过渡区（屎尿/中/下/忐）— 个股概率比全量低5-15pp，ETF比全量高5-15pp
