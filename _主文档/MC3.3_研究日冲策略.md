- 各类条件下日胜率均在 **47%~52%** 之间，接近随机

## 二、日级别执行框架

### 2.1 DXEF-DXCD 日级别执行框架

> 本框架是日冲策略的**核心操作规则**，回答"何时可以买、何时不能买、买了何时卖"的问题。

#### 2.1.1 核心概念

| 层级 | 含义 | 值 | 作用 |
|:----|:-----|:---|:------|
| **DXEF** | 日级别均线排列（战场） | 金/银/唏/嘘/屎/尿 | 决定整体趋势方向 |
| **DXCD** | 日级别护级（时机） | 上/中/下/忐/忠/忑 | 决定具体操作时机 |
| **DXAB** | 日级别护级 | 上/中/下/忐/忠/忑 | 实际就是月基带日的定义 |

**DXCD→DXEF 带动逻辑：**
| DXCD | 传导方向 | 对DXEF的影响 |
|:----:|:--------:|:------------|
| 上/忐 | ↗ 向上 | 带动DXEF转金银 |
| 中/忠 | ○ 无 | 无法传导，等待 |
| 下/忑 | ↘ 向下 | 带动DXEF转屎尿 |

#### 2.1.2 完整执行规则

##### ① 完全禁止介入（绝对禁止，无例外）

| 场景 | 状态 | 理由 |
|:-----|:-----|:------|
| 屎尿区 | DXEF<0, DXZE<0, DXCD<0, DXZC<0 | 未上破DJC，无任何试仓价值 |
| 屎尿区·最危险 | DXEF<0, DXZE<0, DXCD<0, DXZC<0, DXZA>0 | 镜面：曾站上DJA却仍在DJE之下，假突破，最易诱多 |
| 嘘区 | DXEF>0, DXZE<0 | **必须退出**，无任何操作空间 |
| 金银区·退出 | DXCD>0, DXZD<0 | DXCD已负面带动DXEF，应退出 |

##### ② 仅观察，不介入（可以看，不能买）

| 场景 | 状态 | 理由 |
|:-----|:-----|:------|
| 屎尿区·观察 | DXEF<0, DXZE<0, DXCD<0, DXZC>0 | 仅观察，容易再次下破DJC |
| 屎尿区·关注 | DXEF<0, DXZE<0, DXCD<0, DXZC<0, DXAB=甲乙己 | 关注DXAB，但未上破DJC无试仓价值 |
| 唏区·中性 | DXEF<0, DXZE>0, DXCD=中/忠 | DXCD无法传导至DXEF，等待 |
| 金银区·暂退 | DXCD>0, DXZC<0 | 可暂时清仓，但DXCD未形成负面带动，还有机会站上DJC |

##### ③ 可警惕（向下传导，可能恶化）

| 场景 | 状态 | 理由 |
|:-----|:-----|:------|
| 唏区·警惕 | DXEF<0, DXZE>0, DXCD=下/忑 | DXCD向下传导(↘)，DXEF可能进一步恶化 |

##### ④ 超短/试仓（手痒可做，但必须严格止损）

| 场景 | 状态 | 止损条件 |
|:-----|:-----|:---------|
| 屎尿区·试仓 | DXEF<0, DXZE<0, DXCD<0, DXZD>0 | 以DJC为丘，下破DJC退出 |
| 屎尿区·试仓 | DXEF<0, DXZE<0, DXCD<0, DXZC>0, 刚上破DJC | 以DJC为丘，下破DJC退出 |
| 唏区·试仓 | DXEF<0, DXZE>0, DXCD=上/忐 | DXAB传导至DXCD→DXEF(↗)，有望转势 |

##### ⑤ 正式介入（主战场）

| 场景 | 状态 | 操作 |
|:-----|:-----|:------|
| **屎尿区·主战场** | DXEF<0, DXZE<0, **DXCD>0, DXZC>0** | 站上DJC，带动DXEF |
| → 主动 | DXZA>0 | **日级别主动持仓** |
| → 被动 | DXZA<0, DXZB>0 | 日级别被动持有 |
| → 持有 | DXZB<0 | 可持有 |
| **金银区·主战场** | DXEF>0, DXZE>0, **DXCD>0, DXZC>0** | 主战场 |
| → 主动 | DXZA>0 | **日级别主动持仓** |
| → 被动 | DXZA<0, DXZB>0 | 日级别被动持有 |
| → 持有 | DXZB<0 | 可持有 |

**镜面映射（同一条件在正反战场效果相反）：**

| 主战场(DXCD>0,DXZC>0) | 禁止区(DXCD<0,DXZC<0) |
|:----------------------|:----------------------|
| DXZA>0 → **主动持仓** ✅ | DXZA>0 → **最危险，假突破** ❌ |
| DXZA<0, DXZB>0 → 被动持有 | DXZA<0, DXZB>0 → 完全禁止 |
| DXZB<0 → 持有，无威胁 | DXZB<0 → **可关注，最接近转势** ⚠️ |

#### 2.1.3 核心流程图

```
DXEF>0, DXZE>0 (金银)
  ├─ DXCD>0, DXZC>0 → 主战场 ✅
  │   ├─ DXZA>0       → 主动持仓
  │   ├─ DXZA<0,DXZB>0 → 被动持有
  │   └─ DXZB<0       → 持有
  ├─ DXCD>0, DXZC<0   → 可暂退
  └─ DXCD>0, DXZD<0   → 应退出 ❌
DXEF>0, DXZE<0 (嘘) → 必须退出 ❌
DXEF<0, DXZE>0 (唏)
  ├─ DXCD=上/忐       → 可试仓 ⚠️ (↗)
  ├─ DXCD=下/忑       → 可警惕 (↘)
  └─ DXCD=中/忠       → 仅观察
DXEF<0, DXZE<0 (屎尿)
  ├─ DXCD>0, DXZC>0   → 主战场 ✅ (站上DJC带动DXEF)
  │   ├─ DXZA>0       → 主动持仓
  │   ├─ DXZA<0,DXZB>0 → 被动持有
  │   └─ DXZB<0       → 持有
  ├─ DXCD>0, DXZC<0   → 可暂退
  ├─ DXCD<0, DXZD>0   → 以DJC为丘试仓 ⚠️
  ├─ DXCD<0, DXZC>0   → 仅观察
  └─ DXCD<0, DXZC<0   → 完全禁止 ❌
      ├─ DXZA>0       → 最危险（假突破）
      ├─ DXZA<0,DXZB>0 → 完全禁止
      └─ DXZB<0       → 可关注（最接近转势）
```


#### 2.1.4 与日冲策略的关系

日冲策略的核心问题是"次日冲高概率多大"，而本框架回答的是"当前位置是否可以操作"。两者结合：

| 状态 | 日冲操作 |
|:-----|:---------|
| **主战场·主动** | 可正常操作日冲策略 |
| 主战场·被动 | 可操作，但需降低仓位 |
| 试仓 | 极小仓试探，严格止损 |
| 仅观察 | 不操作，等待 |
| 完全禁止 | **绝对不操作** |

## 三、216分支深度分析

> 本节是研究的结论落脚点。所有分析数据、验证结果、核心发现均汇总于此。
> 研究路径：第二节定义框架 → 本节深入分析 → 综合结论。

### 3.1 基础概率验证

> **数据来源：** 7462只股票，20,032,387个有效交易日。按DXEF×DXCD×DXAB三级分类，共216分支。
> **生成方式：** XL算展取谕组日 导出日线谕组CSV，216分支全量概率表生成（含贝叶斯收缩）。
> **概率含义：** 次日日柱转为目标状态的可能性。**概率即分数**，下次介入时直接查 →ZE>0 列。

> **贝叶斯收缩：** 总样本2000万行但分布极不均匀（金/上/上=284万行，银/忠/下=12行）。
> 收缩公式：p = (n × p_raw + k × p_parent) / (n + k)，k=100。
> 样本≥100时不收缩；16个N<100的分支被收缩，集中在银/尿战场的"矛盾组合"中。

#### 核心发现：DXEF > DXCD > DXAB，三级递减

**① DXEF > DXCD > DXAB，三级递减：**
| 层级 | 最大概率跨度 | 说明 |
|:----|:----------:|:------|
| **DXEF**（金 vs 屎尿） | 99.8% → 0.2% | **决定性因素**，Δ=99.6pp |
| DXCD（上 vs 忑） | 99.8% → 72.3% | 次级因素，Δ=27.5pp（金战场内） |
| DXAB（上 vs 忑） | 99.8% → 99.2% | 最次，Δ=0.6pp（金/上战场内） |

**② 过渡区才需要关注低等级均线：**
| 场景 | DXAB=上→忑的差值 | 说明 |
|:-----|:---------------:|:------|
| 金/上（最强） | 99.8%→99.2% **Δ=0.6pp** | DXAB几乎无用 |
| 金/忑（金中最弱） | 88.8%→72.3% **Δ=16.5pp** | 金变弱时DXAB开始起作用 |
| 屎尿/上（屎尿中最强） | 73.5%→18.1% **Δ=55.4pp** | DXAB分割力极强 |
| 屎尿/忑（屎尿中最弱） | 2.1%→0.3% **Δ=1.8pp** | 已经烂透，DXAB也没用了 |

**③ 绝对不要靠直觉交易：**
- "屎尿跌多了该抄底" → 屎尿/忠/上=**1.9%** →ZE>0，不是底
- "金涨多了落袋为安" → 金/上/上=**99.8%** 续涨，提早卖出错失主升
- "DXAB转差危险了" → 金/上/忑=**99.0%** 续涨，DXAB转差但金趋势仍在

### 3.2 ZE阈值分析：主升区 vs 震荡区

### 3.5 小样本分布规律

#### 3.5.1 核心规律

小样本的本质不是绝对N值小，而是**该DXCD占该战场总样本的比例极低**。

| 战场 | 主流DXCD | 占比 | 小样本出现区 | 该区占比 | 小样本数 |
|:----|:--------|:---:|:-----------|:--------:|:-------:|
| **金** | 上 | 61.9% | 无 | — | 0 |
| **银** | **上** | **79.2%** | **忐忑忠** | **2.9%** | **6** |
| 嘘 | 忑 | 67.7% | 上中 | 1.9% | 3 |
| **唏** | **上** | **66.9%** | **忐忑忠** | **7.8%** | **2** |
| 屎 | 忑 | 63.0% | 无 | — | 0 |
| **尿** | **上** | **80.4%** | **上中下** | **2.5%** | **5** |

#### 3.5.2 具体分布

- **银战场**：DXCD=忐忑忠占银总量仅2.9%，忠只有0.1%→ 6个小样本
- **嘘战场**：DXCD=上中占嘘总量仅1.9%，中只有0.3%→ 3个小样本
- **唏战场**：DXCD=忐忑忠占唏总量7.8%，忠只有0.4%→ 2个小样本
- **尿战场**：DXCD=上中下占尿总量仅2.5%，中只有0.1%→ 5个小样本

**金和屎没有小样本**，因为它们的DXCD分布相对均匀，最差的DXCD也占总样本>0.7%。

#### 3.5.3 条件格式

小样本的判断应基于**"该分支占该战场总样本的比例"**，而非绝对N值：

- 当某DXCD占战场比例<2%时，该DXCD下的DXAB分支容易出现小样本
- 银/忐忑忠、嘘/上中、尿/上中下 是典型的小样本高发区
- 金/屎 各DXCD占比>0.7%，无小样本

### 3.6 综合结论

> 本节汇总所有分析结论，是研究日冲策略的最终结论落脚点。

#### 3.6.1 框架有效性

**DXEF > DXCD > DXAB，三级递减，分类有效。**
- DXEF（战场）是决定性因素，Δ=99.5pp
- DXCD（时机）是次级因素，金战场内Δ=27.5pp
- DXAB（参考）最次级，仅过渡区起作用
- 绝对不要靠直觉交易：数据验证了"跌多了该抄底"和"涨多了落袋为安"都是错误的

#### 3.6.2 操作条件

**核心结论：用 DXZE>0+DXZC>0 替代 DXZC>0，排除震荡，抓住主升。**

单用 DXZC>0 会混入大量"DJC到DJE之间震荡"的样本，收益有天花板。必须同时满足 DXZE>0（站上DJE），才能打开收益空间。

**不是必赢，而是让赢的时候值得赢。** DXZE>0+DXZC>0 的退出盈利比例是89.9%（约10%仍亏钱出场），与震荡区的89.6%几乎持平。真正差距在于**收益幅度**：

| 条件 | 定位 | 中位持有期收益 | P90 | 持有期>50%概率 |
|:----|:-----|:-------------:|:---:|:-------------:|
| **DXZE>0+DXZC>0** | **主升区** | **8.23%** | **77.77%** | **16.9%** |
| DXZE≤0+DXZC>0 | 震荡区 | 3.96% | 21.01% | 1.3% |
| 倍数 | — | **2.1x** | **3.7x** | **13x** |

- **概率验证（3.1）：** →ZE>0概率最高，金/上/上=99.8%
- **收益验证（3.2）：** 持有期收益中位8.23%，是震荡区2.1倍
- 主升区（DXZE>0+DXZC>0）收益无限，P90=77.77%
- 震荡区（DXZE≤0+DXZC>0）收益有天花板，中位仅3.96%
- 突破DJE是打开收益空间的关键门槛

#### 3.6.3 筛选条件

**26个分支满足日冲筛选条件，占全量33.2%。**
- 第1类（18分支）：当前ZE>0+ZC>0+ZA>0，最强，占比24.6%
- 第2类（8分支）：当前ZE>0+ZC>0但ZA小于等于0，占比8.6%
- 第3类（28分支）：ZE>0但ZC小于等于0，不作为日冲备选

#### 3.6.4 冲高条件

**DXAB=强 是冲高概率大于等于30%的核心条件，但冲高不等于安全。**
- DSHA>3大于等于50%需要DXCD=强且DXAB=强，共12个分支
- DSHA>3大于等于40%只需要DXAB=强，共38个分支
- 各战场都有高冲高分分支（龙/虎/武），冲高概率高不等于安全性高
- 管宽是形态上最强的单一指标（详见第四节）

#### 3.6.5 数据可靠性

- **市板差异极小**：核心结论在所有市板间普适（金/上/上 99.6~99.9%，屎尿禁止区 0.3~0.7%）
- **小样本警告**：银/忐忑忠、嘘/上中、尿/上中下 的分支数据不可靠，需谨慎对待
- 金和屎的DXCD分布均匀，无小样本问题

## 四、按形态探索

### 4.1 管宽 — 最强区分指标

| 管宽 | P(≥3%) | 均HR | 样本 | 相对基准 |
|:----|:------:|:----:|:----:|:--------:|
| 0~5（极窄） | 3.7% | 0.75% | 26,044 | 0.5x |
| 5~10 | 11.8% | 1.30% | 8,381 | 1.6x |
| 10~20 | **24.8%** | **1.98%** | 3,418 | **3.3x** |

| >40（极宽） | **43.1%** | **3.55%** | 58 | **5.8x** |

**结论：** 管宽（顶JC）是日级别最强的单一指标。管宽>10时，次日冲高≥3%的概率是基准的3倍以上。建议将管宽作为日冲评分公式的核心维度。

### 4.2 DSHA（偏离DJA）— 与直觉相反

| DSHA | P(≥3%) | 均HR | 样本 |
|:----|:------:|:----:|:----:|
| 0~3（贴均线） | 4.1% | 0.76% | 54,203 |
| 3~5 | 12.3% | 1.29% | 14,268 |
| 5~8 | 23.2% | 1.87% | 4,979 |
| >10（大幅偏离） | **42.4%** | **3.44%** | 816 |

**结论：** 原"偏BSHA警告"假设不成立。DSHA越大后续日涨幅越大，不是回撤风险高。大幅偏离DJA的股票次日仍有更大波动，可能是趋势延续而非反转。

### 4.3 鼎 — 区分度有限

| 鼎值 | P(≥3%) | 均HR |
|:----|:------:|:----:|
| 1~2（初现） | 8.2% | 1.02% |
| 3~4 | 7.3% | 1.01% |
| 5~6 | 8.5% | 1.03% |
| 7~8 | 9.4% | 1.10% |
| ≥9（高位） | 11.5% | 1.21% |

**结论：** 鼎值高≠要跌。鼎连续出现的衰竭信号仅对单只股票成立，不是普遍规律。鼎不适合作为日冲评分中的否决条件。

### 4.4 四域日 / 柱排 — 区分度弱

**四域日：** 多长(8.3%) vs 空长(7.1%)，差仅1.2pp
**柱排：** 升(8.1%) vs 跌(7.2%)，差仅0.9pp

**结论：** 四域日和柱排在日级别上的预测力非常有限，不值得作为独立评分维度。它们作为操作准入条件（日服从周）仍有意义，但对冲高幅度筛选帮助不大。

### 4.5 关键启示

```
日级别最强信号：管宽 > DSHA > 鼎 > 四域日 ≈ 柱排

管宽 >10 时，次日冲高概率从 ~4% 跳跃到 ~25%~43%
这是日冲评分公式的基石指标
```
