## 一、总览

### 1.1 策略定位

| 维度 | 内容 |
|:----|:-----|
| 策略类型 | 日冲策略（极短线） |
| 核心问题 | 次日盘中冲高概率有多大？ |
| 时间尺度 | 日级别（前日尾盘买入→次日冲高卖出） |
| 评估工具 | 日冲评分（待设计） |
| 分析体系 | **以均线为骨（第三节、第五节），以形态修补（第四节）** |


### 1.2 现状与瓶颈

现有日级别回测数据显示：
- 各类条件下日胜率均在 **47%~52%** 之间，接近随机
- 唯一略优的是 **金+甲乙己+买初** 区域，胜率54.3%
- 日级别预测力有限，**核心价值在筛选冲高幅度而非方向**

- [x] 日级别哪些条件能有效提升次日冲高概率？已组织日级别探索路径，见[研究日级别探索路径.md](研究日级别探索路径.md)（含36个探索子项，待逐项回测）

## 二、日级别执行框架

### 2.1 DXEF-DXCD 日级别执行框架

> 本框架是日冲策略的**核心操作规则**，回答"何时可以买、何时不能买、买了何时卖"的问题。

#### 2.1.1 核心概念

| 层级 | 含义 | 值 | 作用 |
|:----|:-----|:---|:------|
| **DXEF** | 日级别均线排列（战场） | 金/银/唏/嘘/屎/尿 | 决定整体趋势方向 |
| **DXCD** | 日级别护级（时机） | 上/中/下/忐/忠/忑 | 决定具体操作时机 |
| **DXAB** | 日级别护级 | 上/中/下/忐/忠/忑 | 实际就是月基带日的定义 |

**DXCD→DXEF 带动逻辑：**
| DXCD | 传导方向 | 对DXEF的影响 |
|:----:|:--------:|:------------|
| 上/忐 | ↗ 向上 | 带动DXEF转金银 |
| 中/忠 | ○ 无 | 无法传导，等待 |
| 下/忑 | ↘ 向下 | 带动DXEF转屎尿 |

**完整带动规则（AB→CD 与 CD→EF 同逻辑）：**

| 条件 | 信号 | 含义 |
|:----|:----:|:------|
| 上游∈{上,忐} 且 下游∈{上,忐} | **▲** 同上 | 两级别同步向上，趋势最强 |
| 上游∈{下,忑} 且 下游∈{下,忑} | **▽** 同下 | 两级别同步向下，趋势最弱 |
| 上游∈{上,忐} 但 下游不在{上,忐} | **↗** 抬 | 上游向上拉下游，有改善趋势 |
| 上游∈{下,忑} 但 下游不在{下,忑} | **↘** 压 | 上游向下压下游，有恶化趋势 |
| 上游∈{中,忠} | **○** 待定 | 上游方向不明，带动作用不确定 |

> 注：CD→EF的"下游"判定中，{上,忐}映射为{金,银}，{下,忑}映射为{屎,尿}。

**日EF护级判定规则：**

| 条件 | 护级 | 含义 |
|:----|:----:|:------|
| BTEF>0 且 BTZF<0 | 尿 | EF>0但ZF下破，走弱 |
| BTEF>0 且 BTZE<0 | 嘘 | EF>0但ZE下破，混合 |
| BTEF>0 且 BTZE<BTEF | 金 | EF>0, ZE>0但低于EF，上升中 |
| BTEF>0 且 BTZE≥BTEF | 金 | EF>0, ZE≥EF，强升 |
| BTEF≤0 且 BTZF>0 | 银 | EF≤0但ZF>0，恢复中 |
| BTEF≤0 且 BTZE>0 | 唏 | EF≤0但ZE>0，混合 |
| BTEF≤0 且 BTZE>BTEF | 屎 | EF≤0, ZE>EF，下降中 |
| BTEF≤0 且 BTZE≤BTEF | 屎 | EF≤0, ZE≤EF，强降 |

**月基带日输出格式：** `(EF护级)(CD促EF)(CD护级)(AB促CD)(AB护级)`

| 输出值 | 含义 |
|:------|:------|
| `(金)▲(上)↗(上)` | EF金级，CD同上(▲)，CD上，AB抬(↗)，AB上 → 全线向上，最强状态 |
| `(屎)▽(下)↘(下)` | EF屎级，CD同下(▽)，CD下，AB压(↘)，AB下 → 全线向下，最弱状态 |
| `(银)↗(中)↗(上)` | EF银级，CD抬(↗)，CD中，AB抬(↗)，AB上 → AB向上带动CD，CD在恢复中 |
| `(金)○(忠)↘(下)` | EF金级，CD待定(○)，CD忠，AB压(↘)，AB下 → AB向下压CD，CD方向不明 |

#### 2.1.2 完整执行规则

##### ① 完全禁止介入（绝对禁止，无例外）

| 场景 | 状态 | 理由 |
|:-----|:-----|:------|
| 屎尿区 | DXEF<0, DXZE<0, DXCD<0, DXZC<0 | 未上破DJC，无任何试仓价值 |
| 屎尿区·最危险 | DXEF<0, DXZE<0, DXCD<0, DXZC<0, DXZA>0 | 镜面：曾站上DJA却仍在DJE之下，假突破，最易诱多 |
| 嘘区 | DXEF>0, DXZE<0 | **必须退出**，无任何操作空间 |
| 金银区·退出 | DXEF=金/银, DXCD>0, DXZD<0 | DXCD正面但ZD已转负，表明CD开始负面带动DXEF，应退出 |

##### ② 仅观察，不介入（可以看，不能买）

| 场景 | 状态 | 理由 |
|:-----|:-----|:------|
| 屎尿区·观察 | DXEF<0, DXZE<0, DXCD<0, DXZC>0 | 仅观察，容易再次下破DJC |
| 屎尿区·关注 | DXEF<0, DXZE<0, DXCD<0, DXZC<0, DXAB=甲乙己 | 关注DXAB，但未上破DJC无试仓价值 |
| 唏区·中性 | DXEF<0, DXZE>0, DXCD=中/忠 | DXCD无法传导至DXEF，等待 |
| 金银区·暂退 | DXEF=金/银, DXCD>0, DXZC<0 | 可暂时清仓，但DXCD未形成负面带动（ZC转负但ZD仍正），还有机会站上DJC |

##### ③ 可警惕（向下传导，可能恶化）

| 场景 | 状态 | 理由 |
|:-----|:-----|:------|
| 唏区·警惕 | DXEF<0, DXZE>0, DXCD=下/忑 | DXCD向下传导(↘)，DXEF可能进一步恶化 |

##### ④ 超短/试仓（手痒可做，但必须严格止损）

| 场景 | 状态 | 止损条件 |
|:-----|:-----|:---------|
| 屎尿区·试仓 | DXEF<0, DXZE<0, DXCD<0, DXZD>0 | 以DJC为丘，下破DJC退出 |
| 屎尿区·试仓 | DXEF<0, DXZE<0, DXCD<0, DXZC>0, 刚上破DJC | 以DJC为丘，下破DJC退出 |
| 唏区·试仓 | DXEF<0, DXZE>0, DXCD=上/忐 | DXAB传导至DXCD→DXEF(↗)，有望转势 |

##### ⑤ 正式介入（主战场）

| 场景 | 状态 | 操作 |
|:-----|:-----|:------|
| **屎尿区·主战场** | DXEF<0, DXZE<0, **DXCD>0, DXZC>0** | 站上DJC，带动DXEF |
| → 主动 | DXZA>0 | **日级别主动持仓** |
| → 被动 | DXZA<0, DXZB>0 | 日级别被动持有 |
| → 持有 | DXZB<0 | 可持有 |
| **金银区·主战场** | DXEF>0, DXZE>0, **DXCD>0, DXZC>0** | 主战场 |
| → 主动 | DXZA>0 | **日级别主动持仓** |
| → 被动 | DXZA<0, DXZB>0 | 日级别被动持有 |
| → 持有 | DXZB<0 | 可持有 |

**镜面映射（同一条件在正反战场效果相反）：**

| 主战场(DXCD>0,DXZC>0) | 禁止区(DXCD<0,DXZC<0) |
|:----------------------|:----------------------|
| DXZA>0 → **主动持仓** ✅ | DXZA>0 → **最危险，假突破** ❌ |
| DXZA<0, DXZB>0 → 被动持有 | DXZA<0, DXZB>0 → 完全禁止 |
| DXZB<0 → 持有，无威胁 | DXZB<0 → **可关注，最接近转势** ⚠️ |

#### 2.1.3 核心流程图

```
DXEF>0, DXZE>0 (金银)
  ├─ DXCD>0, DXZC>0 → 主战场 ✅
  │   ├─ DXZA>0       → 主动持仓
  │   ├─ DXZA<0,DXZB>0 → 被动持有
  │   └─ DXZB<0       → 持有
  ├─ DXCD>0, DXZC<0   → 可暂退
  └─ DXCD>0, DXZD<0   → 应退出 ❌
DXEF>0, DXZE<0 (嘘) → 必须退出 ❌
DXEF<0, DXZE>0 (唏)
  ├─ DXCD=上/忐       → 可试仓 ⚠️ (↗)
  ├─ DXCD=下/忑       → 可警惕 (↘)
  └─ DXCD=中/忠       → 仅观察
DXEF<0, DXZE<0 (屎尿)
  ├─ DXCD>0, DXZC>0   → 主战场 ✅ (站上DJC带动DXEF)
  │   ├─ DXZA>0       → 主动持仓
  │   ├─ DXZA<0,DXZB>0 → 被动持有
  │   └─ DXZB<0       → 持有
  ├─ DXCD>0, DXZC<0   → 可暂退
  ├─ DXCD<0, DXZD>0   → 以DJC为丘试仓 ⚠️
  ├─ DXCD<0, DXZC>0   → 仅观察
  └─ DXCD<0, DXZC<0   → 完全禁止 ❌
      ├─ DXZA>0       → 最危险（假突破）
      ├─ DXZA<0,DXZB>0 → 完全禁止
      └─ DXZB<0       → 可关注（最接近转势）
```


#### 2.1.4 与日冲策略的关系

日冲策略的核心问题是"次日冲高概率多大"，而本框架回答的是"当前位置是否可以操作"。两者结合：

| 状态 | 日冲操作 |
|:-----|:---------|
| **主战场·主动** | 可正常操作日冲策略 |
| 主战场·被动 | 可操作，但需降低仓位 |
| 试仓 | 极小仓试探，严格止损 |
| 仅观察 | 不操作，等待 |
| 完全禁止 | **绝对不操作** |

### 3.0 三级别甲乙己/丙丁戊分类系统（前置于分析）

> 本节将 DXEF/DXCD/DXAB 三级各分为"甲乙己（好）"和"丙丁戊（差）"，形成8格分类系统，作为日级别操作的执行框架。

**核心框架：当前位置 × 明日概率**

当前位置（由 DXEF 定义）：
- DXEF=金银唏 → 当前 DXZE>0 → 当前在 DJE 之上 → **无限收益区**（收益无上限）
- DXEF=嘘尿屎 → 当前 DXZE<0 → 当前在 DJE 之下 → **有限收益区**（收益受 DJE 距离限制）

明日概率：
- 金银唏（当前在无限区）→ `→ZE>0` = 留在无限区的概率
- 嘘尿屎（当前在有限区）→ `→ZE>0` = 进入无限区的概率

**8格分类表：**

| 等级 | DXEF | DXCD | DXAB | 当前位置 | `→ZE>0` | `→ZE>0+ZC>0` | 含义 |
|:----|:----|:----|:----|:-------|:-------:|:------------:|:------|
| **A级** | 金银唏 | 上中忐 | 上中忐 | 无限区 | **92.2%** | **70.4%** | 极大概率留在无限区 |
| B级 | 金银唏 | 上中忐 | 下忠忑 | 无限区 | 80.4% | 50.0% | 大概率留在无限区 |
| C级 | 金银唏 | 下忠忑 | 上中忐 | 无限区 | 76.2% | 39.0% | 中等概率留在无限区 |
| D级 | 金银唏 | 下忠忑 | 下忠忑 | 无限区 | 45.5% | 19.1% | 低概率留在无限区 |
| E级 | 嘘尿屎 | 上中忐 | 上中忐 | 有限区 | 54.5% | 45.3% | 中等概率进入无限区 |
| F级 | 嘘尿屎 | 上中忐 | 下忠忑 | 有限区 | 25.7% | 20.7% | 低概率进入无限区 |
| G级 | 嘘尿屎 | 下忠忑 | 上中忐 | 有限区 | 20.9% | 12.3% | 极低概率进入无限区 |
| **H级** | 嘘尿屎 | 下忠忑 | 下忠忑 | **有限区** | **8.3%** | **4.7%** | 几乎不可能进入无限区 |

**四层操作规则：**

**核心原则：只在 DJE 之上介入，不在 DJE 之下抄底。**

DJE 之下介入的真实风险不是"亏损概率"，而是"趋势不延续"：
- DJE 之上（金银唏）：73.6% 概率次日仍在 DJE 之上，趋势延续
- DJE 之下（嘘尿屎）：72.7% 概率次日仍在 DJE 之下，反复摩擦

两者收益空间对比：
- 主升区（ZE>0+ZC>0）：中位持有期收益 8.23%，P90=77.77%
- 震荡区（ZE≤0+ZC>0）：中位持有期收益 3.96%，P90=21.01%
- 差距：中位 2.1x，P90 3.7x，>50% 收益概率 13x

**分层使用：三级分类 + 管宽/市板/DSHA**

三级分类系统回答的是"当前位置在无限区还是有限区"（收益空间），不回答"明天涨不涨"（短期波动）。短期冲高概率由管宽、市板、DSHA 决定，两者独立使用：

| 维度 | 工具 | 回答的问题 |
|:----|:-----|:----------|
| **收益空间** | 三级分类（8格） | 当前位置在无限区还是有限区？能涨多少？ |
| **短期波动** | 管宽 / 市板 / DSHA | 明天冲高概率多大？ |

**永远不要做的三件事：**
1. ❌ "跌多了该抄底" → 屎尿/忠/上 的 `→ZE>0` 仅 1.9%，不是底
2. ❌ "涨多了落袋为安" → 金/上/上 的 `→ZE>0`=99.8%，续涨概率极高
3. ❌ "在 DJE 之下抢反弹" → P90 收益仅 21%，但承担的风险和 DJE 之上一样

#### 3.0.1 核心机制：趋势长度决定收益，而非单日概率

> 基于216分支全量概率表分析，揭示"无限收益"的真正来源。

**关键发现：单日概率几乎相同，差异在趋势长度（复利效应）。**

| 指标 | A级（主升区） | H级（震荡区） | 倍数 |
|:----|:------------:|:--------------:|:----:|
| 次日正向概率（DSHR>0） | 84.0% | 83.6% | **1.00x** |
| 次日平均幅度（均HR） | 1.89% | 1.65% | **1.15x** |
| 持有期中位天数 | **7天** | **3天** | **2.33x** |
| 中位持有期收益 | 8.23% | 3.96% | 2.08x |
| P90持有期收益 | 77.77% | 21.01% | 3.70x |

**结论：单日胜率（84%）和单日幅度（1.89% vs 1.65%）在A级和H级之间几乎没有差异。** 真正的差距在于趋势能延续多久——7天 vs 3天。复利效应下，7天连涨累积的收益远大于3天。

**"无限收益"的真实含义：不是单日涨得猛，而是能连续涨多天。**

**这也是必须选择长周期均线（DJE）的原因。** 如果优势来自7天的趋势延续，那么使用的均线必须能捕捉这个时间尺度的趋势。DJE（60日EMB级别）的周期长度恰好对应7天的持有期——它过滤掉了1~3天的短期噪音，只保留能持续一周以上的趋势信号。如果用短周期均线（如DJA，5日EMA），会频繁进出，无法享受复利累积。

**对交易策略的启示：**

| 位置 | 趋势长度 | 正确策略 | 错误策略 |
|:----|:--------:|:---------|:---------|
| **主升区（S/B级）** | 7天 | 持有，让复利工作 | "涨多了落袋为安"会错失后续复利 |
| **震荡区（E级）** | 3天 | 快进快出，不贪 | 持有过久会坐过山车 |
| **禁止区** | <3天 | 不参与 | "抄底"进去赚不到大钱 |

### 3.1 基础概率验证

> **数据来源：** 7462只股票，20,032,387个有效交易日。按DXEF×DXCD×DXAB三级分类，共216分支。<br>
> **生成方式：** XL算展取谕组日 导出日线谕组CSV，216分支全量概率表生成（含贝叶斯收缩）。<br>
> **概率含义：** 次日日柱转为目标状态的可能性。**概率即分数**，下次介入时直接查 →ZE>0 列。

> **贝叶斯收缩：** 总样本2000万行但分布极不均匀（金/上/上=284万行，银/忠/下=12行）。<br>
> 收缩公式：p = (n × p_raw + k × p_parent) / (n + k)，k=100。<br>
> 样本≥100时不收缩；16个N<100的分支被收缩，集中在银/尿战场的"矛盾组合"中。

#### 核心发现：DXEF > DXCD > DXAB，三级递减

**① DXEF > DXCD > DXAB，三级递减：**
| 层级 | 最大概率跨度 | 说明 |
|:----|:----------:|:------|
| **DXEF**（金 vs 屎尿） | 99.8% → 0.2% | **决定性因素**，Δ=99.6pp |
| DXCD（上 vs 忑） | 99.8% → 72.3% | 次级因素，Δ=27.5pp（金战场内） |
| DXAB（上 vs 忑） | 99.8% → 99.2% | 最次，Δ=0.6pp（金/上战场内） |

**② 过渡区才需要关注低等级均线：**
| 场景 | DXAB=上→忑的差值 | 说明 |
|:-----|:---------------:|:------|
| 金/上（最强） | 99.8%→99.2% **Δ=0.6pp** | DXAB几乎无用 |
| 金/忑（金中最弱） | 88.8%→72.3% **Δ=16.5pp** | 金变弱时DXAB开始起作用 |
| 屎尿/上（屎尿中最强） | 73.5%→18.1% **Δ=55.4pp** | DXAB分割力极强 |
| 屎尿/忑（屎尿中最弱） | 2.1%→0.3% **Δ=1.8pp** | 已经烂透，DXAB也没用了 |

**③ 绝对不要靠直觉交易：**
- "屎尿跌多了该抄底" → 屎尿/忠/上=**1.9%** →ZE>0，不是底
- "金涨多了落袋为安" → 金/上/上=**99.8%** 续涨，提早卖出错失主升
- "DXAB转差危险了" → 金/上/忑=**99.0%** 续涨，DXAB转差但金趋势仍在

- **个股（Qif/Qic/Qim/Qin）结论高度一致：** 主升中位8~10%，震荡中位4~5%，倍数2.1~2.2x。主升>50%概率17~20%，震荡>50%概率1.0~1.7%
- **Qim(中证小盘)最强：** 主升中位10.32%，>50%概率19.5%，适合做趋势
- **Qin(中证非)P90比最高（3.7x）：** 尾部收益差异最大，一旦突破空间极大

#### 3.2.4 结论

**ZE<0+ZC>0 就是在DJC到DJE之间震荡，收益有天花板，赚不到大钱。** 中位持有期收益仅2~5%，持有期超10%的概率只有12~42%。

**ZE>0+ZC>0 才是主升，收益无限。** 中位持有期收益5~14%，持有期超10%的概率40~65%，最大收益可达ZE<0的3~6倍。

**日冲筛选的硬过滤条件 ZE>0+ZC>0 是正确的。** 突破DJE是打开收益空间的关键门槛，DJE之下即使ZC>0也不值得参与。

### 3.4 DSHR>1 梯度分布规律

#### 3.4.1 核心发现

基于216分支概率表，分析下日DSHR>1（简单高幅>1%即冲高大于等于1%）的分布规律。

**DSHR>1 整体水平较高，但分化有限。**
- 全量平均：**52.1%**
- 最大值：**61.6%**（金/上/下）
- DSHR>1 ≥ 50%：**153个分支**（占71%）
- DSHR>1 ≥ 60%：**6个分支**

**DSHR>1 梯度分布：**

| DSHR>1区间 | 分支数 | 比例 | 说明 |
|:----------|:-----:|:----:|:------|
| **≥60%** | 6 | 3% | 最强，金/银/尿均有 |
| 50~60% | 147 | 68% | 主体区间，多数条件都有50%+概率 |
| 40~50% | 55 | 25% | 偏低区间 |
| <40% | 8 | 4% | 低概率区间，多为小样本分支 |

**关键发现：**

1. **DSHR>1 区分度有限。** 71%的分支都在50%以上，强弱分支差距不大（最强61.6% vs 最弱30.8%），说明"下日冲高≥1%"是一个普遍现象，不是稀有事件。

2. **DSHR>1 不与 →ZE>0 正相关。** 有些分支→ZE>0很低但DSHR>1很高（如尿/中/上→ZE>0=51.8%但DSHR>1=30.8%），反之亦然，说明冲高概率和方向概率是独立的两个维度。

3. **日冲策分（→ZE>0+ZC>0+ZA>0）才是核心指标。** DSHR>1普遍较高，不适合作为主要筛选依据；日冲策分（概率0~100）的区分度更大，更能反映下日冲高的真实概率。

```
DSHR>1 大于等于 50%:  DXCD=强(上忐忠) + DXAB=强(上忐忠)  → 12个分支
DSHR>1 大于等于 40%:  DXAB=强(上忐忠) (DXCD任意)         → 38个分支
DSHR>1 大于等于 30%:  DXAB=强(上忐忠) (DXCD任意)         → 70个分支
```

**DSHR>1 大于等于 60% 的6个分支（最强冲高）：**

|:----|:------:|:----:|:-----:|:----:|

| 金/上/中 | 61.0% | 2.10% | 99.3% | 龙强 |
| 银/上/下 | 61.0% | 1.95% | 96.9% | 龙强 |
| 银/上/中 | 60.6% | 2.03% | 99.1% | 龙强 |
| 金/下/忑 | 60.2% | 1.90% | 60.5% | 龙弱 |
| 尿/忐/中 | 60.0% | 1.88% | 13.8% | 武弱 |

#### 3.4.3 发现

1. **DSHR>1 普遍偏高，区分度有限。** 71%的分支≥50%，最强仅61.6%。说明"下日冲高≥1%"是普遍现象，不宜作为主要筛选指标。
2. **DSHR>1 和 →ZE>0 不是正相关。** 金/下/忑的→ZE>0=60.5%但DSHR>1=60.2%，尿/忐/中的→ZE>0=13.8%但DSHR>1=60.0%，说明冲高概率和方向概率独立。
3. **日冲策分（→ZE>0+ZC>0+ZA>0）才是核心指标。** 策分区分度大，应作为日冲决策的主要依据，DSHR>1仅作辅助参考。

### 3.5 小样本分布规律

#### 3.5.1 核心规律

小样本的本质不是绝对N值小，而是**该DXCD占该战场总样本的比例极低**。

| 战场 | 主流DXCD | 占比 | 小样本出现区 | 该区占比 | 小样本数 |
|:----|:--------|:---:|:-----------|:--------:|:-------:|
| **金** | 上 | 61.9% | 无 | — | 0 |
| **银** | **上** | **79.2%** | **忐忑忠** | **2.9%** | **6** |
| 嘘 | 忑 | 67.7% | 上中 | 1.9% | 3 |
| **唏** | **上** | **66.9%** | **忐忑忠** | **7.8%** | **2** |
| 屎 | 忑 | 63.0% | 无 | — | 0 |
| **尿** | **上** | **80.4%** | **上中下** | **2.5%** | **5** |

#### 3.5.2 具体分布

- **银战场**：DXCD=忐忑忠占银总量仅2.9%，忠只有0.1%→ 6个小样本
- **嘘战场**：DXCD=上中占嘘总量仅1.9%，中只有0.3%→ 3个小样本
- **唏战场**：DXCD=忐忑忠占唏总量7.8%，忠只有0.4%→ 2个小样本
- **尿战场**：DXCD=上中下占尿总量仅2.5%，中只有0.1%→ 5个小样本

**金和屎没有小样本**，因为它们的DXCD分布相对均匀，最差的DXCD也占总样本>0.7%。

#### 3.5.3 条件格式

小样本的判断应基于**"该分支占该战场总样本的比例"**，而非绝对N值：

- 当某DXCD占战场比例<2%时，该DXCD下的DXAB分支容易出现小样本
- 银/忐忑忠、嘘/上中、尿/上中下 是典型的小样本高发区
- 金/屎 各DXCD占比>0.7%，无小样本

### 3.6 综合结论

> 本节汇总所有分析结论，是研究日冲策略的最终结论落脚点。

#### 3.6.1 框架有效性

**DXEF > DXCD > DXAB，三级递减，分类有效。**
- DXEF（战场）是决定性因素，Δ=99.5pp
- DXCD（时机）是次级因素，金战场内Δ=27.5pp
- DXAB（参考）最次级，仅过渡区起作用

#### 3.6.2 操作条件

**核心结论：用 DXZE>0+DXZC>0 替代 DXZC>0，排除震荡，抓住主升。**

单用 DXZC>0 会混入大量"DJC到DJE之间震荡"的样本，收益有天花板。必须同时满足 DXZE>0（站上DJE），才能打开收益空间。

**不是必赢，而是让赢的时候值得赢。** DXZE>0+DXZC>0 的退出盈利比例是89.9%（约10%仍亏钱出场），与震荡区的89.6%几乎持平。真正差距在于**收益幅度**：

| **DXZE>0+DXZC>0** | **主升区** | **8.23%** | **77.77%** | **16.9%** |
| DXZE≤0+DXZC>0 | 震荡区 | 3.96% | 21.01% | 1.3% |
| 倍数 | — | **2.1x** | **3.7x** | **13x** |

- **概率验证（3.1）：** →ZE>0概率最高，金/上/上=99.8%
- **收益验证（3.2）：** 持有期收益中位8.23%，是震荡区2.1倍
- 主升区（DXZE>0+DXZC>0）收益无限，P90=77.77%
- 震荡区（DXZE≤0+DXZC>0）收益有天花板，中位仅3.96%
- 突破DJE是打开收益空间的关键门槛

### 3.8 三级别分类规则验证

## 四、按形态探索

### 4.1 管宽 — 最强区分指标

| 管宽 | P(≥3%) | 均HR | 样本 | 相对基准 |
|:----|:------:|:----:|:----:|:--------:|
| 0~5（极窄） | 3.7% | 0.75% | 26,044 | 0.5x |
| 5~10 | 11.8% | 1.30% | 8,381 | 1.6x |
| 10~20 | **24.8%** | **1.98%** | 3,418 | **3.3x** |
| 20~40 | **39.9%** | **3.06%** | 696 | **5.4x** |
| >40（极宽） | **43.1%** | **3.55%** | 58 | **5.8x** |

**结论：** 管宽（顶JC）是日级别最强的单一指标。管宽>10时，次日冲高≥3%的概率是基准的3倍以上。建议将管宽作为日冲评分公式的核心维度。

### 4.2 DSHA（偏离DJA）— 与直觉相反

| DSHA | P(≥3%) | 均HR | 样本 |
|:----|:------:|:----:|:----:|
| 0~3（贴均线） | 4.1% | 0.76% | 54,203 |
| 3~5 | 12.3% | 1.29% | 14,268 |
| 5~8 | 23.2% | 1.87% | 4,979 |
| >10（大幅偏离） | **42.4%** | **3.44%** | 816 |

**结论：** 原"偏BSHA警告"假设不成立。DSHA越大后续日涨幅越大，不是回撤风险高。大幅偏离DJA的股票次日仍有更大波动，可能是趋势延续而非反转。

### 4.3 鼎 — 区分度有限

| 鼎值 | P(≥3%) | 均HR |
|:----|:------:|:----:|
| 1~2（初现） | 8.2% | 1.02% |
| 3~4 | 7.3% | 1.01% |
| 5~6 | 8.5% | 1.03% |
| 7~8 | 9.4% | 1.10% |
| ≥9（高位） | 11.5% | 1.21% |

**结论：** 鼎值高≠要跌。鼎连续出现的衰竭信号仅对单只股票成立，不是普遍规律。鼎不适合作为日冲评分中的否决条件。

### 4.4 四域日 / 柱排 — 区分度弱

**四域日：** 多长(8.3%) vs 空长(7.1%)，差仅1.2pp
**柱排：** 升(8.1%) vs 跌(7.2%)，差仅0.9pp

**结论：** 四域日和柱排在日级别上的预测力非常有限，不值得作为独立评分维度。它们作为操作准入条件（日服从周）仍有意义，但对冲高幅度筛选帮助不大。

**月基带日+柱排过滤验证：** 柱排对月基带日(V4)的带动链（DXAB→DXCD→DXEF）无过滤效果。相同带动链下，柱排=升 vs 跌的P(≥3%)差距最大仅3.8pp，且方向与直觉相反（跌排时P(≥3%)反更高）。月基带日无需加柱排过滤。

### 4.5 关键启示

```
日级别最强信号：管宽 > DSHA > 鼎 > 四域日 ≈ 柱排

管宽 >10 时，次日冲高概率从 ~4% 跳跃到 ~25%~43%
这是日冲评分公式的基石指标
```

### 4.6 窄管蓄力验证（200只×160组合，VBA回测）

> **VBA模块：** `Call XL展探窄管蓄力` — 参数网格：窗口×DS顶JA×波动阈值×均线级别

| 窗口 | 均阳柱率 | 总样本 | 最佳参数 | 说明 |
