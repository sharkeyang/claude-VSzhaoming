### 1.1 金银区域限定

**原文：** "应只做WXCD金银。祖训：绝不介入WJD之下。"

**推导逻辑：**
- WXCD=金/银 → 上升趋势/震荡上升 → 可操作
- WXCD=屎/尿/唏 → 下降趋势 → 不操作
- WJD是月级别均线，WJD之下意味着月线级别空头

**数据验证（全量7,463只，2026-07-19修正）：**

**① 金升 vs 银升 关键区别：**

| 指标 | 银升（CD≤0+ZD>0） | 金升（CD>0） |
|:----|:-----------------:|:------------:|

| 收益均值 | **-4.3%** | **19.9%** |
| 收益中位数 | **-3.8%** | **2.2%** |
| 假信号率 | **50.1%** | — |

**② 银升的命运：**
- 61,680次银升跟踪中，50.1%（30,890次）是假信号，直接退出不转金升
- 这些假信号84.2%亏损，均值-4.3%
- 只有49.7%（30,682次）成功转金升，转金升后收益与直接金升相同

**③ 结论修正：**
- ❌ 旧结论：金银差距仅0.9pp，两者都可作为有效操作区域
- ✅ **新结论：银升不能作为交易依据，必须等金升（CD>0）才能进场。银升阶段只跟踪，不算交易。**

**实施现状：** ✅ 月基策略已实施（只认金升），命分只统计金升阶段收益

## 第二章：基础理论与思维框架

### 2.1 股场动力学公理（P2）

**统一对称思维：** 正向与反向符合统一的思维与算法。
**把握阴阳转换节奏：** 阴阳转换过程以反复波动过程进行，单向趋势从小到大再到小，转为反向趋势后重复此过程。
**圈定操作区域：** 按WJC选上不选下/延拓至WJCDE确定大趋势。
**圈定主升区域：** 选升不选震/选主升不选再升/选触顶不选离顶。

#### 阴阳思维（5条）
1. **存在平衡位置：** 不要总担心下跌，由于无重力场 ⇒ 存在平衡位置
2. **存在坡度路线：** 要选取一定角度≥30°，不要选贴伏均线或无坡度波动
3. **存在单向冲高：** WJC偏离可以很大很久，要利用这一特征而非故步自封
4. **存在马太效应：** 均线之上多阳柱，连阳后有连阳。宁选阳中阴，不选阴中阳。摒弃扶弱思维，善用惯性与股性
5. **微观逆向捡漏：** 在低维度，均线不具有趋势效应，要阴入阳出，与大势相反

#### 无我思维（3条）
1. **基于规则思维：** 不要主观预判，选取合理位置基于规则进行操作。多看excel少盯盘
2. **先短线再长线：** 先关注短线走势，见好就收。长线守仓以WJC为界
3. **不受持仓影响：** 不要因短期走势未如预期而放弃。要持有虚拟仓位

### 2.2 第一性原理（P3）

**基于EMA数学特性的精确进出：**
- 正向思考：EMA为何能用于抓涨？
- 逆向思考：EMA在什么情况下抓涨失败？
- 极限思考：最优情况如何？

**原有归纳法总结的抓涨方法论：**
- 指标之间的衍生关系：柱排(底层驱动)⇒均线(核心参考)⇒顶型(辅助判断)
- 利用WJC丘必赢策略

### 2.3 思维法宝（P4）

#### 坐公交理论
只要路线正确，中途即使存在与目标方向不同的路径（逆向、停顿、平行等），只要保证该路径经过目的地，最终都能到达。
- 要确定入点：作为可上车的站点
- 要确定出点：作为可下车的站点
- 要确定路线：趋势线未破，逻辑未结束

#### 舍的功效
- 舍我：应对持仓成本陷阱。不要以自身仓位为准，要以市场均线为准
- 舍末：不要纠结于最后一段涨幅，舍去顶部安全退出

#### 持股三要素（@邻居大爷）
1. **看逻辑有没有结束？** 是否有持续的政策与市场关注度？是否有反复的刺激？是否缩量下跌？
2. **看趋势线有没有结束？** 单一趋势用DJA、DJB做风控。放量下破就离场；缩量下破看三天内能否收回来
3. **看主力有没有出货？** 股价在高位，是否出现放量的阳柱或阴柱？如果之前缩量上涨，突然大放量，代表集中筹码交换

## 第六章：大局观——WJC层界体系

### 6.1 趋势判定原则——做多与做空的区别（P25）

趋势判定基于WJC/WJB/WJA均线层级，核心原则是**趋势有逻辑，震荡无厘头**，不要混淆做多与做空的边界。

**四大原则：**
1. **原则1（原旨教义）**：必要条件是在WJC之上。WJC之下不存在操作价值。
2. **原则2（跨期扩展）**：利用WXCD确定月级别大势。月势决定WJC丘的幅度。
3. **原则3（核心工具）**：用WXAB观察阴阳大势的演化。WXAB是核心，WJC是止损。
4. **原则4（负向扩展）**：基于对称原则确定下降趋势判定原则。

**做多与做空的方向选择：**
- 第一层决策：做多/观望/做多/观望/做多/观望/做多（左侧）；做空（右侧）
- 尾部警告：随时可能转跌（尾部被诱多的原因）
- WJC启动：WJC开始做多（左侧）；WJC开始做空（右侧）
- 均线层级：WJC/WJB/WJA自上而下排列
- 均线警告：弃WJA上，随时可能转跌；弃WJB上，随时可能转跌

### 6.2 以WJC丘统一各种算法（P27）

**核心思路：** 通过柱体分布，以"WJC丘必赢"统一各种算法——将WJB丘、WXAB护型、日类算法统一纳入WJC丘框架，明确选择必赢区域中的主升区域。

**步骤一：WJC丘重要性。** 基于EMA数学性质，得到WJC丘必赢。以WJC向上扩展，确定WJCDE大势。

**步骤二：WJC以上柱体的分布规律。** 已知在WJC上为升势，但柱体并非均匀分布于（顶,WJC）之内的空间，而是可以利用次级均线进行分层：
- （在WJC之上的上升区域）大部分在WJB之上
- （在WJB之上的上升区域）大部分在WJA之上
- 以此类推→（在WJA之上的上升区域）大部分在DJB/DJA之上

**重要启示：** 在保证在WJC之上的基础前提后，优先选择其中的主升区域。

**步骤三：WJB的重要性。** WJB是操作底线，不破WJB不出，保证经过最高点。

**日类细化的契机与误区：**
- **契机：** 将周范围（顶,WJB）展开为日线级别（顶,DJD）后，可将"WJC以上柱体分布"延展至日级别，存在DJCBA级别反复波动，从而存在"高抛低吸"进行仓位管理的可能。
- **误区：** 防止沉迷于日线维度，特别是在出现日级别下降信号时丢失底仓，从而踏空。

**此思路的统一意义：** 统一了"WJB丘必赢"、"WXAB护型"、"利用波型区分主升"三种算法。原来总是担心下破WJA，现在将（顶,WJA）纳入（顶,WJC）整体视野，若在WJA之上就安心持有，若经过冲高后下破WJA就退出。

### 6.3 标准走势图谱——周奏（P28）

**月走势（葛兰比法则）：**
月势根据WJCDE划分全时间段的月级别走势：
- 剔顶部震荡：/C7/C6
- 剔底部震荡：/X0/B0
- 剔下降趋势：/X6/X4
- 月势重要性：以月为准，找周主升突破点
- 月蓄势典型形态：先MXAB收敛，再上破MJC

**周走势（周奏&周波）：**

**筛选1：周类范围（WXBC）**
升态（根口）WXZC>0且WXZB>0 -> 优选
中间态-破 WXZC>0且WXZB<0 -> 方向选择
中间态-潜 WXZC<0且WXZB>0 -> 方向选择
跌态（*）WXZC<0且WXZB<0 -> 舍弃

**筛选2：WXAB丘**
WXAB护型是下周冲高的最重要决定因素。护型位置：上/中/下/忐/忠/忑，优选已正交。
WJA丘周期：突首/价鼎/价薡/突末，优选WTZA>=2。

**筛选3：日类联动**
满足DXZE>0且DXZC>0。从DJC开始做丘，可在DJC之上提前退出，可在DJC下进入。
不要被低级均线束缚，在WJA之上可提前退出，跌破WJA后可介入。

**周日联动分类：** @适合下周冲高 / _符合范围但不适合 / N不在范围

**VBA参考因素：**
1. WXAB→DXCD。要求DXZD>0，优选DXCD>0，选择DXBC>0
2. 周触顶与日触顶的协同效应
3. WJC以上大部分在DJB之上，先站上DJB再介入

### 9.3 日连升图谱（P70）

日连升是一种独立的操盘方法，需明确其重要性。

**主升结构启动的必要条件：**
1. **触顶**—一定要触顶，最好连续贴附于顶（触a或触b）
2. **DJA**—要求DTZA>=3，柱体脱离JA，或继鼎
3. **偏**—剔除偏离过大，不要追高，宽>20的情况可被动进入

主升结构形成只会在特梯/特栏/特栅之后，不会在DXZA劫恢复之后。

**启动信号：**（连升+调整结构）之后，特别是回踩DJA或DJB后得到支撑。持有过程可以包括：升连/跌孕/升吞/跌吞单次/跌连单次/破DJA单次。

**三种模式：**
1. **跟在上破DJA之后**：注意上破DJA后很可能是平移阴柱而非垒升，需要多柱确认
2. **枝贯日鼎之后**：之前为下破一柱/下破两柱；不要选择下破多柱
3. **连阳开启**：柱体逐步放大后进入哼JA管

**注意事项：** 尽量不要选择柱体不均匀情况，后面可能跟阴柱回踩确认。

## 第十章：基础工具（底层概念体系）

### 10.1 柱型全分类演变路径

柱型分类基于WJA之上，不考虑逆向趋势或WJA之下的情况。

#### 柱排基本分类

**升排（方向向上）：**
- 尾Q（连升）：/升连升连/升吞升连/升孕升连
- 尾O（调整后升）：/跌孕升吞
- 尾v（含调整）：/升连跌孕/跌孕升吞跌孕

**跌排（方向向下）：**
- 尾W（连跌）：/跌连跌连/跌吞跌连/跌孕跌连
- 尾V（反弹后跌）：/升孕跌吞
- 尾o（止跌）：/跌连升孕/升孕跌吞升孕

**人排（方向需结合均线判定）：**
非升排但可能是上升中继的情况，需区分前置柱排类型。

#### 演变路径

**升排演变路径：**
升连 → 升连(持续上升) → 升连跌孕(正常调整)
升连 → 跌孕升吞(调整后恢复) → 跌孕升吞跌孕(小幅波动)
升连 → 跌孕升吞 → 升孕跌吞(反弹失败)

**人排演变路径（衔接升排）：**
升连跌吞(栅) → 升连跌吞升吞(栅) → 升连跌吞升孕(栅)
→ 升连跌孕升孕(栅) → 跌孕升吞跌孕升孕(栅) → (衔人)升孕跌孕

**人排演变路径（衔接跌排）：**
跌连升吞 → 跌连升吞跌吞 → 跌连升吞跌孕
→ 跌连升孕跌孕 → (衔人)跌孕升孕
→ 升吞跌吞升吞 → 升吞跌吞升吞跌孕

**跌排演变路径：**
跌连(起始) → 跌连(持续下跌)
跌连 → 升孕跌吞(反弹失败) → 升孕跌吞升孕(弱反弹)
跌连 → 跌连升孕(止跌企稳) → 升吞(恢复)

#### 核心规则

1. **可介入** DJA之上的跌连（DJA之上很难容纳跌连，跌连之后是机会）
2. **可介入** 首下破DJA的跌连
3. **不可介入** 下破DJA两柱的跌排
4. 等待出现升孕/升吞且站上DJA再介入
5. 跌排必须结合均线才可介入

### 10.2 日类势头判断工具

适用于DJB之上，可推广至所有区域。

#### 指标优先级

判定指标的优先级为：
**宽**(分类标准) > **顶型** > **均线管**(顶,DJC) > **DXAB护型** > **柱与DJA丘的关系** > **地型** > **柱排**(底层驱动)

#### 触顶与均线的关系

触顶与均线是内在统一，均线更基础，触顶是子集。

- 【柱与DJA的关系】：代表进入管(哼DJA)，但存在大量虚假突破
- 【触顶哼】：代表达到管(哼DJA)的上沿，属于管的一部分
- 【管宽DS顶JC】：下(不入) ⇒ 0(可入) ⇒ 5(低波) ⇒ 20(高波) ⇒ 超（只出不进）

#### 管宽分类策略

| 管宽范围 | 策略 |
|:---------|:-----|
| <5 | 不区分柱排，任何柱排都可持有 |
| 5~20 | 未冲高情况。不破DJB不退出，退出后再站上DJB要进入 |
| >20 | 冲高情况，满足止盈条件(高偏宽连)。在DJA之上出现跌排或下破DJA都是提前卖出信号。如中途止盈必须保留底仓 |

#### DJB之上势头判断

根据（日层类+日护型+日柱排+日顶型），在日管(顶,DJB)中锁定日类上涨机会：

- **主层**：若呈放射状，适用于按DJB止损；其余层类按DJC止损
- **再层**：如果已冲高或已经历完整丘，很可能诱多
- **DXAB护型**：上涨阶段主要集中于DJB之上。不破DJB则DXAB不会负交

### 10.3 左侧止盈与卖出条件

#### 四类警盈（提前止盈信号）

| 信号 | 条件 | 操作 |
|:----|:-----|:------|
| 偏 | WSHA＞10（高幅偏离） | 减仓 |
| 宽 | WS顶JC＞20（管宽过大） | 减仓 |
| 叠 | 连续大幅上涨 | 减仓 |
| 久 | 长久运行后 | 关注 |

#### 顶部特征（冲高最后一柱）

1. 连续拉升后，不重叠柱体，逐渐转变为并排平移(十字星或小阳柱)/阴阳交错
2. 冲高形成偏离较大后迅速回撤：射击之星
3. 连阳之后悬空阴柱（可能仍是上涨但柱体高开低收）
4. 连阳之后高开吞阴
5. 快速上升后平移后下破DJA
6. 快速上升后回踩后下破DJA

#### 卖出条件优先级

1. WJC止损 — 最终退出线
2. WJB止损 — 主升阶段退出线
3. 提前止盈（偏宽叠久）— 可在WJB之上提前退出
4. 冲高后下破DJA — 日级别提前退出

### 10.4 WJA丘的典型运行形态

#### 核心原则

**WJA不是止盈或止损线，而是调整仓位的工具。** 用于建仓、捡漏、冲高、衡量偏离。

- **依赖WJB的核心理念**：相信神秘力量——柱运行在管(顶,WJA)内，允许围绕WJA正常波动
- **周柱排的应用场景**：当WTZA≥2（在WJA单边两柱以后）再参考柱排，其余情况不需要
- **冲高策略**：首选升连且未冲高；次选升连后单跌（/跌孕/跌吞）；再次选跌连后单升（/升孕/升吞）

#### 基本条件（关注前周WTZA）

| WTZA | 状态 | 操作 |
|:----:|:-----|:------|
| ≥2 | 最适合介入 | 可形成趋势上升，可参考周柱排 |
| 1 | 待选择方向 | 日级别快入快出，等待两柱站稳 |
| -1 | 待选择方向 | 日级别快入快出，寄希望为临时下破 |
| ≤-2 | 已确认下行 | 不参与，可能形成趋势下降 |

#### 下破WJA的应对

| 前WTZA | 方案：周末确认 | 方案：日类确认 |
|:------:|:-------------|:--------------|
| ≥2 | 周中下破不退出，期待反弹站回 | 下破DJC时退出 |
| 1 | 周中下破不退出，周末下破则退出 | 下破DJC时退出 |
| -1 | 本周形成WJA之下双柱，确认下破 | 前周应已退出 |
| ≤-2 | 已确认下破 | 勿介入 |

## 第十一章：思维陷阱

### 11.1 主升中的思维陷阱

**陷阱1：连升后以为会持续垒升**
连升后可能持续垒升，但以下情况很可能失败：
- 多柱横盘≥5柱，很有可能进入震荡下跌
- 在已冲高、已整弧远离WJC后，WXZA劫后站上WJA：即使是升排也很可能诱多
- 在WJA之下运行较长时间后，刚突破WJA形成升排：很有可能诱多
- 刚站上WJC：很容易失败，特别是未上破WJD的情况

**陷阱2：在WJB丘之上捡漏（下破WJA/跌排/跌吞）**
垒升不会均匀分布，出现以上异常情况属于已偏离主升。主升只会容忍夹杂少数阴柱的连阳，一旦偏离了匀速主升，虽然后面可能会有诱多的大阳柱，但升势已破。

**陷阱3：在跌排出现单阳后介入，期盼出现垒升**
要先确定主战场，在主升阶段而非震荡阶段。要按均线定位升势中的WJC大丘→按WJB止损→不要关注WJA丘或柱排。

**陷阱4：按日走势操盘，忽略周垒升**
应遵守"先周后日"原则，日走势好时不追，日走势不好时不退出，按WJB止损。

**陷阱5：日类出现涨停追涨**
要以周类走势为准，"先周后日"。

### 11.2 顶部结构识别

在WJB之上，出现以下情况可确认进入顶部结构：

**异常情况——WJA之上非升排（顶部震荡）：**
- 久丘后/跌吞/跌连
- 冲高回落遇到WJA反弹形成阳柱，后跟阴柱，继而下破WJA
- 从远离回归WJA后贴附于WJA

**特殊形态——见顶信号：**
- 三连阴：代表已逆转趋势
- 阴阳阴：且第三个阴柱应为跌吞
- 两阴夹多阳：典型顶部剧震
- 阴阳交错：毫无规律，是典型震荡形态

**下破WJA的顶部信号：**
- 单大阴下破WJA后，小孕阳柱未站上WJA（极度危险）
- 从远离WJA到逐步贴附于WJA，然后下破WJA
- 频繁贯穿WJA震荡，阴阳交错
- 连阳后破WJA，可能由主升转变为震荡

### 11.3 思维陷阱：穿越WJA的误判

**上破WJA的误判：**
- 单柱上破WJA不能确认站稳，须两柱确认或等待回踩确认
- 当WXAB负交时，上破WJA须两柱确认
- 当WXAB正交时，可单柱上破就介入，但也要防止震荡诱多

**下破WJA的误判：**
- 下破WJA单柱：面临方向选择，可能以鼎开启连阳，也可能构成跌排
- 下破WJA二柱：若为跌连，即使阳柱反弹仍可能确认跌破
- 下破WJA三柱：按镜面原则对比下破WJA阴阳阴进行判断
- 下破WJA多柱：不认为是短暂下破，须上破回踩后再介入

**核心原则：** 穿越WJA时会有反复贯穿，至少三柱才能确认站稳WJA。在主升阶段很少出现下破WJA，特别是不会出现DXBC负交的情况。若以单一均线为标准判断趋势，会因频繁贯穿、诱多、诱空所误导，必须参考柱排。
