## 〇、适用范围：日冲策略的股票池限定

### 0.1 猜想

日冲策略（等高线+BSHA信号）不应该对所有市板一视同仁。月基策略主要针对 Qd(指数成分)/Qe(基金)/Qif(沪深300)，而日冲策略应该专注于排除这些后的核心股票池。Qst(ST/退市) 风险过高也应排除。

### 0.2 验证（全量7461文件，2010万行）

**分组：**
- **核心池（日冲策略主战场）：** Qic(中证500) + Qimit(中证1000/2000) + Qin(非成分股)
- **排除池（月基策略主战场+风险股）：** Qd(指数成分) + Qe(基金/ETF) + Qif(沪深300)

**市板分组统计（代码数+样本数，花册花天→谕组日CSV匹配）：**

| 分组 | 市板 | 含义 | 代码数 | 代码占比 | 样本数 | 样本占比 |
|:---:|:---:|:----|------:|:-------:|------:|:-------:|
| **排除池** | Qd | 指数成分 | 550 | 7.4% | 1,920,167 | 9.6% |
| | Qe | 基金/ETF | 1,498 | 20.1% | 1,441,014 | 7.2% |
| | Qif | 沪深300 | 300 | 4.0% | 1,229,334 | 6.1% |
| | **小计** | | **2,348** | **31.5%** | **4,590,515** | **22.8%** |
| **核心池** | Qic | 中证500 | 499 | 6.7% | 1,953,575 | 9.7% |
| | Qimit | 中证1000/2000 | 2,958 | 39.7% | 9,098,598 | 45.3% |
| | Qin | 非成分股 | 1,656 | 22.2% | 4,459,696 | 22.2% |
| | **小计** | | **5,113** | **68.5%** | **15,511,869** | **77.2%** |
| **总计** | | | **7,461** | **100%** | **20,102,384** | **100%** |

**① 基准差异巨大（18.0pp）：**

| 池 | 加权平均基准≥2% | 总样本 |
|:---|:--------------:|:-----:|
| **核心池** | **37.1%** | 1,551万（占77%） |
| 排除池 | 19.1% | 459万（占23%） |

**② 核心池内高度同质（极差仅0.9pp），排除池内极度异质（极差24.7pp）：**

| 池 | 组成 | 基准范围 | 极差 |
|:---|:----|:-------:|:---:|
| 核心池 | Qic=36.1% / Qimit=37.2% / Qin=37.0% | 36.1~37.0% | **0.9pp** |
| 排除池 | Qd=13.3% / Qe=15.1% / Qif=33.0% | 13.3~33.0% | **24.7pp** |

**③ 策略在核心池命中率更高（+2~4pp）：**

| 策略 | 核心池≥2% | 排除池≥2% | 优势 |
|:----|:--------:|:--------:|:---:|
| 等3+BSHA5+连阳+周门 | 57.6% | 53.6% | **+4.0pp** |
| 等3+BSHA5 | 53.7% | 52.4% | +1.3pp |
| 等1+BSHA5+连阳+周门 | 59.9% | 58.5% | +1.4pp |

### 0.3 结论

**日冲策略（等高线+BSHA+连阳等所有信号）的应用范围限定为：**

> ✅ **核心池：** Qic(中证500) + Qimit(中证1000/2000) + Qin(非成分股) = 5,113只
> ❌ 排除：Qd(指数成分) + Qe(基金/ETF) + Qif(沪深300) = 2,348只

**理由：**
1. 核心池占全样本**77%**（1,551万行），策略空间充足
2. 核心池内高度同质（0.9pp），可统一处理
3. 核心池基准（37.1%）vs 排除池（19.1%），**差异18.0pp**
4. 策略在核心池命中率比排除池高1~4pp
5. Qd/Qe 基准极低（13~15%），非日冲策略有效战场
6. Qif 是月基策略主战场，日冲策略避免冲突

## 一、分类系统设计

### 1.1 核心变量

| 变量 | 来源 | 含义 |
|:----|:-----|:------|
| **DTZA（日ZA）** | ARRLLL(基位日类+位osBTZA) | JZ快均线相对JA慢均线的衍生交叉天数，正数=JZ在JA之上N柱，负数=JZ在JA之下N柱（详见VBA函数 `STBASE结算工具_衍生交叉天数`） |
| **日中符（中符串）** | 谕组(位谕of日管中符串) | 5位移位寄存器，末位（Right$）为当前柱与JA的关系。A=全上(最强)，B=上探，C=鼎(继鼎)，D=反鼎，E=下探，F=全下(最弱) |
| **顶型** | ARRLLL(基位日类+位os基顶型) | 多空力量综合分类，含"鼎"字=有支撑（数据中几乎无鼎样本） |

### 1.2 DTZA的设置理由（寿命分布 + 最优分割证明）

> **数据：** 核心池5113只（1551万行），DTZA正数/负数运行长度分布。

**DTZA 寿命分布（JZ在JA之上；负数运行几乎对称）：**

| 指标 | 正数运行 |
|:----|:-------:|
| 均值 | 5.29天 |
| 中位数 | **4.0天** |
| 标准差 | 4.87天 |
| 最大值 | 164天 |

**累计分布 = 运行≥该天数的概率（这是DTZA阈值划分的核心依据）：**

| 天数 | 单日占比 | 累计（≥该天） |
|:----:|:------:|:----------:|
| 1 | 21.4% | 100% |
| 2 | 14.1% | 78.6% |
| **3** | **11.2%** | **64.5%** |
| 4 | 9.3% | 53.3% |
| 5 | 8.0% | 44.0% |
| 7 | 5.5% | 29.0% |
| 10 | 3.1% | 15.4% |

**关键结论：**

1. **21.4% 的上升段只持续1天**（DTZA=1后就被打回）——"刚突破可能失败"的数据支撑。
2. **每个 step 的续存率约82~83%**（DTZA=2→3有64.5/78.6=82%，DTZA=3→4有53.3/64.5=83%），恒定衰减。
3. **DTZA≥4 只占53.3%**——过半的上升段不到4天就结束。
4. **DTZA≥7 仅29%，≥10 仅15.4%**——长趋势是少数。

**为什么阈值选3（|DTZA|=3是拐点）：**

- **中位数4天**说明DTZA=4已处于一次运行的中后段。
- **续存率从DTZA=3开始从高位滑落**：DTZA=2→3续存82%，DTZA=3→4续存83%，但运行≥4天只有53.3%。
- **DTZA=-3~3是"频繁贯穿、积蓄力量区"**：JZ围绕JA上下波动，|DTZA|≤3时方向倾向弱（贯穿区与稳态区方向差异仅0.9~2.5pp），|DTZA|>3进入趋势/回归稳态。
- **与柱型系统重合**：DTZA=-3~3 = 柱型的根(-3~0)+枝(1~3)区域（重合度99%+），印证2026-08-08阈值更新与柱型对齐的正确性。

**末符区分力 vs DTZA区分力（证明DTZA阈值只做微调）：**

| 划分 | 类别 | 下柱>0 | 方向差异 |
|:----|:----|:-----:|:-------:|
| **末符（强力维度）** | AB末符(等3) | 85.3% | **15.1pp** |
| | CDEF末符(等2+等4) | 70.2% | |
| **DTZA阈值（微调）** | 等2(DTZA=2~3) | 73.8% | **5.2pp** |
| | 等4(DTZA≥4) | 68.6% | |

**等高线的方向区分力主要来自末符（AB vs CDEF，15.1pp），DTZA阈值（等2 vs 等4）仅贡献1.6pp（全量数据验证）。** DTZA的主要作用是把"频繁贯穿区"（|DTZA|≤3）与"稳态区"（|DTZA|>3）分开，而非在CDEF末符内部细分方向。

**⚠️ 2026-08-12 全量修正：** 原文档§1.2声称等2vs等4方向差5.2pp，但全量7461只核心池数据验证方向差为-6.39pp（等2方向更好），等2与等4的P(≥3%)差仅2.98pp（核心池）/1.57pp（全量）。**等2+等4合并为等2，等6+等8合并为等6**，详见§4.4。

### 1.3 分类规则（VBA末位逻辑，6等简化版）

> **关键修正：** 全量验证发现VBA代码使用 `Right$(中符串,1)`（末位）而非"包含"逻辑。旧版文档用"包含"造成等2/等4/等6/等8的分类偏差。**本表已更新为末位逻辑。**
> **2026-08-12 6等简化：** 等2+等4合并为等2（ZA≥2+CDEF），等6+等8合并为等6（ZA≤-2+ABCD）。DTZA阈值细分（2~3 vs >3）无必要。

**DTZA > 0（JZ在JA之上）：**

| 分类 | 条件 | 含义 |
|:----|:-----|:------|
| **等1** | DTZA=1 | JZ刚上穿JA。刚突破，可能形成上攻，也可能围绕DJA波动 |
| **等2** | DTZA≥2 且 末符∈CDEF | JA之上且当前柱与JA相交（鼎C/反鼎D/下探E/全下F）。含原等2(DTZA2~3)和等4(DTZA>3)合并。**回归DJA，需确认是再开新丘还是下破DJA** |
| **等3** | DTZA≥2 且 末符∈AB | JA之上且当前柱强势（全上A/上探B），有向上动力 |

**DTZA < 0（JZ在JA之下）：镜面映射**

| 分类 | 条件 | 含义 |
|:----|:-----|:------|
| **等5** | DTZA=-1 | 等1镜面：JZ刚下穿JA，可能继续，也可能围绕DJA波动 |
| **等6** | DTZA≤-2 且 末符∈ABCD | JA之下且当前柱偏强（全上A/上探B/鼎C/反鼎D）。含原等6(DTZA-3~-2)和等8(DTZA<-3)合并。**需确认是否止跌反弹** |
| **等7** | DTZA≤-2 且 末符∈EF | 等3镜面：JA之下且当前柱弱势（下探E/全下F），有向下动力 |

> **镜面映射规则：** A↔F, B↔E, C↔D。上侧AB（强势）镜面为下侧EF（弱势），上侧CDEF镜面为下侧ABCD（偏强）。
> **集合镜面：** AB（上侧强势）↔ EF（下侧弱势）；CDEF（上侧弱）↔ ABCD（下侧偏强）。

## 二、下日盘中冲高概率（核心池口径）

> **数据：** 核心池（Qic+Qimit+Qin），全量5113文件。分类逻辑为VBA末位（`Right$(中符串,1)`），6等简化（等2+等4合并，等6+等8合并）。

### 2.1 分类分布（6等）

| 分类 | 条件 | 样本 | 占比 |

### 2.2 下日冲高≥0% ~ ≥5% 逐层对比（6等，核心池全量）

|:----|-----:|:---:|:---:|:----:|:----:|:----:|

| 等1 | 1,462,211 | 91.0% | 60.4% | 39.0% | 25.8% | 12.4% |
| — | — | — | — | — | — | — |
| 等7 | 5,159,593 | 91.8% | 60.7% | 36.2% | 21.8% | 8.7% |
| 等5 | 1,457,630 | 91.6% | 60.8% | 35.3% | 21.0% | 8.4% |

**关键发现：区分度随阈值递增，≥0%完全扁平，≥2%已有区分度。**

| 对比 | 最高 | 最低 | 差距 |
|:----|:----:|:----:|:----:|
| 下日冲高≥0% | 等7=91.8% | 等2=90.6% | **1.2pp（完全扁平）** |
| 下日冲高≥1% | 等2=61.8% | 等6=57.6% | 4.2pp（轻微） |
| **下日冲高≥2%** | **等2=40.2%** | **等6=33.0%** | **7.2pp** |
| **下日冲高≥3%** | **等2=26.9%** | **等6=19.5%** | **7.4pp** |
| **下日冲高≥5%** | **等2=13.0%** | **等6=7.7%** | **5.3pp** |

**结论：核心池下，等高线在≥2%已有明显区分度（7.2pp），≥3%区分度最大（7.4pp）。**

- **等2最佳**：下日冲高≥2%=40.2%，≥3%=26.9%。每10个交易日有4次下日冲高≥2%，2.7次下日冲高≥3%。
- **等6最差**：下日冲高≥2%=33.0%，≥3%=19.5%。每10个交易日仅3.3次下日冲高≥2%，2次下日冲高≥3%。
- 上侧（等2）下日冲高≥3%比下侧（等6）高 **7.4pp**，优势明显。

### 2.3 下日冲高≥0% 无区分度，≥1% 轻微

下日冲高≥0% 在所有分类中 **90.6~91.8%，仅1.2pp差距，完全扁平。** 说明"是否冲高"由市场整体决定，与DTZA无关。

下日冲高≥1% 有 **4.2pp差距**（等2=61.8% vs 等6=57.6%），轻微但存在。

**等高线的价值在≥2%及以上，不在基础概率（≥0%和≥1%）。**

### 2.4 核心发现：等高线不预测方向（6等）

| 分类 | 下柱≥2%天数比 | 下柱高幅均值 | 下柱低幅均值 | 幅度比 | 期望收益/天 |
|:----|:-----------:|:---------:|:---------:|:-----:|:---------:|
| 等1 | 38.8% | 2.22% | 1.97% | 1.12 | +0.246% |
| **等2(原等2+等4)** | 40.0% | 2.28% | 2.18% | 1.05 | +0.102% |
| 等3 | 38.6% | 2.25% | 2.29% | 0.98 | -0.038% |
| 等5 | 35.1% | 1.92% | 2.16% | 0.89 | -0.235% |
| **等6(原等6+等8)** | 32.8% | 1.82% | 2.02% | 0.90 | -0.196% |
| 等7 | 36.0% | 1.95% | 2.11% | 0.92 | -0.167% |

**所有分类的下柱≥2%天数比都在 32~40% 之间，接近 50/50 随机。** 等高线几乎不预测"明天涨还是跌"。

**核心发现：** 等1（DTZA=1，刚突破）的期望收益最高（+0.246%/天），因为高幅（2.22%）远超低幅（1.97%），幅度比1.12。等3（趋势延续）的期望收益接近零（-0.038%/天），高幅低幅几乎相等。下侧（等5~等7）期望收益均为负，其中等5最差（-0.235%/天）。

### 2.5 等高线预测什么？

等高线虽然不预测方向，但**预测冲高幅度**（≥2%/≥3%），以及**趋势延续/反转概率**：

**① 冲高幅度：** 等2下日冲高≥3%=26.9%，等6=19.5%，差7.4pp
**② 趋势延续：** 等3/等7延续性强，等2/等6反转概率高（详见下柱DTZA方向）

### 2.6 等2/等6 回归确认性质（下柱DTZA方向，核心池全量，6等）

### 3.5 综合结论
#### 3.5.1 核心发现：DXZC和DXCD是"周门"，其他都是微调

**研究过程：** 等高线（DTZA+中符串末位）本身对延续性（→ZE>0）有一定区分度，但在周门（ZC>0+DXCD=上）的约束下，所有等高线分类的→ZE>0都在93%以上。

**周门验证（核心池，阈值3）：**

| 等高线 | ZC>0 + DXCD=上（满足周门） | ZC≤0 或 DXCD≠上（不满足周门） |
|:------|:-----------------------:|:-------------------------:|
| 等1 | →ZE>0=**96.1%** | →ZE>0=19.4% |
| **等2(原等2+等4)** | →ZE>0=**98.1%** | →ZE>0=22.2% |
| 等3 | →ZE>0=**98.7%** | →ZE>0=26.6% |
| 等5 | →ZE>0=**95.4%** | →ZE>0=20.8% |
| **等6(原等6+等8)** | →ZE>0=**93.7%** | →ZE>0=21.9% |
| 等7 | →ZE>0=**93.9%** | →ZE>0=21.5% |

**关键发现：**

- **满足周门（ZC>0+DXCD=上）→ →ZE>0=93~99%，无论等高线分类**
- **不满足周门（ZC≤0 或 DXCD≠上）→ →ZE>0<27%，无论等高线分类**

#### 3.5.2 等高线的实际价值

等高线不回答"能不能做"，只回答"**做了以后弹性多大**"。具体来说：

1. **冲高幅度：** 等2下日冲高≥3%=26.8%（最高），等6=19.4%（最低），差7.4pp
2. **回归确认：** 等2后24.1%会下破，等6后21.6%会反弹——这是等高线独有的预测力，周门不能替代
3. **趋势延续：** 等3后80.9%继续走，等7后84.6%继续跌
4. **持有期：** 核心池下各等高线持有期差异不大，等3/等2略优

#### 3.5.3 最终结论

**决定"做不做"的唯一因素是：ZC>0 且 DXCD=上。**

```
ZC>0 且 DXCD=上 → 做（→ZE>0>93%）
ZC≤0 或 DXCD≠上 → 不做（→ZE>0<28%）
```

**等高线的作用：** 不是"做不做"的决定因素，而是"满足周门后"的微调工具——等2冲高弹性最大但需确认是否下破，等3趋势延续最稳，等1刚突破持有期最好。

### 5.1 日冲策略全景流程（四级过滤）

```
输入：当前股票 + 当日谕组数据
  │
  ├─ 第1级：【市板过滤】← 核心池限定
  │   ├─ ✅ 核心池：Qic(Q中证500) / Qimit(中证1000/2000) / Qin(非成分) → 继续
  │   └─ ❌ 排除池：Qd(指数) / Qe(基金) / Qif(沪深300) / Qst(ST/退市) → 跳过，无策略
  │
  ├─ 第2级：【周门过滤】
  │   ├─ ✅ ZC>0 且 CD=上 → 继续
  │   └─ ❌ 否则 → 跳过，无策略
  │
  ├─ 第3级：【等高线定位】
  │   ├─ DTZA=1 → 等1（刚穿越，可能上攻或震荡）
  │   ├─ DTZA≥2 + 末位AB → 等3（趋势延续，最强）
  │   ├─ DTZA≥2 + 末位CDEF → 等2（回归确认，需验证）
  │   ├─ DTZA=-1 → 等5（刚下穿）
  │   ├─ DTZA≤-2 + 末位ABCD → 等6（回归反弹，需验证）
  │   └─ DTZA≤-2 + 末位EF → 等7（弱势延续）
  │
  ├─ 第3.5级：【增强过滤】← 操作区域限定 + 前一柱护型（详见§5.6）
  │   ├─ 下侧等高线（等5~等7）→ 强制操作区域限定（ZC>0 或 AB∈甲乙己），+2.5~4.4pp
```

## 六、连阳趋势延续分析

> **⚠️ 范畴说明：连阳（BT连阳≥3）本质属于 [等3（趋势延续）](#13-分类规则vba末位逻辑) 的范畴。** 等3（DTZA≥2 + 末位AB）是"JA之上且当前柱强势，有向上动力"；连阳是"连续阳柱"的动量延续信号。两者都描述"趋势延续"，连阳是等3内部更细的动量细分。因此本分析应放在等高线（等3）框架下理解，连阳信号是对等3趋势延续的精细量化。

---

### 6.1 核心发现

**连阳越长，下日冲高概率越高（单调递增，无衰减）。** 这打破了"连阳长了会衰竭"的直觉——实际是"越连越强，强者恒强"。

> **数据：** 核心池，门开后。
> **基线：** P(≥2%)=43.3%，P(≥3%)=30.0%。

### 6.2 连阳位置与下日冲高概率

### 6.4 打板策略（市场连阳/涨停板）

> **范畴：** 打板策略（追涨停/连板）本质上是连阳信号在 A 股短线市场的应用，属于等3（趋势延续）范畴的极端形态。

**打板策略与连阳的关系：**
- 打板 = 追涨停板（首板/二板/三板...），本质是"连阳/连板的动量延续"
- 连阳（BT连阳）聚类了"连续上涨"的动量状态，打板是其最激进的应用
- **连板数越高，次日冲高概率越高**——与连阳"越长越强"的规律一致
- 打板的风险：连板后期（≥8板）样本骤减，追高风险大，需结合护型/BSHA确认

**打板策略的等高线框架：**
```
等高线等3（趋势延续）→ 连阳（动量延续）→ 打板（连板的极端形态）
```
打板是连阳信号在短线交易中的极致应用，其收益与风险都远高于普通连阳。当连阳≥5且满足等3+BSHA5时，可视为打板候选（P(≥2%)达60%+）。
