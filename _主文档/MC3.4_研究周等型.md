# 研究周等型（周级别等高线）

> 周级别分析框架 + 周等型的有效性与等2/等4合并分析
> 基于9个算展文件（29,114行），2026-08-10

## 一、周级别分析框架

在一个确定的级别（如日级别、周级别），指标分三层：

**日级别：**
- **宏观（均线）**：DXAB、DXCD 等均线 → 决定趋势方向
- **微观（低级别聚焦指标）**：日层等、日柱型、日柱排、日顶型 → 细节聚焦

**周级别：**
- **宏观（大势）**：WXCD → 决定大势方向
- **中观**：WXAB → 决定中观趋势
- **微观（管下沿）**：周地型、周柱型、周柱排
- **微观（管上沿）**：周顶型

> 周等高线（周等型）属于**微观指标（管下沿）**，与周柱型/周柱排同级。

## 二、周等型定义（仿照日级别等高线）

```
周ZA=1                     → 等1（WJA边缘刚站上）
周ZA=2~3 + 周末位CDEF      → 等2（近WJA软弱）
周ZA≥2 + 周末位AB          → 等3（远离WJA强势主升）
周ZA>3 + 周末位CDEF        → 等4（回归WJA）
周ZA=-1                    → 等5（WJA边缘下方）
周ZA=-3~-2 + 周末位ABCD    → 等6（近WJA下方偏强）
周ZA≤-2 + 周末位EF         → 等7（远离WJA弱势）
周ZA<-3 + 周末位ABCD       → 等8（回归WJA）
```

变量：周ZA（周BTZA）+ 周中符串末位 + 阈值3，与日级别完全一致。

## 四、等2 vs 等4 合并分析

**结论：等2与等4区分度不足（差3.3pp），建议合并。**

| 分组 | 样本 | P(≥3%) | 说明 |
|------|------|--------|------|
| 等2（ZA=2~3+CDEF） | 720 | 43.2% | |
| 等4（ZA>3+CDEF） | 1761 | 46.5% | 差3.3pp |
| **等2+等4合并** | 2481 | 45.5% | 建议合并为"等2CDEF" |
| 等3（ZA≥2+AB） | 8846 | 47.1% | 与合并后差1.6pp |

**末位AB vs CDEF 的区分不规则：**

| ZA值 | AB末位P3 | CDEF末位P3 | 差 |
|------|---------|-----------|-----|
| 2 | 44.8% | 40.6% | +4.3pp ✅ |
| 3 | 45.2% | 45.2% | 0.0pp ❌ |
| 4 | 46.4% | 50.5% | -4.1pp ❌ |
| 5 | 46.3% | 40.1% | +6.2pp ✅ |
| 6 | 49.1% | 33.5% | +15.5pp ✅ |

- ZA=3处AB与CDEF无区分 → 阈值3对周级别可能非最优
- ZA=4处CDEF反而更好 → 末位逻辑在周级别不一定成立

## 六、操作启示

- **上侧（等1~4）P3≈43~47%**：站上WJA，下周冲高机会
