# 研究周等型（周级别等高线）

> 周级别分析框架 + 周等型的有效性与等2/等4合并分析
> 基于9个算展文件（29,114行），2026-08-10

## 一、周级别分析框架

在一个确定的级别（如日级别、周级别），指标分三层：

**日级别：**
- **宏观（均线）**：DXAB、DXCD 等均线 → 决定趋势方向
- **微观（低级别聚焦指标）**：日层等、日柱型、日柱排、日顶型 → 细节聚焦

**周级别：**
- **宏观（大势）**：WXCD → 决定大势方向
- **中观**：WXAB → 决定中观趋势
- **微观（管下沿）**：周地型、周柱型、周柱排
- **微观（管上沿）**：周顶型

> 周等高线（周等型）属于**微观指标（管下沿）**，与周柱型/周柱排同级。

## 二、周等型定义（仿照日级别等高线）

```
周ZA=1                     → 等1（WJA边缘刚站上）
周ZA=2~3 + 周末位CDEF      → 等2（近WJA软弱）
周ZA≥2 + 周末位AB          → 等3（远离WJA强势主升）
周ZA>3 + 周末位CDEF        → 等4（回归WJA）
周ZA=-1                    → 等5（WJA边缘下方）
周ZA=-3~-2 + 周末位ABCD    → 等6（近WJA下方偏强）
周ZA≤-2 + 周末位EF         → 等7（远离WJA弱势）
周ZA<-3 + 周末位ABCD       → 等8（回归WJA）
```

变量：周ZA（周BTZA）+ 周中符串末位 + 阈值3，与日级别完全一致。

## 五、阈值优化分析

**核心发现：周级别末位AB vs CDEF 几乎无区分力，与日级别完全不同。**

**不同阈值下 AB vs CDEF 的区分度：**

| 阈值t | AB末位P3 | CDEF末位P3 | 差pp | 说明 |
|------|---------|-----------|------|------|
| ZA≥1 | 46.7% | 46.9% | -0.2pp | ❌ 无区分 |
| ZA≥2 | 47.1% | 45.5% | +1.6pp | 弱 |
| ZA≥3 | 47.6% | 46.3% | +1.4pp | 弱 |
| ZA≥5 | 48.5% | 45.7% | **+2.8pp** | 最佳但仅2.8pp |
| ZA≥8 | 48.0% | 49.9% | -2.0pp | CDEF反超 |

**最佳阈值 t=5，区分度仅2.8pp**，远低于日级别的5pp+。

**真正的区分度在于 ZA正负（上侧 vs 下侧）：**

| 条件 | 上侧P3 | 下侧P3 | 差pp |
|------|-------|-------|------|
| ZA>0 vs ZA<0 | 46.8% | 31.0% | **+15.7pp** |
| ZA>2 vs ZA<0 | 47.3% | 31.0% | **+16.3pp** |
| ZA>5 vs ZA<0 | 48.5% | 31.0% | **+17.5pp** |
