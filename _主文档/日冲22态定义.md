# 日冲22态定义（2026-08-02 定稿）

> 通俗解释版 — 每个状态配一个"市场人格"比喻，一眼记住它的脾气。

---

## 前提：日ZA是什么？

**日ZA（位osBTZA）是一个天数计数器，不是到均线的距离。**

- 在DJA上方：ZA=+1, +2, +3... 每天+1（像在楼上待的天数）
- 在DJA下方：ZA=-1, -2, -3... 每天-1（像在地下室待的天数）
- 穿越DJA时重置为±1（像换了一层楼）

## 命名规则

格式：`前缀 + 序号 + 第二部分 + 第三部分`

例：`H2_升_护型强`

排序：按全名字符串排序，H1 < H2 < ... < H6 < I1 < ... < V4

### 前缀

| 前缀 | 含义 | 条件 |
|:----:|:------|:------|
| H | DJA之上（High） | ZA>0 |
| I | 负转正当天（In） | ZA从<0穿越到≥0 |
| O | 正转负当天（O/出） | ZA从>0穿越到≤0 |
| V | DJA之下（V/下） | ZA<0 |

### 第二部分

| 第二部分 | 含义 | 适用 |
|:---------|:-----|:------|
| 升 | 升排 | H_/T_ |
| 人 | 人排（非升非跌） | H_/T_ |
| 跌 | 跌排 | H_/T_ |
| 暴涨 | 大幅直接穿越（ZA升/降≥3且涨/跌幅≥2%） | I_/S_ |
| 归JA | 前5天ZA在DJA附近（ZA≤3或ZA≥-3） | I_/S_ |
| 双穿 | 两次穿越DJA形成M头/M底（DTZA≤5） | I_/S_ |
| 碎步 | 连续阴/阳柱缓慢穿越 | I_/S_ |
| 其他 | 其他未归类 | I_/S_ |

### 第三部分

| 第三部分 | 含义 | 适用 |
|:---------|:-----|:------|
| 日中符C | 升排+含C（鼎信号） | H1 |
| 护型强 | 升排+甲/乙/己，强护型 | H2/V2 |
| 护型弱 | 升排+丙/丁/戊，弱护型 | H3/V3 |
| ZA3内 | 人排+ZA在DJA附近（≤3或≥-3） | H4/V4 |
| ZA3外 | 人排+ZA>3或ZA<-3，远离DJA | H5/V5 |
| 跌排 | 跌排 | H6 |
| 大柱上破 | 大阳柱直接上破 | I1 |
| 回落确认 | 触DJA→回落→再上破 | I2 |
| 直上DJA | 触DJA直上（样本极少） | I3 |
| M底加仓 | 长负→弱负(DTZA≤5)→再正 | I4 |
| 缓步上升 | 连续3+阳柱 | I5 |
| 其他上破 | 其他未归类 | I6 |
| 大柱下破 | 大阴柱直接下破 | O1 |
| 反弹失败 | 触DJA→反弹→再破 | O2 |
| 直破DJA | 触DJA直破（样本极少） | O3 |
| M头逃命 | 长正→弱正(DTZA≤5)→再负 | O4 |
| 缓步阴跌 | 连续3+阴柱 | O5 |
| 其他跌破 | 其他未归类 | O6 |

## 一、H_ — DJA之上（6种）🏔️ 楼上

楼上的状态，ZA>0，股价在均线之上。

### H1_升_日中符C — 🚀 "火箭带信标"
**升排 + 中符串含C（鼎信号）**

升排上涨中，还带鼎信号（C），就像火箭已经点火，还额外装了信标——最强信号组合。P(次日冲高≥3%) = 33.5%，仅次于I1和H2。

> 市场形象：**一个正在上升的股票，技术面给出了明确的"鼎"信号，双重确认。**

### H2_升_护型强 — 🐉 "龙抬头"
**升排 + 护型∈{甲,乙,己}（强护型）**

上升排列，且护型是最强的那一组（甲/乙/己）。就像龙从水里抬起头来，气势已经起来了。P(≥3%) = 36.2%，**H_中最高**。

> 市场形象：**一条龙从水面昂首，气势已成，稳住就能吃肉。**

### H3_升_护型弱 — 🐍 "蛇探头"
**升排 + 护型∈{丙,丁,戊}（弱护型）**

同样是升排，但护型是弱组（丙/丁/戊）。看起来在涨，但骨架不稳，像蛇探头一样——随时可能缩回去。P(≥3%) = 22.9%，比H2低了13.3pp。

> 市场形象：**表面在涨，但内功不够，随时可能变脸。H2是龙，H3是蛇，区别就在护型。**

### H4_人_ZA3内 — 🌀 "云中漫步"
**人排（非升非跌）+ ZA在1~3之间（靠近DJA）**

没涨也没跌，在均线附近晃荡。像人在云里漫步——方向不明，但位置不危险。P(≥3%) = 31.4%，意外地还不错。

> 市场形象：**横盘整理，离均线不远，随时可能选择方向。**

### H5_人_ZA3外 — ☁️ "高空飘浮"
**人排 + ZA>3（远离DJA）**

没涨没跌，但已经远离均线好几天了。像在高空飘着——没有动力继续往上，也没有掉下来，悬着。P(≥3%) = 30.2%。

> 市场形象：**悬在半空中，上不去下不来，要等风来（放量选择方向）。**

### H6_跌_跌排 — 🪂 "伞兵降落"
**跌排**

在均线之上但已经在跌了。像伞兵正在降落——虽然还在楼上（ZA>0），但趋势已向下。P(≥3%) = 26.8%。

> 市场形象：**从高处往下跳，还没落地，但下降趋势已经确立。**

## 二、T_ — DJA之下（5种）🕳️ 地下室

楼下的状态，ZA<0，股价在均线之下。

### V1_升 — 🐟 "死鱼翻身"
**升排（不区分护型）**

在均线之下出现升排。DJA之下甲/己不可能出现、乙仅8.2%，所以护型在T_升排中无区分意义。就像一条死鱼翻了个身——看着动了，但还是死的。P(≥3%) = 18.8%，**全部23态中最低之一**。

> 市场形象：**地下室的弱反弹，不要被迷惑，DJA之下的升排大概率是弱反弹。**

### V2_跌_护型强 — ⚡ "地底闪电"
**跌排 + 护型∈{甲,乙,己}（甲/己不存在，实际=乙）**

在均线之下还在跌，但护型是乙（中性护型，快线≈慢线）。就像在地窖里突然闪了一道光——虽然整体在跌，但乙护型暗示快线已接近慢线，可能反转。P(≥3%) = **21.6%**，比弱组高3.0pp。

> 市场形象：**跌跌不休中的一丝希望，乙护型是跌排中最强的信号。**（条件写"甲/乙/己"保持命名一致，甲/己在DJA之下不存在）

### V3_跌_护型弱 — 🕳️ "深渊坠落"
**跌排 + 护型∈{丙,丁,戊}**

在均线之下还在跌，且护型弱。像掉进深渊继续往下掉，没有支撑。P(≥3%) = 18.6%，样本量最大（510万，占25.0%），说明市场多数时间在下跌趋势中。

> 市场形象：**地下室还有地下室，跌跌不休，不要接飞刀。**

### V4_人_ZA3内 — 🚪 "门口徘徊"
**人排 + ZA在-3~-1之间（靠近DJA）**

在均线下面但没继续跌，就在门口晃悠。像一个人站在地下室的门口——可能推门出去（上破），也可能退回去。P(≥3%) = 24.4%。

> 市场形象：**离DJA一步之遥，横盘等方向，比V5有盼头。**

### V5_人_ZA3外 — 🏚️ "地窖深处"
**人排 + ZA<-3（远离DJA）**

在均线下面很深的地方横盘。像在地窖深处猫着，不上不下。P(≥3%) = 20.8%。

> 市场形象：**深跌区横盘，没力气反弹也没继续暴跌，死气沉沉。**

## 三、I_ — 负转正当天（6种）🌅 日出

前一天还在楼下（ZA<0），今天上来了（ZA≥0），穿越DJA。

### I1_暴涨_大柱上破 — 💥 "霸王硬上弓"
**当日ZA - 前日ZA ≥ 3（跳升3天以上）AND 涨幅≥2%**

前日还在楼下至少-2天，今天一根大阳柱直接干穿DJA，涨幅≥2%。像项羽霸王硬上弓——暴力突破，气势如虹。**P(≥3%) = 41.1%，全部23态中最高！**

> 市场形象：**深蹲后暴力起跳，次日惯性冲高概率最大。唯一超过40%的状态。**

### I2_归JA_回落确认 — 🎯 "回马枪"
**前5天靠近DJA（ZA≥-3），曾短暂上破又回落，今天再上破确认**

之前靠近DJA，试过一次没过去，退回来，今天再冲一次——成功了。像回马枪一样，先佯退再突刺。P(≥3%) = 25.9%，样本量最大（91万，占I_的48.5%）。

> 市场形象：**"一鼓作气，再而衰，三而竭"——但这里是第二次就成功了。最常见的上破方式。**

### I3_归JA_直上DJA — 🏹 "一箭穿心"
**前5天靠近DJA，无回落过程，直接上破**

没有试探，没有回踩，直接上穿。像一箭射穿靶心。样本极少（0.05万，占0.0%），**统计意义有限**。

> 市场形象：**极其罕见，直上直下型，样本太少不可靠。**

### I4_双穿_M底加仓 — 🪤 "M底陷阱"
**前5天深跌（ZA均≤-3），上破后短暂回落（≤5天）再上破**

深跌区上来，短暂回落一下再冲——M底形态。但**P(≥3%) = 14.1%，全部23态中最低！** 说明M底确认后次日反而最弱。

> 市场形象：**看着像M底加仓信号，但次日冲高概率最低——M底是反转信号，不是即日冲高信号。不要因为M底就急着追。**

### I5_碎步_缓步上升 — 🐢 "乌龟爬坡"
**连续3+阳柱，涨幅<2%，前5天最低ZA≤-2**

连续小阳柱，每根涨幅不到2%，慢慢从坑里爬上来。像乌龟爬坡——慢但稳。样本较少（2.2万，占1.2%）。P(≥3%) = 20.2%。

> 市场形象：**小碎步慢慢涨，不是暴力突破，但胜在持续。**

### I6_其他_其他上破 — 🎭 "杂牌军"
**不满足以上任何条件**

兜底状态，各种杂七杂八的上破方式。P(≥3%) = 18.7%。

> 市场形象：**说不清怎么上来的，各种情况都有，信心不足。**

## 四、S_ — 正转负当天（6种）🌇 日落

前一天还在楼上（ZA>0），今天掉下来了（ZA≤0），跌破DJA。

### O1_暴跌_大柱下破 — ⚡ "晴天霹雳"
**当日ZA - 前日ZA ≤ -3（跳降3天以上）AND 跌幅≤-2% AND 前3天都不是跌排**

前日还在楼上至少3天，今天一根大阴柱直接砸穿DJA，跌幅≥2%。像晴天霹雳——毫无预兆的暴跌。**P(≥3%) = 30.9%，所有S_中最高！** 意味着暴跌当天买入，次日仍有31%概率吃大肉。

> 市场形象：**高位暴跌，但次日反弹概率反而最高——"暴跌次日公式"有效。**

### O2_归JA_反弹失败 — 🎪 "诱多陷阱"
**前5天靠近DJA（ZA≤3），曾短暂跌破又反弹，今天再跌破确认**

之前靠近DJA，试过反弹诱多，没成功，今天再跌穿。像诱多陷阱——给你希望再掐灭。P(≥3%) = 21.2%，样本量最大（113.6万，占S_的60.3%）。

> 市场形象：**最常见的跌破方式——先反弹诱多，再真跌。不要被反弹骗进去。**

### O3_归JA_直破DJA — 🗡️ "一刀两断"
**前5天靠近DJA，无反弹，直接跌破**

没有挣扎，没有反弹，直接跌穿。像一刀两断。样本极少（0.4万，占0.2%）。**明高率仅72.7%，是唯一低于80%的状态**——次日连冲高都难。

> 市场形象：**最阴险的跌破——连反弹都不给你，直接闷杀。次日冲高概率也最低。**

### O4_双穿_M头逃命 — 🏃 "M头逃命"
**前5天高位（ZA均≥3），跌破后短暂反弹（≤5天）再跌破**

高位下来，短暂反弹诱多，再跌穿——M头形态。P(≥3%) = 27.0%，明高率89.2%是S_中最高，说明M头虽然难看，但次日反弹机会不小。

> 市场形象：**M头形态，但次日反弹概率反而最高——趁反弹跑路的最佳时机。**

### O5_碎步_缓步阴跌 — 💧 "温水煮青蛙"
**连续3+阴柱，跌幅>-2%**

连续小阴柱，每根跌幅不到2%，慢慢跌。像温水煮青蛙——等你发现已经深套了。样本较少（1.9万，占1.0%）。

> 市场形象：**阴跌是最磨人的，不是暴跌但每天都在跌，钝刀割肉。**

### O6_其他_其他跌破 — 🎭 "杂牌军（跌）"
**不满足以上任何条件**

兜底状态。P(≥3%) = 30.6%，**意外地高**——说明很多"说不清"的跌破，次日反而反弹不错。

> 市场形象：**杂七杂八的跌破，反而次日反弹概率不低。**

## 六、核心策略

**优选买入**（P≥30%）：I1 > H2 > H1 > H4 > O1

**坚决回避**（P<20%）：I4、V1、V3、V5、I6、I5

**必须盘中卖出**：所有状态的均涨%≈0，说明冲高后多数回落 → 收盘买入后，次日必须在 **盘中高点卖出**，不能等收盘。

## 七、重要说明

### 7.1 护型分组

| 分组 | 护型 | 样本占比(H_) | P(≥3%) |
|:-----|:-----|:------------:|:-------:|
| 强组 | 甲/乙/己 | 82.5% | **36.2%** |
| 弱组 | 丙/丁/戊 | 17.5% | **22.9%** |
| 差距 | — | — | **13.3pp** |

### 7.2 V_中护型处理

**V1_升不区分护型**：甲/己在DJA之下不可能出现（0样本），乙仅8.2%，护型在T_升排中无区分意义。

**V2/V3_跌按护型拆分**：全量7,462只股票验证，跌排中乙占13.5%，P(≥3%)=21.6%（vs弱组18.6%），有3.0pp区分度。甲/己虽不存在，条件仍写"甲/乙/己"以保持命名一致性。

### 7.3 O3明高率异常低

O3_归JA_直破DJA 明高率仅72.7%，其他21种状态都在80-89%之间。唯一<80%的状态，应作为预警信号。
