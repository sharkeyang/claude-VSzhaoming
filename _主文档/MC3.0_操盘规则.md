# 第一部分：基础共用层（所有方法共享）

> 以下规则是所有方法（方法周A/周B、方法日漏C/D、方法日趋A/B）共享的**前提与底线**，任何方法都必须遵守。

## 一、核心框架：先周后日（铁律）

> **周线定方向（大势），日线定时机（介入点）。周线不在沃土，日线再好也不介入。**

**操作顺序：**
1. **先看周线**：是否在沃土（WXZC>0 + WXAB上/忐）？
2. **再看日线**：是否也在沃土（DXZE>0 + DXCD上/忐）？
3. **都满足才介入**。

> 数据：周线沃土是唯一重仓区。日线突破 DXZC>0 可能完全处于周线下跌趋势中，追高必套。（C7 §6.2.1.9）

**周类四类区域（C7 §6.2.1.9）：**

| 区域 | 条件 | 操作 |
|:--|:--|:--|
| **沃土** | WXZC>0 + WXAB上/忐 | 唯一重仓区 |
| **鸡肋土** | (WXAB忠，无论ZC) + (WXZC<0 + WXAB上/忐) | 可持有，不宜过早介入 |
| **执念土** | (WXAB中，无论ZC) + (WXZC>0 + WXAB下/忑) | 观察不介入 |
| **禁土** | WXZC<0 + WXAB下/忑 | 坚决不介入 |

**日类四类区域（C7 §6.2.1.8）：**

## 四、最核心的5条铁律

1. **先周后日**：周线不在沃土，日线再好也不介入。
2. **沃土必赢**：只在沃土（DXZE>0+CD上/忐）重仓，禁土坚决不碰。
3. **升连+涨幅≥2%**：升连是主升核心（贡献113%涨幅），但必须配合涨幅≥2%（92.75%）。
4. **下破WXZC<0强制退出**：下周涨>0 仅 2.8%，几乎必跌，不退出以后想退都退不了。
5. **均上期权：站上 DXZA>0 / WXZA>0 是"提供上升机会"**（祖训，最重要发现）：虽然可能下跌，但最重要的是提供上升机会。不能仅凭站上就判断必涨，需等趋势本身确认。

> 🔴 **祖训（2026-10-21 用户确认）：** 站上 DXZA>0 / WXZA>0 是**提供上升的机会**，虽然可能下跌，但最重要的是提供上升机会。这是全系统最重要发现。
>
> 🔴 **均上期权 / 不对称操作（2026-10-21 用户深化，2026-10-22 命名"均上期权"）：** 站上均线（DXZA>0、WXZA>0、DXZC>0、WXZC>0 等）之上，实际是提供一种**期权**——一种**不对称操作**，命名为**"均上期权"**：
> - **"均"** = 均线（EMA5/EMA12/EMA26 等），**"上"** = 站上（价格在均线之上），**"期权"** = 提供上升机会（不对称操作）。
> - **均上期权 = 站上均线提供上升机会**——DXZA>0（站上 DJA=EMA5）、WXZA>0（站上 WJA=EMA5）、DXZC>0（站上 DJC=EMA26）、WXZC>0（站上 WJC=EMA26）等，都是均上期权。
> - **DXZA>0 时寻找上升机会**（利用期权，做多方向）
> - **不按 DXZA<0 进行卖出操作**（因为由其他均线定义的趋势并没有改变——DXZA 只是 EMA5，跌破它不代表趋势改变）
> - **本质**：均上期权 = 提供上升机会（可利用），跌破均线不是"卖出信号"（趋势由更高层均线定义）。**只做多方向的期权，不做空方向的卖出。**

> - **或虽看日类但不按日类积极性卖出**——日线 DXZA<0 不是卖出信号，因为由其他均线（WJC）定义的趋势并没有改变。
> - **DXZA>0 是期权（提供上升机会），DXZA<0 不是卖出信号**——只做多方向的期权，不做空方向的卖出。
> - **本质**：方法周A的持有/退出由**周线 WXZC** 决定（WXZC>0 持有，WXZC<0 退出），**日线 DXZA 只提供上升机会的期权，不决定卖出**。

**本质分类（2 种介入逻辑 × 2 种操作周期）：**

| | 日线级别 | 周线级别 |
|:--|:--|:--|
| **回调买入** | 方法日漏D（低频省心，跌破DJA/DJB低吸）+ 方法日漏C（DXZA>0阴柱捡漏，预留） | — |
| **趋势确认** | 方法日趋A（升连≥2%）+ 方法日趋B（BSHA5偏离DJA≥5%） | 方法周A（WJC 入口）+ 方法周B（WJB 入口，预留） |

> **关键洞察：**
> - **方法日趋A（升连≥2%）是方法日漏D（低频省心）的"优选增强"**——低频省心策略在沃土内买入后，如果恰好遇到升连+涨幅≥2%，胜率从 ~73% 提升到 92.75%。**方法日趋A不是独立方法，而是方法日漏D的"抓谁在涨"增强**（C7 §6.1.1 明确：沃土必赢是底线，升管垒升是优选非必须）。
> - **方法日趋B（BSHA5）是追涨（趋势确认），不是回调买入（2026-10-22 用户修正）**——BSHA5 = 偏离 DJA≥5%，价格已经涨了一波（偏离均线远），是**追涨**逻辑。**与低吸的区别**：方法日漏D（低频省心）是跌破 DJA/DJB 低吸（回调买入）；方法日趋B（BSHA5）是偏离 DJA≥5% 追涨（趋势确认）。**两者介入逻辑相反。**
> - **方法周A（WJC 入口）是方法日漏D的"周线级别版本"**——低频省心策略是日线级别操作，WJC 入口是周线级别操作（突破 WJC 时介入，持有至 WXZB 转负）。
> - **方法周A是底线，其他是增强**——方法周A只依赖 WXZC>0（EMA 数学必赢），其他方法叠加更多条件（护型/升连/BSHA5）提高每次胜率，但代价是交易频率更低。
> - **方法周B（WJB 入口）与方法日漏C（DXZA>0 阴柱捡漏）为预留方法**——方法周B 是方法周A 的补充（在 WXZC>0 基础上以 WJB 入口 + 升连周边介入）；方法日漏C 是方法日漏D 的对称（D 是跌破 DJA 劫时低吸，C 是 DXZA>0 时阴柱介入）。具体操作流程待设计。
