> **定位：** 这是日类第三阶段（微观指标微调）的具体落地——在护型操作范围内，用微观指标判断"甲是否即将转乙（DXZA<0）"以及"甲 DXZA>0 时是否该提前退出"。数据：谕组日全量约 2020 万样本。
>
> **框架衔接：** 见 `MC3.3_C2日DXZC+DXAB全维度分析.md` 第四章 §4.3（日类三阶段框架的第三阶段）。C2 第四章 §4.4 仅保留概括性叙述与计划，详细微观数据与本处一致。

### 5.2 微观指标的座次与决策树（最佳底座问题）

> **结论先行：** **日等型（等高线）是最佳底座**——它与 DXAB 护型**共享日ZA 底层变量**（等高线由 DTZA 决定，DXAB 乙/戊由 DXZA 符号决定），天然衔接；完全划分（等1~等7 覆盖所有 DTZA 状态）；方向稳定（下柱>0 85-87%）满足"同类别稳定"。**定位：等高线是 DXAB 之上的微调（从属），不推翻 DXAB 取舍表**——DXAB 决定"能否做"，等高线微调"何时做"。
>
> **决策树座次：** DXEF（天时）→ DXCD（地利）→ DXZC → **DXAB（护型，主/被决定）** → **等高线（底座，微调介入时机）** → 顶型/柱排（增强信号）。微观指标只做微调，不推翻 DXAB 取舍表。

> **🔴 底座标准（用户定义，2026-09-03）：** 底座需满足 3 条：
> 1. **衔接上级指标 DXAB** —— 底座分类 × DXAB 有交叉意义（揭示"何时做 × 能否做"配合规律）
> 2. **完全划分** —— 每个样本都归入某个类别，无遗漏
> 3. **同类别稳定** —— 同一底座类别内性质稳定（同质性高）
>
> ⚠️ 此标准**不同于** 2.2 的"位置信息"标准——2.2 看"单独区分度最强"，本标准看"能否衔接 DXAB + 完全划分 + 同类别稳定"。

**⑤ 核心结论（日等型是最佳基座的证据）**

**① 等型是下日冲高的主要区分维度。** 等1（2.46%）> 等2（2.40%）> 等3（2.35%）> 等7（2.18%）> 等5/等6（2.09~2.10%），排序与 ZC 和护型无关。

**② ZC 和护型对下日冲高的边际贡献有限（0.2~0.6pp），远小于对收盘涨幅的贡献（0.6~1.0pp）。** 这是因为盘中冲高受短期波动影响大，而收盘涨幅更反映趋势质量。

**③ 护型区分的是"收盘能否守住"而非"盘中能否冲高"。** 差护型（丙丁）盘中也能冲高（ZC>0 时 2.10%/24~25%），但收盘会跌回去（丙 ZC>0 时 -1.70%/23%）。

**④ 操作含义：** 如果策略目标是"下日盘中冲高就跑"（日冲），等型本身已提供足够区分度，ZC 和护型的边际价值有限。如果策略目标是"持有数日等收盘涨幅"（日浮仓），ZC 和护型至关重要——它们决定的是"收盘能否守住"，而非"盘中能否冲高"。

> **结论：** 等型（等高线）是下日冲高的主要区分维度，ZC/护型只是微调——**这直接支持"日等型是最佳基座"**（等高线提供位置信息，ZC/护型无法替代）。

1. **日等型（等高线）最符合底座定义**——它与 DXAB **共享日ZA底层变量**，天然结合度好。等高线完全由 DTZA 决定（等1=DTZA=1、等2/等3=DTZA≥2+末位、等5=DTZA=-1、等6/等7=DTZA≤-2+末位），而 DXAB 护型（乙/戊）也由 DXZA 符号决定（C2 §2.1.4.1：乙(DXZA>0) vs 乙(DXZA≤0) 完全相反）。**两者同源，衔接是天然的，无需额外交叉验证。**
2. **日柱排"种类太多且不明确"**——柱排有大量子类型（升连按连阳数 Q2~Q206 细分、升吞、跌孕、人排变体），粗分类"升/人/跌"掩盖了内部巨大差异（升连Q2 与升连Q10 性质完全不同）。**作为底座，柱排分类不明确、同类别不稳定。**
3. **等高线"同类别稳定"满足（方向稳定）**——**方向非常稳定**（下柱>0 85-87%，柱排方向波动仅 2-4.4pp）。冲高幅度虽受 BSHA 影响（20-26pp 波动），但**"稳定"标准侧重方向**（用户确认，2026-09-03），故等高线满足"同类别稳定"。
4. **三个候选都能衔接 DXAB**（2026-09-03 验证）——日顶型 DXAB 交叉区分度最高（11.0pp），日柱排 7.7pp，管中形态（日管宽哼JA）6.3pp（管宽≥10+甲乙己 49.1% vs 非甲乙己 42.8%）。**但日顶型"完全划分"粒度太粗**（触顶/非触顶 二元，非触顶占 82.6%），**管中形态是连续变量分类不明确**。
5. **统一口径 P3 下，管中形态（管宽）是最强候选**——管宽≥10 P3=46.4%、管宽≥20 P3=56.3%，远超日顶型触顶（29.8%）和等高线等2（26.8%）。**但管宽≥10 仅占 9.1%（100万样本）、≥20 仅占 0.8%（8.4万样本），样本量小**，且管宽是连续变量分类不明确。日顶型触顶（29.8%）次之，但二元划分粒度太粗。

### 5.3 日冲策略位置坐标系（DXZC × DXAB × 等型）

> **数据：** 高波池（Qic+Qim+Qit），3451 文件全量，11,031,366 行。指标为**下日高幅**（次日盘中最高涨幅）。

#### 5.3.1 位置坐标系总览

日冲策略的完整决策链为：`DXEF → DXCD → DXZC → DXAB → 日等型 → 日柱排/日顶型`。其中 **DXZC、DXAB、日等型** 构成三维位置坐标系：

| 维度 | 变量 | 分段 | 含义 |
|:----|:-----|:-----|:------|
| **DJA位置** | 日等型 | 等1/等2/等3/等5/等6/等7 | JZ相对JA的位置与方向 |
| **DJC位置** | DXZC | ZC>0（DJC上方）/ ZC<0（DJC下方） | 中期趋势支撑 |
| **护型质量** | DXAB | 甲/乙/丙/丁/戊/己 | 均线排列质量 |

**位置坐标系回答三个问题：**
1. **当前在 DJA 的什么位置？**（等型）
2. **当前在 DJC 的什么位置？**（ZC 符号）
3. **均线排列质量如何？**（护型）

| 层级 | 位置条件 | 基准H2 | 操作 |

| 🥈 **等信号** | 等3/等5/等6/等7 + ZC>0 + 任意护型 | 36~42% | 等待 BSHA5 触发，BSHA5 后 H2 可达 50~62% |
| 🥉 **超跌反弹** | 等5 + ZC>0 + 乙 | 39.7% | BSHA5 时最强（61.5%），等5 专属策略 |
| ❌ **禁止** | 任何 + ZC<0 + 丙丁戊 | 30~35% | 基准差，BSHA5 样本太小，不建议操作 |

**核心原则：**
1. **ZC>0 是操作的前提条件**——ZC<0 时无论护型多好都不建议主动介入
2. **位置优先于信号**——等1+ZC>0+甲 基准 H2=45.8%，比等3+ZC<0+戊+BSHA5（51.7%）只低 5.9pp，但样本大 400 倍
3. **BSHA5 是触发器**——好位置 + BSHA5 → H2=57~60%
4. **等5 是特殊位置**——基准差但 BSHA5 时反转最强，超跌反弹逻辑
5. **ZC<0 时慎入**——基准 H2 仅 30~35%，即使有 BSHA5 样本也太小

##### 5.7.2.3 冲顶星 VBA 落地


> **目的：** 将 §5.10 的最强信号（触顶 + 十字星无长上影 + BSHA≥8 ≈ 64-68% 次日冲高）写入系统的 **日层机警** 字段，使筛选/回测可直接读取。

**① 日层机警 原有逻辑（`IQQQ跨码_D据擎2神谕.bas` L3825-3839）：**

| 机警值 | 触发条件 |
|:--|:--|
| 等3顶 | 等3 + ZC>0 + 顶型含龙 + 上符末位A |
| 等3 | 等3 + ZC>0 |
| 开门 | ZC>0 + CD>0 |
| （空） | 其余 |

**② 新增最高优先级信号"冲顶星"（2026-08-31 写入）：**

| 机警值 | 触发条件（全部满足） |
|:--|:--|
| **冲顶星** | **ZC>0 + 触顶(上符末位A) + BSHA≥8 + 十字星(无长上影)** |

- 十字星(无长上影) 判断：`实体=Abs(今收-今开)`，`全幅=今高-今低`，`上影=今高-Max(今收,今开)`；`全幅>0 And 实体<0.1*全幅 And 上影<=2*实体`
- **优先级最高**：若触发"冲顶星"，则不再覆盖为 等3/开门（先判冲顶星，未触发才回退等高线机警）

**③ VBA 实现（已在 `IQQQ跨码_D据擎2神谕.bas` L3825-3849）：**

```vba
'--- 最强信号：触顶+十字星(无长上影)+BSHA≥8 → 高概率次日冲高（C6§5.10 约64-68%） ---
If 日类BTZC > 0 And Right$(等上符, 1) = "A" Then
    If Val(谕组(X, 位谕of日层BSHA)) >= 8 Then
        Dim 实体 As Double: 实体 = Abs(日类今收 - 日类今开)
        Dim 全幅 As Double: 全幅 = 日类今高 - 日类今低
        Dim 上影 As Double: 上影 = 日类今高 - IIf(日类今收 > 日类今开, 日类今收, 日类今开)
        If 全幅 > 0 And 实体 < 0.1 * 全幅 And 上影 <= 2 * 实体 Then
            等机警 = "冲顶星"
        End If
    End If
End If
'--- 若未触发最强信号，回退到等高线机警 ---
If 等机警 = "" Then
    ' 原有 等3顶/等3/开门 逻辑不变
    ...
End If
谕组(X, 位谕of日层机警) = 等机警
```

**④ 使用说明：**
- **日层机警 = "冲顶星"** → 最强单日介入信号（次日冲高率约 64-68%），可作筛选/回测的高优买入条件
- **日层机警 = "等3顶"** → 次强（等高线龙头触顶）
- 该字段已通过 CSV [19] 日机警 导出（若导出代码含该列），可直接 Python 读取

**结论：乙(DXZA>0) 在跌排（跌吞）、地型栅/柜、盈提示偏/宽、高等等型（等14+）时更易转坏（乙→非稳定态）——预示"乙即将转坏"，应警惕退出/减仓；升排、0橅地型、盈提示a系、低等等型时乙稳定，可继续持有。**


#### 5.9.1 与 5.9.2 的结果一致性（日稳定态转坏预警的统一依据）

**甲→非稳定态（5.9.1）与 乙(DXZA>0)→非稳定态（5.9.2）的微观指标映射，定性规律完全一致：**

| 微观指标 | 甲→非稳定态（高转坏）| 乙→非稳定态（高转坏）| 一致性 |
|:--|:--|:--|:--|
| **日柱排** | 跌排/连后吞（4.8%）| 跌排/连后吞（4.9%）| ✅ 一致 |
| **日地型** | 栅/柜（5.6%）| 栅/柜（5.3%）| ✅ 一致 |
| **盈提示** | 偏/宽/宽偏（13.2%）| 偏/宽/宽偏（12.9%）| ✅ 一致 |
| **日等型** | 高等等型（5.0%）| 高等等型（4.5%）| ✅ 一致 |
| **日顶型** | 上b（4.2%）| 上b（4.4%）| ✅ 一致 |

**五个维度（柱排/地型/盈提示/等型/顶型）的定性规律完全一致**——都是"跌排/栅柜/盈偏宽/高等等型 → 转坏，升排/0橅/a系/低等等型 → 稳定"。

**数值有细微差异（但方向一致）：**
- **总转坏率**：甲 3.16%，乙 3.62%——乙略高（乙(DXZA>0) 转坏略频繁）
- **最高转坏率的具体形态**：甲 最高柱排是"跌.尾连VW.W2"（4.8%），乙 是"跌.尾连vW.W2"（4.9%）——都是跌排，具体形态略不同；甲 最高等型是"等11"（5.0%），乙 是"等18"（4.5%）——都是高等等型

**结论：** 甲 和 乙(DXZA>0) 作为**日稳定态**，其转坏（脱离稳定态）的微观指标映射**定性规律完全一致**——印证了 **甲乙(DXZA>0) 是同一类稳定态**，其转坏预警逻辑可以统一（合并为一个"日稳定态转坏预警"，见 §5.9.3）。数值差异（乙转坏率略高、具体形态略不同）不影响定性结论，只影响预警的敏感度阈值（如等型阈值甲≥8、乙≥14，合并后取 ≥8 更保守）。

### 6.2 DXAB 微观特征分析

> **来源：** 2026-09-05 新增。基于高波池全量（3451 文件，1109 万样本）验证 DXAB 正交护型与上涨区域的关系。DXAB 是日级别护型编码（第 2 位=护型汉字甲/乙/丙/己/戊/丁，第 3 位=正交符号↗/→/↘）。

#### 6.2.1 DXAB 正交护型分类（观察假设）

> **观察：** DXAB 是否正交与上涨区域有很大关联。以下寻找与 DXAB 正交相关的护型：
>
> - **可能负转正**：己、戊（DXZA>0）
> - **正交**：甲、乙（DXZA>0）、乙（DXZA<0）
> - **可能正转负**：戊
> - **无需持有**：丁、戊（DXZA<0）
>
> **假设：** 这些护型可能随时转正，所以都有主动持有或被动持有的可能；而剩下的（丁、戊(DXZA<0)）则无需持有。**这种分类对于 DXZC>0 更加有效，而 DXZC<0 则视情况而定。**

#### 6.2.2 护型 × ZC方向 数据验证与初步结论

##### 6.2.2.1 数据验证（高波池全量）

| 护型 | ZC>0 | ZC<=0 | 全部 | n(全部) |
|:--|:--|:--|:--|:--|
| **乙** | **28.30%** | 19.49% | 27.99% | 2,508,158 |
| **甲** | 27.26% | 19.58% | 26.56% | 2,279,001 |
| 己 | 25.79% | 21.28% | 22.76% | 648,128 |
| 丙 | 24.33% | 19.84% | 22.68% | 686,447 |
| 丁 | 24.92% | 20.99% | 21.23% | 2,391,454 |
| 戊 | 24.41% | 19.28% | 19.41% | 2,577,397 |
| **基线** | **27.34%** | **20.14%** | **23.61%** | 11,090,585 |

> **注：** 表中数值为**次日冲高≥3% 概率**（P(≥3%)）。高波池全量 2026-09-05 重跑。

##### 6.2.2.2 初步结论

**① 正交类 vs 非正交类：**
- **乙（正交）最强**：ZC>0 28.30%，高于基线 +0.96pp，是**最强护型**。
- **甲（正交）**：ZC>0 27.26%，接近基线（-0.08pp），**不突出**——"甲有特权"在数据上暂不明显。
- **己（正交）**：ZC>0 25.79%，低于基线（-1.55pp）。
- **丙/丁/戊（非正交）**：ZC>0 均 24-25%，低于基线。

**结论：** 正交类（甲/乙/己）整体高于非正交类（丙/丁/戊），但**乙显著最强**，甲/己只是略高。观察假设方向正确，但"甲有特权"**已验证不成立**（见 6.2.3/6.2.4）。

**② DXZC>0 更有效：**
- ZC>0 时护型差异大（乙 28.30% vs 戊 24.41%，差 3.89pp）。
- ZC<=0 时差异小（甲 19.58% vs 丁 20.99%，差 1.41pp）。
- **支持观察假设**：DXZC>0 时分类更有效。

**③ 戊确实弱：** ZC>0 24.41%、ZC<=0 19.28%，均低于基线，支持"可能正转负/无需持有"。

**④ 丁在 ZC<=0 反而高于基线**（20.99% vs 20.14%），**不支持"丁无需持有"**——丁在 ZC<=0 时仍有相对机会。

#### 6.2.3 甲的特权与乙的差异（已验证，见 6.2.4）

> **甲的特权（观察）：** 属于 DXAB 刚正交，会有很多特权，如 0<DXAB≤4 内出现阴柱，基本都会转为阳柱。优选连阳后第一个阴柱（vV），第一次回踩 DJA 后一般都有反弹。
>
> **乙的差异（观察）：** 因为只是再次突破 DXZA，就没有 DXAB 由负转正的特权，必须形成突破回踩、启动结构，才能再次推高顶进行拉升。
>
> **验证结论（高波池全量 2026-09-05）：**
> - **甲的特权不成立 ✗**：甲 DXZA1-4 阴柱（22.43%）、连阳后首阴（24.45%）、阴柱+升排（24.40%）次日冲高均低于甲基线（26.56%）。"阴柱转阳/连阳后首阴反弹"无数据支持。
> - **乙需结构成立 ✓**：乙(DXZA>0) 龙猪（主升）31.56%、龙管（突破回踩）29.05%，均高于乙基线（27.99%）；无结构（其他）25.41% 低于基线。
> - **乙 DXZA<0 不适用 ✗**：乙护型 DXZA 不会为负（最小 2），且 DXZA 越接近 DJA 次日冲高越弱（≤5 时 22.15%）。
>
> **详细数据见 6.2.4。**

#### 6.2.4 综合结论（高波池全量验证，2026-09-05）

**① 广义正交护型覆盖上涨区域 ✓（最重要发现）**

> **广义正交护型（己、戊(DXZA>0)、甲、乙(DXZA>0)、乙(DXZA<0)、戊）覆盖 DXZC>0 样本的 97.25%（520万/535万）。几乎包含所有主升阶段。观察有依据，太重要了！**

- **结论：DXAB 正交护型几乎覆盖所有主升阶段，是划分阶段的第一位指标。**

#### 6.2.5 微观指标四层结构（融合到 1.5.1 日冲策略全景流程）

> **结论：微观指标第一层是 DXAB 划分阶段，第二层是日等型区分情况，第三层是日柱排判定方向（特别优待升排），第四层是顶型判断特殊情况（乙入管）。**

- **第一位：DXAB 划分阶段** ✓（覆盖 97.25%，几乎包含所有主升阶段）
- **第二位：日等型区分情况**（等高线，预测冲高幅度）
- **第三位：日柱排判定方向**（特别优待升排）
- **第四位：顶型判断特殊情况**（乙入管——乙突破回踩/启动结构才可靠）

> **注：后续融合到 1.5.1 日冲策略全景流程（四级过滤）。** **甲的特权不成立（见 6.2.4 ②），第四位不再给"甲护型"特殊待遇**——甲在阴柱/连阳后首阴时次日冲高反而低，应与其他正交护型同等对待。第四位聚焦"乙入管"（乙需突破回踩/启动结构，见 6.2.4 ③）。

### 6.3 日等型基础（等高线）

> **来源：** 原 MC3.3.3 第一章 §1.1（2026-09-03 移入本文件）。日等型（等高线）是日冲策略的**执行层底座**，确定"当前在 DJA 哪个位置"，是后续形态探索（6.2 起）的基础框架。

> **核心原则：** 等高线**不预测方向**（下柱≥2%天数比 33~41%，接近随机），但**预测冲高幅度**（≥2%/≥3%）。等2（回归DJA）下日冲高最强（≥3%=26.9%），等6最弱（19.5%），差 **7.4pp**。

#### 6.3.1 核心变量

| 变量 | 来源 | 含义 |
|:----|:-----|:------|
| **DTZA（日ZA）** | ARRLLL(基位日类+位osBTZA) | JZ快均线相对JA慢均线的衍生交叉天数，正数=JZ在JA之上N柱，负数=JZ在JA之下N柱 |
| **日中符（中符串）** | 谕组(位谕of日管中符串) | 5位移位寄存器，末位（Right$）为当前柱与JA的关系。A=全上(最强)，B=上探，C=鼎(继鼎)，D=反鼎，E=下探，F=全下(最弱) |

#### 6.3.2 分类规则（VBA末位逻辑，6等简化版）

> 分类逻辑：VBA代码使用 `Right$(中符串,1)`（末位）判定当前柱与JA的关系，而非"包含"逻辑。6等设计：以 DTZA 阈值（|DTZA|≤3 vs >3）结合末符强弱，将日等型划分为 6 等。

**DTZA > 0（JZ在JA之上）：**

| 分类 | 条件 | 含义 |
|:----|:-----|:------|
| **等1** | DTZA=1 | JZ刚上穿JA。刚突破，可能形成上攻，也可能围绕DJA波动 |
| **等2** | DTZA≥2 且 末符∈CDEF | JA之上且当前柱与JA相交。回归DJA，需确认是再开新丘还是下破DJA |
| **等3** | DTZA≥2 且 末符∈AB | JA之上且当前柱强势，有向上动力 |

**DTZA < 0（JZ在JA之下）：镜面映射**

| 分类 | 条件 | 含义 |
|:----|:-----|:------|
| **等5** | DTZA=-1 | 等1镜面：JZ刚下穿JA，可能继续，也可能围绕DJA波动 |
| **等6** | DTZA≤-2 且 末符∈ABCD | JA之下且当前柱偏强。需确认是否止跌反弹 |
| **等7** | DTZA≤-2 且 末符∈EF | 等3镜面：JA之下且当前柱弱势，有向下动力 |

> **镜面映射规则：** A↔F, B↔E, C↔D。上侧AB（强势）镜面为下侧EF（弱势），上侧CDEF镜面为下侧ABCD（偏强）。

|:----|:-----|-----:|-----:|

#### 6.3.6 等高线预测什么？

等高线虽然不预测方向，但**预测冲高幅度**（≥2%/≥3%），以及**趋势延续/反转概率**：
① **冲高幅度：** 等2下日冲高≥3%=26.9%，等6=19.5%，差7.4pp
② **趋势延续：** 等3/等7延续性强，等2/等6反转概率高

#### 6.3.7 等2/等6 回归确认性质（下柱DTZA方向）

| 分类 | 下柱DTZA>0(继续走) | 下柱DTZA<0(反转) | 含义 |
|:----|:-------------------:|:-----------------:|:-----|

| **等2(回归)** | 70.2% | **29.8%** | 回归后29.8%会下破DJA，需确认 |
| 等7(趋势) | 14.3% | **85.7%** | 弱势延续，很少反弹 |
| **等6(回归)** | **31.4%** | 68.6% | 回归后31.4%会反弹，需确认 |

**等2 后 29.8% 会下破（DTZA转负），是等3（15.0%）的 2 倍。** 等6 后 31.4% 会反弹（DTZA转正），是等7（14.3%）的 2.2 倍。

### 6.4 日柱排

> 基于日CSV柱排数据，研究升排/单阳柱/诱多对下日冲高的预测能力。<br>
> 数据源：日CSV列10（柱排）、列30（上符串）、列34（并符串）、列21（BSHA）、列24（宽哼JC）等。<br>
> 验证日期：2026-09-03，**高波池（Qic+Qim+Qit）全量**，11,087,371 样本。<br>
> 指标定义：P3 = 下日高幅（次日高幅）>= 3% 的概率；期望HR = 下日高幅均值。<br>
> 柱排编码：升连 = 连续阳柱；升吞 = 单阳柱吞没前阴；跌孕 = 阴柱后小阳/十字星止跌。

> **核心原则（数据修正版）：** 日柱排才是关键。**升吞不是诱多，反而是最强的升排形态**（P3=26.8% > 升连25.7%）。真正的诱多信号是"**冲不动**"（BSHA<3%）或"**未站稳**"（宽哼JC<5），而非"单阳柱/升吞"这个形态本身。
>
> **最关键的 3 个发现：**<br>
> ① **升吞是升排中最强**——P3=26.8%，比升连(25.7%)还高，推翻"升吞=诱多"的旧认知（见 §6.3.1）；<br>
> ② **诱多的本质是"冲不动"**——升吞+BSHA<3% 时 P3 暴跌到 14.7%（见 §6.3.2）；<br>
> ③ **高位升吞不是诱多**——等型≥3 时 P3=32.5%，除非 BSHA<5%（22.9%）（见 §6.3.2）。

#### 6.4.9 DTZA 阈值选3的理由

> **来源：** 原 MC3.3.3 §1.1.2（DTZA 设置理由），因 DTZA（JZ相对JA的交叉天数）与突破/回踩形态相关，移至本章 6.2。
> **数据：** 高波池3,452只（1,103万行），DTZA正数/负数运行长度分布。

**① DTZA 寿命分布（JZ在JA之上；负数运行几乎对称）：**

| 指标 | 正数运行 |
|:----|:-------:|
| 均值 | 5.29天 |
| 中位数 | **4.0天** |
| 标准差 | 4.87天 |
| 最大值 | 164天 |

**② 累计分布（阈值划分依据）：**

**累计分布 = 运行≥该天数的概率（这是DTZA阈值划分的核心依据）：**

| 天数 | 单日占比 | 累计（≥该天） |
|:----:|:------:|:----------:|
| 1 | 21.4% | 100% |
| 2 | 14.1% | 78.6% |
| **3** | **11.2%** | **64.5%** |
| 4 | 9.3% | 53.3% |
| 5 | 8.0% | 44.0% |
| 7 | 5.5% | 29.0% |
| 10 | 3.1% | 15.4% |

**③ 关键结论：**

1. **21.4% 的上升段只持续1天**（DTZA=1后就被打回）——"刚突破可能失败"的数据支撑。
2. **每个 step 的续存率约82~83%**（DTZA=2→3有64.5/78.6=82%，DTZA=3→4有53.3/64.5=83%），恒定衰减。
3. **DTZA≥4 只占53.3%**——过半的上升段不到4天就结束。
4. **DTZA≥7 仅29%，≥10 仅15.4%**——长趋势是少数。

**④ 为什么阈值选3（|DTZA|=3是拐点）：**

- **中位数4天**说明DTZA=4已处于一次运行的中后段。
- **续存率从DTZA=3开始从高位滑落**：DTZA=2→3续存82%，DTZA=3→4续存83%，但运行≥4天只有53.3%。
- **DTZA=-3~3是"频繁贯穿、积蓄力量区"**：JZ围绕JA上下波动，|DTZA|≤3时方向倾向弱（贯穿区与稳态区方向差异仅0.9~2.5pp），|DTZA|>3进入趋势/回归稳态。
- **与柱型系统重合**：DTZA=-3~3 = 柱型的根(-3~0)+枝(1~3)区域（重合度99%+），印证2026-08-08阈值更新与柱型对齐的正确性。

**⑤ 末符区分力 vs DTZA区分力（证明DTZA阈值只做微调）：**

| 划分 | 类别 | 下柱>0 | 方向差异 |
|:----|:----|:-----:|:-------:|
| **末符（强力维度）** | AB末符(等3) | 85.3% | **15.1pp** |
| | CDEF末符(等2) | 70.2% | |
| **DTZA阈值（微调）** | DTZA=2~3 | 73.8% | **5.2pp** |
| | DTZA≥4 | 68.6% | |

**等高线的方向区分力主要来自末符（AB vs CDEF，15.1pp），DTZA阈值（2~3 vs ≥4）仅贡献1.6pp（全量数据验证）。** DTZA的主要作用是把"频繁贯穿区"（|DTZA|≤3）与"稳态区"（|DTZA|>3）分开，而非在CDEF末符内部细分方向。

**⑥ DTZA阈值不细分的依据：** 高波池全量数据验证，DTZA=2~3 与 DTZA≥4 的方向差为 -6.39pp（DTZA=2~3方向更好），P(≥3%)差仅 2.98pp（高波池）/1.57pp（全量）。DTZA阈值细分边际价值低，故不细分。

> **结论：** DTZA 阈值3 是"频繁贯穿区"与"稳态区"的分界，与突破/回踩形态相关（刚突破 DTZA=1 可能失败，DTZA≥4 进入稳态）。等高线分类用 DTZA=1/≥2（非阈值3），DTZA 阈值3 只做微调。

### 6.5 日顶型

> 基于日CSV上符串数据，研究触顶/触哼/合顶对下日冲高的预测能力。<br>
> 数据源：日CSV列30（上符串）、列29（上符范）、列43（顶型）、列22（宽哼JC）等。<br>
> 验证日期：2026-08-22，**高波池（Qic+Qim+Qit）全量**，11,031,366 样本。<br>
> 指标定义：P3 = 下日高幅（次日高幅）>= 3% 的概率；期望HR = 下日高幅均值。<br>
> 触顶 = 上符串末位为 'A'（今天创新高）；触哼 = 上符串末位为 'B'（触到哼JA）；强触顶 = BSHA>=5 且 触顶。<br>
> 合顶天数 = 从上符串末位开始往左数连续A的个数。

> **核心逻辑链（一句话）：** ZC>0 是前提 → 触顶是信号 → 合顶天数定强度 → BSHA/宽哼JC 增强 → 等高线定位置 → 综合操作。<br>
>
> **最关键的 3 个发现：**<br>
> ① **ZC 方向是总开关**——ZC<=0 时触顶无效，ZC>0 时触顶才有效（见 §6.4.2）；<br>
> ② **合顶天数是最强单一指标**——区分度 16.5pp，5天全触顶 P3=39%（见 §6.4.3）；<br>
> ③ **合顶的意义在趋势延续**——合顶5天未来20天累计收益 453%（见 §6.4.7）。

#### 6.5.1 上符串编码与基础定义

**上符串（日CSV列30）：** 5位滚动记录，末位=今天，每位含义：
- `A` = 触顶（创新高）
- `B` = 触哼（触到哼JA）
- `v` = 触哈
- `_` = 无触顶

**上符范（日CSV列29）：** 编码值，含触顶次数/触哼次数等信息。

**顶型（日CSV列43）：** 龙/雀/虎/篪/武等分类。

**宽哼JC（日CSV列22）：** 管上壁（龟结哼）相对 **JC（EMA26）** 的宽度百分比（`(龟结哼/日类JC-1)*100`）。注意"宽哼JC"的"JC"指分母均线是 JC，不是"距哼JA"。

#### 6.5.7 触顶增强维度

> 以下分析均在 ZC>0+今天触顶 条件下，各维度对P3的增强效果。

##### 6.4.4.1 BSHA（冲高幅度）

**BSHA（当日高幅）与触顶后的P3强正相关，区分度极高。** 触顶当天的冲高幅度越大，下日继续冲高的概率越高。

| BSHA | P3 | 样本 | 判断 |
|:----:|:--:|-----:|:----|
| 0~1% | 20.7% | 6,433 | ⚠️ 样本少 |
| 1~2% | 7.4% | 84,218 | ❌ 极弱 |
| 2~3% | 13.1% | 193,823 | ❌ 弱 |
| 3~5% | 21.6% | 452,345 | ⚠️ 接近基线 |
| **5~10%** | **36.1%** | 651,618 | ✅ 强信号 |
| **>=10%** | **54.7%** | 281,002 | ✅ 极强信号 |

**BSHA>=5%+触顶是最强组合之一（P3=36.1%），BSHA>=10%+触顶更是高达54.7%。** 而BSHA<3%+触顶几乎无效（P3<14%），说明"冲不动的触顶"是假信号。

##### 6.4.4.2 宽哼JC（管宽）

**宽哼JC（管上壁相对 JC=EMA26 的宽度）与触顶后的P3强正相关。** 触顶时管上壁离 JC 越远，下日冲高概率越高。

> **定义（VBA 神谕.bas L1390）：** `宽哼JC = (龟结哼 / 日类JC - 1) * 100`——管上壁（龟结哼）相对 **JC（EMA26）** 的宽度。注意"宽哼JC"的"JC"指**分母均线是 JC**，不是"距哼JA"（周线管宽才用 JA 作分母，见 §9.3.22）。

| 宽哼JC | P3 | 样本 | 判断 |
|:-----:|:--:|-----:|:----|
| <5（刚突破） | 15.3% | 411,315 | ❌ 弱 |
| 5~20 | 31.9% | 1,030,867 | ✅ 正常 |
| **>=50%** | **56.0%** | 227,257 | ✅ 极强信号 |

**宽哼JC>=20时P3=56.0%**，说明触顶时已远离均线很远，趋势极强。宽哼JC<5时P3仅15.3%，说明刚突破哼JA时触顶信号弱。

##### 6.4.4.3 等高线（位置）

**等高线在ZC>0+触顶条件下仍有区分度。** 等1/等2（刚站上DJA附近）触顶最强，等3（远离DJA）最弱。

| 等高线 | P3 | 样本 | 判断 |
|:-----:|:--:|-----:|:----|
| **等1** | **34.9%** | 95,966 | ✅ 刚站上DJA+触顶，最强 |
| **等2** | **32.7%** | 245,130 | ✅ 回归DJA+触顶 |
| 等3 | 30.6% | 1,307,747 | ⚠️ 一般 |
| 等5 | 27.4% | 18,616 | ⚠️ 弱（样本少） |
| 等6 | 22.3% | 1,270 | ❌ 弱（样本少） |
| 等7 | 22.3% | 710 | ❌ 弱（样本少） |

**等1/等2（DJA附近）触顶远强于等3（远离DJA）触顶。** 等1=34.9% vs 等3=30.6%，差4.3pp。说明在DJA附近触顶是有效突破，远离DJA后触顶是强弩之末。

##### 6.4.4.4 柱体形态（叠幅/上身）

**叠幅（当日涨跌幅）与触顶后的P3强正相关。** 触顶当天涨幅越大，下日冲高概率越高。

| 叠幅 | P3 | 样本 | 判断 |
|:----:|:--:|-----:|:----|
| 叠幅<0（阴线触顶） | 样本不足 | — | — |
| 叠幅0~3% | 3.8% | 10,856 | ❌ 极弱 |
| 叠幅3~5% | 8.4% | 103,633 | ❌ 弱 |
| 叠幅5~10% | 18.8% | 555,756 | ⚠️ 一般 |
| **叠幅>=10%** | **40.4%** | 991,453 | ✅ 强信号 |

**结论：叠幅与BSHA高度相关（大涨的柱叠幅也大），叠幅本身不是独立信号，BSHA更直接。**

##### 6.4.4.5 顶型（龙/雀/虎）

**顶型在ZC>0+触顶条件下区分度有限。** 只有a龙（33.2%）和非龙（25.3%）之间有7.9pp差距。

| 顶型 | P3 | 样本 | 判断 |
|:----|:--:|-----:|:----|

**结论：在ZC>0+触顶条件下，顶型的边际贡献7.9pp，不如BSHA和宽哼JC有价值。**

#### 6.5.5 触顶后行为

##### 6.4.5.1 合顶中断后的走势

**合顶中断（昨天触顶+今天不触顶）本身不是危险信号（P3=29.9%），但结合跌幅有区分度。**

| 条件 | P3 | 样本 | 判断 |
|:----|:--:|-----:|:----|
| 合顶中断（无条件） | 29.9% | 765,710 | ⚠️ 接近基线 |
| 合顶中断+**跌幅>3%** | **37.5%** | 151,391 | ✅ **暴跌后反弹，强信号** |
| 合顶中断+跌幅1~3% | 24.7% | 238,044 | ⚠️ 一般 |
| 合顶中断+跌幅0~1% | 19.9% | 146,624 | ❌ 微跌，弱 |
| 合顶中断+上涨 | 27.9% | 237,500 | ⚠️ 一般 |

**合顶中断+跌幅>3%是强信号（P3=37.5%），说明暴跌后次日反弹概率高。** 而微跌（0~1%）后P3=19.9%最弱，说明"慢慢跌"比"暴跌"更危险。

##### 6.4.5.2 触顶后次日是否还能触顶

**今天触顶→明天也触顶的概率为50.7%。** 宽哼JC越小，明天继续触顶的概率越高。

| 条件 | 明天触顶概率 | 样本 |
|:----|:-----------:|-----:|
| 宽哼JC<5 | **58.7%** | 411,315 |
| 宽哼JC 5~20 | 48.9% | 1,030,867 |
| 宽哼JC>=20 | 51.2% | 227,257 |

**宽哼JC<5时，明天继续触顶的概率接近60%**，说明刚突破哼JA时趋势延续性最强。

#### 6.5.6 触顶信号 vs 日策略P2 / 日层段 一致性

##### 6.4.6.1 触顶信号 vs 日策略P2（等高线+BSHA）

日策略P2 = 等高线 + BSHA（偏5/偏3）+ 连阳/层主/升排/跌排。它已包含BSHA信息，但**未包含触顶信息**。

**偏5（BSHA>=5）中触顶占比62.3%**，两者高度一致。

| 条件 | P3 | 样本 |
|:----|:--:|-----:|
| 等1+偏5+触顶 | 43.6% | 53,290 |
| 等2+偏5+触顶 | 43.8% | 127,812 |
| 等3+偏5+触顶 | 41.2% | 744,147 |

**关键发现：在偏5（BSHA>=5）条件下，触顶的边际贡献有限。** 因为BSHA>=5本身已是强信号（P3~41%），触顶与否的差异不大。

##### 6.4.6.2 触顶信号 vs 日层段

> 日层段定义（持主/持被/卖浮）见 [MC3.3.1_日类必赢算法.md §2.6](MC3.3.1_日类必赢算法.md#26-日层段细分持主持被卖浮)。

**触顶信号与日层段高度一致：**

| 条件 | P3 | 样本 | 判断 |
|:----|:--:|-----:|:----|
| **持主+强触顶(BSHA>=5)** | **43.0%** | 752,387 | ✅ 最强 |
| 持被+强触顶 | 42.0% | 6,047 | ✅ 强（样本少） |
| 持主+触顶 | 33.9% | 1,215,024 | ✅ |
| 持被+触顶 | 28.1% | 14,972 | ⚠️ |

**强触顶信号中持主占绝大多数**，触顶信号几乎都发生在持主阶段。

##### 6.4.6.3 结论

1. **触顶信号与日策略P2一致**：偏5信号中触顶占比高，但偏5本身已足够强，触顶的边际贡献小
2. **触顶信号与日层段一致**：强触顶信号主要出现在持主，持主+强触顶=43.0%最强
3. **日层段是比触顶更强的过滤条件**：持主+强触顶=43.0% vs 持被+强触顶=42.0%，差1.0pp

#### 6.5.7 合顶周期（趋势延续）

##### 6.4.7.1 核心发现：合顶不是看单日，而是看整个周期

之前验证"合顶天数×下日P3"发现合顶天数越长P3越高，但那是**只看下日冲高**（单日）。**合顶的真正意义在于"趋势延续"**——从合顶开始到离顶结束的整个周期，累计收益显著。

##### 6.4.7.2 合顶天数 × 未来N天累计收益

| 合顶天数 | 未来1天 | 未来3天 | 未来5天 | 未来10天 | 未来20天 |
|:-------:|:------:|:------:|:------:|:-------:|:-------:|
| 1天 | 16.18% | 34.45% | 43.82% | 88.05% | 150.84% |
| 2天 | 14.84% | 41.78% | 48.59% | 108.61% | 171.49% |
| 3天 | 18.59% | 49.05% | 63.18% | 149.48% | 222.64% |
| 4天 | 36.03% | 61.57% | 87.10% | 191.83% | 272.59% |
| **5天** | **55.09%** | **139.87%** | **207.67%** | **357.87%** | **453.04%** |

**合顶天数越长，未来累计收益越高。** 合顶5天 vs 合顶1天：
- 未来5天：207.67% vs 43.82%（差163.85pp）
- 未来10天：357.87% vs 88.05%（差269.82pp）
- 未来20天：453.04% vs 150.84%（差302.20pp）

##### 6.4.7.3 合顶天数 × 未来N天冲高>=3%概率

| 合顶天数 | 未来1天 | 未来3天 | 未来5天 | 未来10天 |
|:-------:|:------:|:------:|:------:|:-------:|
| 1天 | 26.5% | 53.1% | 66.7% | 82.7% |
| 2天 | 28.6% | 55.3% | 68.8% | 83.9% |
| 3天 | 30.6% | 57.3% | 70.6% | 84.8% |
| 4天 | 31.8% | 59.1% | 72.2% | 85.6% |
| **5天** | **37.5%** | **64.6%** | **76.2%** | **87.4%** |

**任何合顶天数下，未来5天冲高>=3%的概率都超过66%！** 未来10天更是超过82%。

##### 6.4.7.4 结论

1. **合顶周期是有效的**——合顶天数越长，未来累计收益越高（合顶5天未来20天=453%）
2. **合顶开始是入场信号**——合顶开始后未来5天冲高>=3%概率66.7%+
3. **合顶的意义在于"趋势延续"**——连续创新高代表趋势强，未来N天累计收益高

#### 6.5.9 综合操作规则

### 6.8 连阳趋势延续分析

> **范畴说明：** 连阳（BT连阳≥3）本质属于等3（趋势延续）范畴的动量细分信号。从 MC3.3.3 移入本文档（探索层），作为形态探索的一部分。

#### 6.8.1 核心发现

**连阳越长，下日冲高概率越高（单调递增，无衰减）。** 这打破了"连阳长了会衰竭"的直觉——实际是"越连越强，强者恒强"。

> **数据：** 高波池，门开后。
> **基线：** P(≥2%)=43.3%，P(≥3%)=30.0%。

#### 6.8.2 连阳位置与下日冲高概率

|:---:|:---:|:---:|:---:|:---:|:---:|:---|
| 基线 | 3,500,000+ | 43.3% | — | 30.0% | 2.08% | — |
| **第1根** | 1,223,704 | 45.8% | +2.5pp | 32.6% | 2.65% | ❌ 最弱 |
| 第2根 | 513,661 | 48.0% | +4.7pp | 35.4% | 2.91% | 一般 |
| **第3根** | 199,803 | **52.3%** | +9.0pp | 40.6% | 3.36% | ✅ 跳升点 |
| 第4根 | 77,260 | 56.3% | +13.0pp | 45.6% | 3.72% | 强 |
| 第5根 | 31,090 | 64.1% | +20.8pp | 54.9% | 4.83% | 很强 |
| 第6根 | 14,339 | 61.0% | +17.7pp | 53.4% | 4.37% | 强 |

**关键发现：**
1. **连阳第1根是最弱的（45.8%）**，不是"更容易冲高"
2. **连阳≥3 是明显跳升点**（48.0%→52.3%），这也是赛马用连阳≥3的依据

**连阳在等3升强基座内的规律与全局一致，且幅度更大（第5根+19.9pp）。**

| 连阳区间 | P(≥2%) | 操作建议 |

#### 6.8.4 打板策略（市场连阳/涨停板）

> **范畴：** 打板策略（追涨停/连板）本质上是连阳信号在 A 股短线市场的应用，属于等3（趋势延续）范畴的极端形态。

**打板策略与连阳的关系：**
- 打板 = 追涨停板（首板/二板/三板...），本质是"连阳/连板的动量延续"

**打板策略的等高线框架：**

### 9.1 明确错误：龙a / 龙b（已修正）

**原文档定义（错误）：** 曾把"龙a/龙b"定义为**合顶天数**分类（合顶≥2 vs 合顶=1）。**已修正为"合顶≥2/合顶=1"。**

**VBA 真实定义：** "a龙/b龙"是**顶型**（`位os基顶型`），与合顶天数**完全无关**。

`IQQQ跨码_D据擎2神谕.bas:4520-4528`（正向 JC 以上，多头排列，BT哼≥-2 龙族）：
```vba
If ARROS(位os龟BT哼) >= -2 Then        '龙族：t顶>=-2
    If ARROS(位os龟BT顶) > 0 Then
        ARROS(位os基顶型) = "a龙"       'a龙 = 今日触顶（t顶>0）
    ElseIf ARROS(位os龟BT顶) >= -2 Then
        ARROS(位os基顶型) = "b龙"       'b龙 = 距顶2日内未触顶（t顶∈[-2,0]）
    Else
        ARROS(位os基顶型) = "c雀"
    End If
End If
```
反向 JC 以下（`IQQQ跨码_D据擎2神谕.bas:4589-4597`）对称用 BT底/BT哈。

**结论：a龙 = 已触顶（t顶>0），b龙 = 接近顶但未触顶（t顶∈[-2,0]）。** 文档曾用"龙a/龙b"命名"合顶天数"分类是**错误借用**了 VBA 的"龙"概念，已修正。

### 9.2 口径需注意：合顶天数

**文档口径：** 合顶天数 = 从右往左连续 'A' 的个数（Python 脚本 `calc_合顶天数` 即此口径）。

**VBA 口径：** `IQQQ跨码_D据擎5结算.bas:645` + `1298-1316`（`STBASE结算工具_衍生交叉天数`）：
```vba
'位os龟BT合顶 = 衍生交叉天数(位os龟BT合顶, 结哼, 结顶)
'当 结哼 >= 结顶 时 前值+1，否则重置为 -1
'结哼 = Max(H0..H4) = 5日最高；结顶 = Max(H0..H9) = 10日最高
```
