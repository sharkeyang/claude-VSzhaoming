### 1.7 修正后的统一模型规则

```
DXZC > 0（多头环境）：
  ┌── 己 → 最优介入 → 重仓
  ├── 甲 → 优选 → 正常介入
  ├── 乙 → 优选 → 正常介入
  ├── 戊 → 试仓 → 少量试探
  ├── 丁 → 被动持仓 → 不新开仓
  └── 丙 → 排除 → 退出观望

DXZC < 0（空头环境）：
  ┌── 己 → 唯一可操作 → 轻仓介入
  ├── 甲 → 可观察 → 勿重仓
  └── 乙丙丁戊 → 排除 → 不操作
```

### 1.8 关键发现

1. **己的统治性地位：** 己在所有条件下都是最强的护型，无论DXZC正负、无论日线周线、无论哪个花册分组。涨率始终在 73%+ 以上。己的定义是"BTAB≤0 且 BTZB>0"（均线负交但短均线走强），这本质上是"回调尾声"的信号。

2. **丙的异常：** 丙在所有条件下（包括DXZC>0）都表现为负收益，夏普为-61.10。丙的定义是"BTAB>0 且 BTZB<0"（均线正交但短均线已走弱），表明护型进入衰减阶段。建议将丙直接视为"退出观望"信号，而非任何形式的持仓信号。

3. **跨周期普适性：** 日线护型排序与周线护型排序完全一致，说明DXZC+DXAB（以及WXZC+WXAB）是**基于均线的跨周期普适规律**，不依赖于时间周期。

4. **跨规模普适性：** 沪深300/中证500/中证小盘/中证非四大花册分组的护型排序完全一致（排名跨度=0），说明此规律是**跨市值规模的普遍规律**，大小盘股通用。

### 14.2 维度二：DXAB×DXCD 联动 — 护型与护级的二维组合

> **核心发现：DXCD（护级）与DXZC有高度相关性，DXZC>0时DXCD=上/忐/忠，DXZC<0时DXCD=中/下/忑。DXCD的加入没有带来独立的增量信息，而是DXZC的另一种表达。**

**探索子项：**

### 14.2 偏管警告

**规则：** 去掉偏离DJC>20%的DTZA=1/2。

**条件：**

- `DTZA = 1` 或 `DTZA = 2`

## 十五、日周结合：先周后日操作框架

> 合并自 `MC3.3_研究日周结合.md`（2026-07-25 整合）

### 15.1 核心原则

| 层级 | 职责 | 决策依据 |
|:----|:-----|:---------|
| 🔴 **周级别** | 定方向、定可否操作 | `WXZC>0` + `WXAB>0` |
| 🟢 **日级别** | 定时机、定点位 | `DXZC>0` + `DXAB>0`（在周级别框架内） |

**不存在脱离周级别的日级别独立操作。**

### 15.2 镜面对称：上升过程 vs 下跌过程

**上升过程（DJCBA多头排列）：**
| 阶段 | 特征 | 操作 |
|:----|:-----|:------|
| ① 初升 | 刚上破DJC，ZA>0不久 | 注意回踩确认 |
| ② 主升 | DJA之上，柱排列多头 | 持有，不轻易止盈 |
| ③ 鼎盛 | 连续阳柱，偏离大 | 准备止盈 |
| ④ 衰退 | 开始出现阴柱，但仍在DJA之上 | 观察，不主动退出 |

**下跌过程（DJCBA空头排列）：**
| 阶段 | 特征 | 操作 |
|:----|:-----|:------|
| ① 初跌 | 刚下破DJC | 浮仓退出 |
| ② 主跌 | DJA之下，柱排列空头 | 基仓退出 |
| ③ 衰退 | 跌势减缓，开始出现阳柱 | 可关注，但不介入 |
| ④ 筑底 | 止跌走稳 | 等待周级别信号 |

### 15.3 日级别介入决策清单

**应介入：**
- 周级别 `WXZC>0` 且 `WXAB>0`（周级上升中）
- DJCBA多头排列，在DJA之上
- 窄管中蓄力、突破回踩、悬阳升连等日机信号出现
- 周级别框架内，日级别信号确认

**不应介入：**
- 周级别 `WXZC≤0` 或 `WXAB<0`
- DJCBA空头排列，在DJC之下
- 周级别处于屎尿状态
- 仅凭日级别信号，周级别未确认

**不确定（需结合上下文）：**
- 周级别上升但日级别出现阴柱
- 日级别信号出现但周级别处于过渡区（唏/嘘）
- DXAB转差但DXCD仍为正
- DXAB的验证需要日级别数据，可复用日级别探索路径的数据框架
