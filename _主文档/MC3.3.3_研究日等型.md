### 1.4 日冲策略综合（策略赛马）

#### 1.4.1 策略赛马（位置+条件排名，新高波池口径）

> **数据：** 高波池（Qic+Qim+Qit），3451 文件，11,031,366 行。全量基准 H2=37.2%。
> **方法：** 所有位置+条件组合一起比较，按 H2（下日高≥2%）排序。样本量越大越可靠。

**策略命名说明：**
- `{条件}+{等型}` — 条件在前，等型在后。例：`ZC>0+BSHA5+等5` = ZC>0 + BSHA5 + 等5
- **条件简写：** BSHA5=当日高偏离JA>5%，连=BT连阳>0，门=ZC>0+CD=上，ZC>0=DJC上方，甲乙己=好护型
- **跨等型汇总：** `+全量` 表示不限定等型

**边际贡献结论：**
- **`连` 和 `门` 是真正有区分度的条件**——等1/等3/等6 各 +2~3pp，等2/等7 的 `门` +1.6~1.9pp
- **`ZC>0` 和 `甲乙己` 边际贡献极小**（多数等型仅 +0~0.5pp），是制造重复行的元凶
- **等5 是唯一 `甲乙己` 有明显贡献的等型**（+1.5pp，61.5%），但样本仅 1.99 万，需谨慎
- **等3 的 `连+门` 叠加最强**（+3.7pp，57.4%），但绝对 H2 仍低于等1/等2

##### 1.4.1.2 择优建议

| 场景 | 推荐策略 | H2 | 样本 | 理由 |
|:----|:--------|:--:|:---:|:-----|
| **全场最强** | **ZC>0+甲乙己+BSHA5+等5** | **61.5%** | 1.99万 | 超跌反弹+好护型+ZC>0，H2最高 |
| 等3+BSHA5 | BSHA5+等3 | 53.7% | 109万 | 样本最大但 H2 平庸 |
| 大样本兼顾概率 | ZC>0+BSHA5+等3 | 53.9% | 100万 | 样本最大，执行门槛低 |
| 无BSHA5时（BSHA3） | BSHA3+等5 | 52.7% | 13.6万 | BSHA3 是 BSHA5 的最佳替代 |
| 无BSHA时（连阳） | 连+门+等3 | 49.9% | 64万 | 连阳+门，无BSHA时的最优选择 |
| 无BSHA时（位置本身） | 等1+ZC>0+甲（基准） | 45.8% | 5.5万 | 位置本身就好，不依赖信号 |

**核心说明：**
- **BSHA5 是日冲策略的核心信号**，所有 H2>55% 的组合都包含 BSHA5
- **等5（刚下穿DJA）在 BSHA5 时反转最强**（61.5%），但样本仅 1.98 万
- **等3（上方强势）在 BSHA5 时反而平庸**（53.7%），样本最大但 H2 不如等1/等2
- **ZC>0 和 甲乙己 在 BSHA5 时的边际贡献很小**（1~2pp），BSHA5 本身已足够强
- **无 BSHA5 时，位置本身决定 H2**——等1+ZC>0+甲 基准 45.8%，已超过全量基准 8.6pp

##### 1.4.1.3 条件边际贡献与叠加规律

> **数据：** 高波池（Qic+Qim+Qit），3451 文件全量。以下为各条件单独及叠加后的 H2，用于分析条件之间的边际贡献和叠加效应。

**各条件单独 vs 全量基准（37.2%）：**

| 条件 | H2 | 边际贡献 | 类型 |
|:----|:--:|:--------:|:----|
| **BSHA5**（当日高偏离JA>5%） | **54.6%** | **+17.4pp** | 🚀 核武器 |
| BSHA3（当日高偏离JA>3%） | 48.3% | +11.1pp | 💪 强信号 |
| 连阳（BT连阳>0） | 48.1% | +10.9pp | 💪 强信号 |
| BT鼎（BT鼎>0） | 43.7% | +6.5pp | 🔫 中等 |
| 门（ZC>0+CD=上） | 43.4% | +6.2pp | 🔫 中等 |
| 层主（层界=主） | 43.3% | +6.1pp | 🔫 中等 |
| ZC>0（DJC上方） | 40.8% | +3.6pp | 📏 位置基准 |
| 甲乙己（好护型） | 40.0% | +2.8pp | 📏 位置基准 |

**BSHA5 的边际贡献（+17.4pp）是第二名 BSHA3（+11.1pp）的 1.6 倍，是 ZC>0（+3.6pp）的 4.8 倍。**

**BSHA5 之上叠加其他条件的边际收益：**

| 叠加路径 | H2 | 每步提升 |
|:---------|:--:|:--------:|
| BSHA5 单独 | 54.6% | — |
| → +连阳 | 56.9% | +2.3pp |
| → +门 | 56.6% | +2.0pp |
| → +连阳+门 | 57.9% | +1.0pp |
| → +ZC>0 | 54.8% | +0.2pp（几乎无） |
| → +甲乙己 | 54.7% | +0.1pp（几乎无） |

**BSHA5 之上，连阳的叠加效果最好（+2.3pp），门的叠加次之（+2.0pp），ZC>0 和甲乙己几乎无叠加效果（+0.1~0.2pp）。**

**无 BSHA5 时的最佳替代路径：**

| 路径 | H2 | 说明 |
|:----|:--:|:-----|
| **BSHA3+连阳** | **52.1%** | 无 BSHA5 时的最优选择，接近 BSHA5 单独（54.6%） |
| BSHA3+门 | 51.0% | 次优 |
| 连阳+门 | 48.8% | 无 BSHA 时的选择 |
| BSHA3 单独 | 48.3% | 基准 |
| 连阳 单独 | 48.1% | 基准 |

**条件叠加的"甜区"在 2~3 个条件：**

| 条件数 | 示例 | H2 |
|:------:|:----|:--:|
| 0 | 全量基准 | 37.2% |
| 1 | BSHA5 | 54.6% |
| 2 | BSHA5+连阳 | 56.9% |
| 3 | BSHA5+连阳+门 | 57.9% |
| 4+ | BSHA5+ZC>0+甲乙己+连阳 | 59.8% |

**从 1 个条件到 2 个条件提升最大（+2.3pp），3 个条件以上提升急剧缩小（+1.0pp→+0.2pp）。**

**日冲策略的"黄金公式"：**

```
BSHA5 + 连阳 + 门 = H2 57.9%（样本 57 万）
```

这是性价比最高的组合。再加 ZC>0 和甲乙己 只能再提升 1~2pp，但样本量会大幅下降。

如果 BSHA5 不满足：
```
BSHA3 + 连阳 = H2 52.1%（样本 107 万）
```

如果 BSHA 都不满足：
```
连阳 + 门 = H2 48.8%（样本 134 万）
```

如果什么都不满足：
```
等1+ZC>0+甲（位置基准）= H2 45.8%（样本 5.4 万）
```

### 1.5 操作指南（四层）


#### 1.5.1 日冲策略全景流程（四级过滤）

```
输入：当前股票 + 当日谕组数据
  │
  ├─ 第1级：【市板过滤】← 高波池限定
  │   ├─ ✅ 高波池：Qic(中证500) / Qim(中证1000) / Qit(中证2000) → 继续
  │   └─ ❌ 低波池：Qd(指数) / Qe(基金) / Qif(沪深300) / Qst(ST/退市) / Qin(非成分) → 跳过，无策略
  │
  ├─ 第2级：【周门过滤】
  │   ├─ ✅ ZC>0 且 CD=上 → 继续
  │   └─ ❌ 否则 → 跳过，无策略
  │
  ├─ 第3级：【等高线定位】
  │   ├─ DTZA=1 → 等1（刚穿越，可能上攻或震荡）
  │   ├─ DTZA≥2 + 末位AB → 等3（趋势延续，最强）
  │   ├─ DTZA≥2 + 末位CDEF → 等2（回归确认，需验证）
  │   ├─ DTZA=-1 → 等5（刚下穿）
  │   ├─ DTZA≤-2 + 末位ABCD → 等6（回归反弹，需验证）
  │   └─ DTZA≤-2 + 末位EF → 等7（弱势延续）
  │
  ├─ 第3.5级：【增强过滤】← 操作区域限定 + 前一柱护型（详见§1.5.5）
  │   ├─ 下侧等高线（等5~等7）→ 强制操作区域限定（ZC>0 或 AB∈甲乙己），+2.5~4.4pp
  │   ├─ 等1 → 前一柱护型要求乙/丙（+2~3.5pp）
  │   ├─ 等2/等5/等6 → 前一柱护型要求甲乙，回避戊己（+3~5pp）
  │   └─ 不满足 → 降级或跳过
  │
  └─ 第4级：【条件评分】→ 映射策略名
      ├─ BSHA>5 → 偏5（最强信号，+7~8pp）
      ├─ BSHA>3 → 偏3（次强信号）
      ├─ 连阳>0 → 连（+1~3pp）
      ├─ 层主+升排 → 层主升（+3~5pp）
      ├─ 层主 → 层主
      └─ 升排 → 升
```

| 等2出现后下一柱DTZA继续正 | 持有 | 确认再开新丘 |

#### 1.5.5 等高线增强过滤条件（操作区域限定 + 前一柱护型）

> **数据：** 高波池3,452只（1,103万行）。等高线的定义只依据DTZA，但实际操盘需结合操作区域（DXZC符号×DXAB）与前一柱护型，可显著提升下日冲高≥2%概率。

##### 1.5.5.1 操作区域限定（下侧等高线强制）

等高线必须限定在可操作区域（`DXZC>0` 或 `DXZC≤0 且 DXAB∈甲乙己`）内，下侧提升明显：

| **等2** | 40.2% | 41.2% | +1.0pp |
| 等3 | 38.7% | 39.3% | +0.6pp |
| 等5 | 35.4% | 38.6% | **+3.2pp** |
| **等6** | 33.0% | 38.4% | **+5.4pp** |
| 等7 | 36.1% | 40.5% | **+4.4pp** |

**结论：操作区域限定对下侧等高线（等5~等7）效果明显（+3.2~5.4pp），上侧（等1~等3）效果有限（+0.6~3.1pp）。下侧等高线应强制加操作区域限定。**

##### 1.5.5.2 等1 前一柱护型过滤

等1（DTZA=1）前一柱必为DTZA<0，其DXAB护型决定本柱站稳DJA的概率：

**结论：等1选股时，前一柱护型为乙最佳（42.9%），丙次之（41.7%），丁/戊应回避（差5.5pp）。** 操作区域限定可部分修复丁/戊（丁37.2%→暂无，戊36.4%→暂无）。

##### 1.5.5.3 等2/等5/等6 前一柱护型过滤

2. **BSHA3策略的样本是BSHA5的1.7~2.3倍，但≥2%概率低5.4~6.0pp**

**实操结论：**

##### 1.5.5.9 触顶类别取代好模型（最强信号）

> **数据：** 高波池全量（Qic+Qim+Qit，3451 只）。验证本文件"好模型"（ZC>0+甲乙己+BSHA5，全场最强 61.5%）能否转成"普适触顶（末位 A）类别"。
> **触顶定义：** 上符串末位 **A**（t顶>0），非旧文档的"含 v"（v 实为触哈）。

**① 好模型 ZC>0+甲乙己 上，触顶A vs BSHA5：**

| 条件 | P(次日≥3%) | 增益 |
|:--|:--:|:--:|
| 好模型（ZC>0+甲乙己 基准） | 27.7% | — |
| 好模型 + **BSHA5** | 37.9% | +10.2pp（核心信号）|
| 好模型 + **触顶A** | 31.1% | +3.4pp（弱）|
| **好模型 + 触顶A + BSHA5** | **41.7%** | **+14.0pp（联合最强）** |
| 好模型 + 触顶A + 合顶≥3 | 34.1% | +6.4pp |

> **触顶A 不能替代 BSHA5**（BSHA5 +10.2pp ≫ 触顶A +3.4pp），但**触顶A 是 BSHA5 的叠加增强**（41.7%，+3.8pp 高于 BSHA5 单独）。

**② 真正的最强转触顶类别信号（叠加 BSHA≥8 + 十字星无长上影）：**

| 组合 | P(≥3%) | 均值 | 样本 |
|:--|:--:|:--:|:--:|
| 触顶A+BSHA8+十字星 | **64.4%** | 5.17 | 10,834 |
| [好模型甲乙己]+触顶A+BSHA8+十字星 | 64.4% | 5.17 | 10,834 |
| **乙+触顶A+BSHA8+十字星** | **67.8%** | 5.40 | 4,006 |
| **触顶A+BSHA8+合顶≥3+十字星** | **65.3%** | 5.22 | 6,245 |
| 触顶A+BSHA8（无十字星） | 50.1% | 3.99 | 470,774 |
| **不触顶+BSHA8+十字星（对照）** | **40.6%** | 3.02 | 20,965 |

**③ 关键结论：**

1. **"好模型"（甲乙己）在这个最强触顶信号下是冗余的**：触顶A+BSHA8+十字星 = 64.4%，与 [好模型甲乙己]+ 完全相同（n 一致 10834）——满足该触顶组合后，护型甲乙己与否不再影响。
2. **触顶A 是十字星增强的必要前提（决定性）**：触顶A+BSHA8+十字星 = 64.4% vs 不触顶+BSHA8+十字星 = 40.6%，**相差 23.8pp**。
3. **最强转触顶类别信号：** 触顶A(末位) + BSHA≥8 + 十字星(无长上影) ≈ **64%**；再叠合顶≥3 → **65.3%**；乙护型 → **67.8%**。

**④ 结论：好模型可转触顶类别，但正确方式不是用触顶A替代BSHA5，而是建立新的最强触顶类别信号：**

> **触顶类别（最强）= 触顶A + BSHA≥8 + 十字星(无长上影) ≈ 64-68% 次日冲高**，取代/超越原"ZC>0+甲乙己+BSHA5"好模型。此触顶类别已并入日层机警"冲顶星"（[C6 §5.4.2.3](MC3.3_C6研究日类微观形态.md#5423-冲顶星-vba-落地)）。
