### 1.3 日冲策略位置坐标系（DXZC × DXAB × 等型）

> **数据：** 高波池（Qic+Qim+Qit），3451 文件全量，11,031,366 行。指标为**下日高幅**（次日盘中最高涨幅）。
> **核心思路：** 用 DXZC（DJC位置）、DXAB（护型质量）、等型（DJA位置）构建三维位置坐标系，在每个位置内评估 BSHA5/连阳 的增强效果。

#### 1.3.1 位置坐标系总览

日冲策略的完整决策链为：`DXEF → DXCD → DXZC → DXAB → 日等型 → 日柱排/日顶型`。其中 **DXZC、DXAB、日等型** 构成三维位置坐标系：

| 维度 | 变量 | 分段 | 含义 |
|:----|:-----|:-----|:------|
| **DJA位置** | 日等型 | 等1/等2/等3/等5/等6/等7 | JZ相对JA的位置与方向 |
| **DJC位置** | DXZC | ZC>0（DJC上方）/ ZC<0（DJC下方） | 中期趋势支撑 |
| **护型质量** | DXAB | 甲/乙/丙/丁/戊/己 | 均线排列质量 |

**位置坐标系回答三个问题：**
1. **当前在 DJA 的什么位置？**（等型）
2. **当前在 DJC 的什么位置？**（ZC 符号）
3. **均线排列质量如何？**（护型）

三个维度组合，形成 **6 × 2 × 6 = 72 个位置**，每个位置有独立的基准 H2 和 BSHA5 增强效果。

| 位置 | 甲+BSHA5 | 乙+BSHA5 | 差 |
|:----|:--------:|:--------:|:--:|

**发现：** 护型在 BSHA5 时的区分度很小（1.5~2.2pp）。**BSHA5 足够强，护型在 BSHA5 时几乎不需要额外过滤。**

#### 1.3.6 操作规则

基于位置坐标系，日冲策略的操作规则可简化为：

| 优先级 | 位置条件 | 基准H2 | BSHA5时H2 | 操作建议 |
|:------|:--------|:-----:|:---------:|:--------|
| 🥇 | **等1/等2 + ZC>0 + 甲乙** | 43~46% | 57~60% | 最优位置，有 BSHA5 直接做 |
| 🥈 | **等5 + ZC>0 + 乙** | 39.7% | **61.5%** | 超跌反弹，BSHA5 时最强 |
| 🥉 | **等3 + ZC>0 + 甲乙** | 39~42% | 53~55% | 位置尚可，BSHA5 增强中等 |
| ④ | **等7 + ZC>0 + 丙丁** | 40~41% | — | 位置差但 ZC>0 时基准不差 |
| ❌ | **任何 + ZC<0 + 丙丁戊** | 30~35% | 50~54% | ZC<0 时基准差，BSHA5 可救但样本小 |

**核心原则：**
1. **位置优先于信号**——等1+ZC>0+甲 基准 H2=45.8%，比等3+ZC<0+戊+BSHA5（51.7%）只低 5.9pp，但样本大 400 倍
2. **BSHA5 是触发器**——好位置 + BSHA5 → H2=57~60%
3. **等5 是特殊位置**——基准差但 BSHA5 时反转最强，超跌反弹逻辑
4. **ZC<0 时慎入**——基准 H2 仅 30~35%，即使有 BSHA5 样本也太小

#### 1.5.1 日冲策略全景流程（四级过滤）

```
输入：当前股票 + 当日谕组数据
  │
  ├─ 第1级：【市板过滤】← 高波池限定
  │   ├─ ✅ 高波池：Qic(中证500) / Qim(中证1000) / Qit(中证2000) → 继续
  │   └─ ❌ 低波池：Qd(指数) / Qe(基金) / Qif(沪深300) / Qst(ST/退市) / Qin(非成分) → 跳过，无策略
  │
  ├─ 第2级：【周门过滤】
  │   ├─ ✅ ZC>0 且 CD=上 → 继续
  │   └─ ❌ 否则 → 跳过，无策略
  │
  ├─ 第3级：【等高线定位】
  │   ├─ DTZA=1 → 等1（刚穿越，可能上攻或震荡）
  │   ├─ DTZA≥2 + 末位AB → 等3（趋势延续，最强）
  │   ├─ DTZA≥2 + 末位CDEF → 等2（回归确认，需验证）
  │   ├─ DTZA=-1 → 等5（刚下穿）
  │   ├─ DTZA≤-2 + 末位ABCD → 等6（回归反弹，需验证）
  │   └─ DTZA≤-2 + 末位EF → 等7（弱势延续）
  │
  ├─ 第3.5级：【增强过滤】← 操作区域限定 + 前一柱护型（详见§1.5.5）
  │   ├─ 下侧等高线（等5~等7）→ 强制操作区域限定（ZC>0 或 AB∈甲乙己），+2.5~4.4pp
  │   ├─ 等1 → 前一柱护型要求乙/丙（+2~3.5pp）
  │   ├─ 等2/等5/等6 → 前一柱护型要求甲乙，回避戊己（+3~5pp）
  │   └─ 不满足 → 降级或跳过
  │
  └─ 第4级：【条件评分】→ 映射策略名
      ├─ BSHA>5 → 偏5（最强信号，+7~8pp）
      ├─ BSHA>3 → 偏3（次强信号）
      ├─ 连阳>0 → 连（+1~3pp）
      ├─ 层主+升排 → 层主升（+3~5pp）
      ├─ 层主 → 层主
      └─ 升排 → 升
```
