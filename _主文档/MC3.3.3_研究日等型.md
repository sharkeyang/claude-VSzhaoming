### 1.4 策略赛马（位置+条件排名，高波池全量口径）


> **数据：** 高波池全量（Qic+Qim+Qit），3451 文件，11,031,366 行。全量基准 H2=37.2%。
> **方法：** 所有位置+条件组合一起比较，按 H2（下日高≥2%）排序。样本量越大越可靠。

**策略命名说明：**
- `{条件}+{等型}` — 条件在前，等型在后。例：`ZC>0+BSHA5+等5` = ZC>0 + BSHA5 + 等5
- **条件简写：** BSHA5=当日高偏离JA>5%，连=BT连阳>0，门=ZC>0+CD=上，ZC>0=DJC上方，甲乙己=好护型
- **跨等型汇总：** `+全量` 表示不限定等型

#### 1.4.1 全条件赛马排名（高波池全量口径，H2 ≥ 基准 37.2%）

**边际贡献结论：**
- **`连` 和 `门` 是真正有区分度的条件**——等1/等3/等6 各 +2~3pp，等2/等7 的 `门` +1.6~1.9pp
- **`ZC>0` 和 `甲乙己` 边际贡献极小**（多数等型仅 +0~0.5pp），是制造重复行的元凶
- **等5 是唯一 `甲乙己` 有明显贡献的等型**（+1.5pp，61.5%），但样本仅 1.99 万，需谨慎
- **等3 的 `连+门` 叠加最强**（+3.7pp，57.4%），但绝对 H2 仍低于等1/等2

#### 1.4.2 择优建议

| 场景 | 推荐策略 | H2 | 样本 | 理由 |
|:----|:--------|:--:|:---:|:-----|
| **全场最强** | **ZC>0+甲乙己+BSHA5+等5** | **61.5%** | 1.99万 | 超跌反弹+好护型+ZC>0，H2最高 |
| 等3+BSHA5 | BSHA5+等3 | 53.7% | 109万 | 样本最大但 H2 平庸 |
| 大样本兼顾概率 | ZC>0+BSHA5+等3 | 53.9% | 100万 | 样本最大，执行门槛低 |
| 无BSHA5时（BSHA3） | BSHA3+等5 | 52.7% | 13.6万 | BSHA3 是 BSHA5 的最佳替代 |
| 无BSHA时（连阳） | 连+门+等3 | 49.9% | 64万 | 连阳+门，无BSHA时的最优选择 |
| 无BSHA时（位置本身） | 等1+ZC>0+甲（基准） | 45.8% | 5.5万 | 位置本身就好，不依赖信号 |

**核心说明：**
- **BSHA5 是日冲策略的核心信号**，所有 H2>55% 的组合都包含 BSHA5
- **等5（刚下穿DJA）在 BSHA5 时反转最强**（61.5%），但样本仅 1.98 万
- **等3（上方强势）在 BSHA5 时反而平庸**（53.7%），样本最大但 H2 不如等1/等2
- **ZC>0 和 甲乙己 在 BSHA5 时的边际贡献很小**（1~2pp），BSHA5 本身已足够强
- **无 BSHA5 时，位置本身决定 H2**——等1+ZC>0+甲 基准 45.8%，已超过全量基准 8.6pp

#### 1.4.3 条件边际贡献与叠加规律

> **数据：** 高波池（Qic+Qim+Qit），3451 文件全量。以下为各条件单独及叠加后的 H2，用于分析条件之间的边际贡献和叠加效应。

**各条件单独 vs 全量基准（37.2%）：**

| 条件 | H2 | 边际贡献 | 类型 |
|:----|:--:|:--------:|:----|
| **BSHA5**（当日高偏离JA>5%） | **54.6%** | **+17.4pp** | 🚀 核武器 |
| BSHA3（当日高偏离JA>3%） | 48.3% | +11.1pp | 💪 强信号 |
| 连阳（BT连阳>0） | 48.1% | +10.9pp | 💪 强信号 |
| BT鼎（BT鼎>0） | 43.7% | +6.5pp | 🔫 中等 |
| 门（ZC>0+CD=上） | 43.4% | +6.2pp | 🔫 中等 |
| 层主（层界=主） | 43.3% | +6.1pp | 🔫 中等 |
| ZC>0（DJC上方） | 40.8% | +3.6pp | 📏 位置基准 |
| 甲乙己（好护型） | 40.0% | +2.8pp | 📏 位置基准 |

**BSHA5 的边际贡献（+17.4pp）是第二名 BSHA3（+11.1pp）的 1.6 倍，是 ZC>0（+3.6pp）的 4.8 倍。**

**BSHA5 之上叠加其他条件的边际收益：**

| 叠加路径 | H2 | 每步提升 |
|:---------|:--:|:--------:|
| BSHA5 单独 | 54.6% | — |
| → +连阳 | 56.9% | +2.3pp |
| → +门 | 56.6% | +2.0pp |
| → +连阳+门 | 57.9% | +1.0pp |
| → +ZC>0 | 54.8% | +0.2pp（几乎无） |
| → +甲乙己 | 54.7% | +0.1pp（几乎无） |

**BSHA5 之上，连阳的叠加效果最好（+2.3pp），门的叠加次之（+2.0pp），ZC>0 和甲乙己几乎无叠加效果（+0.1~0.2pp）。**

**无 BSHA5 时的最佳替代路径：**

| 路径 | H2 | 说明 |
|:----|:--:|:-----|
| **BSHA3+连阳** | **52.1%** | 无 BSHA5 时的最优选择，接近 BSHA5 单独（54.6%） |
| BSHA3+门 | 51.0% | 次优 |
| 连阳+门 | 48.8% | 无 BSHA 时的选择 |
| BSHA3 单独 | 48.3% | 基准 |
| 连阳 单独 | 48.1% | 基准 |

**条件叠加的"甜区"在 2~3 个条件：**

| 条件数 | 示例 | H2 |
|:------:|:----|:--:|
| 0 | 全量基准 | 37.2% |
| 1 | BSHA5 | 54.6% |
| 2 | BSHA5+连阳 | 56.9% |
| 3 | BSHA5+连阳+门 | 57.9% |
| 4+ | BSHA5+ZC>0+甲乙己+连阳 | 59.8% |

**从 1 个条件到 2 个条件提升最大（+2.3pp），3 个条件以上提升急剧缩小（+1.0pp→+0.2pp）。**

#### 1.4.4 日冲策略的"黄金公式"（从最优到兜底）

**🥇 首选 — BSHA5 满足**
> **BSHA5 + 连阳 + 门 = H2 57.9%**（样本 57 万）
> 性价比最高；再加 ZC>0/甲乙己 仅 +1~2pp，但样本大降

**🥈 次选 — BSHA5 不满足**
> **BSHA3 + 连阳 = H2 52.1%**（样本 107 万）
> BSHA3 是 BSHA5 的最佳替代

**🥉 三选 — BSHA 都不满足**
> **连阳 + 门 = H2 48.8%**（样本 134 万）
> 无 BSHA 时的最优选择

**⚪ 兜底 — 什么都不满足**
> **等1+ZC>0+甲 = H2 45.8%**（样本 5.4 万）
> 位置本身就好，不依赖信号
