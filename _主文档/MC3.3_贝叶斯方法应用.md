# MC3.3_贝叶斯方法应用：频率派 vs 贝叶斯派

> 数据日期：2026-09-27 | 数据源：谕组日 1115 万行（高波池） | 脚本：`_产出物/_工具/vba表贝叶斯因子.py`、`vba表贝叶斯组合.py`
> 目标指标：次日冲高≥2%（列[26]）

## 一、核心原理：频率派 vs 贝叶斯派，何时用哪个

**数学上等价：** 数据充足时，`P(A|B)=n(A∩B)/n(B)`（频率）与 `P(A|B)=P(B|A)·P(A)/P(B)`（贝叶斯）收敛到同一值。

**区别不在公式，在于你手里有什么数据：**

| | 频率派 | 贝叶斯派 |
|:--|:--|:--|
| 做法 | 直接统计 P(A\|B) | 用反向 P(B\|A) + 先验 P(A) 推导 |
| 需要 | 大量同条件样本 | 先验 + 反向概率（样本不足时也能算） |
| 适合 | 离线研究、海量样本 | 在线决策、样本不足 |

**本系统的应用判断（关键）：**

| 情况 | 用哪个 | 原因 |
|:--|:--|:--|
| 单特征查表（门开/顶型/护型） | **频率派** | 样本 1115 万，直接数最准 |
| 组合特征（门开后叠加 2-3 层） | **频率派** | 仍有几万~几十万样本 |
| **深层组合（叠加 4 层以上）** | **贝叶斯收缩** | n<1000，频率派是噪声 |
| 跨周期融合（周→日→叠层） | **贝叶斯先验** | 深层样本不足 |
| 实盘持有期动态更新 | **贝叶斯更新** | 单只股票只有历史，无平行样本 |

> **一句话：离线研究用频率派，实盘决策用贝叶斯派。**

## 二、应用点1：单特征贝叶斯因子（已实现）

对每个特征 B，算 `P(冲高≥2% | B)` 相对互补组 `P(冲高≥2% | ¬B)` 的贝叶斯因子（对数似然比），判断特征是否真有区分力。

### 结果（1115 万行，基线 P(A)=37.19%）

**正向特征（提升冲高概率）：**

| 特征 | P(A\|B) | P(A\|¬B) | Δpp | 证据 |
|:--|:--:|:--:|:--:|:--|
| **门开** | 43.4% | 34.3% | **+9.1** | 中等 |
| **顶型_龙** | 43.9% | 35.5% | **+8.5** | 中等 |
| **护型_乙** | 41.5% | 35.9% | **+5.6** | 中等 |
| 等型_等2 | 40.2% | 36.9% | +3.3 | 弱 |
| 护型_甲 | 39.5% | 36.6% | +2.9 | 弱 |
| 等型_等3 | 38.7% | 36.5% | +2.2 | 弱 |

**反向特征（降低冲高概率）：**

| 特征 | P(A\|B) | P(A\|¬B) | Δpp | 证据 |
|:--|:--:|:--:|:--:|:--|
| **护型_戊** | 32.8% | 38.5% | **-5.7** | 反向 |
| 等型_等6 | 33.0% | 37.6% | -4.6 | 反向 |
| 护型_丁 | 35.5% | 37.7% | -2.1 | 反向 |

**结论：**
1. **门开是单特征最强信号**（+9.1pp），符合"门才是做不做的主决定因子"
2. **顶型_龙有独立价值**（+8.5pp），但门开后边际贡献小（见等高线验证）——两者不矛盾
3. **护型_戊是最弱护型**（-5.7pp），符合"戊(ZA>0)转甲率仅3.44%"的弱势结论

### ⚠️ 超大样本下的证据分级失真

1115 万行下，任何 Δpp 差异都会导致 BF→∞（统计显著），**"统计显著性"失去意义**。真正重要的是 **Δpp 的操作意义**（+9 vs +2 有本质区别）。贝叶斯因子在此的价值不是"判断显著"，而是**排序特征价值**。

## 三、应用点2：组合特征逐级更新（已实现，气象预报模式）

气象预报不是一次算完，而是逐级更新：
```
P(下雨) → 看到云层 → P(下雨|云) → 看到气压 → P(下雨|云,气压) → ...
```

**本系统同理：从门开出发，逐级叠加特征，看概率能推到多高。**

### 结果（按 P(A|B) 降序，样本充足部分）

**最强组合：**

| 组合 | P(A\|B) | Δpp | n |
|:--|:--:|:--:|:--:|
| **门开+顶型龙+护型甲+等型等1** | **54.7%** | **+17.5** | 12,140 |
| 门开+顶型龙+等型等1 | 50.3% | +13.2 | 63,252 |
| 门开+顶型龙+护型乙+等型等1 | 49.3% | +12.1 | 51,083 |
| 门开+护型甲+等型等1 | 48.2% | +11.0 | 34,259 |
| 门开+顶型龙+护型乙+等型等2 | 47.9% | +10.7 | 155,711 |
| 门开+顶型龙 | 46.2% | +9.0 | 1,690,202 |

**拖累组合：**

| 组合 | P(A\|B) | Δpp | n |
|:--|:--:|:--:|:--:|
| 门开+等型等7 | 41.9% | +4.7 | 486,123 |
| 门开+护型戊 | 38.2% | +1.0 | 61,557 |
| 门开+护型戊+等型等3 | 34.7% | -2.5 | 6,929 |

### 关键发现

**1. 等型等1 是"门开后"的最强叠加因子**
```
门开 = 43.4%
门开+顶型龙 = 46.2%
门开+顶型龙+等型等1 = 50.3%   ← 等1（DTZA=1，JZ刚上穿JA）= 趋势刚启动
门开+顶型龙+护型甲+等型等1 = 54.7%  ← 最强组合
```
**逻辑：** 门开（ZC>0+DXCD=上）+ 刚上穿（等1）意味着趋势刚启动，动量最强。

**2. 护型甲 vs 乙 在门开后反转**
- 单特征：护型乙最强（+5.6）
- 门开后：护型甲+等型等1（48.2%）> 护型乙+等型等1（45.5%）
- **这是贝叶斯逐级更新的价值——单特征结论在叠加后可能反转**

**3. 等型等7 是门开后的"拖累"**（41.9%，低于门开+等1/等2/等3）

## 四、应用点3：深层组合的贝叶斯收缩（待实现）

**问题：** 组合叠加 4 层后样本骤减（门开+顶型龙+护型丁+等型等7 仅 n=24），频率派直接数 P(A|B) 是噪声：
- n=24，P=25.0% —— 真实概率可能接近基线
- n=9，P=22.2% —— 完全不可信

**贝叶斯收缩公式：**
```
P(A|B)_收缩 = (n·P_观测 + k·P_先验) / (n + k)
```
- `P_先验`：全局基线（37.2%）或门开基线（43.4%）
- `k`：先验强度（建议 100~500）

**目的：** 防止被 n<30 的极端值误导。深层组合的结论必须在收缩后给出。

## 五、操作含义

```
门开（43.4%）→ 基础入场条件
  + 顶型龙（46.2%）→ 加分
  + 等型等1（50.3%）→ 强加分（趋势刚启动）
  + 护型甲（54.7%）→ 最强组合
```

- **门开+等1+龙+甲 → 可重仓/积极介入**（冲高≥2% 概率从 43% 提到 55%）
- **门开+等7 → 谨慎**（概率被拖累）
- **门开+护型戊 → 回避**（戊是最弱护型）

## 六、⚠️ 检察官谬误警示

**检察官谬误 = 把 `P(证据|无辜)` 当成 `P(无辜|证据)`。**

**本系统对应风险：** 把 `P(冲高|门开)`=43.4% 当成"门开**导致**冲高"。

**实际：** 门开和冲高可能都受第三个因素驱动（如大盘普涨日）。两者**相关但不因果**。文档措辞必须用"伴随/条件下"，**绝不用"导致/因为"**。
