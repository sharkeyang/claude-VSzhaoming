## 一、上符串编码与基础定义

**上符串（日CSV列30）：** 5位滚动记录，末位=今天，每位含义：
- `A` = 触顶（创新高）
- `B` = 触哼（触到哼JA）
- `v` = 触哈
- `_` = 无触顶

**上符范（日CSV列29）：** 编码值，含触顶次数/触哼次数等信息。

**顶型（日CSV列43）：** 龙/雀/虎/篪/武等分类。

**宽哼JC（日CSV列22）：** 当前价格距哼JA的百分比距离。

## 二、ZC方向×触顶状态 核心模型

> 验证日期：2026-08-17，抽样500文件/150万行。

**先看ZC方向，再看触顶状态。** ZC<=0时触顶无效，ZC>0时触顶有效。

| 条件 | P3 | vs基线 |
|------|:--:|:------:|
| **ZC>0 + 触顶(A)** | **24.5%** | **+5.4pp** |
| ZC>0 + 触哼(B) | 22.4% | +3.3pp |
| ZC>0 + 无(_) | 21.8% | +2.7pp |
| ZC<=0 + 触顶(A) | 19.4% | +0.3pp |
| ZC<=0 + 触哼(B) | 17.5% | -1.6pp |
| **ZC<=0 + 无(_)** | **17.3%** | **-1.8pp** |

**ZC>0+触顶 vs ZC<=0+无 = 7.2pp**，方向明确。

## 七、触顶+BSHA（冲高幅度）

## 十二、触顶信号 vs 日策略P2 / 日层段 一致性

> 验证日期：2026-08-17，抽样500文件/150万行。

### 12.1 触顶信号 vs 日策略P2（等高线+BSHA）

日策略P2 = 等高线 + BSHA（偏5/偏3）+ 连阳/层主/升排/跌排。它已包含BSHA信息，但**未包含触顶信息**。

**偏5（BSHA>=5）中触顶占比62.3%**，两者高度一致。

| 条件 | P3 |
|:----|:--:|
| 等1+偏5+触顶 | 40.5% |
| 等1+偏5+未触顶 | 46.9% |
| 等2+偏5+触顶 | 42.1% |
| 等2+偏5+未触顶 | 46.2% |
| 等3+偏5+触顶 | 41.6% |
| 等3+偏5+未触顶 | 42.3% |

**关键发现：在偏5（BSHA>=5）条件下，触顶 vs 未触顶的P3差异很小（<5pp）。** 因为BSHA>=5本身已是强信号（P3=41.8%），触顶与否的边际贡献有限。

### 12.2 触顶信号 vs 日层段

**触顶信号与日层段高度一致：**

| 条件 | P3 | 判断 |
|:----|:--:|:----:|
| **持主+强触顶(BSHA>=5)** | **42.7%** | ✅ 最强 |
| 持被+强触顶 | 40.1% | ✅ 强（样本少） |
| 卖浮+强触顶 | 34.2% | ⚠️ 一般 |
| 持主+触顶 | 27.8% | ✅ |
| 持主+未触顶 | 23.6% | ⚠️ |
| 卖浮+触顶 | 19.6% | ❌ 几乎无效 |
| 卖浮+未触顶 | 19.4% | ❌ |

**强触顶信号中持主占72.9%**，触顶信号几乎都发生在持主阶段。

### 12.3 三层叠加（触顶+日层段+等高线）

| 条件 | P3 |
|:----|:--:|
| 等1+偏5+触顶+持主 | 43.9% |
| 等2+偏5+触顶+持主 | 43.7% |
| 等3+偏5+触顶+持主 | 43.9% |

**三层叠加后P3稳定在43.7~43.9%**，说明等高线在偏5+触顶+持主条件下已无区分度——三者已充分表达信号。

### 12.4 结论

1. **触顶信号与日策略P2一致**：偏5信号中62.3%触顶，但偏5本身已足够强，触顶的边际贡献小
2. **触顶信号与日层段一致**：强触顶信号72.9%出现在持主，持主+强触顶=42.7%最强
3. **日层段是比触顶更强的过滤条件**：持主+强触顶=42.7% vs 卖浮+强触顶=34.2%，差8.5pp
4. **三层叠加后P3饱和在~44%**：等高线+BSHA+触顶+持主已充分表达信号

## 十三、日层段 = DXZE>0+DXZC>0 验证

> 验证日期：2026-08-17，抽样500文件/150万行。

### 13.1 日层段VBA定义

```vba
日层段 = "NA"
If 日类BTZE > 0 Then          ' DXZE>0（站上DJE）
    If 日类BTZC <= 0 Then      ' DXZC<=0（跌破DJC）
        日层段 = "卖浮"
    ElseIf 日类BTZA > 0 Then   ' DXZA>0（站上DJA）
        日层段 = "持主"
    Else                       ' DXZA<=0
        日层段 = "持被"
    End If
End If
```

**日层段 = DXZE>0 为前提，再按DXZC/DXZA细分：**
- **持主** = DXZE>0 + DXZC>0 + DXZA>0（三线全上）
- **持被** = DXZE>0 + DXZC>0 + DXZA<=0（ZE/ZC上，ZA下）
- **卖浮** = DXZE>0 + DXZC<=0（ZE上，ZC下）

### 13.2 日层段 vs 三线条件 一致性

**理论条件与日段样本完全一致：**

| 理论条件 | 日段 | 样本 |
|:--------|:----:|:----:|
| ZE>0+ZC>0+ZA>0 | 持主 | 374,872 |
| ZE>0+ZC>0+ZA<=0 | 持被 | 127,682 |
| ZE>0+ZC<=0 | 卖浮 | 150,661 |

### 13.3 持主是否必赢？

**不是必赢，但显著优于基线。**

| 指标 | 持主 | 基线 |
|:----|:----:|:----:|
| 下日P0(>=0%) | 89.5% | ~80% |
| 下日P1(>=1%) | 57.6% | ~55% |
| 下日P2(>=2%) | 37.2% | ~33% |
| 下日P3(>=3%) | 25.4% | 20.2% |
| 下日P5(>=5%) | 12.9% | ~10% |
| **期望HR** | **2.19%** | **1.84%** |

**持主不是必赢**——下日P0=89.5%（仍有10.5%概率下日亏损），P3=25.4%（仅1/4概率冲高3%+）。但期望HR=2.19%显著高于基线1.84%。

### 13.4 持主+强触顶 是否必赢？

**接近必赢，但仍不是100%。**

| 指标 | 持主+BSHA>=5+触顶 |
|:----|:-----------------:|
| 下日P0(>=0%) | 87.6% |
| 下日P1(>=1%) | **71.2%** |
| 下日P2(>=2%) | **55.2%** |
| 下日P3(>=3%) | **42.7%** |
| 下日P5(>=5%) | 26.6% |
| **期望HR** | **3.42%** |

**持主+强触顶的期望HR=3.42%，是基线的1.86倍。** 下日P1=71.2%（7成概率下日涨1%+），P3=42.7%（4成概率冲高3%+）。虽然不是"必赢"（仍有12.4%概率下日亏损），但已是极强的信号。

### 13.5 持主 vs 卖浮

| 指标 | 持主 | 卖浮 |
|:----|:----:|:----:|
| P0 | 89.5% | 90.3% |
| P3 | 25.4% | 19.4% |
| 期望HR | 2.19% | 1.76% |

**持主和卖浮的P0几乎相同（89.5% vs 90.3%），但P3和期望HR差异明显。** 卖浮阶段下日不亏的概率也高，但冲高幅度小——卖浮是"不涨不跌"的横盘，持主是"有冲高机会"的上升。

### 13.6 结论

1. **日层段 = DXZE>0+DXZC>0 确认**（持主还要求DXZA>0）
2. **持主不是必赢**，但期望HR=2.19%显著优于基线1.84%
3. **持主+强触顶（BSHA>=5+触顶）接近必赢**：期望HR=3.42%，P1=71.2%，P3=42.7%
4. **"必赢"不成立**——任何条件下下日都有约10%概率亏损，但持主+强触顶是期望收益最高的组合

## 十四、合顶周期（趋势延续）

> 验证日期：2026-08-17，抽样500文件/150万行。

### 14.1 核心发现：合顶不是看单日，而是看整个周期

之前验证"合顶天数×下日P3"发现合顶在控制BSHA后是负信号，但那是**只看下日冲高**（单日）。**合顶的真正意义在于"趋势延续"**——从合顶开始到离顶结束的整个周期，累计收益显著。

### 14.2 合顶天数 × 未来N天累计收益

| 合顶天数 | 未来1天 | 未来3天 | 未来5天 | 未来10天 | 未来20天 |
|:-------:|:------:|:------:|:------:|:-------:|:-------:|
| 1天 | 2.12% | 8.51% | 12.60% | 22.15% | 40.02% |
| 2天 | 2.18% | 9.98% | 13.91% | 23.66% | 41.54% |
| 3天 | 2.26% | 9.30% | 15.35% | 24.88% | 42.53% |
| 4天 | 2.49% | 9.70% | 16.82% | 26.14% | 43.37% |
| **5天** | **2.61%** | **10.61%** | **17.74%** | **29.94%** | **45.74%** |

**合顶天数越长，未来累计收益越高。** 合顶5天 vs 合顶1天：
- 未来5天：17.74% vs 12.60%（差5.14pp）
- 未来10天：29.94% vs 22.15%（差7.79pp）
- 未来20天：45.74% vs 40.02%（差5.72pp）

### 14.3 合顶天数 × 未来N天冲高>=3%概率

| 合顶天数 | 未来1天 | 未来3天 | 未来5天 | 未来10天 |
|:-------:|:------:|:------:|:------:|:-------:|

**任何合顶天数下，未来5天冲高>=3%的概率都超过94%！** 未来10天更是超过97%。

### 14.4 合顶开始 vs 结束

| 指标 | 合顶开始 | 合顶结束 |
|:----|:-------:|:-------:|
| 未来1天 | 2.12% | 1.92% |
| 未来3天 | 8.51% | 6.55% |
| 未来5天 | 12.60% | 12.28% |
| 未来10天 | 22.15% | 22.69% |
| 未来20天 | 40.02% | 40.64% |

**合顶开始和结束的未来收益几乎相同！** 说明合顶结束后（离顶）并不代表趋势结束——离顶后未来20天仍有40%的累计收益。

### 14.5 结论

1. **合顶周期是有效的**——合顶天数越长，未来累计收益越高（合顶5天未来20天=45.74%）
2. **合顶开始是入场信号**——合顶开始后未来5天冲高>=3%概率94.9%
3. **合顶结束不是离场信号**——离顶后未来20天仍有40%收益，说明离顶只是短期回调，不是趋势反转
4. **合顶的意义在于"趋势延续"**——连续创新高代表趋势强，未来N天累计收益高

## 十五、合顶天数 × BSHA 交叉验证（合顶不是单向增值指标）

> 验证日期：2026-08-17，抽样500文件/150万行。

### 15.1 核心发现：合顶只在偏5条件下有效，在偏3/非偏条件下反而有害

**等高线×BSHA×合顶天数 全组合实际概率（ZC>0范围内）：**

**偏5（BSHA>=5）条件下：**

| 条件 | 未来5天 | 未来10天 | 未来20天 | 5天P3 |
|:----|:-------:|:-------:|:-------:|:-----:|
| 等1+偏5+合顶<3 | 21.15% | 36.46% | 69.43% | 97.9% |
| 等2+偏5+合顶<3 | 23.41% | 35.89% | 68.14% | 98.5% |
| **等3+偏5+合顶>=3** | **27.84%** | **42.62%** | 64.66% | 98.7% |
| 等3+偏5+合顶<3 | 24.00% | 40.70% | 69.35% | 99.7% |

**等3+偏5+合顶>=3（27.84%）vs 等3+偏5+合顶<3（24.00%）= +3.84pp（未来5天）**

**偏3（BSHA3~5）条件下：**

| 条件 | 未来5天 | 未来10天 | 未来20天 |
|:----|:-------:|:-------:|:-------:|
| 等3+偏3+合顶>=3 | 10.12% | 18.21% | 32.54% |
| 等3+偏3+合顶<3 | 13.12% | 24.63% | 46.37% |

**等3+偏3+合顶>=3（10.12%）vs 等3+偏3+合顶<3（13.12%）= -3.00pp！合顶在偏3条件下反而更差！**

**非偏（BSHA<3）条件下：**

| 条件 | 未来5天 | 未来10天 | 未来20天 |
|:----|:-------:|:-------:|:-------:|
| 等3+非偏+合顶>=3 | 5.23% | 9.99% | 18.51% |
| 等3+非偏+合顶<3 | 6.50% | 13.38% | 26.49% |

**等3+非偏+合顶>=3（5.23%）vs 等3+非偏+合顶<3（6.50%）= -1.27pp！合顶在非偏条件下也更差！**

### 15.2 合顶天数的方向性

| BSHA条件 | 合顶>=3 vs 合顶<3 | 判断 |
|:--------|:-----------------:|:----:|
| **偏5(BSHA>=5)** | **+3.84pp** | ✅ 合顶有效 |
| 偏3(BSHA3~5) | -3.00pp | ❌ 合顶有害 |
| 非偏(BSHA<3) | -1.27pp | ❌ 合顶有害 |

### 15.3 原因分析

**合顶>=3天但BSHA<5，说明"连续创新高但冲高幅度小"——这是顶部震荡（涨不动了），不是趋势延续。** 只有"连续创新高+大幅冲高"（合顶>=3+偏5）才是真正的强趋势。

### 15.4 结论：合顶不是单向增值指标，不适合作为通用策略维度

1. **合顶不是单向增值指标**——只在偏5条件下有效（+3.84pp），在偏3/非偏条件下反而有害（-3.00pp / -1.27pp）
2. **合顶不适合作为独立策略维度**——如果把它作为通用加分项，会在偏3/非偏条件下误判
3. **合顶的正确用法**：作为"偏5"的增强条件，而不是独立维度
   - 等X.偏5 + 合顶>=3天 → 未来5天27.84%（强）
   - 等X.偏5 + 合顶<3天 → 未来5天24.00%（一般）
   - 等X.偏3 + 合顶>=3天 → 未来5天10.12%（弱，应降级）
   - 等X.非偏 + 合顶>=3天 → 未来5天5.23%（很弱，应排除）
4. **日策略P2不纳入合顶是合理的**——合顶不是独立信号，且方向不固定，纳入会引入噪声
