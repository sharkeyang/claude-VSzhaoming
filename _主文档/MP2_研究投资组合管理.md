## 一、定位

昭明计划现有体系侧重**选股与择时**（WXCD/WXAB/护级/仓类），但在**仓位管理**层面缺少系统化的规则引擎。本文件记录投资组合管理的基本规则与昭明计划适配方案。

**交割单的角色：** 交割单只用于回顾策略执行情况，不参与组合管理的实时评估。组合管理的数据源是花册（当前持仓）+ 神谕（策略评分）。

## 二、账户策略分配

### 2.1 两账户定位

```
总资金 100%
  ├── 宝彦账户（稳健型）60%    ← 月基策略 ≥ 60%，ETF 为主
  └── 宝福账户（积极型）40%    ← 月基策略 30%~40%，个股为主
```

### 2.2 宝彦账户（60%）

目标：月基策略占比 ≥ 60%，以 ETF 和月基核心持仓为主。

| 子层 | 比例 | 说明 |
|:-----|:----|:-----|
| ETF | 30% | 沪深300 + 行业ETF |
| 月基核心（多长+策分≥80） | 20% | 按月基策略选出 |
| 月基辅助（多长+策分≥60） | 10% | 按月基策略选出 |
| 周冲/日冲 | ≤ 5% | 轻量操作 |

**门槛：** 月基命分 ≥ 50，月基策分 ≥ 60

### 2.3 宝福账户（40%）

目标：月基策略占比 30%~40%，主动操作为主。

| 子层 | 比例 | 说明 |
|:-----|:----|:-----|
| ETF | 10% | 行业ETF为主 |
| 月基核心（多长+策分≥80） | 10% | 按月基策略选出 |
| 月基辅助（多长+策分≥60） | 10% | 按月基策略选出 |
| 周冲/日冲 | 10% | 短线操作 |

**门槛：** 月基命分 ≥ 30，月基策分 ≥ 40

### 2.4 通用规则

**单票上限（两账户共用）：**

| 池 | 单票上限 | 说明 |
|:---|:--------|:-----|
| 金池 | ≤ 20% | 核心持仓 |
| 银池 | ≤ 10% | 辅助持仓 |
| 铜池 | ≤ 5% | 试探持仓 |
| 黑池 | ≤ 2% | 观察名单 |

**行业上限：** 单一行业（含 ETF）≤ 30%

**总仓位上限（基于 WXCD，两账户共用）：**

| WXCD | 总仓位上限 | 说明 |
|:-----|:----------|:-----|
| 金/银 | ≤ 90% | 上升趋势 |
| 唏/嘘 | ≤ 50% | 震荡/半仓 |
| 屎/尿 | ≤ 20% | 下降趋势，轻仓 |

## 三、三层决策框架

```
第一层：宏观环境    决定「总仓位上限」
  WXCD → 总仓位上限
  月基带向 → 方向偏好

第二层：策略评分    决定「单票上限」
  月基策略 + 月基策分 → 基础上限
  月基命分 → 过滤恶庄
  周冲策略 → 置信度调整

第三层：执行时机    决定「操作窗口」
  周冲策分 → 入场窗口
  月基带日 → 日级别入场点
  仓日类 → 当前仓位状态
```

### 3.1 宏观环境（第一层）

| WXCD 状态 | 总仓位上限 | 说明 |
|:----------|:----------|:-----|
| 金 / 银 | ≤ 90% | 上升趋势，可重仓 |
| 唏 / 嘘 | ≤ 50% | 震荡/选择方向，半仓 |
| 屎 / 尿 | ≤ 20% | 下降趋势，轻仓（不是不能投，是限制仓位） |

方向偏好（基于月基带向）：
- 11双好 → 可加仓，方向一致
- 10反险 → 谨慎，WXAB 已破但大局尚好
- 01正潜 → 可建仓，WXAB 完好但趋势差
- 00双差 → 不参与

### 3.2 策略评分（第二层）

**单票仓位上限（基于月基策略 + 月基策分）：**

| 策略 | 策分 | 单票上限 |
|:-----|:----|:--------|
| 多长 | ≥80 | 20% |
| 多长 | ≥60 | 10% |
| 多长 | <60 | 5% |
| 多被 | — | 5% |
| 空看/空长 | — | 不参与 |

**命分过滤：** 命分 < 30 → 不参与

**周冲策略置信度调整：**
- 金升非 → 单票上限 × 100%
- 金升 → 单票上限 × 70%
- 其他 → 单票上限 × 50%

### 3.3 执行时机（第三层）

**入场：**
- 周冲策分 ≥ 70% + 月基带向 ≠ 00双差 → 可建仓
- 周冲策分 ≥ 50% + 月基带向 = 11双好 → 可加仓
- 周冲策分 < 50% → 等待

**出场/减仓：**
- 月基带向 = 00双差 → 减仓至底仓
- 月基带日 = 下/忑 → 减仓
- WXCD = 屎/尿 → 减仓至 ≤ 20%

## 四、仓位计算示例

```
总资金 = 100万（宝彦60万 + 宝福40万）

宝彦账户（60万）：
  ETF = 18万（30%）
  月基核心 = 12万（20%）
  月基辅助 = 6万（10%）
  周冲/日冲 = 3万（5%）

  股票A：月基策略=多长, 策分=85, 命分=60, 池=金
    命分60 ≥ 50 → 可参与 ✅
    单票上限 = 20%（金池）
    股票A入月基核心池 → 上限12万
    实际仓位 = 8万 → 未超限 ✅

宝福账户（40万）：
  ETF = 4万（10%）
  月基核心 = 4万（10%）
  月基辅助 = 4万（10%）
  周冲/日冲 = 4万（10%）

  股票B：月基策略=多长, 策分=65, 命分=35, 池=银
    命分35 ≥ 30 → 可参与 ✅
    单票上限 = 10%（银池）
    股票B入月基辅助池 → 上限4万
    实际仓位 = 5万 → 超限 ⚠️ 需减至4万
```

## 六、实现路径

```
Phase 1: 规则引擎
  → 独立 VBA 模块，读取花册 + 神谕数据
  → 按账户（宝彦/宝福）分别计算
  → 输出：每账户的单票上限 + 总仓位 + 超限预警

Phase 2: 组合仪表盘
  → 分账户展示（宝彦/宝福）
  → 行业分布图
  → 仓位超限预警
  → 月基策略占比监控

Phase 3: 自动化
  → 与花册导入联动，导入后自动检查
  → 与菜单集成，一键查看
```

## 八、伪代码

```pseudocode
' 投资组合管理引擎 — 按账户分别计算
Sub 投资组合管理_检查()
    ' ① 读取基础数据
    ' 花册：CIDL、行业、在池、持仓数量
    ' 神谕：WXCD、月基策略、月基策分、月基命分、月基带向、周冲策分

    ' ② 按账户设置策略参数
    ' 宝彦：月基≥60%，命分门槛≥50，策分门槛≥60
    ' 宝福：月基30~40%，命分门槛≥30，策分门槛≥40

    ' ③ 宏观 → 总仓位上限（两账户共用）
    Select Case WXCD
        金/银 → 90%   唏/嘘 → 50%   屎/尿 → 20%
    End Select

    ' ④ 按账户逐只检查
    For Each 账户 In [宝彦, 宝福]
        For Each 股票 In 该账户持仓
            If 命分 < 账户.命分门槛 Then 跳过
            单票上限 = 计算(池, 策分, 周冲置信度)
            If 当前仓位 > 单票上限 Then 输出超限
        Next
        If 账户总仓位 > 总上限 Then 输出总仓位超限
        If 月基占比 < 账户.月基目标 Then 输出月基不足
    Next
End Sub
```

Anthropic 把组合管理拆为 **3 个 Skill**，占私募投研/风控负责人约 **35% 的日常时间**：

| Skill | 中文 | 核心功能 | 传统耗时 | AI 辅助后 |
|:------|:-----|:---------|:--------|:---------|
| portfolio-monitoring | 持仓监控 | 收益对比、行业贡献、风险指标、实时告警 | 1-1.5h/天 | 15min/天 |
| risk-attribution | 风险归因 | Brinson 归因、因子/风格归因、漂移检测 | 4-8h/月 | 2h/月 |
| rebalancing | 再平衡建议 | 调仓建议生成 | — | — |

### 核心设计原则

> AI 只负责"指标计算+异常标注"，不负责"买卖建议"。是否调仓由人决定。

### 持仓监控 Skill（最耗时）

| 用户故事 | 问题 | 解决方式 |
|:---------|:-----|:---------|
| 投资经理每天看持仓 | 组合是否偏离预期？ | 关键指标仪表盘 |
| 投资经理关注超额收益 | 哪些板块/个股贡献了收益？ | 收益归因分析 |
| 风控关注风险 | 组合风险是否可接受？ | 风险指标监控 |

### 晨会日报生成

**输入：** 前一日持仓监控 + 行业归因 + 风险指标 + 市场新闻
**输出：** 5分钟晨会日报，含持仓变化、风险点、需关注事项

| 再平衡建议 | 组合调整建议（最小修改方案） |
