## 第一章：祖训（最高优先级）

> 以下规则在所有场景下必须遵守，它们经过了全量数据验证，是体系的基石。

### 1.1 金银区域限定

**原文：** "应只做WXCD金银。祖训：绝不介入WJD之下。"

**设计逻辑：**
- WXCD决定大势方向。金=上升趋势，银=震荡上升，其余=不参与
- 数据验证：金银区域5周续持率76%，其余区域远低于此

**现状：**
- ✅ 月基策略已验证（金银 vs 屎尿唏）
- ✅ 周冲策略已实现（只有金/银有策分）
- ⚠️ 日冲策略尚未验证（日级别是否也应只做金银？）

### 1.2 WXAB甲乙己优先

**原文：** "应只做WXAB甲乙己。介入后按WJC止损。"

**设计逻辑：**
- WXAB护型决定持仓安全性。甲乙己=正交，丙丁戊=负交
- 月基策略中甲乙己5周续持率78.8%，比丙戊高21.4pp

**现状：**
- ✅ 月基策略已验证（甲乙己 > 丙戊 > 丁）
- ✅ 周冲策略已隐含（金系条件含甲乙己）
- ⚠️ DXAB引领WXAB变化尚未量化验证

### 1.3 先周后日

**原文：** 多个章节反复出现，如"要把日线当作周线辅助工具，不要把日线当作操作依据"

**设计逻辑：**
- 周级别决定方向和是否可以操作
- 日级别只负责择时和止盈
- 不存在脱离周级别的日级别独立操作

**现状：**
- ✅ 研究日周结合.md已文档化
- ✅ 筛选流程已实现（先周层再日层）

### 1.4 WJC止损

**原文：** "以WJC为保险带（破WJC就出来），不要单独下破DJB/DJA就出来"

**设计逻辑：**
- WJC是趋势的最终防线，下破WJC意味着趋势终结
- 低阶均线（DJB/DJA）的破位不代表趋势终结

**现状：**
- ✅ 月基策略已实现（WXZC<0退出）
- ⚠️ 消极区内的ZA下降/跌吞等信号是否可提前触发退出？未量化

## 第二章：大局观——WJC生命周期

> 核心是寻找WJC最大偏离位置。WJC之上才有操作价值，WJC之下无操作。

### 2.1 趋势判定三原则

**原则1：WJC是必要条件**
- WXZC>0是大涨必要条件
- WJC之下不存在操作价值

**原则2：WJB丘必赢**
- 优化至WJB丘为止
- 不破WJB不出

**原则3：WXCD定位月级别大势**
- WJCDE决定WJC丘幅度
- 月级别WJC丘和WJB丘的关系
- 高阶均线决定仓位限额，低阶均线决定进出时点

**待验证：**
- [ ] WJD/WJE对WJC丘幅度的定量影响
- [ ] WJB丘必赢 vs 周冲提前止盈的冲突点

### 2.2 操作区域划分

从大到小四级区域：

```
月级别（WJCDE）→ 周级别（WJCBA）
   → 日级别（DJCBA）→ 介入时点（DJA/DJB）
```

**各层级职责：**
| 层级 | 职责 | 核心指标 |
|:----|:-----|:---------|
| 月级别 | 定大势方向 | WXCD, WJCDE |
| 周级别 | 定操作范围 | WXZC>0, WXAB>0, WXZB>0 |
| 日级别 | 定择时 | DXZC>0, DXAB>0 |
| 介入点 | 定具体点位 | DJA/DJB位置 |

### 2.3 WJC丘结构

WJC丘的完整生命周期：

```
WJC丘开始 → WJB之上运行 → 偏离WJC
  → 回归WJC → 下破WJC（趋势终结）
```

核心主题：
1. **奏（渡主）**：WJC丘的结构与形状
2. **地型（调整结构）**：WJC丘内部的整理形态（栏/栅/余）
3. **柱型（主升特征）**：升排、跌排、人排
4. **反例**：最后一柱、升排失势

## 第三章：龙战法（周冲策略体系）

> 这是周冲策略VBA的原始设计文档。

### 3.1 龙战法核心

**周级别下柱冲高最靠谱**，按周为周期进行操作，映射到日级细化。

**适用条件：**
1. WXZB>0（周级别B线之上）
2. WXAB>0（正交）
3. 周柱排不是跌连

**底仓退出程序：**
- WJB止损
- 可在WJB之上提前止盈（四类警盈：偏宽叠久）
- WJC是最终退出线

### 3.2 下周冲高筛选漏斗（已实现于VBA）

```
第一层：剔除（指数/基金/ST/北交所）
第二层：剔除（涨停/持仓/今池）
第三层：筛选均线（DTZE<0剔除）
第四层：按波型分类（龙猪/龙管/头正/震正）
第五层：按柱型分类（升排/人排/跌排）
第六层：输出按策略优先级排序
```

**对应VBA实现：**
- 前3层 → 筛选.bas预处理
- 第4层 → 神谕.bas波型判定 → 概率表查分
- 第5层 → 柱排升/人/跌分类
- 第6层 → 11组（A+~G）策略输出

### 3.3 周冲战法 vs 月基策略的边界

| 对比项 | 周冲策略 | 月基策略 |
|:------|:---------|:---------|
| 时间尺度 | 下周冲高 | 5周续持 |
| 核心问题 | 下周P(≥3%)=? | 5周后P(WXZC>0)=? |
| 退出条件 | 趋势转弱信号 | WXZB≤0 |
| 选股范围 | 金银+甲乙己 | 金银+甲乙己 |
| 冲突点 | 周冲可能在中途提前退出 | 月基要求长期持有 |

**待验证：**
- [ ] 周冲条件满足时开仓，是否影响月基持仓？两者如何共存？

## 第四章：主升图谱（筛选与分类体系）

### 4.1 垒升的形成条件

抓涨的终极目标是寻找升排，特别是叠垒式柱排。

**垒升定位四步：**
1. WXAB层段
2. 周地型的典型模式
3. WXAB层段 & 周中符
4. 日类展开模式（日周联动 + 日漏）

### 4.2 周地型分类

| 地型 | 含义 | 操作 |
|:----|:-----|:------|
| 0无 | 无调整结构 | 反例：最后一柱 |
| 1栏 | 横向整理 | 可调整结构 |
| 2栅 | 三柱/四柱栅 | 可继续持有 |
| 3余 | 其他形态 | 视情况 |

**待验证：**
- [ ] 周地型对下周冲高概率的影响（全量数据验证）
- [ ] 地型=0无时的"最后一柱"特征总结

### 4.3 陷阱汇总

**周级别典型的诱多形态：**
- 久下破WJA后首上破 → 很可能是诱多
- 暂下破WJA后上破 + 已冲高/已整弧 → 很可能是诱多
- WJA之上阴阳阴 + 已冲高 → 很可能是诱多

**何时必须坚持：**
- 趋势形成初期，明知会出现低级别劫
- 尚未冲高或经历完整弧
- 单巨阳柱不等于见顶

**待验证：**
- [ ] 以上诱多形态的定量胜率统计
- [ ] "已冲高"的量化标准（DSHA阈值？）

## 第五章：日周联动（日级别辅助体系）

### 5.1 日类基本条件

```
DXZE > 0（DJE之上）
DXZC > 0（DJC之上）
DXAB > 0（正交）
DXZA > 0（DJA之上）
```

### 5.2 日柱择入机

**日护型：** 以DJA丘辅助的DJB丘
- 核心在DJB之上寻找上升机会
- 以DJC止损

**日柱排：** 预谋吃第几个阳柱
- 区分升连/调整/阴柱类型
- 给出启动图谱

**日顶型：** 触顶判定
- 首触顶：可能后续连续触顶
- 连阳触顶：需区分柱叠垒向上 vs 柱并排平移

### 5.3 日周联动聚焦日机的整体思路

```
（周1）WXZB>0 → 周操作范围
（周2）WXAB>0 → 周主升结构
（周3）周柱排 → 限制本柱排使下周冲高
（日1）DXZE>0 → 日基本条件
（日2）DXZC>0 → 日操盘线
（日3）DJB之上介入 → 日择时
```

**核心思想：** 因为无法根据上周末的日线推断出下周是否冲高，**一定要先按周柱判断下周冲高，再用日柱择机。**

**待验证：**
- [ ] 日周联动各层级的叠加效果（N条件叠加时P(≥3%)提升多少？）
- [ ] 日级别介入点位对周冲结果的影响

## 第六章：基础工具（底层概念群）

### 6.1 波型状态流转

**龙猪/龙管：** 趋势型庄家，最友善
**头正：** 头部形成，可能见顶
**震正：** 高位震荡，直接否决
**头负/震负：** 弱势，不参与

### 6.2 护型体系

**WXAB护型（周级）：**
- 甲/乙/己 = 正交 → 最优
- 丙/丁/戊 = 负交 → 次优/不参与

**DXAB护型（日级）：**
- 领先WXAB变化
- 甲/乙/己 = 优选
- 其他 = 可接受

### 6.3 柱型分类

| 柱型 | 周级别意义 | 日级别意义 |
|:----|:----------|:----------|
| 升连 | 主升最典型形态 | 趋势延续 |
| 升排（含跌孕） | 调整后继续上升 | 调整结构 |
| 人排 | 过渡形态 | 方向待定 |
| 跌排 | 趋势走弱 | 下跌趋势 |
| 跌吞 | 阴吞前阳，主力离场 | 顶部信号 |
| 尾反孕 | 末端十字星 | 末端信号 |

### 6.4 地型体系

| 地型 | 定义 | 操作价值 |
|:----|:-----|:---------|
| 栏 | 横向窄幅整理 | 可等待方向 |
| 栅 | 三柱/四柱整理形态 | 启动信号 |
| 枝 | 上破失败/下破失败 | 假突破预警 |
| 余 | 其他调整形态 | 视情况 |
