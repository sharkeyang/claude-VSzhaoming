> ## 核心信念：天底下没有新鲜事
>
> 股票市场每天涨涨跌跌，看似随机。但 **"天底下没有新鲜事"**——相同条件的结果会重复。
>
> 过去30年，A股市场走过了422万周。在这422万周中，每当某些条件同时出现时，下周的走势就呈现出可预测的规律。这不是玄学，不是预测，而是**统计规律**——当条件A出现时，历史上B发生的概率是X%。
>
> 我们做的，就是找出这些条件，给每个条件组合打一个概率分。

> ## 我们找到了什么
>
> | 成果 | 证据 | 意味着什么 |
> |:----|:------|:-----------|
> | **<金升非盈龙> 76%概率达标** | 76,078周，P(≥3%)=**76.0%** | 最强条件组合，约3/4概率下周冲高≥3% |
> | **<金升非盈> 75%概率达标** | 89,545周，P(≥3%)=**75.2%** | 次优组合，接近金升非盈龙 |
> | **<金升非> 57.8%** | 531,119周 | **金系基础条件** |
> | **<银盈> 73.8%** | 37,536周 | 银系最优，备用钥匙 |
> | **11种策略分组输出** | VBA已上线 | 每日筛选自动按策略优劣排序 |
>
> > **这不是万能钥匙，是大概率钥匙。** 历史概率是最佳指南，但不是承诺。每100次操作中，金升非盈龙以外的策略总有几次会"打不开"——这是正常的，不影响策略的长期有效性。

> ## 这个研究的价值
>
> 1. **不靠感觉，靠数据** — 422万周的统计，不是拍脑袋
> 2. **不预测涨跌，筛选冲高幅度** — 核心目标是"下周冲高≥3%"，不是"下周涨"
> 3. **可验证、可迭代** — 每项策略有验证报告，实盘偏差>5pp即修正
> 4. **可操作** — VBA每日自动筛选，A+→G共11组，优先级一目了然

## 第一章 总体思路

### 1.1 适用对象：小市值个股

**⚠️ 周冲策略适合个股，不适合ETF/指数。** 这是全量数据验证过的核心结论，所有周冲策略操作前必须优先确认标的是否适用。

全量7463只按类别拆分后，效果差异显著：

| 类别 | 全量均高幅 | 金+甲乙己均高幅 | 均高幅提升 | 全量P(≥3%) | 金+甲乙己P(≥3%) | 概率提升 | 周冲策略适用性 |
|:----|:--------:|:-------------:|:---------:|:----------:|:---------------:|:--------:|:-------------:|
| 🟤 基金ETF | 2.44% | 3.00% | +0.55pp | **29.0%** | 29.7% | **+0.7pp** | ❌ 不适合，建议月基策略 |
| 🟤 指数 | 2.32% | 2.83% | +0.51pp | **28.6%** | 28.7% | **+0.1pp** | ❌ 不适合，建议月基策略 |
| 🟡 沪深300 | 4.50% | 6.21% | +1.70pp | 50.5% | 54.6% | +4.1pp | ⚠️ 可参与 |
| 🟡 中证500 | 4.94% | 7.00% | +2.04pp | 53.8% | 58.6% | +4.8pp | ⚠️ 可参与 |
| 🟢 **中证1000** | 5.22% | 7.45% | **+2.23pp** | 55.6% | 59.6% | +4.0pp | ✅ **推荐** |
| 🟢 **中证2000** | 5.39% | 7.77% | **+2.38pp** | 55.6% | 59.6% | +4.0pp | ✅ **推荐** |
| 🟢 **非板块** | 5.38% | 7.84% | **+2.45pp** | 55.0% | 58.8% | +3.8pp | ✅ **推荐**（含北交所、次新股） |

**结论：** 周冲策略应聚焦个股（中证1000/2000/非板块），ETF/指数应留给月基策略。标的不适用时，直接跳过周冲策略，不必再查后续的条件判定。

### 1.2 设计哲学 + 梯度分析

**核心问题**
> 是否只使用最优条件进行下周冲高判定？次要条件是否有分数？

**答案**

**周冲评分方案：概率即分数。** 策分 = 下周冲高≥3%的概率（P(≥3%)），直接查概率表赋值。

例如 "<金升非>" 在中证500上 P(≥3%)=90.3%，策分就是 90.3 分。
详见 [§1.2 概率即分数](#12-概率即分数-评分设计) 和 [§4.2 全量条件概率表](#42-全量条件概率表)。

**哲学：** 策分本质是 **0~100 的连续概率值**，不是"通过/不通过"的二元判定。全量梯度分析证实：



| 概率区间 | 周数 | 均高幅 | 相对基准 | 操作建议 |
|:------|:----:|:-----:|:--------:|:--------|
| 🏆 85~100 | 254272 | **11.90%** | 2.5x | A级 核心买入 |
| 🟢 70~84 | 648007 | **6.32%** | 1.33x | B级 辅助买入 |
| 🟡 50~69 | 638106 | **5.70%** | 1.20x | C级 观察 |
| 🟠 30~49 | 1703450 | **3.80%** | 0.80x | D级 回避 |
| 🔴 0~29 | 983395 | **2.95%** | 0.62x | E级 剔除 |
| **基准** | **4229602** | **4.76%** | 1x | — |

**关键结论：梯度平滑，无阈值效应。** 70~84 仍有 6.32% 均高幅（高出基准 32%），次优条件有价值。策分的连续分布保证了自然排序——高分高概率，低分低概率，无需人为分档。

**次要条件的自然处理**
概率即分数的设计天然处理了次要条件：条件越严格 → P(≥3%) 越高 → 策分越高，无需额外加权求和逻辑。

例如：
- <金长> → 中证500上 69.5分
- +升排 → 81.4分（+11.9pp）
- +非孕 → 90.3分（+8.9pp）
- +盈高+龙猪 → 100分（+9.7pp）

分数 = 历史数据说话，不是拍脑袋定的权重。

### 1.3 概率即分数 — 评分设计

##### 1.3.1 核心概念

**策分 = 条件组合在下周冲高≥3%的历史概率。**

```
策分不再是"专家打分"，而是"历史数据说话"。

<金升非> 在中证500上 → 历史上H R≥3%的概率 = 90.3%
                                          ↓
                               策分 = 90.3分
```

**分数含义就是概率：** 策分 90 意味着"如果今日满足此条件，下周有 90% 的概率冲到 3% 以上"。每10次出现，就有9次达标。

##### 1.3.2 为什么选 P(≥3%)？

| 计分基准 | 基准值 | 最优条件值 | 区分度 | 缺陷 |
|:---------|:-----:|:---------:|:-----:|:------|
| **P(>0)** | 91.5% | 100% | 8.5pp | 区分度太小，大部分组合都接近100% |
| **P(≥3%)** ✅ | **50.6%** | **100%** | **49.4pp** | **区分度最大，核心操作阈值** |
| P(≥5%) | 32.8% | 100% | 67.2pp | 最优条件以下大部分组合低于50%，参考性差 |

**P(≥3%) 是最佳平衡点：**
- 基准值 50.6% 恰好在中间，留出上下各 50pp 的分布空间
- **补充：下周平均高幅（均高幅）= 4.76%**（全量基准），高于 3%。这说明 3% 是一个**保守的达标阈值**——低于整体平均水平，即使随机持有也有 50.6% 的概率达到。让筛选条件既能在"低于 3%"的方向上筛除劣质，又能在"高于 3%"的方向上筛选优质，上下都有空间。
- 3% 是实际交易中有意义的冲高幅度（覆盖手续费+利润空间）
- 低于基准 50.6% 的条件自动表明"不如随机持有" → 不参与

##### 1.3.3 分数意味着什么

| 策分 | 概率语言 | 操作语言 |
|:---:|:---------|:---------|
| 100 | 下周必冲到3%以上 | 最强信号，几乎无风险 |
| 90 | 10周中9周达标 | 极大概率，放心操作 |
| 80 | 10周中8周达标 | 高概率，正常操作 |
| 70 | 10周中7周达标 | 中高概率，可参与 |
| 60 | 10周中6周达标 | 中性，略优于基准 |
| 50 | 等于全量基准 | 无区分度，不操作 |
| <50 | 低于全量基准 | 不如不操作 |

#### 2.1.2 条件定义：四域完整度——周线趋势在哪个区域？

<table border="1" cellpadding="8" cellspacing="0" style="border-collapse:collapse;border:2px solid #888;margin:8px 0"><tr><td>

**1. 四域完整度——周线趋势在哪个区域？**

**VBA判定（实际代码，`IQQQ跨码_D据擎2神谕.bas` §2722）：**
```
' 四域周（基于ZC/CD/ZB三线）
谕组(X, 位谕of周层四域) = ""
If 周类BTZC > 0 Then               ' 满足门槛：周ZC > 0（WJC之上）
    If 周类BTZC > 0 And 周类BTCD > 0 And 周类BTZB > 0 Then
        四域 = "多长"               ' ZC>0 + CD>0 + ZB>0 → 三线全正
    Else
        四域 = "多被"               ' ZC>0但CD≤0或ZB≤0 → 有一线未正
    End If
Else
    If 周类BTZC <= 0 And 周类BTCD <= 0 And 周类BTZB <= 0 Then
        四域 = "空长"               ' 三线全负 → 空头趋势
    Else
        四域 = "空看"               ' 其他 → 选择方向
    End If
End If
```

**通俗解释：** 趋势好不好？多长=在高速公路上开车，又快又稳。多被=在国道上开，也能走但要小心。空看/空长=在水沟或悬崖边开，不应该参与。

**20分的意思：** 四域是周冲策略的基础条件——只有多长区才能参与。给20分是因为它是入场门槛，没有这个条件其他都免谈。

#### 2.1.3 ZA区间——趋势处于什么阶段？

<table border="1" cellpadding="8" cellspacing="0" style="border-collapse:collapse;border:2px solid #888;margin:8px 0"><tr><td>

**VBA定义：**
```
ZA周 = 谕组(X, 位谕of周类BTZA)  ' 周线站稳WJA（A线）的天数，取值范围：0~20+
```

**这个条件的意义：** ZA 告诉我们当前股票在趋势中处于什么位置——是刚启动、正在加速、还是接近尾声。这是区分下周冲高空间最核心的条件之一。

**为什么重要：**
- **ZA ≤0**：未站稳均线，不参与。
- **ZA 1~2**：刚站稳均线，还不稳定，下周冲高概率低于基准。
- **ZA 3~5**：初期加速，可以参与但需要关注后续变化。
- **ZA 5~10**：**最佳区间**。列车刚启动正在加速，下周冲高概率最高（HR≥3%达57.3%），均高幅+4.6%。这个窗口内庄家还在拉升初期，空间最大。
- **ZA >10**：已经涨了一段，可能接近尾声，冲高空间有限但仍有收益。

**如何使用：** 优先选择 ZA 5~10 的股票。当 ZA 进入此区间时，说明趋势已确认但未过热，是最佳入场窗口。配合其他条件（柱排、波型）可进一步提高胜率。

#### 2.1.4 柱排+盈提示——短期趋势稳定吗？

<table border="1" cellpadding="8" cellspacing="0" style="border-collapse:collapse;border:2px solid #888;margin:8px 0"><tr><td>

**VBA定义：**
```
柱排周 = 谕组(X, 位谕of周层柱排)  ' 升/跌/人（周K线排列方向）
盈提示 = 谕组(X, 位谕of周层盈提示)  ' 高/宽/丘/空（盈利信号等级）
```

**这个条件的意义：** 柱排告诉我们本周K线的方向（升/跌/人），盈提示告诉系统是否认为当前有盈利机会。两者结合可以判断短期趋势的稳定性和持续性，这是甄别下周能否继续冲高的关键。

**为什么重要：**
- **柱排升 + 非孕 + 盈有**：三者同时满足是最强组合。升排=短期向上，非孕=不是末端十字星（不是尾段），盈提示有=系统确认有盈利空间。此组合下周冲高概率最高。
- **柱排升（仅）**：短期向上但缺乏系统确认，胜率中等。
- **人排**：方向不明，观望。
- **柱排跌**：短期向下，回避。
- **盈提示有**：盈提示本身是正信号（均高幅+4.96% vs 无时+3.70%），不是见顶信号。盈提示在ETF上效果最显著（宽基63%下周冲高）。
- **尾反孕**：不是"最后一柱"。尾反孕(54%) vs 非尾反孕(52%) —— 差异不显著，不构成减分理由。

**如何使用：** 优先选择 柱排升 + 非孕 + 盈有 的股票。柱排升是基础门槛，盈提示有是加分项。当盈提示出现时，下周冲高概率显著提升，不应视为见顶信号而卖出。

</td></tr></table>



#### 2.1.5 波型——庄家是什么风格？

<table border="1" cellpadding="8" cellspacing="0" style="border-collapse:collapse;border:2px solid #888;margin:8px 0"><tr><td>

**VBA定义：**
```
波型周 = 谕组(X, 位谕of周层波型)  ' 龙猪/龙管/头正/头负/震正/震负
```

**这个条件的意义：** 波型反映庄家的操作风格，不同的庄家风格决定了下周冲高的概率和空间。这是甄别"庄家是否友善"的核心指标。

**为什么重要：**
**纯波型全量数据（不限金/银，全量回测）：**

| 波型 | 均高幅 | 下周冲高率 | HR≥3% | 推荐 |
|:----|:-----:|:---------:|:-----:|:----:|
| **龙猪/龙管** | **4.88%** | **94%↑** | **47%** | **✅ 推荐** |
| 头正 | 3.87% | 94% | — | 可用 |
| 震正 | 0.02% | 47% | — | ❌ 直接否决 |

- **龙猪/龙管**：趋势型庄家，走势稳健。均高幅+4.88%（高于全量基准4.76%），是唯一稳定跑赢大盘的波型。
- **头正**：头部形成，可能见顶，下周转为冲高概率仍高（94%）但空间有限（均高幅+3.87%）。
- **震正**：震荡型庄家洗盘，下周收益几乎为零（均高幅+0.02%），**直接否决**。

**波型叠加条件的效果：** 波型与其他条件叠加后会大幅提升区分度。例如波型+银条件下，龙猪的HR≥3%可达74.4%，详见 [§2.3.3 银+波型](#233-银波型)。

**如何使用：** 优先选择 龙猪/龙管 波型的股票。龙猪是趋势型庄家的标志，下周冲高概率最高且稳定。震正波型直接否决——无论其他条件多好，出现震正都不参与。

#### 2.1.6 震正波型——直接否决条件

<table border="1" cellpadding="8" cellspacing="0" style="border-collapse:collapse;border:2px solid #888;margin:8px 0"><tr><td>

**VBA定义：**
```

```

**这个条件的意义：** 震正波型是唯一一个**一票否决**条件——无论其他条件多好，只要出现震正，下周基本没有冲高动力。

**数据证实（纯波型全量回测）：**
- 震正波型下周均高幅仅 **+0.02%**，几乎等于随机
- 下周冲高率（P>0）仅 **47%**——超过一半的周次连正冲高都做不到
- 在所有波型中排名垫底，远低于基准水平

**操作规则：** 震正波型出现 → **直接否决**，不参与周冲策略。这是一个硬性过滤条件，不需要配合其他条件判断。

### 2.4 其他条件探索

#### 2.4.1 突破WJA/WJC后持续冲高验证 ✅ 已完成

**背景：** 有观点认为"少数突破WJA或突破WJC的股票每周都会冲高"。需验证此说法是否成立，以及条件能否归入现有策略体系。

**数据验证（500只×全历史周线抽样）：**

| 指标 | 突破WJA后 | 突破WJC后 | 全量基准 |
|:----|:---------:|:---------:|:--------:|
| 下周HR≥3% | 54.3% | 53.9% | 50.5% |
| 连续段内HR≥3%率 | 52.8% | 48.9% | — |
| 最佳单因子(盈有) | 62.4% | 62.5% | — |
| 最优组合(龙猪+升排) | 58.2% | 58.1% | — |

**结论：**

1. **"突破后每周稳定冲高"不成立。** 突破WJA后连续段内HR≥3%率平均仅52.8%，突破WJC后仅48.9%，接近全量基准50.8%。仅1.4%的段能达到90%以上——所谓"少数股票每周冲高"只是极少数特例，不具备统计意义。

2. **无需新建模型，直接归入现有策略。** 最佳条件已全部存在于现有策略体系中：
   - 突破WJA+盈有=62.4% → 归入 **<银盈>**（71.5%）
   - 突破WJA+龙猪+升排=58.2% → 归入 **<金升>**（57.9%）
   - 突破WJA+龙猪=58.0% → 归入 **<金长>+龙猪**

3. **突破WJA/WJC本身不是独立因子。** 它只是已有策略的叠加效果——当ZA>0且ZC>0时，股票已经处于金/银条件区域，现有策略天然覆盖了这些情况。

### 3.2 为什么要做系统性验证？

策分告诉了我们"这个条件下周冲高≥3%的概率是X%"，但一个数字背后藏着很多问题：这个概率稳不稳？样本够不够？最坏情况会亏多少？过去的规律现在还有效吗？

不回答这些问题，策分就只是一个"看起来很美"的数字。**系统性验证就是为了回答这五个问题：**

| 问题 | 举例 | 影响 |
|:----|:------|:------|
| **① 概率稳定吗？** | 76.0%是50周平均还是5周平均？近10周是否下滑到70%？ | 策分可能已过时 |
| **② 样本够吗？** | 76.0%基于多少周数据？100周 vs 10000周可信度差很远 | 小样本策分不可靠 |
| **③ 尾部风险？** | 即使76.0%达标，那24.0%失败的周里最大跌幅是多少？ | 单次亏损可能吃掉多次收益 |
| **④ 条件交互？** | 升排+非孕效果好，但再加波型=震正是否直接归零？ | 策略叠加可能产生负效应 |
| **⑤ 时间衰减？** | 这个条件3年前有效，现在是否仍然有效？ | 市场风格变化后旧规律失效 |

**核心矛盾：** 策分只能回答"历史上有多少比例冲高"，但无法回答"这个策略未来是否依然可靠"。系统性验证就是要回答后者。

### 3.3 如何验证？

采用 **5 维度验证框架**，每项策略逐一检验。这五个维度从可靠性、稳定性、风险性三个角度全面评估一个策略的真实价值：

| 维度 | 方法 | 判定标准 | 
|:----|:------|:---------|
| **① 稳定性** | 按年切片计算 P(≥3%)，观察年际波动幅度 | 最大偏差 ≤5pp = 稳定；≤10pp = 可接受；>10pp = 警告 |
| **② 置信度** | Wilson 95% 置信区间宽度 | 宽度 ≤10pp = 高置信度；≤15pp = 可接受；>15pp = 样本不足 |
| **③ 样本量** | 策略命中总周数 | ≥5000 周 = 可信；500~5000 = 需谨慎；<200 = 不可靠 |
| **④ 尾部风险** | 失败周中最差5%的HR分布 | 最差5% ≤ -5% = 高尾部风险 |
| **⑤ 时间衰减** | 近年(2023-2026)趋势是否与历史均值方向一致 | 逐年显著下降 = 策略可能失效 |
