# 日类必赢算法

> 基于DXZE>0+DXZC>0条件，从进入到退出持有期胜率93.1%的策略。
> 高波池（Qic+Qim+Qit）验证（2026-08-17）。

---

## 重要修正说明（2026-08-17）

**之前版本用HR（高幅，盘中最高涨幅）计算累计收益，导致收益虚高约4倍。** HR是当日盘中最高涨幅（最高价/前收盘-1），把每天的最高涨幅累加，不代表真实持有期收益。

**修正后用PR（涨幅，收盘涨幅）复利计算，结论如下：**

| 指标 | 之前（用HR高幅累加） | 修正后（用PR涨幅复利） |
|:----|:--------------:|:----------------:|
| 胜率（持有到条件不满足） | 99.5% | **93.1%** |
| 均收益（持有到条件不满足） | 30.29% | **9.20%** |
| 胜率（目标5%退出） | 94.5% | **94.5%**（不变） |
| 均收益（目标5%退出） | 4.66% | **4.66%**（不变） |

**目标5%退出策略的数据不受影响**——因为达标退出的交易必然达到5%涨幅，达标率/胜率/均收益都是用PR计算的，与HR无关。

**受影响的是"持有到条件不满足"策略**——之前用HR累加计算胜率99.5%、均收益30.29%，修正后用PR复利计算胜率93.1%、均收益9.20%。

> **注意：** 以上修正说明中的"次日开盘买入"验证方式，适用于被动等待收盘信号确认的情况。但本策略的核心是**精确进出**——在观察到即将突破时提前准备，在上穿瞬间精确买入，在即将跌破时提前卖出。因此策略本身不受"次日开盘"限制，关键在于防范**上破后立刻下破（假突破）** 的风险。

## 一、目标5%退出策略（推荐）

> **2026-08-17 高波池（Qic+Qim+Qit）验证，结论稳定可靠。**

**策略：初次满足DXZE>0+DXZC>0时介入，持有到条件不满足时退出（不设左侧退出）。**

| 指标 | 数值 |
|:----|:----:|
| 胜率 | **93.1%** |
| 亏损率 | 5.9% |
| 亏损<-5% | 0.2% |
| 平均收益 | 9.20% |
| 中位数收益 | 3.31% |
| 平均持有天数 | 13.3天 |
| 年化收益 | **~156%** |

**为什么选"持有到条件不满足"而非目标5%退出：**
- **胜率93.1% vs 75.7%**——高出近20pp
- **<-5%亏损仅0.2% vs 11.3%**——风险低50倍
- **年化收益相同（156%）**——收益不差
- 左侧退出（目标阈值）的未达标交易亏损大，拉低了整体表现

**年化估算：** 每13.3天赚9.20%，一年约19次交易，年化约156%（未计复利）。

**增强条件（介入时满足DXAB>0+合顶+升排）：**
- 均收益从9.20%提升到9.73%
- 胜率略降（93.1%→93.6%）

### 1.6 退出阈值测试（重点研究）

> 验证日期：2026-08-17，**高波池（Qic+Qim+Qit+Qin）**。
> 策略：初次满足ZE>0+ZC>0时介入，达到目标涨幅退出 vs 持有到条件不满足退出。

#### 1.6.1 各策略对比

| 策略 | 交易 | 胜率 | 亏损率 | <-5% | 均收益 | 中位数 | 均天数 | 年化收益 |
|:----|:----:|:----:|:-----:|:----:|:-----:|:-----:|:-----:|:-------:|
| **目标3%退出** | 81,929 | 76.6% | 23.4% | 10.3% | 2.80% | 3.83% | 4.5天 | **157%** |
| **目标5%退出** | 65,901 | 75.7% | 24.3% | 11.3% | 3.48% | **5.44%** | 5.6天 | 156% |
| 目标7%退出 | 56,470 | 76.3% | 23.7% | 11.7% | 4.07% | 7.09% | 6.5天 | 156% |
| 目标10%退出 | 47,452 | **77.9%** | 22.1% | 11.5% | **4.84%** | 3.54% | 7.8天 | 156% |
| **持有到条件不满足** | 27,626 | **93.1%** | **5.9%** | **0.2%** | **9.20%** | 3.31% | 13.3天 | 156% |

#### 1.6.2 关键发现

**年化收益全部在156~157%——几乎一样。** 因为年化收益 = 均收益 × 交易次数，均收益高的策略交易次数少，两者抵消。

**但风险差异巨大：**

**持有到条件不满足（不左侧退出）：**
- 胜率最高（93.1%），亏损率最低（5.9%）
- **<-5%的亏损仅0.2%**（远低于左侧退出的10%+）
- 持有期最长（13.3天），交易次数最少（19次/年）

**目标3%退出（最左侧）：**
- 交易次数最多（56次/年）
- 但<-5%亏损高达10.3%（50倍于不左侧退出）

#### 1.6.3 结论

**不左侧退出（持有到条件不满足）明显更优：**
1. **胜率93.1% vs 75~78%**——高出近20pp
2. **<-5%亏损仅0.2% vs 10%+**——风险低50倍
3. **年化收益相同（156%）**——收益不差
4. **中位数3.31%虽低，但胜率93.1%意味着几乎每笔都赚**

**左侧退出（目标阈值）的问题：** 虽然达标率高，但未达标的交易亏损大（<-5%占10%+），拉低了整体表现。年化收益并不比不左侧退出高。

**推荐：不设左侧退出，持有到条件不满足时退出。** 如果非要设目标，3%是最佳（交易次数最多，年化收益相同）。

## 二、必赢算法基础

### 2.1 核心发现

**DXZE>0+DXZC>0 从条件满足时进入，到条件不满足时退出，持有期胜率93.1%。** 高波池验证，591,283个持有周期中只有0.3%亏损。

**但基础条件持有期较长（平均12.6天，中位数6天）。** 通过叠加增强条件（升排/合顶/ZA>0），可以大幅缩短持有期，同时保持高胜率。

---

### 2.2 基础条件：DXZE>0+DXZC>0

> 验证日期：2026-08-17，高波池（Qic+Qim+Qit+Qin）。

**条件定义：**
- DXZE>0（站上DJE，EMA120）
- DXZC>0（站上DJC，EMA26）

**条件覆盖率：36.9%**（约1/3的交易日满足）

| 指标 | 数值 |
|:----|:----:|
| 总持有周期 | 27,626个 |
| **胜率（收益>0）** | **93.1%** |
| 亏损率（收益<=0） | 5.9% |
| 亏损<-5% | 0.2% |
| 平均收益 | 9.20% |
| 中位数收益 | 3.31% |
| 平均持有天数 | 13.3天 |
| 中位数持有天数 | 6.0天 |

**亏损周期（1,633个，占5.9%）：**
- 平均亏损：-0.83%
- 最大亏损：-38.26%
- 平均持有天数：3.6天

> 亏损主要发生在短期持有（1~2天），持有5天以上胜率接近100%。

### 2.3 增强条件对比

> 验证日期：2026-08-17，高波池（Qic+Qim+Qit+Qin）。

在基础条件上叠加增强条件，可以大幅缩短持有期：

| +ZA>0 | 25,684 | 82.2% | 7.65% | 2.85% | 13.8天 |
| +甲乙己 | 25,919 | 92.0% | **8.46%** | 3.30% | 13.9天 |

### 增强效果总结

**在"持有到条件不满足"策略下，增强条件反而降低胜率：**

| 增强条件 | 胜率变化 | 均收益变化 | 均天数变化 |
|:--------|:-------:|:---------:|:---------:|
| +ZA>0 | 94.1→82.2%（-11.9pp） | 8.31→7.65% | 13.3→13.8天 |
| +甲乙己 | 94.1→92.0%（-2.1pp） | 8.31→8.46%（+0.15pp） | 13.3→13.9天 |
| +升排 | 94.1→89.4%（-4.7pp） | 8.31→8.04% | 13.3→14.0天 |
| +合顶 | 94.1→83.4%（-10.7pp） | 8.31→8.77%（+0.46pp） | 13.3→15.6天 |
| 全条件 | 94.1→72.7%（-21.4pp） | 8.31→8.26% | 13.3→17.3天 |

**结论：在"持有到条件不满足"策略下，增强条件会降低胜率、延长持有期。** 因为增强条件筛选出的交易波动更大，持有期更长，中途转负的概率更高。**基础条件（ZE>0+ZC>0）本身已足够好，不需要增强。**

### 2.6 日层段细分（持主/持被/卖浮）

> 合并自 `MC3.3.5_日级别触顶.md` §十三（2026-08-22 整合）。
> 验证日期：2026-08-22，**高波池（Qic+Qim+Qit+Qin）全量**，14,409,735 样本。
> 指标定义：下日P0/P1/P2/P3/P5 = 下日高幅（次日高幅）>= 0/1/2/3/5% 的概率；期望HR = 下日高幅均值。

#### 2.6.1 日层段VBA定义

```vba
日层段 = "NA"
If 日类BTZE > 0 Then          ' DXZE>0（站上DJE）
    If 日类BTZC <= 0 Then      ' DXZC<=0（跌破DJC）
        日层段 = "卖浮"
    ElseIf 日类BTZA > 0 Then   ' DXZA>0（站上DJA）
        日层段 = "持主"
    Else                       ' DXZA<=0
        日层段 = "持被"
    End If
End If
```

**日层段 = DXZE>0 为前提，再按DXZC/DXZA细分：**
- **持主** = DXZE>0 + DXZC>0 + DXZA>0（三线全上）
- **持被** = DXZE>0 + DXZC>0 + DXZA<=0（ZE/ZC上，ZA下）
- **卖浮** = DXZE>0 + DXZC<=0（ZE上，ZC下）

#### 2.6.2 日层段 vs 三线条件 一致性

**理论条件与日段样本完全一致：**

| 理论条件 | 日段 | 样本 |
|:--------|:----:|:----:|
| ZE>0+ZC>0+ZA>0 | 持主 | 3,829,195 |
| ZE>0+ZC>0+ZA<=0 | 持被 | 1,336,676 |
| ZE>0+ZC<=0 | 卖浮 | 1,539,429 |

#### 2.6.3 持主是否必赢？

**不是必赢，但显著优于基线。**

| 指标 | 持主 | 基线 |
|:----|:----:|:----:|
| 下日P0(>=0%) | 90.3% | 91.3% |
| 下日P1(>=1%) | 63.8% | 60.4% |
| 下日P2(>=2%) | 43.5% | 37.2% |
| 下日P3(>=3%) | 30.4% | 23.5% |
| 下日P5(>=5%) | 15.9% | 10.5% |
| **期望HR** | **2.52%** | **2.07%** |

**持主不是必赢**——下日P0=90.3%（仍有9.7%概率下日不冲高），P3=30.4%（约3成概率冲高3%+）。但期望HR=2.52%显著高于基线2.07%。

#### 2.6.4 持主+强触顶 是否必赢？

**接近必赢，但仍不是100%。**

| 指标 | 持主+BSHA>=5+触顶 |
|:----|:-----------------:|
| 下日P0(>=0%) | 87.3% |
| 下日P1(>=1%) | **71.4%** |
| 下日P2(>=2%) | **55.4%** |
| 下日P3(>=3%) | **43.2%** |
| 下日P5(>=5%) | 27.0% |
| **期望HR** | **3.44%** |

**持主+强触顶的期望HR=3.44%，是基线的1.66倍。** 下日P1=71.4%（7成概率下日冲高1%+），P3=43.2%（4成概率冲高3%+）。虽然不是"必赢"（仍有12.7%概率下日不冲高），但已是极强的信号。

#### 2.6.5 持主 vs 卖浮

| 指标 | 持主 | 卖浮 |
|:----|:----:|:----:|
| P0 | 90.3% | 91.4% |
| P3 | 30.4% | 23.2% |
| 期望HR | 2.52% | 2.01% |

**持主和卖浮的P0几乎相同（90.3% vs 91.4%），但P3和期望HR差异明显。** 卖浮阶段下日不亏的概率也高，但冲高幅度小——卖浮是"不涨不跌"的横盘，持主是"有冲高机会"的上升。

#### 2.6.6 结论

1. **日层段 = DXZE>0+DXZC>0 确认**（持主还要求DXZA>0）
2. **持主不是必赢**，但期望HR=2.52%显著优于基线2.07%
3. **持主+强触顶（BSHA>=5+触顶）接近必赢**：期望HR=3.44%，P1=71.4%，P3=43.2%
4. **"必赢"不成立**——任何条件下下日都有约10%概率不冲高，但持主+强触顶是期望收益最高的组合

## 三、进出点选择与操作指南

### 3.1 入场信号对比

**在ZE>0+ZC>0条件下，各入场信号的持有期表现：**

| 入场信号 | 周期 | 胜率 | 均收益 | 中位数 | 均天数 |
|:--------|:----:|:----:|:-----:|:-----:|:-----:|
| 无条件(仅ZE+ZC) | 27,626 | **93.1%** | 9.20% | 3.31% | 13.3天 |
| **升排** | 25,300 | 89.4% | 8.04% | 2.90% | 14.0天 |
| **合顶** | 20,855 | 83.4% | 8.77% | 3.29% | 15.6天 |
| **甲乙己** | 25,919 | 92.0% | **8.46%** | 3.30% | 13.9天 |
| 升排+合顶 | 18,895 | 81.2% | 8.56% | 2.87% | 16.2天 |

### 3.2 出场策略

**出场原则：持有到条件不满足时退出（ZE<=0 或 ZC<=0）。**

不建议提前出场，因为：
- 合顶结束（离顶）不代表趋势结束——离顶后未来20天仍有40%收益
- 升排结束（转跌排）可能是短期回调
- 增强条件在"持有到条件不满足"策略下反而降低胜率

### 3.3 三层过滤体系

**优化方向：** 在入场时增加BSHA>=3%或宽哼JC>=5%的条件，可以大幅提升达标率（从53%提升到65~76%）。

### 4.10 通俗解释：达标率低的交易是什么样

**用最通俗的话说，达标率低（没吃到5%）的交易，主要是三种情况：**

**① 入场时"冲不动"（BSHA低）**
- 买进去那天，股票当天就没怎么涨（冲高幅度小）
- 当天冲高<3%的，60~74%都吃不到5%；当天冲高≥5%的，只有15~24%吃不到
- 就像一个人跑步，起跑就慢吞吞的，后面也很难突然加速

**② 入场时"刚站上均线"（宽哼JC小）**
- 买进去那天，股价才刚站上关键均线，趋势还没走稳
- 刚站上均线（距离<5%）的，60%吃不到5%；已经远离均线（距离>20%）的，只有16%吃不到
- 就像刚爬上台阶还没站稳，容易又滑下来

**③ 入场时"没创新高"（非合顶）**
- 买进去那天，股价没有创出新高，说明上涨动力不足
- 没创新高的，54%吃不到5%；创新高的，只有40%吃不到
- 就像爬山爬到一半没到顶，容易回落

**一句话总结：达标率低的交易，就是"入场时股票本身没劲"——当天冲不高、刚站上均线、没创新高。** 这些股票往往在达到5%之前就因为趋势转弱（ZC转负）被提前踢出来了。

**反过来，要吃到5%，最好等"当天冲高≥5% + 已远离均线 + 创新高"再入场**——这样的股票达标率能到76~85%。
