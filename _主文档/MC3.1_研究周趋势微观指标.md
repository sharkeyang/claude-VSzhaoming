## 一、周级别分析框架

在一个确定的级别（如日级别、周级别），指标分三层：

**日级别：**
- **宏观（均线）**：DXAB、DXCD 等均线 → 决定趋势方向
- **微观（低级别聚焦指标）**：日等型、日柱型、日柱排、日顶型 → 细节聚焦

**周级别：**
- **宏观（大势）**：WXCD → 决定大势方向
- **中观**：WXAB → 决定中观趋势
- **微观（管下沿）**：周地型、周柱型、周柱排
- **微观（管上沿）**：周顶型

> 周等型属于**微观指标（管下沿）**，与周柱型/周柱排同级。

### 1.1 框架数据验证（2026-08-14，全量7461只周CSV/425万行）

**各层级区分度（下周P3最佳vs最差）：**

| 层级 | 最佳 | 最差 | 区分度 |
|------|------|------|--------|
| 🥇 **微观柱排** | 升.尾反孕 55.7% | 跌.尾吞 44.8% | **10.9pp** |
| 🥈 **中观WXAB** | 甲 56.2% | 丙 46.6% | **9.6pp** |
| 🥉 **宏观WXCD** | 银升 55.2% | 屎降 45.7% | **9.5pp** |
| ④ **微观波型** | Aa龙猪 52.8% | Fa震正〇 46.3% | 6.5pp |

**结论：框架合理，微观指标比预期更有价值。**（基线50.6%，全量7461只/425万行）

- **WXCD（宏观）** 区分度9.5pp——若按"站上WJC vs 之下"衡量，区分度可达18pp，确为"大势"级别
- **WXAB（中观）** 区分度9.6pp——略高于WXCD，验证"WXAB是核心引擎"
- **微观指标（柱排/波型）** 区分度6.5~10.9pp——柱排与宏观中观相当，波型略弱但仍有独立价值，不应忽视

**框架的合理性更多在于操作逻辑层次，而非纯预测力：**
- WXCD → 决定"能做什么市场"（大势方向）
- WXAB → 决定"能做什么股票"（护型质量）
- 微观 → 决定"什么时候入场"（具体时机）

三者是操作流程的递进关系，不是替代关系。数据支持这个框架。

## 二、周等型定义（仿照日等型，6等简化版）

> **2026-08-12 更新：** 等2+等4合并为等2（ZA≥2+CDEF），等6+等8合并为等6（ZA≤-2+ABCD）。DTZA阈值细分（2~3 vs >3）经全量数据验证无必要，日/周定义统一。

```
周ZA=1                     → 等1（WJA边缘刚站上）
周ZA≥2 + 周末位CDEF        → 等2（近/回归WJA，原等2+等4合并）
周ZA≥2 + 周末位AB          → 等3（远离WJA强势主升）
周ZA=-1                    → 等5（WJA边缘下方）
周ZA≤-2 + 周末位ABCD       → 等6（近/回归WJA下方，原等6+等8合并）
周ZA≤-2 + 周末位EF         → 等7（远离WJA弱势）
```

变量：周ZA（周BTZA）+ 周中符串末位，与日级别完全一致。

**6等全量验证（4130只周CSV，下周P≥3%）：**

**排序完全单调：** 等3(56.22%) > 等2(54.37%) > 等1(52.52%) > 等7(46.73%) > 等6(45.79%) > 等5(44.84%)

## 六、周柱型/周柱排（最后一柱特征）

> 以下内容合并自 `MC3.1_研究月基策略最后一柱.md`，待结论确认后并入主文档

### 6.1 核心定义

**最后一柱**：虽然符合WJA之上升排，但已代表主升结束。

- **延续性**：只要不是最后一柱，且处于主升区域，都可备选进行下柱冲高
- **中止性**：主升遇到最后一柱，代表前一波主升趋势的停止，其后转入震荡或开启下一波主升
- **注意**：不一定是最高点，而是**主升浪的结束**

---

### 6.2 三大类形态

#### 一、逐步放大模式

| 特征 | 说明 | 操作 |
|:-----|:-----|:-----|
| 连阳之后 + 巨阳柱 | 可止盈并不再持仓 | 巨阳(>20) / 巨阳后走平(小阳/十字/小阴) |
| (连阳3+)(孕阴)(大阳) | 连阳后的阴柱，最后冲高，预示最后冲高后结束主升 | 止盈 |
| 连阳之后 + 逐步放大 | 上冲过猛，可能转为锐角下跌 | 止盈 |
| 连阳之后 / 上影线小柱 | 可止盈并不再持仓，代表趋势衰竭 | 止盈 |
| 连阳之后 + 高开悬阴柱 | 可获利并不再持仓 | 获利止盈 |
| (中阳)(十字星)(中阳) | 其后可能形成阴柱 | 观察 |

#### 二、逐步缩小模式

| 特征 | 说明 | 操作 |
|:-----|:-----|:-----|
| 连阳之后 + 小阳柱/十字星/小阴柱 | 连阳柱体逐步缩小，代表升势衰竭 | 止盈 |
| 连阳之后 + 长下影线小柱 | 很可能属于趋势尾部 | 止盈 |
| (中阳+十字星+中阳) + 长下影小柱 | 下探后恢复，但主力很可能已逃跑 | 观望 |
| 连阳之后 + 先上影再下影 | 代表升势衰竭 | 止盈 |

#### 三、由阳转阴模式

| 特征 | 说明 | 操作 |
|:-----|:-----|:-----|
| 由连阳逐步转为阴阳相间 | 当单阳或连阳夹在两个阴柱之间，可能已见顶 | 止盈 |
| 连阳后 + 跌孕 + 升吞 + 单阴（/跌孕/跌吞） | 见顶转跌 | 清仓 |
| 连阳后 + 跌孕 + 连阳 + 单阴（/跌孕/跌吞） | 见顶转跌 | 清仓 |
| 跌吞：连阳之后 + 单巨阴柱下破WJA | 趋势完全逆转 | 清仓 |
| 久丘后四柱栅：连阳之后出现跌连 | 升势终结 | 清仓 |

## 七、周日联动（周←→日映射）

> 合并自 `MC3.3.4_研究日冲策略探索形态.md` §四、`昭明计划大局观体系.md` §九
> 周日联动连接周级别（月基策略）和日级别（日冲策略），提供双向映射框架。

### 7.1 核心原则：先周后日

| 层级 | 职责 | 决策依据 |
|:----|:-----|:---------|
| 🔴 **周级别** | 定方向、定可否操作 | `WXZC>0` + `WXAB>0` |
| 🟢 **日级别** | 定时机、定点位 | `DXZC>0` + `DXAB>0`（在周级别框架内） |

**不存在脱离周级别的日级别独立操作。**

> 核心思想："因为无法根据上周末的日线推断出下周是否冲高，所以，一定要先按周柱判断下周冲高，再用日柱择机。"

### 7.2 周←→日映射关系

| 周级别 | 映射到日级别 | 含义 |
|:------|:-----------|:------|
| **WXCD**（周CD方向） | → **DXEF**（日EF战场） | 均线排列方向，金/银/唏=好，嘘/尿/屎=差 |
| **WXZC**（周ZC位置） | → **DXZE**（日ZE位置） | 是否在DJE之上，>0=无限区，≤0=有限区 |
| **WXAB**（周AB护型） | → **DXCD**（日CD护段） | 护型质量，上/中/忐=好，下/忠/忑=差 |

### 7.3 漏斗筛选（顺应最小阻力原理）

**筛选1：周类范围（WXBC）**
- 升态（根口）WXZC>0且WXZB>0 → 优选
- 中间态-破 WXZC>0且WXZB<0 → 方向选择
- 中间态-潜 WXZC<0且WXZB>0 → 方向选择
- 跌态（*）WXZC<0且WXZB<0 → 舍弃

**筛选2：WXAB丘**
- WXAB护型是下周冲高最重要决定因素。护型位置：上/中/下/忐/忠/忑，优选已正交
- WJA丘周期：突首/价鼎/价薡/突末，优选WTZA>=2

**筛选3：日类联动**
- 满足DXZE>0且DXZC>0。从DJC做丘，可在DJC之上提前退出，可在DJC下进入
- 不要被低级均线束缚，在WJA之上可提前退出，跌破WJA后可介入

**周日联动分类：** `@`适合下周冲高 / `_`符合范围但不适合 / `N`不在范围

### 7.4 日级别介入决策清单

**应介入：**
- 周级别 `WXZC>0` 且 `WXAB>0`（周级上升中）
- DJCBA多头排列，在DJA之上
- 窄管中蓄力、突破回踩、悬阳升连等日机信号出现

**不应介入：**
- 周级别 `WXZC≤0` 或 `WXAB<0`
- DJCBA空头排列，在DJC之下
- 周级别处于屎尿状态

**不确定（需结合上下文）：**
- 周级别上升但日级别出现阴柱
- 日级别信号出现但周级别处于过渡区（唏/嘘）
- DXAB转差但DXCD仍为正

### 7.5 VBA参考因素

1. WXAB→DXCD。要求DXZD>0，优选DXCD>0，选择DXBC>0
2. 周触顶与日触顶的协同效应
3. WJC以上大部分在DJB之上，先站上DJB再介入
