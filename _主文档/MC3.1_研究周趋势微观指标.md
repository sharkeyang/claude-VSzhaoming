## 一、周级别分析框架

在一个确定的级别（如日级别、周级别），指标分三层：

**日级别：**
- **宏观（均线）**：DXAB、DXCD 等均线 → 决定趋势方向
- **微观（低级别聚焦指标）**：日层等、日柱型、日柱排、日顶型 → 细节聚焦

**周级别：**
- **宏观（大势）**：WXCD → 决定大势方向
- **中观**：WXAB → 决定中观趋势
- **微观（管下沿）**：周地型、周柱型、周柱排
- **微观（管上沿）**：周顶型

> 周等高线（周等型）属于**微观指标（管下沿）**，与周柱型/周柱排同级。

## 二、周等型定义（仿照日级别等高线）

```
周ZA=1                     → 等1（WJA边缘刚站上）
周ZA=2~3 + 周末位CDEF      → 等2（近WJA软弱）
周ZA≥2 + 周末位AB          → 等3（远离WJA强势主升）
周ZA>3 + 周末位CDEF        → 等4（回归WJA）
周ZA=-1                    → 等5（WJA边缘下方）
周ZA=-3~-2 + 周末位ABCD    → 等6（近WJA下方偏强）
周ZA≤-2 + 周末位EF         → 等7（远离WJA弱势）
周ZA<-3 + 周末位ABCD       → 等8（回归WJA）
```

变量：周ZA（周BTZA）+ 周中符串末位 + 阈值3，与日级别完全一致。

**核心发现：周级别末位AB vs CDEF 几乎无区分力，与日级别完全不同。**

**不同阈值下 AB vs CDEF 的区分度：**

## 六、周柱型/周柱排（最后一柱特征）

> 以下内容合并自 `MC3.1_研究月基策略最后一柱.md`，待结论确认后并入主文档

### 核心定义

**最后一柱**：虽然符合WJA之上升排，但已代表主升结束。

- **延续性**：只要不是最后一柱，且处于主升区域，都可备选进行下柱冲高
- **中止性**：主升遇到最后一柱，代表前一波主升趋势的停止，其后转入震荡或开启下一波主升
- **注意**：不一定是最高点，而是**主升浪的结束**

---

### 三大类形态

#### 一、逐步放大模式

| 特征 | 说明 | 操作 |
|:-----|:-----|:-----|
| 连阳之后 + 巨阳柱 | 可止盈并不再持仓 | 巨阳(>20) / 巨阳后走平(小阳/十字/小阴) |
| (连阳3+)(孕阴)(大阳) | 连阳后的阴柱，最后冲高，预示最后冲高后结束主升 | 止盈 |
| 连阳之后 + 逐步放大 | 上冲过猛，可能转为锐角下跌 | 止盈 |
| 连阳之后 / 上影线小柱 | 可止盈并不再持仓，代表趋势衰竭 | 止盈 |
| 连阳之后 + 高开悬阴柱 | 可获利并不再持仓 | 获利止盈 |
| (中阳)(十字星)(中阳) | 其后可能形成阴柱 | 观察 |

#### 二、逐步缩小模式

| 特征 | 说明 | 操作 |
|:-----|:-----|:-----|
| 连阳之后 + 小阳柱/十字星/小阴柱 | 连阳柱体逐步缩小，代表升势衰竭 | 止盈 |
| 连阳之后 + 长下影线小柱 | 很可能属于趋势尾部 | 止盈 |
| (中阳+十字星+中阳) + 长下影小柱 | 下探后恢复，但主力很可能已逃跑 | 观望 |
| 连阳之后 + 先上影再下影 | 代表升势衰竭 | 止盈 |

#### 三、由阳转阴模式

| 特征 | 说明 | 操作 |
|:-----|:-----|:-----|
| 由连阳逐步转为阴阳相间 | 当单阳或连阳夹在两个阴柱之间，可能已见顶 | 止盈 |
| 连阳后 + 跌孕 + 升吞 + 单阴（/跌孕/跌吞） | 见顶转跌 | 清仓 |
| 连阳后 + 跌孕 + 连阳 + 单阴（/跌孕/跌吞） | 见顶转跌 | 清仓 |
| 跌吞：连阳之后 + 单巨阴柱下破WJA | 趋势完全逆转 | 清仓 |
| 久丘后四柱栅：连阳之后出现跌连 | 升势终结 | 清仓 |

---

### 栏栅调整后的失败情况

| 模式 | 后续 |
|:-----|:-----|
| 跌孕 + 升吞/升孕 + 跌吞/跌孕 | (阴+阳+阴)后可能转为下跌 |
| 跌吞 + 升吞/升孕 + 跌孕 | (阴+阳+阴)随后可能转向下跌 |
| (跌吞+升孕) | 可能转为下跌趋势 |

### 跌连规律

| 情况 | 概率 | 操作 |
|:-----|:----:|:-----|
| 随后立刻进入连阳 | 极少 | 例外 |
| 由主升转为震荡或下跌 | **多数** | 等待出现(升连)或(启动结构)再介入 |

### 升排失势的特征

| 特征 | 说明 | 5周内ZC<0 |
|:-----|:-----|:---------:|
| 升排+ZA下降 | 升排中ZA开始下降，趋势减弱 | **79.2%** |
| 升排+震荡 | 阴阳交替、振幅缩小，趋势犹豫 | 58.5% |
| 升排+长上影 | 冲高回落，上攻受阻 | 54.8% |

| 升排+大阳后大阴 | 大阳后大阴回到WJA，继续连阳接近前高 | 41.8% |

### 数据验证结论（全量7463只，有效5930只≥200周）

| 特征 | 样本 | 1周内ZC<0 | 3周内ZC<0 | 5周内ZC<0 | 预警强度 |
|:----|:----:|:---------:|:---------:|:---------:|:--------:|
| 🚨 **跌吞(阴吞前阳)** | 454,789 | **61.7%** | **70.5%** | **75.4%** | **最强** |
| ⚠️ 上影线小柱 | 1,110,786 | 47.2% | 56.2% | 62.8% | 强 |
| ⚠️ 连阳3+转阴 | 256,743 | 31.9% | 42.1% | 49.4% | 中 |
| ⚠️ 连阳3+十字星 | 58,975 | 27.2% | 36.7% | 43.6% | 中 |
| ▫️ 连阳逐步缩小 | 87,743 | 20.9% | 29.0% | 36.4% | 弱 |
| ▫️ 连阳3+巨阳>10% | 36,848 | 6.0% | 10.2% | 16.5% | 安全 |
| ✅ 连阳3+巨阳>20% | 9,264 | **2.3%** | **4.9%** | **9.5%** | **最安全** |

**核心发现：**
1. **跌吞是ZC<0的最强预测信号（75.4% 5周内）**
2. **上影线小柱被严重低估（62.8%）**
3. **巨阳柱不代表见顶**——连阳3+巨阳>20%后，5周内ZC<0率仅9.5%
4. **连阳逐步缩小转负率仅36.4%**——缩小不代表立即转跌

## 七、周日联动（周←→日映射）

> 合并自 `MC3.3.4_研究日冲策略探索形态.md` §四、`昭明计划大局观体系.md` §九
> 周日联动连接周级别（月基策略）和日级别（日冲策略），提供双向映射框架。

### 7.1 核心原则：先周后日

| 层级 | 职责 | 决策依据 |
|:----|:-----|:---------|
| 🔴 **周级别** | 定方向、定可否操作 | `WXZC>0` + `WXAB>0` |
| 🟢 **日级别** | 定时机、定点位 | `DXZC>0` + `DXAB>0`（在周级别框架内） |

**不存在脱离周级别的日级别独立操作。**

> 核心思想："因为无法根据上周末的日线推断出下周是否冲高，所以，一定要先按周柱判断下周冲高，再用日柱择机。"

### 7.2 周←→日映射关系

| 周级别 | 映射到日级别 | 含义 |
|:------|:-----------|:------|
| **WXCD**（周CD方向） | → **DXEF**（日EF战场） | 均线排列方向，金/银/唏=好，嘘/尿/屎=差 |
| **WXZC**（周ZC位置） | → **DXZE**（日ZE位置） | 是否在DJE之上，>0=无限区，≤0=有限区 |
| **WXAB**（周AB护型） | → **DXCD**（日CD护段） | 护型质量，上/中/忐=好，下/忠/忑=差 |

### 7.3 漏斗筛选（顺应最小阻力原理）

**筛选1：周类范围（WXBC）**
- 升态（根口）WXZC>0且WXZB>0 → 优选
- 中间态-破 WXZC>0且WXZB<0 → 方向选择
- 中间态-潜 WXZC<0且WXZB>0 → 方向选择
- 跌态（*）WXZC<0且WXZB<0 → 舍弃

**筛选2：WXAB丘**
- WXAB护型是下周冲高最重要决定因素。护型位置：上/中/下/忐/忠/忑，优选已正交
- WJA丘周期：突首/价鼎/价薡/突末，优选WTZA>=2

**筛选3：日类联动**
- 满足DXZE>0且DXZC>0。从DJC做丘，可在DJC之上提前退出，可在DJC下进入
- 不要被低级均线束缚，在WJA之上可提前退出，跌破WJA后可介入

**周日联动分类：** `@`适合下周冲高 / `_`符合范围但不适合 / `N`不在范围

### 7.4 日级别介入决策清单

**应介入：**
- 周级别 `WXZC>0` 且 `WXAB>0`（周级上升中）
- DJCBA多头排列，在DJA之上
- 窄管中蓄力、突破回踩、悬阳升连等日机信号出现

**不应介入：**
- 周级别 `WXZC≤0` 或 `WXAB<0`
- DJCBA空头排列，在DJC之下
- 周级别处于屎尿状态

**不确定（需结合上下文）：**
- 周级别上升但日级别出现阴柱
- 日级别信号出现但周级别处于过渡区（唏/嘘）
- DXAB转差但DXCD仍为正

### 7.5 VBA参考因素

1. WXAB→DXCD。要求DXZD>0，优选DXCD>0，选择DXBC>0
2. 周触顶与日触顶的协同效应
3. WJC以上大部分在DJB之上，先站上DJB再介入
