# 研究周趋势微观指标（合并草稿→待结论确认后并入主文档）

> 周级别微观指标集合：**周波型、周柱型、周等型、周柱排**
> 框架：宏观(WXCD)→中观(WXAB)→微观(周波型/周柱型/周等型/周柱排/周顶型)
> ⚠️ **草稿文件**，各子项结论待全量验证后分别合并入对应主文档。

## 一、周级别分析框架

在一个确定的级别（如日级别、周级别），指标分三层：

**日级别：**
- **宏观（均线）**：DXAB、DXCD 等均线 → 决定趋势方向
- **微观（低级别聚焦指标）**：日层等、日柱型、日柱排、日顶型 → 细节聚焦

**周级别：**
- **宏观（大势）**：WXCD → 决定大势方向
- **中观**：WXAB → 决定中观趋势
- **微观（管下沿）**：周地型、周柱型、周柱排
- **微观（管上沿）**：周顶型

> 周等高线（周等型）属于**微观指标（管下沿）**，与周柱型/周柱排同级。

## 二、周等型定义（仿照日级别等高线）

```
周ZA=1                     → 等1（WJA边缘刚站上）
周ZA=2~3 + 周末位CDEF      → 等2（近WJA软弱）
周ZA≥2 + 周末位AB          → 等3（远离WJA强势主升）
周ZA>3 + 周末位CDEF        → 等4（回归WJA）
周ZA=-1                    → 等5（WJA边缘下方）
周ZA=-3~-2 + 周末位ABCD    → 等6（近WJA下方偏强）
周ZA≤-2 + 周末位EF         → 等7（远离WJA弱势）
周ZA<-3 + 周末位ABCD       → 等8（回归WJA）
```

变量：周ZA（周BTZA）+ 周中符串末位 + 阈值3，与日级别完全一致。

## 五、阈值优化分析

**核心发现：周级别末位AB vs CDEF 几乎无区分力，与日级别完全不同。**

**不同阈值下 AB vs CDEF 的区分度：**

| 阈值t | AB末位P3 | CDEF末位P3 | 差pp | 说明 |

| ZA≥1 | 46.7% | 46.9% | -0.2pp | ❌ 无区分 |
| ZA≥2 | 47.1% | 45.5% | +1.6pp | 弱 |

**最佳阈值 t=5，区分度仅2.8pp**，远低于日级别的5pp+。

## 第二节：周柱型/周柱排（最后一柱特征）

> 以下内容合并自 `MC3.1_研究月基策略最后一柱.md`，待结论确认后并入主文档

### 核心定义

**最后一柱**：虽然符合WJA之上升排，但已代表主升结束。

- **延续性**：只要不是最后一柱，且处于主升区域，都可备选进行下柱冲高
- **中止性**：主升遇到最后一柱，代表前一波主升趋势的停止，其后转入震荡或开启下一波主升
- **注意**：不一定是最高点，而是**主升浪的结束**

---

### 三大类形态

#### 一、逐步放大模式

| 特征 | 说明 | 操作 |
|:-----|:-----|:-----|
| 连阳之后 + 巨阳柱 | 可止盈并不再持仓 | 巨阳(>20) / 巨阳后走平(小阳/十字/小阴) |
| (连阳3+)(孕阴)(大阳) | 连阳后的阴柱，最后冲高，预示最后冲高后结束主升 | 止盈 |
| 连阳之后 + 逐步放大 | 上冲过猛，可能转为锐角下跌 | 止盈 |
| 连阳之后 / 上影线小柱 | 可止盈并不再持仓，代表趋势衰竭 | 止盈 |
| 连阳之后 + 高开悬阴柱 | 可获利并不再持仓 | 获利止盈 |
| (中阳)(十字星)(中阳) | 其后可能形成阴柱 | 观察 |

#### 二、逐步缩小模式

| 特征 | 说明 | 操作 |
|:-----|:-----|:-----|
| 连阳之后 + 小阳柱/十字星/小阴柱 | 连阳柱体逐步缩小，代表升势衰竭 | 止盈 |
| 连阳之后 + 长下影线小柱 | 很可能属于趋势尾部 | 止盈 |
| (中阳+十字星+中阳) + 长下影小柱 | 下探后恢复，但主力很可能已逃跑 | 观望 |
| 连阳之后 + 先上影再下影 | 代表升势衰竭 | 止盈 |

#### 三、由阳转阴模式

| 特征 | 说明 | 操作 |
|:-----|:-----|:-----|
| 由连阳逐步转为阴阳相间 | 当单阳或连阳夹在两个阴柱之间，可能已见顶 | 止盈 |
| 连阳后 + 跌孕 + 升吞 + 单阴（/跌孕/跌吞） | 见顶转跌 | 清仓 |
| 连阳后 + 跌孕 + 连阳 + 单阴（/跌孕/跌吞） | 见顶转跌 | 清仓 |
| 跌吞：连阳之后 + 单巨阴柱下破WJA | 趋势完全逆转 | 清仓 |
| 久丘后四柱栅：连阳之后出现跌连 | 升势终结 | 清仓 |

### 跌连规律

| 情况 | 概率 | 操作 |
|:-----|:----:|:-----|
| 随后立刻进入连阳 | 极少 | 例外 |
| 由主升转为震荡或下跌 | **多数** | 等待出现(升连)或(启动结构)再介入 |

| 特征 | 说明 | 5周内ZC<0 |
|:-----|:-----|:---------:|

### 数据验证结论（全量7463只，有效5930只≥200周）

| 特征 | 样本 | 1周内ZC<0 | 3周内ZC<0 | 5周内ZC<0 | 预警强度 |
|:----|:----:|:---------:|:---------:|:---------:|:--------:|
| 🚨 **跌吞(阴吞前阳)** | 454,789 | **61.7%** | **70.5%** | **75.4%** | **最强** |
| ⚠️ 上影线小柱 | 1,110,786 | 47.2% | 56.2% | 62.8% | 强 |
| ⚠️ 连阳3+转阴 | 256,743 | 31.9% | 42.1% | 49.4% | 中 |
| ⚠️ 连阳3+十字星 | 58,975 | 27.2% | 36.7% | 43.6% | 中 |
| ▫️ 连阳逐步缩小 | 87,743 | 20.9% | 29.0% | 36.4% | 弱 |
| ▫️ 连阳3+巨阳>10% | 36,848 | 6.0% | 10.2% | 16.5% | 安全 |
| ✅ 连阳3+巨阳>20% | 9,264 | **2.3%** | **4.9%** | **9.5%** | **最安全** |

**核心发现：**
1. **跌吞是ZC<0的最强预测信号（75.4% 5周内）**
2. **上影线小柱被严重低估（62.8%）**
3. **巨阳柱不代表见顶**——连阳3+巨阳>20%后，5周内ZC<0率仅9.5%
4. **连阳逐步缩小转负率仅36.4%**——缩小不代表立即转跌

| 特征 | 样本 | 1周内ZC<0 | 3周内ZC<0 | 5周内ZC<0 | 预警强度 |
|:----|:----:|:---------:|:---------:|:---------:|:--------:|

| ⚠️ 升排+长上影 | 277,085 | 38.1% | 47.4% | 54.8% | 强 |
| ⚠️ 升排+柱体缩小 | 322,568 | 37.7% | 46.0% | 53.1% | 强 |

| ▫️ 升排+大阳后大阴 | 81,797 | 24.1% | 33.7% | 41.8% | 中 |

**关键发现：**
1. **升排+ZA下降是最强预警（79.2% 5周内ZC<0）**
2. **升排+震荡（58.5%）**——升排中出现阴阳交替，趋势犹豫
3. **升排+长上影（54.8%）**——冲高回落，上攻受阻
4. **升排+大阳后大阴（41.8%）**——非最强失势信号，可能只是正常回调
