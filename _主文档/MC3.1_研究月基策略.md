## 第一章：祖训——只做金银，等金升再进场

> 全量7463只验证结论（2026-07-19）

### 1.1 祖训详解

#### 1.1.1 核心规则

```
只做WXCD ∈ {金, 银}，排除屎尿唏嘘
金升（CD>0+ZC>0+ZB>0）才正式进场交易
银升（CD≤0+ZD>0+ZC>0+ZB>0）只跟踪，不算交易
```

#### 1.1.2 数据支撑：银升 vs 金升 全量对比

| 指标 | 银升假信号（50.1%概率） | 金升真信号 |
|:----|:---------------------:|:----------:|
| **胜率** | **15.8%** | **61.9%** |
| **收益均值** | **-4.3%** | **19.9%** |
| **收益中位数** | **-3.8%** | **2.2%** |
| 总次数 | 30,890次 | 99,901次 |

**银升的命运：**
- 61,680次银升跟踪中，**50.1%（30,890次）是假信号**，直接退出不转金升
- 这些假信号**84.2%亏损**，均值-4.3%，中位数-3.8%
- 只有**49.7%（30,682次）成功转金升**，转金升后收益与直接金升相同

**金升的效果：**
- 61.9%胜率，均值19.9%，中位数2.2%

#### 1.1.3 结论

**银升不能作为交易依据。** 50%概率是假信号，亏损率84.2%。必须等银升转金升（CD>0确认）才能进场。命分只统计金升阶段的收益，银升阶段完全不计入。

## 第二章：月基策略分类（周层四域→八分类）

> 月基策略分类的核心思想：**用5周续持率来区分不同持仓状态**。如果分类能够拉开5周续持率的差距（积极>不定>消极>多被>空看/空长），说明分类有效，可以作为操作依据。

### 2.1 周层四域 → 月基八分类

#### 2.1.1 周层四域定义

基于 ZC（C线）、CD（大局）、ZB（稳线）三值判定，共 4 种域状态：

```
ZC>0? ──NO──→ CD≤0且ZB≤0? ──YES──→ 空长（三空全）
│                    NO  ──→ 空看（ZC≤0，但CD或ZB有正）
│
└──YES──→ CD>0且ZB>0? ──YES──→ 多长（三多全）
                    NO  ──→ 多被（ZC>0，但CD≤0或ZB≤0）
```

| 四域 | ZC | CD | ZB | 含义 |
|:----|:--:|:--:|:--:|:------|
| **多长** | >0 | >0 | >0 | 三多全，趋势完好 |
| **多被** | >0 | ≤0或≤0 | ≤0或≤0 | C线守住，但大局或稳线失守 |
| **空看** | ≤0 | >0或>0 | >0或>0 | C线失守，但CD或ZB有正，有反弹可能 |
| **空长** | ≤0 | ≤0 | ≤0 | 三空全，最弱状态 |

### 2.2 月基八分类映射

> 月基策略的持仓状态按**周层四域**映射为8类，每类的5周内WXZB<0概率差异显著。

基于全量7,463只×422万周数据，验证结论如下：

| 类别 | 样本 | 5周续持率 | 5周转负率 | 占比 |
|:----|:---:|:---------:|:---------:|:----:|
| **多长(积极)** | 51万 | **68.8%** | 31.2% | 12.1% |
| **多长(不定)** | 17万 | **61.3%** | 38.7% | 4.2% |
| **多长(消极)** | 53万 | **55.7%** | **44.3%** | 12.5% |
| **多被(金)** | 23万 | 40.4% | 59.6% | 5.5% |
| **多被(银)** | 58万 | 19.7% | 80.3% | 13.9% |
| **NA(空看)** | 25万 | 10.7% | 89.3% | 6.1% |
| **NA(空长)** | 193万 | 11.5% | 88.5% | 45.7% |

#### 2.2.1 各项定义（与VBA一致）

| 类别 | 判定条件 |
|:----|:---------|
| **多长(积极)** | 多长 + 波型含"龙猪" + 柱排以"升"开头 |
| **多长(消极)** | 多长中，非积极且有消极信号（按优先级）：①跌吞(本周阴吞前阳) ②ZA下降 ③本周涨<0 ④ZC≤0 ⑤震正波型 |
| **多长(不定)** | 多长中，非积极且无消极信号 |
| **多被(金)** | ZC>0 + (CD≤0或ZB≤0) + WXCD含"金" |
| **多被(银)** | ZC>0 + (CD≤0或ZB≤0) + WXCD含"银" |
| **多被(唏)** | ZC>0 + (CD≤0或ZB≤0) + WXCD不含金银（屎尿唏嘘） |
| **NA(空看)** | ZC≤0 + (CD>0或ZB>0) |
| **NA(空长)** | ZC≤0 + CD≤0 + ZB≤0 |

#### 2.2.2 月基状态细分流程

从周层四域出发，多长内部再分积极/消极/不定，多被按WXCD分金/银/唏：

```
周层四域判定：
  ZC>0? → 否 → CD>0或ZB>0? → 是 → NA(空看)
  │                            否 → NA(空长)
  │
  └── ZC>0? → 是 → CD>0且ZB>0? → 是 → 多长
                    │                 ├── 龙猪+升排?     → 多长(积极)
                    │                 ├── 有消极信号?    → 多长(消极)
                    │                 └── 其他          → 多长(不定)
                    │
                    └── CD≤0或ZB≤0? → 多被
                                      ├── WXCD含"金"? → 多被(金)
                                      ├── WXCD含"银"? → 多被(银)
                                      └── 其他        → 多被(唏)
```

消极信号优先级（从强到弱）：①跌吞(阴吞前阳) ②ZA下降 ③本周涨<0 ④ZC≤0 ⑤震正波型

## 第三章：月基策略操作规则


### 3.1 操作规则

**进场条件：**
- 只做 WXCD ∈ {金, 银}，排除屎尿唏嘘
- **金升（CD>0+ZC>0+ZB>0）** 才正式进场
- 银升（CD≤0+ZD>0+ZC>0+ZB>0）只跟踪，等转金升再进场（50.1%假信号，不提前介入）
- 进场前检查 **月基命分（V1）**，命分<10分的股票天然不参与月基

**退出条件：**
- **硬退出：** WXZB从>0转≤0 → **立即卖出**（当周P(≥3%)=7.6%，几乎必亏）
- **软退出：** 消极区双重确认(ZA下降+本周涨<0) → 不等WXZB转负，提前减仓
- **最终退出：** WXZC<0 → 月基策略最终退出
- **多被(金)** → WXZB转负即卖，不等
- **多被(银)/多被(唏)/NA(空看)/NA(空长)** → 月基不参与，不持仓

```
月基持仓中，每周检查判定类别：

多长(积极) → 继续持有，下周P(≥3%)=61.5%
多长(不定) → 可持有，关注ZA趋势方向
多长(消极) → 准备减仓：ZA下降→关注, 跌吞/本周涨<0→准备, 双重确认→立即减仓
多被(金)   → WXZB从>0转≤0 → 立即卖出（当周P≥3%=7.6%）
多被(银)   → 等待带动信号转多长，否则不参与
多被(唏)   → 月基不参与，趋势极弱
NA(空看)   → 月基不参与，有反弹可能但非月基逻辑
NA(空长)   → 月基不参与，三空全
```



**多长持续性数据：**
- 多长平均段长 **7.1 周**，期间下周冲高概率 **93.9%**（稳定，15周无衰减）
- 说明：多长区一旦进入，通常可持续7周以上，期间几乎每周都能冲高，无需频繁操作
### 3.2 持仓检查：WXZA>0延续性分析

月基策略中，当前WXZA>0（站稳A线）时，下周能否延续？关键因素：

| 因素 | 最优条件 | 延续率 |
|:----|:---------|:------:|
| **波型** | **龙猪** | **87.7%** |
| **盈提示** | **盈高** | **94.1%** |
| **柱排** | **升排** | **89.1%** |
| **ZA区间** | ZA3~5 | 84.0% |
| **最佳组合** | **龙猪+升排+ZA1~5** | **92.8%** |

**龙猪波型的WXZA>0延续率最高（87.7%），远优于震正（71.3%）。**
**盈高是延续性的最强单维度指标（94.1%），有盈高时下周几乎必定继续站稳A线。**
**组合策略建议：** 月基选股优先筛选龙猪波型+升排+ZA1~5，WXZA>0延续率达92.8%。

### 3.3 软退出：消极区操作细则

| 信号 | 操作 | 说明 |
|:----|:------|:------|
| ZA下降 | 关注减仓 | 连续2周下降立即升级 |
| 跌吞 | 准备减仓 | 72.1%概率5周内转负 |
| 本周涨<0 | 准备减仓 | 下周继续恶化立即行动 |
| 震正波型 | 警惕 | 龙猪转震正时趋势不稳 |
| 双重确认(ZA下降+本周涨<0) | **立即减仓** | 不等WXZB转负 |

### 3.4 硬退出：WXZB退出信号验证

基于谕组全量7,463只的ZB周列数据，验证了月基策略的退出预警信号。

**WXZB从>0转≤0是最强退出信号**

| WXZB状态 | 下周P(≥3%) | 真均幅 | 操作 |
|:---------|:----------:|:------:|:----|
| WXZB>0（正常持有） | 63.5% | 6.45% | ✅ 继续持有 |
| WXZB≤0（已下破） | 38.5% | 3.19% | ⚠️ 明显走弱 |
| **从>0转≤0（刚转负）** | **16.7%** | **1.31%** | 🚨 **立即卖出** |
| 转负当周 | **7.6%** | **0.34%** | 🔴 几乎不涨 |
| 转负后下周 | 27.7% | 2.95% | 观望 |
| 转负后下下周 | 31.5% | 3.09% | 仍在恢复 |

**五周内10%低点（信号②）：** 仅0.6%触发，预警价值低。WXZB≤0本身已足够作为退出信号。

**月基退出规则：**
```
月基持有中，每周检查WXZB：
  WXZB从>0转≤0 → 立即退出（当周P(≥3%)=7.6%，继续持有几乎必亏）
  WXZB仍>0 → 继续持有（下周P(≥3%)=63.5%）
```

**结论：** WXZB从>0转≤0时，当周P(≥3%)=7.6%，真均幅仅0.34%。**月基持仓中WXZB转负即卖，不犹豫。**

### 3.5 最终退出：退出阶段

- WXZC<0 = 月基策略的最终退出条件
- 消极区预警通常比WXZC<0提前2~5周触发
- 预警系统的作用是**提前退出，不等WXZC<0**

### 4.2 V1 月基命分（几何均值）

> 月基策略的核心问题：一只股票，是否值得长期持有（月基）？
> 三个变量从不同维度回答这个问题，形成完整的决策体系。
> 本节从 V1 月基命分入手，详解选股维度的核心逻辑。

#### 4.2.1 变量定义

| 项目 | 内容 |
|:----|:------|
| **列名** | `月基命分`（位谕of月基命分），VBA列位+6 |
| **含义** | 金升进入→持有→WXZC<0退出，平均每次交易收益（几何均值） |
| **高分特征** | 突破有效、上升稳定、回踩不破线 → 仁慈庄家 |
| **低分特征** | 突破反复贯穿、暴力回踩破线、长阴破多线 → 恶庄 |
| **数据源** | `_产出物\月基命分结果.csv`，全量7463只回测生成 |
| **评分公式** | 几何均值 = (∏(1+每次收益))^(1/交易次数) - 1，乘以100得命分 |
| **评级** | 🏆仁慈≥20分 / ✅正常10~20分 / ⚠️震荡0~10分 |
| **适用范围** | 全量股票，命分低=天然不参与月基 |

#### 4.2.2 设计初衷：从股性到命分

**股性的本质：** 一只股票在四域操盘法下的持仓收益特征。具体做法：金升介入 → 下破WXZC退出 → 统计该段累计收益 → 跑遍该股所有时段 → 得到全生命周期累计收益。

**命分 = 几何均值 = (∏(1+每次收益))^(1/交易次数) - 1**

**设计理念：** 金升介入→持有→WXZC<0退出，每次交易独立。命分回答"平均每次能赚多少"。几何均值自然惩罚波动（亏一次会拉低整体），过滤假信号。

#### 4.2.3 设计原理

| 维度 | 含义 | 高值特征 | 低值特征 |
|:----|:-----|:--------|:--------|
| **几何均值** | 每次交易的真实平均收益 | 趋势稳定，每次都能赚 | 波动大，盈亏交替 |

几何均值自然惩罚波动：一次亏损会拉低整体，而算术均值可以被一次大赚掩盖。这过滤了"假信号"股票。

**辅助指标说明：**

| 指标 | 含义 | 公式 |
|:----|:-----|:-----|
| **年化收益** | 长期持有能赚多少？ | (1 + 总收益率)^(52/持仓周数) - 1 |
| **胜率** | 做对的概率多大？ | 盈利交易次数 / 总交易次数 |
| **盈亏比** | 赚一次能抵几次亏？ | 平均盈利 / 平均亏损 |
