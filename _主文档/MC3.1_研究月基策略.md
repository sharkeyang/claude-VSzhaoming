## 数据验证：WXAB引领WXCD（全量7463只）

> 验证日期：2026-07-18 | 数据量：7,463只 x 4,229,602行

### 1. WXAB > 0 — 月基策略的生效前提

| 状态 | 金银占比 | 屎尿占比 | 样本量 |
|:----:|:--------:|:--------:|:------:|
| WXAB>0 | **75.5%** | 24.5% | 203万行 |
| WXAB<=0 | **11.0%** | 89.0% | 219万行 |

**月基策略只应在 WXAB>0 时生效。**

### 2. WXAB各等级质量排名（反直觉）

| WXAB | 金银率 | 屎尿率 | 样本量 | 评级 |
|:----:|:------:|:------:|:-----:|:----:|
| **乙** | **89.0%** | 11.0% | 86万 | 最强 |
| **甲** | **76.3%** | 23.7% | 91.5万 | 稳健 |
| 丙 | 56.6% | 43.4% | 27.4万 | 中 |
| **己** | **28.1%** | 71.9% | 26.1万 | 弱 |
| 戊 | **2.9%** | 97.1% | 97.6万 | 垃圾 |

**核心修正：** 乙(89.0%) > 甲(76.3%) > 丙(56.6%) > 己(28.1%) > 戊(2.9%)。己不应与甲乙并列。

### 3. WXAB引领WXCD（全量200,534次跟随事件，双向）

```
WXAB正向（丙戊→甲乙己）后WXCD在1-4周内转金银:

领先1周: 40.3%   ← 操作窗口
领先2周: 25.1%   ← 累积65.4%
领先3周: 19.3%
领先4周: 15.3%
```

WXAB正向带动总事件: 200,534，WXCD跟随率 **57.2%**。

WXAB反向（甲乙己→丙戊）后WXCD转屎尿率 **81.6%**（260,107次事件），说明反向带动比正向带动更强，WXAB转差是更可靠的预警信号。

### 4. 对月基策略的修正建议

| 原规则 | 修正 | 依据 |
|:------|:-----|:-----|
| 金+甲乙己一视同仁 | 乙>甲>丙>己>戊 分段赋分 | 2排名 |
| WXAB己视为积极信号 | 己降档处理(金银率仅28.7%) | 2 |
| WXAB升乙后 | 1周内可提前布局 | 3 |

## 第一章：月基核心框架（长期均线决定）

### 1.1 核心框架

```
限定区域           WXCD ∈ {金, 银}   ← 只做金银，排除屎尿唏
                    WXZC > 0          ← DJC之上（月基前提）

WXAB优先级         甲=乙=己（最优）→ 丙=戊（次优）
                   丁 → 不参与

DXAB引领           DXAB 领先 WXAB 变化
                    甲/乙/己 → 优选
                    其他 → 可接受（需结合趋势判断）

全分类             根据周类柱型，在 WXZC>0 上做全量分类
                    每类的月基策略延续概率
```

### 1.2 分类维度

| 维度 | 分类 | 说明 |
|:----|:-----|:------|
| **WXCD** | 金 / 银 | 只做这两种 |
| **WXAB** | 甲=乙=己 / 丙=戊 / 丁 | 优先级排序 |
| **DXAB** | 甲=乙=己 / 其他 | 引领WXAB变化 |
| **周类柱型** | 升排 / 人排 / 跌排 | WXZC>0下的全部分类 |
| **ZA周** | 各区间 | 站稳均线天数 |
| **波型** | 龙猪/龙管/头正/震正等 | 庄家风格 |

## 第四章：三变量框架

> 月基策略的核心问题：一只股票，是否值得长期持有（月基）？
> 三个变量从不同维度回答这个问题，形成完整的决策体系。

### V1 月基命分（股性分）

| 项目 | 内容 |
|:----|:------|
| **列名** | `月基命分`（位谕of月基命分），VBA列位+6 |
| **含义** | 历史基因——该股沿长期均线操作是否容易赚钱 |
| **高分特征** | 突破有效、上升稳定、回踩不破线 → 仁慈庄家 |
| **低分特征** | 突破反复贯穿、暴力回踩破线、长阴破多线 → 恶庄 |
| **数据源** | `_产出物\月基策分结果.csv`，离线全量回测生成 |
| **评分公式** | 年化×胜率×盈亏比×均单次/(1+震仓) |
| **评级** | 🏆仁慈≥0.8 / ✅正常≥0.3 / ⚠️震荡≥0 / ❌凶残<0 |
| **适用范围** | 全量股票（不分四域），命分低=天然不参与月基 |

### V2 月基策分（存续分）

| 项目 | 内容 |
|:----|:------|
| **列名** | `月基5周分`（位谕of月基策分），VBA列位+7 |
| **含义** | 5周续持概率——当前周波型×柱排状态，5周后是否仍在多长 |
| **评分范围** | **仅限多长区域**，非多长=0分 |
| **与周冲策略的区别** | 周冲=下周冲高概率（P>=3%），月基5周分=5周后是否仍在多长（更宽） |
| **评分逻辑** | 波型×柱排查表（15种组合全覆盖）+ WXAB调节 + 市板调节 |
| **数据来源** | 全量7463只×152万周验证（2026-07-19） |

**评分模型：**
```
基础分 = 查表(波型×柱排)  → 15种组合全覆盖
调节分 = WXAB(A+3/乙-3/己-5) + 市板(Qe/Qd+7, Qit/Qin-3)
最终分 = 基础分 + 调节分，范围0~100，限幅
```

## 附录A：月基选股——股性判断（仁庄 vs 恶庄）

## 1.0 设计初衷：从股性到策分

### 1.0.1 股性的本质

> **股性** = 一只股票在四域操盘法下的**持仓收益特征**。
>
> 具体做法：多长介入 → 下破WGC退出 → 统计该段累计收益 → 跑遍该股所有时段 → 得到全生命周期累计收益。
>
> 这个累计收益就是该股票的**股性分**——它量化了"跟这个庄家玩，长期能赚多少钱"。

### 1.0.2 股性两极画像

| 特征 | 🏆 仁慈庄家 | 💀 恶庄 |
|:----|:-----------|:--------|
| 上升 | 缓慢平稳拉升，回撤小 | 波折多、震仓频繁，非常缓慢 |
| 退出 | 缓慢下破均线，给充足退出时间 | 一个大阴柱直接砸破底线 |
| 收益 | 累计收益高（正分） | 累计收益低甚至为负（负分） |
| 结论 | **优先选择**：每日操作首选标的 | **直接屏蔽**：不跟恶庄玩 |

### 1.0.3 核心设计问题与解答

**Q1：不同上市时长的股票如何可比？**

> 用 **年化收益率** ≈ 累计收益 ÷ 存续时间。上市早的累计收益天然高，除以时间后归一化，使新股老股在同一尺度上比较。

**Q2：上市后一直下跌的股票会怎样？**

> **不会受害。** 一直下跌的股票从未进入 _多长 区，因此没有持仓段，得分为**空（无分数）**而非低分。它最多是"不配参与"，而不是"参与了亏钱"——正是用户说的"不存在于主升期收割，最多没有分数，不是分数很低"。

**Q3：恶庄股会得到什么分数？**

> 频繁拉升→下破WGC→再拉升→再下破的恶庄股，多长段极短、每次收益低甚至为负，累计收益可能为**负数**。这类股票正是月基命分要**屏蔽**的对象。

**Q4：月基命分和周冲择时的关系是什么？**

> 月基命分回答 **"这股票值不值得玩"**（选股），周冲策分回答 **"这周能不能买"**（择时）。
> 股性好的股票优先作为每日操作的备选标的，但具体买点仍需周冲/日冲策分决定。

### 1.0.4 从股性到月基命分的推导

股性分（原始） = Σ(每段多长收益) / 存续时间

但仅有累计收益不够，还需考虑**持仓体验**：

| 问题 | 惩罚因子 | 公式体现 |
|:----|:--------|:---------|
| 震仓多容易拿不住 | 震仓频率 | 分母 (1+震仓频率) |
| 单次收益薄没意义 | 均单次收益 | 乘法因子 |
| 胜率低心态不稳 | 胜率 | 乘法因子 |
| 盈亏比低不划算 | 盈亏比 | 乘法因子 |

**最终公式：**

> **月基命分 = 年化收益 × 胜率 × 盈亏比 × 均单次收益 ÷ (1 + 震仓频率)**

这就是在"原始股性分"基础上，叠加了持仓体验惩罚后的综合分数。分数越高 ≈ 庄家越仁慈 ≈ 越适合长期持有。

### 1.0.5 应用规则

| 分数 | 评级 | 操作 |
|:----:|:----|:-----|
| ≥0.8 | 🏆 仁慈级 | 优先建仓，做月基底仓首选 |
| ≥0.3 | ✅ 正常级 | 可参与，关注震仓频率 |
| ≥0 | ⚠️ 震荡级 | 谨慎持有，恶庄多 |
| <0 | ❌ 凶残级 | **直接屏蔽，不跟庄玩** |
| 无分数 | — | 从未进入多长区，暂不参与 |

## 1.1 月基评分原则

### 1.1.1 设计原理

月基命分的核心目标是评估一只股票在月基策略（多长介入→WXZC<0退出）下的持仓体验。

**为什么用这个公式？**

| 维度 | 含义 | 高值特征 | 低值特征 |
|:----|:-----|:--------|:--------|
| **年化收益** | 长期持有年化收益率 | 趋势强劲，持续上涨 | 趋势弱，震荡不前 |
| **胜率** | 盈利交易占比 | 多长段内稳定上涨 | 多长段内频繁回调 |
| **盈亏比** | 盈利/亏损比值 | 上涨幅度远大于下跌 | 下跌幅度接近上涨 |
| **均单次收益** | 每笔收益率 | 单次趋势利润丰厚 | 单次利润薄 |
| **震仓频率** | 柱排反转/持仓周数 | 庄家仁慈，趋势稳定 | 恶庄频繁洗盘 |

**核心逻辑：** 高分=多长段内趋势稳定+震仓少+退出平缓。这对应的是"仁慈庄家"特征：
- 上涨时回撤小，持股体验好
- 退出时缓慢下破均线，给充足退出时间
- 柱排方向稳定，不频繁反转
- 不挂山顶，趋势末端不出现极端冲高后暴跌

## 1.2 设计哲学（月基命分）

月基命分的核心目标是评估一只股票在月基策略（多长介入->WXZC<0退出）下的持仓体验。

**为什么用这个公式？**

月基命分 = 年化收益 x 胜率 x 盈亏比 x 均单次收益 / (1 + 震仓频率)

| 维度 | 含义 | 为什么重要 |
|:----|:-----|:----------|
| **年化收益** | 多长段内年化收益率 | 衡量趋势盈利能力，收益越高分越高 |
| **胜率** | 盈利交易占比 | 胜率越高，策略越稳定，持股体验越好 |
| **盈亏比** | 平均盈利/平均亏损 | 比值越高，说明上涨幅度远大于下跌幅度 |
| **均单次收益** | 每笔交易平均收益率 | 单次期望收益，越高越好 |
| **震仓频率** | 柱排反转次数/持仓周数 | 越低越好，说明庄家仁慈、趋势稳定 |

**核心逻辑：** 高分=多长段内趋势稳定+震仓少+退出平缓。对应"仁慈庄家"特征：
- 上涨时回撤小，持股体验好
- 退出时缓慢下破均线，给充足退出时间
- 柱排方向稳定，不频繁反转
- 不挂山顶，趋势末端不出现极端冲高后暴跌

## 1.3 条件筛选意义解释

> 月基命分的每个评估维度都有明确的定义和实际意义。

**1. 年化收益——长期持有能赚多少？**

**公式：** 多长段内年化收益率 = (1 + 总收益率)^(52/持仓周数) - 1

**通俗解释：** 年化收益越高，说明这只股票在多头趋势中的上涨动力越强。好比一个人工作能力强，年收入就高。

**2. 胜率——做对的概率多大？**

**公式：** 胜率 = 盈利交易次数 / 总交易次数

**通俗解释：** 胜率越高，说明每次进入多长区后上涨的概率越大。好比一个射手的命中率，越高越可靠。

**3. 盈亏比——赚一次能抵几次亏？**

**公式：** 盈亏比 = 平均盈利 / 平均亏损

**通俗解释：** 盈亏比>1说明赚的时候比亏的时候多。好比打牌，赢一把的钱比输一把的钱多，长期就能赢。

**4. 均单次收益——每笔交易平均赚多少？**

**公式：** 均单次收益 = 累计收益 / 交易次数

**通俗解释：** 每笔交易的平均收益，越高越好。好比每次做生意平均赚的钱。

**5. 震仓频率——庄家洗盘凶不凶？**

**公式：** 震仓频率 = 柱排反转次数 / 持仓周数

**通俗解释：** 震仓频率越低，说明庄家越仁慈，持股体验越好。好比坐车，路越平越舒服。震仓频率高=恶庄频繁洗盘，容易被震下车。

**综合评分逻辑：**

月基命分 = 年化收益 x 胜率 x 盈亏比 x 均单次收益 / (1 + 震仓频率)

分母(1+震仓频率)的作用：震仓频率越高，分母越大，分数越低。这确保了震仓多的股票被降分。

- 金系趋势 + 龙猪趋势庄家 + 升排方向稳定
- 5周续持率71.8%，真均幅11.17%
- 详见：**`MC3.1_研究月基策略最后一柱.md`** §积极条件

**② 多长(消极) —— 消极信号（最后一柱）——筛选链路（从强到弱）：**

| 信号 | 5周转负率 | 含义 | 操作 |
|:----|:---------:|:-----|:-----|
| 🚨 跌吞(阴吞前阳) | 72.1% | 阴线吞噬前阳，主力已离场 | 出现即准备减仓 |
| 🚨 ZA较前周下降 | 69.3% | 站稳A线能力减弱 | 连续2周下降立即行动 |
| 🚨 本周HR<0 | 63.1% | 周线下跌 | 双重确认时减仓 |
| 🚨 ZC≤0 | 60.8% | C线失守 | 比ZB≤0更严重 |
| 🚨 震正波型 | 54.5% | 趋势动荡不稳 | 龙猪转震正时警惕 |

**③ 多长(不定)**
- 无明确消极信号，也无积极条件
- 5周转负率40.6%，接近中性
- 建议：叠加ZA区间/盈提示进一步筛选

**④ 多被(金) —— 金系ZB≤0**
- WXCD=金但ZB≤0，退出信号触发
- 5周续持率仅6.2%，几乎不可能回到WXZB>0
- 当周P(≥3%)=7.6%，**立即退出**

**⑤ 多被(银) —— 银系/其他CD≤0**
- ZC>0但CD不满足，需WXAB或WXZB或日类DXAB带动才能解套
- 等待带动信号转多长

**⑥ NA(空看) / NA(空长)**
- 不满足ZC门槛，月基不参与
- 空看=有反弹可能，空长=三空全

### 1.8.3 操作规则

```
月基持仓中，每周检查判定类别：

多长(积极) → 继续持有，下周P(≥3%)=61.5%
多长(不定) → 可持有，关注ZA趋势方向
多长(消极) → 准备减仓：ZA下降→关注, 跌吞/HR<0→准备, 双重确认→立即减仓
多被(金)   → WXZB从>0转≤0 → 立即卖出（当周P≥3%=7.6%）
多被(银)   → 等待带动信号转多长，否则不参与
NA(空看)   → 月基不参与，有反弹可能但非月基逻辑
NA(空长)   → 月基不参与，三空全
```

> 详见：**`MC3.1_研究月基策略最后一柱.md`** — 各类柱排形态的详细描述与可视化特征。
