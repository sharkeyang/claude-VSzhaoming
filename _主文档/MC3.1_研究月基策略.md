## 第一章：祖训——只做金银，等金升再进场

> 全量7463只验证结论（2026-07-19）

### 1.1 核心规则

```
只做WXCD ∈ {金, 银}，排除屎尿唏嘘
金升（CD>0+ZC>0+ZB>0）才正式进场交易
银升（CD≤0+ZD>0+ZC>0+ZB>0）只跟踪，不算交易
```

### 1.2 数据支撑：银升 vs 金升 全量对比

| 指标 | 银升假信号（50.1%概率） | 金升真信号 |
|:----|:---------------------:|:----------:|
| **胜率** | **15.8%** | **61.9%** |
| **收益均值** | **-4.3%** | **19.9%** |
| **收益中位数** | **-3.8%** | **2.2%** |
| 总次数 | 30,890次 | 99,901次 |

**银升的命运：**
- 61,680次银升跟踪中，**50.1%（30,890次）是假信号**，直接退出不转金升
- 这些假信号**84.2%亏损**，均值-4.3%，中位数-3.8%
- 只有**49.7%（30,682次）成功转金升**，转金升后收益与直接金升相同

**金升的效果：**
- 61.9%胜率，均值19.9%，中位数2.2%

### 1.3 结论

**银升不能作为交易依据。** 50%概率是假信号，亏损率84.2%。必须等银升转金升（CD>0确认）才能进场。命分只统计金升阶段的收益，银升阶段完全不计入。

### 2.1 V1 月基命分（几何均值）

| 项目 | 内容 |
|:----|:------|
| **列名** | `月基命分`（位谕of月基命分），VBA列位+6 |
| **含义** | 金升进入→持有→WXZC<0退出，平均每次交易收益（几何均值） |
| **高分特征** | 突破有效、上升稳定、回踩不破线 → 仁慈庄家 |
| **低分特征** | 突破反复贯穿、暴力回踩破线、长阴破多线 → 恶庄 |
| **数据源** | `_产出物\月基命分结果.csv`，全量7463只回测生成 |
| **评分公式** | 几何均值 = (∏(1+每次收益))^(1/交易次数) - 1，乘以100得命分 |
| **评级** | 🏆仁慈≥20分 / ✅正常10~20分 / ⚠️震荡0~10分 |
| **适用范围** | 全量股票，命分低=天然不参与月基 |

**设计理念：** 金升介入→持有→WXZC<0退出，每次交易独立。命分回答"平均每次能赚多少"。几何均值自然惩罚波动（亏一次会拉低整体），过滤假信号。

### 2.2 V2 月基策分（5周维持）

| 项目 | 内容 |
|:----|:------|
| **列名** | `月基策分(5周维持)`（位谕of月基策分），VBA列位+7 |
| **含义** | 5周续持概率——当前周波型×柱排状态，5周后是否仍在多长 |
| **评分范围** | **仅限多长区域**，非多长=0分 |
| **与周冲策略的区别** | 周冲=下周冲高概率（P>=3%），月基策分=5周后是否仍在多长（更宽） |
| **评分逻辑** | 波型×柱排查表（15种组合全覆盖）+ WXAB调节 + 盈提示调节 + 市板调节 |
| **数据来源** | 全量7463只×121万周验证（金升，2026-07-19） |

**评分模型：**
```
基础分 = 查表(波型×柱排)  → 15种组合全覆盖
调节分 = WXAB(甲+3/乙-3/己-5) 
       + 盈提示(高+宽+8/高+4/宽不加)
       + 市板(Qe/Qd+7, Qit/Qin-3)
最终分 = 基础分 + 调节分，范围0~100，限幅
```

### 2.3 V3 月基带向（双向带动+）

| 项目 | 内容 |
|:----|:------|
| **列名** | `月基带向`（位谕of月基带向），VBA列位+8 |
| **核心** | WXAB→WXCD双向带动（四象限） |
| **11双好** | WXAB正+WXCD好 → 安全持有 |
| **10反险** | WXAB负+WXCD好 → 反向风险81.6%（AB护破但大局尚好） |
| **01正潜** | WXAB正+WXCD差 → 正向潜力61.1%（AB护完好但趋势差） |
| **00双差** | WXAB负+WXCD差 → 观望不参与 |
| **待扩展** | WJB下破对WXCDXCD的带动、柱排启示 |

#### 2.3.1 WXAB→WXCD四象限

WXAB（护型）和WXCD（大局）是两条独立维度的核心指标，它们的组合能揭示"带动效应"：

| 状态 | WXAB | WXCD | 含义 | 续持率 |
|:----|:----:|:----:|:------|:------:|
| 11双好 | 正(甲乙己) | 好(金银) | 安全持有 | 基准 |
| 10反险 | 负(丙丁戊) | 好(金银) | 反向风险81.6% | ⚠️ |
| 01正潜 | 正(甲乙己) | 差(屎尿唏嘘) | 正向潜力61.1% | 关注 |
| 00双差 | 负(丙丁戊) | 差(屎尿唏嘘) | 观望不参与 | ❌ |

#### 2.3.2 数据验证：WXAB引领WXCD（全量7463只）

> 验证日期：2026-07-18 | 数据量：7,463只 x 4,229,602行

**月基策略只应在 WXAB>0 时生效。**

**② WXAB各等级质量排名**

**③ WXAB引领WXCD（全量200,534次跟随事件，双向）**

- 领先4周: 15.3%

WXAB反向（甲乙己→丙戊）后WXCD转屎尿率 **81.6%**（260,107次事件），说明反向带动比正向带动更强，WXAB转差是更可靠的预警信号。

**④ 对月基策略的修正建议**

| 原规则 | 修正 | 依据 |
|:------|:-----|:-----|

| WXAB升乙后 | 1周内可提前布局 | 带动数据 |

## 第四章：月基命分详解（选股）

### 4.1 设计初衷：从股性到命分

**股性的本质：** 一只股票在四域操盘法下的持仓收益特征。具体做法：金升介入 → 下破WXZC退出 → 统计该段累计收益 → 跑遍该股所有时段 → 得到全生命周期累计收益。

**命分 = 几何均值 = (∏(1+每次收益))^(1/交易次数) - 1**

### 4.2 设计原理

| 维度 | 含义 | 高值特征 | 低值特征 |
|:----|:-----|:--------|:--------|
| **几何均值** | 每次交易的真实平均收益 | 趋势稳定，每次都能赚 | 波动大，盈亏交替 |

几何均值自然惩罚波动：一次亏损会拉低整体，而算术均值可以被一次大赚掩盖。这过滤了"假信号"股票。

### 4.3 评分原则

| 命分 | 评级 | 说明 |
|:---:|:----|:------|
| ≥20 | 🏆 仁慈级 | 金升后稳定盈利，优先建仓 |
| 10~20 | ✅ 正常级 | 可参与，金升后能赚钱 |
| 0~10 | ⚠️ 震荡级 | 金升后收益有限，谨慎 |
| 无金升记录 | — | 从未进入金升多长，不参与 |

### 4.4 条件筛选意义解释

**1. 年化收益——长期持有能赚多少？**
多长段内年化收益率 = (1 + 总收益率)^(52/持仓周数) - 1

**2. 胜率——做对的概率多大？**
胜率 = 盈利交易次数 / 总交易次数

**3. 盈亏比——赚一次能抵几次亏？**
盈亏比 = 平均盈利 / 平均亏损

**4. 均单次收益——每笔交易平均赚多少？**
均单次收益 = 累计收益 / 交易次数

**5. 震仓频率——庄家洗盘凶不凶？**
震仓频率 = 柱排反转次数 / 持仓周数

### 4.5 与周冲策分卡的关系

| 维度 | 策分卡 | 月基命分 |
|:-----|:------|:---------|
| 回答 | **这周**能买吗？ | **这股票**值得玩吗？ |
| 频率 | 每周计算 | 一次性（定期更新） |
| 依据 | 本周周级条件 | 全历史模拟交易 |
| 用途 | 择时 | 选股 |

## 第五章：月基持仓预警与退出

### 5.1 WXZB退出信号验证

基于谕组全量7,463只的ZB周列数据，验证了月基策略的退出预警信号。

**WXZB从>0转≤0是最强退出信号**

| WXZB状态 | 下周P(≥3%) | 真均幅 | 操作 |
|:---------|:----------:|:------:|:----|
| WXZB>0（正常持有） | 63.5% | 6.45% | ✅ 继续持有 |
| WXZB≤0（已下破） | 38.5% | 3.19% | ⚠️ 明显走弱 |
| **从>0转≤0（刚转负）** | **16.7%** | **1.31%** | 🚨 **立即卖出** |
| 转负当周 | **7.6%** | **0.34%** | 🔴 几乎不涨 |
| 转负后下周 | 27.7% | 2.95% | 观望 |
| 转负后下下周 | 31.5% | 3.09% | 仍在恢复 |

**五周内10%低点（信号②）：** 仅0.6%触发，预警价值低。WXZB≤0本身已足够作为退出信号。

**月基退出规则：**
```
月基持有中，每周检查WXZB：
  WXZB从>0转≤0 → 立即退出（当周P(≥3%)=7.6%，继续持有几乎必亏）
  WXZB仍>0 → 继续持有（下周P(≥3%)=63.5%）
```

**结论：** WXZB从>0转≤0时，当周P(≥3%)=7.6%，真均幅仅0.34%。**月基持仓中WXZB转负即卖，不犹豫。**

### 5.2 WXZA>0延续性分析

月基策略中，当前WXZA>0（站稳A线）时，下周能否延续？关键因素：

| 因素 | 最优条件 | 延续率 |
|:----|:---------|:------:|
| **波型** | **龙猪** | **87.7%** |
| **盈提示** | **盈高** | **94.1%** |
| **柱排** | **升排** | **89.1%** |
| **ZA区间** | ZA3~5 | 84.0% |
| **最佳组合** | **龙猪+升排+ZA1~5** | **92.8%** |

**龙猪波型的WXZA>0延续率最高（87.7%），远优于震正（71.3%）。**
**盈高是延续性的最强单维度指标（94.1%），有盈高时下周几乎必定继续站稳A线。**
**组合策略建议：** 月基选股优先筛选龙猪波型+升排+ZA1~5，WXZA>0延续率达92.8%。
